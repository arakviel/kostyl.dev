# Скіл: Створення навчальних відео через fframes (fframes Video Creator)

Цей скіл регламентує процес створення програмних навчальних відео за допомогою Rust-фреймворку **`fframes`** (Skia GPU + Metal/Vulkan + FFmpeg) для ілюстрації інженерних, алгоритмічних та математичних концепцій на сайті `kostyl.dev`.

---

## 1. Фундаментальне правило: Обов'язкове інтерактивне узгодження

> [!IMPORTANT]
> **Категорично заборонено починати кодити чи генерувати відео наосліп!**
> Будь-яке відео є дорогим за часом та ресурсами візуальним артефактом. Агент **зобов'язаний** спочатку ініціювати діалог через інструмент `ask_question` (інтерактивні запитання) та отримати чіткі відповіді від людини.

### Обов'язковий чек-лист запитань до користувача:
1. **Сценарій та фокус візуалізації:**
   * Що саме є головним героєм сцени (анатомія об'єкта, покроковий цикл алгоритму, геометрична інтерпретація на площині, порівняння двох підходів side-by-side)?
   * Які конкретні числові дані чи приклади беремо за основу (наприклад, $x = [1.5, 0.8]$, $w = [0.8, 0.5]$)?
2. **Формат та хронометраж:**
   * Співвідношення сторін: зазвичай `16:9` (1920×1080) для повнорозмірних діаграм або `1:1` (1080×1080) для компактних карток у тексті.
   * Тривалість: коротка динамічна петля (8–12 секунд) для безперервного сприйняття чи покроковий ролик з довшими паузами (20–40 секунд).
3. **Візуальний стиль та тема:**
   * Dark Mode (основна палітра `kostyl.dev`: темний графіт `#070b14` / `#0f172a`, акценти cyan `#38bdf8`, indigo `#818cf8`, emerald `#10b981`, amber `#f59e0b`).
   * Light Mode (якщо матеріал вимагає світлого фону, як у лекціях коледжу).
4. **Звуковий супровід:**
   * Беззвучний режим (`muted loop`).
   * Мінімалістичні синтетичні процедурні ефекти (м'який pulse-whoosh під час передачі сигналів, тактильний click/pop у момент спрацювання умови/активації).
5. **Точне місце в статті:**
   * До якого розділу та після якого абзацу вставляється відеоплеєр.

## 2. Стандарти розміщення файлів у репозиторії

### 2.1. Вихідний код програми-генератора (Rust Crate)
Усі вихідні коди проєктів `fframes` зберігаються в каталозі `tools/videos/`:
```text
tools/videos/<topic-slug>/
├── Cargo.toml
├── .gitignore
├── media/
│   ├── Arial.ttf           # Шрифти з підтримкою кирилиці
│   ├── Arial-Bold.ttf
│   ├── pulse.wav           # Звукові ефекти (за потреби)
│   └── activate.wav
└── src/
    ├── lib.rs              # Логіка анімації, часові шкали (timeline!), SVG-дерево
    └── main.rs             # CLI інтерфейс fframes (render, frame, preview)
```

> [!TIP]
> У `.gitignore` проєкту `tools/videos/<topic-slug>/.gitignore` обов'язково мають бути виключені `target/`, тимчасові кадри `frames/` та локальні `out.mp4`.

---

### 2.2. Згенеровані медіа-артефакти (Exported Assets)
Шлях у `public/videos/` **суворо дзеркалить структуру директорії `content/`** (з видаленням числових префіксів сортування `16.`, `12.`, `01.`):

* **Файл статті:**
  `content/16.ai-python/12.neural-networks-basics/01.perceptron-to-mlp.md`
* **Каталог відео:**
  `public/videos/ai-python/neural-networks-basics/perceptron-to-mlp/`

Для кожного відео генерується **повний комплект із 4 файлів**:
1. `<video_name>.mp4` — основний файл H.264 / AAC (висока якість, 1920×1080).
2. `<video_name>.webm` — оптимізована версія VP9 / Opus для сучасних веб-браузерів.
3. `<video_name>.gif` — анімований fallback-файл (15 fps, scale 960px, високоякісна палітра Lanczos).
4. `<video_name>_poster.png` — статичний прев'ю-кадр ключової кульмінаційної фази анімації.

## 3. Технічні стандарти розробки на fframes

### 3.1. Шрифти та підтримка кирилиці
Стандартний шрифт шаблону `fframes` (`DM Sans`) **не містить кириличних символів**.
* Для українського тексту обов'язково додавайте в `media/` перевірений шрифт з повною кирилицею (`Arial.ttf`, `Arial-Bold.ttf` або `SFPro.ttf`).
* Уникайте нестандартних юнікод-індексів (наприклад, `₁`, `₂`, `₀`, `⇒`), які можуть бути відсутні в шрифті. Замість них використовуйте стандартні математичні позначення: `x1`, `x2`, `w1`, `w2`, `w0`, `wi·xi`, `->` або окремі SVG-елементи `<tspan>`.

### 3.2. Безшовний цикл (Seamless Loop)
Якщо відео зациклене (`autoplay loop muted`), кінець ролика повинен органічно повертатися до початку:
* Останні **0.6–0.8 секунди** таймлайну мають містити плавне загасання (`loop_reset` або `fade_out`), щоб активні спалахи, промені та розраховані значення м'яко поверталися до початкового стану без різкого ривка картинки при переході на 0-ву секунду.

### 3.3. Аудіосупровід
* Синтетичні звуки генеруються локально (наприклад, простим Python-скриптом на основі `numpy` та `wave`) і зберігаються як 16-bit WAV 44.1 kHz.
* Підключення в `src/lib.rs` здійснюється через `AudioMap`:
```rust
fn audio(&self) -> AudioMap<'_> {
    AudioMap::from([
        AudioTrack::new("pulse.wav", AudioTimestamp::Second(2.3)..AudioTimestamp::Eof).gain_db(-2.0),
        AudioTrack::new("activate.wav", AudioTimestamp::Second(6.9)..AudioTimestamp::Eof).gain_db(0.0),
    ])
}
```

## 4. Конвеєр команд рендерингу та конвертації

Після написання сцени в `src/lib.rs`:

```bash
# 1. Швидка перевірка контрольних кадрів (наприклад, 1s, 5s, 7.5s)
cargo run -- frame 1s,5s,7.5s

# 2. Рендеринг фінального MP4
cargo run -- render

# 3. Експорт у public/videos/ та генерація WebM, Poster і GIF:
OUT_DIR="public/videos/<category>/<subcategory>/<article>"
mkdir -p "$OUT_DIR"

# MP4
cp tools/videos/<topic>/out.mp4 "$OUT_DIR/<name>.mp4"

# WebM
ffmpeg -y -i "$OUT_DIR/<name>.mp4" -c:v libvpx-vp9 -b:v 1M -c:a libopus "$OUT_DIR/<name>.webm"

# Poster PNG (на кульмінаційній секунді, наприклад 7.5с)
ffmpeg -y -ss 00:00:07.500 -i "$OUT_DIR/<name>.mp4" -vframes 1 "$OUT_DIR/<name>_poster.png"

# GIF (Lanczos + palettegen)
ffmpeg -y -i "$OUT_DIR/<name>.mp4" -vf "fps=15,scale=960:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" "$OUT_DIR/<name>.gif"
```

## 5. Вбудовування в статтю Docus (MDC)

У цільовому markdown-файлі відеоплеєр розміщується з усіма джерелами та постером:

```html
<video controls autoplay loop muted playsinline poster="/videos/<category>/<subcategory>/<article>/<name>_poster.png" class="diagram-img rounded-xl shadow-lg w-full my-6">
  <source src="/videos/<category>/<subcategory>/<article>/<name>.mp4" type="video/mp4">
  <source src="/videos/<category>/<subcategory>/<article>/<name>.webm" type="video/webm">
  <img src="/videos/<category>/<subcategory>/<article>/<name>.gif" alt="Опис анімації для доступності" class="diagram-img">
</video>
```
