- Обходити вкладені об'єкти та масиви.
- Створювати відповідь через `wvalue`: об'єкти, масиви, `null`.
- Передбачати поведінку при відсутньому ключі й невірному типі та перехоплювати винятки.

- **JSON:** текстовий формат обміну даними з об'єктами, масивами, рядками, числами, булевими значеннями й `null`.
- **Серіалізація (*serialization*):** перетворення об'єкта C++ на текст JSON.
- **Десеріалізація (*deserialization*):** розбір тексту JSON у значення, з якими працює код.
- **`crow::json::rvalue`:** розібране JSON-значення тільки для читання.
- **`crow::json::wvalue`:** JSON-значення, яке будують у коді для відповіді.

::

## Формат JSON

JSON (*JavaScript Object Notation*) — текстовий формат, який став стандартом для API завдяки простоті: його читає людина й розбирають усі мови програмування.

```json
{
  "name": "Іван Петренко",
  "age": 25,
  "active": true,
  "score": 4.75,
  "note": null,
  "address": { "city": "Київ", "zip": "01001" },
  "skills": ["C++", "CMake"]
}
```

![Шість типів JSON і методи читання в Crow](/images/cpp/crow-web/json-crow/01-json-types.png){.diagram-img}

JSON має шість типів: рядок, число, булеве значення, `null`, масив і об'єкт. Об'єкт — набір пар «ключ: значення», де ключ — завжди рядок у подвійних лапках. Масив — упорядкований список. Вкладеність необмежена, тому з цих елементів будують дерева будь-якої складності.

Формат не допускає коментарів, одинарних лапок і коми після останнього елемента. Ці дрібниці найчастіше ламають JSON, написаний руками.

::note
JSON не гарантує порядок ключів в об'єкті. У відповідях цього курсу порядок ключів різний у різних запитах і навіть між елементами одного масиву. Клієнт має звертатися до полів за ім'ям.
::

## Два типи Crow

Crow має вбудовану JSON-бібліотеку з двома окремими класами.

![Шлях JSON: текст, rvalue, логіка, wvalue, текст](/images/cpp/crow-web/json-crow/02-rvalue-wvalue.png){.diagram-img}

- `crow::json::rvalue` — результат розбору. Призначений лише для читання.
- `crow::json::wvalue` — значення, яке будує програма. Його конструктор `crow::response` перетворює на текст і сам ставить `Content-Type: application/json`.

Розділення відображає різні ролі: `rvalue` отримують від розбору й тільки читають, а `wvalue` програма заповнює сама.

## Читання: rvalue

Функція `crow::json::load` приймає рядок і повертає `rvalue`. Для некоректного JSON результат «порожній», а його перевірка в умові дає `false`.

```cpp
CROW_ROUTE(app, "/inspect").methods(crow::HTTPMethod::POST)([](const crow::request& req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "Некоректний JSON");

    std::ostringstream out;
    out << "тип кореня: " << type_name(body.t()) << "\n";
    if (body.t() == crow::json::type::Object) {
        for (const auto& key : body.keys())
            out << "  " << key << ": " << type_name(body[key].t()) << "\n";
    }
    return crow::response(200, out.str());
});
```

Метод `t()` повертає тип значення, `keys()` — імена ключів об'єкта. Для кореня потрібна перевірка `t()`: клієнт може надіслати масив, число чи рядок замість об'єкта.

### Витягування значень

Значення дістають методами за типом: `.s()` для рядка, `.i()` для цілого, `.d()` для дробового, `.b()` для булевого. Вкладені поля читаються ланцюжком квадратних дужок, масиви обходяться циклом `for`.

```cpp
std::string name = body["customer"]["name"].s();
double total = 0;
int count = 0;
for (const auto& item : body["items"]) {
    total += item["price"].d() * static_cast<double>(item["qty"].i());
    count += static_cast<int>(item["qty"].i());
}
```

Метод `.size()` повертає довжину масиву, а `.has("ключ")` перевіряє наявність ключа в об'єкті.

::terminal-preview{title="POST /order"}

<div class="line"><span class="opacity-40">$</span> <strong class="font-bold">curl -s -X POST -d '{"customer":{"name":"Марія"},"items":[{"price":10.5,"qty":2},{"price":3,"qty":4}]}' localhost:8087/order</strong></div>
<div class="line">{"units":6,"total":33,"positions":2,"customer":"Марія"}</div>
::

Перевірка: `10.5 × 2 + 3 × 4 = 33`, одиниць `2 + 4 = 6`, позицій 2. Масив може бути порожнім, і тоді цикл не виконується: для `"items": []` відповідь містить нулі.

## Помилки доступу

Читання даних, які надіслав клієнт, найчастіше й ламає сервери: поле може бути відсутнє чи мати інший тип. У Crow такі помилки проявляються винятками.

::::accordion

:::accordion-item{label="⚠️ Відсутній ключ" icon="i-lucide-alert-triangle"}

Звернення `body["customer"]["name"]` до неіснуючого ключа кидає `std::runtime_error` із текстом `cannot find key: name`. Якщо обробник його не перехоплює, Crow сам завершує запит відповіддю **500** і пише в журнал:

::terminal-preview{title="Журнал сервера"}
<div class="line">[ERROR   ] An uncaught exception occurred: cannot find key: name</div>
::

Клієнт отримав помилку сервера, хоча винен був він сам: послав неповні дані.

:::

:::accordion-item{label="⚠️ Невірний тип" icon="i-lucide-alert-triangle"}

Метод `.d()` на рядку кидає виняток `value is not number`. Результат той самий: 500.

:::

::::

Існує два способи цього уникнути. Перший: перевіряти `has()` і `t()` перед читанням, як у лекції 06. Другий: загорнути читання в `try`/`catch` і перетворити виняток на 400.

```cpp
CROW_ROUTE(app, "/order-safe").methods(crow::HTTPMethod::POST)([](const crow::request& req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "Некоректний JSON");
    try {
        double total = 0;
        for (const auto& item : body["items"])
            total += item["price"].d() * static_cast<double>(item["qty"].i());
        crow::json::wvalue res;
        res["total"] = total;
        return crow::response(200, res);
    } catch (const std::runtime_error& e) {
        crow::json::wvalue err;
        err["error"] = std::string("Невірна структура JSON: ") + e.what();
        return crow::response(400, err);
    }
});
```

::terminal-preview{title="POST /order-safe"}

<div class="line"><span class="opacity-40">$</span> <strong class="font-bold">curl -s -w ' [%{http_code}]\n' -X POST -d '{"items":[{"qty":1}]}' localhost:8087/order-safe</strong></div>
<div class="line">{"error":"Невірна структура JSON: cannot find key: price"} [400]</div>
<div class="line"><span class="opacity-40">$</span> <strong class="font-bold">curl -s -w ' [%{http_code}]\n' -X POST -d '{"items":[{"price":2.5,"qty":2}]}' localhost:8087/order-safe</strong></div>
<div class="line">{"total":5} [200]</div>
::

Підхід із винятками коротший, але менш точний: повідомлення вказує, що саме не знайдено, проте не перелічує всі помилки зразу. Для API з поясненнями по кожному полю потрібні явні перевірки з лекції 06.

## Створення: wvalue

Об'єкт `wvalue` будується присвоєнням: оператор `[]` створює ключ, а вкладені ключі виникають самі.

```cpp
crow::json::wvalue j;
j["name"] = "Іван Петренко";
j["age"] = 25;
j["active"] = true;
j["score"] = 4.75;
j["address"]["city"] = "Київ";
j["address"]["zip"] = "01001";
j["note"] = nullptr;
```

Присвоєння `nullptr` дає JSON `null`. Присвоєння рядка, числа чи `bool` створює значення відповідного типу.

Масиви будуються через `crow::json::wvalue::list`. Елементи — рядки, числа чи інші `wvalue`.

```cpp
crow::json::wvalue::list skills;
skills.push_back("C++");
skills.push_back("CMake");
j["skills"] = std::move(skills);

crow::json::wvalue::list projects;
for (int i = 1; i <= 2; ++i) {
    crow::json::wvalue p;
    p["id"] = i;
    p["title"] = "Проєкт " + std::to_string(i);
    projects.push_back(std::move(p));
}
j["projects"] = std::move(projects);
return j;
```

Цикл у прикладі збирає масив об'єктів: це типовий патерн для відповіді-списку, де кожен елемент — запис із бази. Перенесення (`std::move`) уникає зайвого копіювання.

::terminal-preview{title="GET /profile"}

<div class="line"><span class="opacity-40">$</span> <strong class="font-bold">curl -s localhost:8087/profile</strong></div>
<div class="line">{"skills":["C++","CMake"],"note":null,"name":"Іван Петренко","address":{"zip":"01001","city":"Київ"},"score":4.75,"projects":[{"id":1,"title":"Проєкт 1"},{"title":"Проєкт 2","id":2}],"active":true,"age":25}</div>
::

Відповідь компактна: без пробілів і переносів, щоб передавати менше байтів. Для читання людиною її форматують зовнішніми засобами, наприклад `curl ... | python3 -m json.tool` чи `jq`.

## Безпечне читання без винятків

Для перевірки значення за один крок зручно скласти з `has()` і `t()` невеликі допоміжні функції.

```cpp
static std::optional<std::string> get_string(const crow::json::rvalue& obj, const char* key) {
    if (!obj.has(key) || obj[key].t() != crow::json::type::String) return std::nullopt;
    return std::string(obj[key].s());
}
```

Функція повертає `std::optional`: порожнє значення означає «ключа немає або тип не той». Обробник тоді вирішує, чи це помилка (400), чи треба підставити значення за замовчуванням.

Для демо `/probe` усі стани перевіряються без винятків:

::terminal-preview{title="POST /probe"}

<div class="line"><span class="opacity-40">$</span> <strong class="font-bold">curl -s -X POST -d '{"name":5,"age":"x"}' localhost:8087/probe</strong></div>
<div class="line">{"name_type":"number","age_as_int":-1,"has_missing":false}</div>
::

## Обмеження вбудованої бібліотеки

Бібліотека Crow покриває типові потреби API, але має межі: немає автоматичного перетворення структур у JSON і назад, немає схеми валідації, а читання потребує ручного коду для кожного поля. Для проєктів із десятками структур зручніша бібліотека nlohmann/json, яку розглядає наступна лекція.

## Запитання

::::accordion

:::accordion-item{label="❓ Чим JSON відрізняється від XML?" icon="i-lucide-help-circle"}

JSON коротший і прямо відображає структури даних мов програмування: об'єкти, масиви, числа. XML має теги, атрибути, простори імен і краще підходить для документів зі змішаним вмістом. Для API між програмами JSON став стандартом через простоту.

:::

:::accordion-item{label="❓ Чи можна довіряти числам у JSON як точним?" icon="i-lucide-help-circle"}

Ні. JSON не розрізняє цілі й дробові, а багато бібліотек читають числа як `double`, який точно зберігає цілі лише до 2^53. Великі ідентифікатори й суми грошей передають рядками.

:::

:::accordion-item{label="❓ Чому порядок ключів не збігається з порядком присвоєння?" icon="i-lucide-help-circle"}

JSON-об'єкт — невпорядкований набір пар. Crow зберігає ключі у внутрішній структурі, яка порядок вставки не гарантує, і серіалізує їх у довільному порядку.

:::

:::accordion-item{label="❓ Чому тіло запиту не можна передавати в wvalue напряму?" icon="i-lucide-help-circle"}

`rvalue` і `wvalue` — різні типи. Щоб повернути отримане значення клієнту, його потрібно скопіювати в `wvalue` поле за полем або повернути вихідний текст `req.body` як рядок із заголовком `Content-Type: application/json`.

:::

## Практика

::::accordion

:::accordion-item{label="📋 Завдання 1: статистика масиву" icon="i-lucide-clipboard-list"}

Створіть `POST /stats`, що приймає `{"numbers": [3, 1, 4, 1, 5]}` і повертає `min`, `max`, `sum`, `avg`, `count`. Для порожнього масиву поверніть 400.

:::

:::accordion-item{label="✅ Розв'язок завдання 1" icon="i-lucide-check-circle"}

```cpp
CROW_ROUTE(app, "/stats").methods(crow::HTTPMethod::POST)([](const crow::request& req) {
    auto body = crow::json::load(req.body);
    if (!body || !body.has("numbers") || body["numbers"].t() != crow::json::type::List)
        return crow::response(400, "Потрібен масив numbers");
    if (body["numbers"].size() == 0) return crow::response(400, "Масив порожній");

    double mn = 1e300, mx = -1e300, sum = 0;
    for (const auto& n : body["numbers"]) {
        if (n.t() != crow::json::type::Number) return crow::response(400, "Елементи мають бути числами");
        double v = n.d();
        mn = std::min(mn, v); mx = std::max(mx, v); sum += v;
    }
    crow::json::wvalue res;
    res["min"] = mn; res["max"] = mx; res["sum"] = sum;
    res["avg"] = sum / static_cast<double>(body["numbers"].size());
    res["count"] = body["numbers"].size();
    return crow::response(200, res);
});
```

## Підсумок

- `crow::json::load` повертає `rvalue`: порожній при помилці розбору. Типи читають методами `.s()`, `.i()`, `.d()`, `.b()`, вкладеність — ланцюжком `[]`.
- Відсутній ключ чи невірний тип кидають `std::runtime_error`, який без перехоплення стає відповіддю 500. Чужі дані перевіряють через `has()` і `t()` або `try`/`catch`.
- `crow::json::wvalue` будується присвоєнням, масиви через `wvalue::list`; конструктор `crow::response` перетворює його на текст.
- Порядок ключів у JSON не гарантований.
