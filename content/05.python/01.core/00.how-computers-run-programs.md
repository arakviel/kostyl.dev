# Як комп'ютер виконує програму

## Що таке програма

**Програма** — це послідовність інструкцій, які комп'ютер виконує по черзі. Комп'ютер не додумує і не вгадує: він робить рівно те, що написано, і в тому порядку, в якому написано.

Типова програма виконує три дії: отримує дані, обробляє їх і видає результат. Калькулятор отримує числа, додає їх і показує суму. Ігровий застосунок отримує натискання клавіш, змінює стан гри й малює новий кадр.

Python — одна з мов, якими такі інструкції записують. У цій лекції розглянуто, що відбувається з рядком Python-коду від натискання «Run» до результату на екрані.

## Процесор, пам'ять і диск

У виконанні програми беруть участь три компоненти.

**Процесор** (*CPU, Central Processing Unit*) виконує інструкції. Він бере одну інструкцію, виконує її, переходить до наступної. Інструкції прості: додати два числа, порівняти два числа, скопіювати значення. Сила процесора в швидкості: він виконує мільярди таких кроків за секунду.

**Оперативна пам'ять** (*RAM, Random Access Memory*) — робоче сховище. У ній лежить усе, з чим програма працює зараз: код, числа, проміжні результати. Пам'ять швидка, але після вимкнення комп'ютера її вміст зникає.

**Диск** (*SSD або HDD*) зберігає файли постійно. Читання з диска значно повільніше, ніж з RAM, тому процесор напряму з диском не працює.

Звідси висновок: програму спершу **завантажують з диска в оперативну пам'ять**, і лише потім процесор бере звідти інструкції.

## Усе в пам'яті — числа

Оперативна пам'ять — це ряд однакових комірок, і кожна комірка має адресу. Одна комірка вміщує один **байт** (*byte*). Байт складається з 8 **бітів** (*bit*), кожен біт дорівнює 0 або 1, тому байт вміщує 256 значень: числа від 0 до 255. Усе, що зберігається в пам'яті, записане такими числами.

Приклад: слово `Hello`. Кожній літері відповідає номер за таблицею символів. Літера `H` має номер `72`, `e` — `101`, `l` — `108`, `o` — `111`. Слово займає п'ять сусідніх комірок.

![Слово Hello в оперативній пам'яті: п'ять комірок з числами 72, 101, 108, 108, 111](/images/python/core/how-computers-run-programs/02-ram-cells.png){.diagram-img}

Python має функції для перевірки: `ord()` повертає номер літери, `chr()` виконує зворотну дію.

```python
print(ord("H"))
print(chr(101))
```

::terminal-preview{title="python numbers.py"}

<div class="line">72</div>
<div class="line">e</div>

::

Так само зберігаються й інші дані. Колір пікселя — це три числа (червоний, зелений, синій). Звук — послідовність чисел. **Команди процесора** теж числа. Тому байт сам по собі не має змісту: число `72` може бути літерою `H`, яскравістю пікселя або частиною команди. Зміст залежить від того, як програма його читає. На цьому ґрунтується поняття типу даних.

## Мови високого рівня і машинний код

Процесор виконує **машинний код** (*machine code*): числові команди, специфічні для архітектури процесора. Чипи Intel і AMD мають одні команди, чипи Apple та більшість смартфонів — інші. Вручну такі команди писати довго й складно: щоб додати два числа й вивести результат, потрібні десятки команд, а помилку в ряді чисел важко помітити.

Тому існують **мови програмування високого рівня** (*high-level languages*): C, Java, JavaScript, Python. Їхній синтаксис ближчий до людської мови:

```python
print("Hello")
```

Один такий рядок замінює багато команд машинного коду. Але процесор його не розуміє. Між текстом програми й процесором потрібен перекладач.

## Компілятор і інтерпретатор

Є два способи перекладу.

**Компілятор** (*compiler*) перекладає всю програму в машинний код *один раз, до запуску*. Результат — виконуваний файл (на Windows це `.exe`). Далі запускають саме його, вихідний код уже не потрібен. Так працюють C, C++, Go, Rust. Аналогія: книгу перекладають повністю й видають готовий переклад.

**Інтерпретатор** (*interpreter*) — програма, яка читає код і виконує його *під час запуску*, без окремого виконуваного файлу. Аналогія: перекладач перекладає кожне речення в момент розмови.

![Порівняння компіляції та інтерпретації](/images/python/core/how-computers-run-programs/04-compile-vs-interpret.png){.diagram-img}

| | Компіляція | Інтерпретація |
|---|---|---|
| Коли відбувається переклад | один раз, перед запуском | щоразу під час запуску |
| Швидкість виконання | зазвичай вища | зазвичай нижча |
| Перенесення на інший комп'ютер | збирати окремо під кожен процесор | достатньо мати інтерпретатор |
| Приклади | C, C++, Go, Rust | bash; Python (після компіляції в байт-код) |

## Що насправді робить Python

Поширена відповідь — «Python інтерпретована мова». Вона неповна.

Python не виконує текст програми рядок за рядком. Спочатку він **компілює** код у *проміжну мову* — **байт-код** (*bytecode*). Це набір простих команд, які не залежать від процесора. Потім **віртуальна машина Python** (*PVM, Python Virtual Machine*) виконує ці команди по черзі. Вона і є інтерпретатором у класичному розумінні.

![Шлях Python-програми: текст, компіляція, байт-код, віртуальна машина](/images/python/core/how-computers-run-programs/05-python-pipeline.png){.diagram-img}

Перед створенням байт-коду текст розбивається на частини (токени) і з них будується дерево програми. Докладно ці етапи показано у відео. Python виконує обидві дії: **компілює** текст у байт-код, потім **інтерпретує** байт-код. Наслідки:

- синтаксичні помилки знаходяться до виконання першого рядка;
- байт-код не залежить від процесора, тому програма працює скрізь, де встановлено Python.

Байт-код можна переглянути модулем `dis`:

```python
import dis

dis.dis('print("Hello")')
```

```text
  0           RESUME                   0

  1           LOAD_NAME                0 (print)
              PUSH_NULL
              LOAD_CONST               0 ('Hello')
              CALL                     1
              RETURN_VALUE
```

`LOAD_NAME` знаходить об'єкт `print`, `LOAD_CONST` кладе текст `'Hello'`, `CALL 1` викликає функцію з одним аргументом. `RESUME` і `PUSH_NULL` — службові команди віртуальної машини, зараз вони не потрібні.

::note
Набір команд змінюється між версіями Python. Вивід отримано в Python 3.15. Назви команд запам'ятовувати не потрібно. Важливо, що **команди прості й виконуються по черзі**.
::

::note
Програма, яку запускає команда `python`, називається **CPython**, бо написана мовою C. Існують й інші реалізації (PyPy, Jython). У курсі використовується CPython версії 3.15.
::

:::accordion-item{label="❓ Чому тоді кажуть, що Python повільніший за C?" icon="i-lucide-help-circle"}

У C компілятор створює машинні команди, які процесор виконує напряму. У Python кожну команду байт-коду виконує віртуальна машина, а це додатковий рівень роботи. Швидкість обмінюється на простоту й гнучкість мови.

:::

Ні. Байт-код виконує віртуальна машина, яка входить до складу Python. Існують інструменти, що пакують програму разом з інтерпретатором в один файл, але інтерпретатор у ньому все одно є.

:::

### REPL і скрипт

Код запускають у двох режимах.

**REPL** (*Read-Eval-Print Loop*) — інтерактивний режим: ви вводите рядок, Python виконує його, показує результат і чекає наступного. Підходить для експериментів. Запуск:

```bash
python
```

З'явиться запрошення `>>>`. Введіть вираз і натисніть Enter:

::terminal-preview{title="python"}

<div class="line"><span class="text-blue-400 font-bold">&gt;&gt;&gt;</span> 2 + 3</div>
<div class="line">5</div>
<div class="line"><span class="text-blue-400 font-bold">&gt;&gt;&gt;</span> print("Hello")</div>
<div class="line">Hello</div>
<div class="line"><span class="text-blue-400 font-bold">&gt;&gt;&gt;</span> exit()</div>

::

Вихід з REPL — `exit()`. Кожен рядок у REPL проходить той самий шлях: компіляція в байт-код, виконання.

**Скрипт** (*script*) — файл `.py` з усією програмою. Створіть `hello.py` з рядком `print("Hello")` і запустіть:

```bash
python hello.py
```

Скрипт зберігається на диску, його можна запускати повторно й передавати іншим. Реальні програми пишуть саме у файлах.

### Звідки береться `__pycache__`

У папці проєкту може з'явитися каталог `__pycache__` з файлами `.pyc` — це збережений байт-код. Коли програма імпортує інший файл, Python компілює його й кладе байт-код у `__pycache__`, щоб не компілювати повторно, якщо вихідний файл не змінився. Назва містить версію Python, наприклад `hello.cpython-315.pyc`.

::warning
Скрипт, який запускають напряму (`python hello.py`), у `__pycache__` **не потрапляє**. Кеш створюється лише для імпортованих файлів. Відсутність папки після запуску скрипта — нормальна поведінка.
::

5. Код запускають у REPL або як скрипт; `__pycache__` зберігає байт-код імпортованих файлів.

## Типові хибні уявлення

::::accordion

:::accordion-item{label="⚠️ «Комп'ютер розуміє Python»" icon="i-lucide-alert-triangle"}

Процесор розуміє тільки машинний код. Між текстом і процесором стоїть CPython: він компілює код у байт-код і виконує його.

:::

:::accordion-item{label="⚠️ «Python не компілює»" icon="i-lucide-alert-triangle"}

Python компілює, але не в машинний код, а в байт-код. Файли `.pyc` у `__pycache__` — результат цієї компіляції.

:::

:::accordion-item{label="⚠️ «Папка pycache з'являється після кожного запуску»" icon="i-lucide-alert-triangle"}

Лише для імпортованих файлів. Скрипт, який запускають напряму, не кешується.

:::
