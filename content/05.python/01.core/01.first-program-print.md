## Перша програма: Hello, World!

```python
print("Hello, World!")
```


Розберемо рядок за частинами:

- `"Hello, World!"` — аргумент: рядок (*string*), текст у лапках. Лапки показують початок і кінець тексту, у вивід вони не потрапляють.

## Функція і її виклик

**Функція** (*function*) — іменований фрагмент коду, який виконує певну роботу. Щоб запустити функцію, пишуть її ім'я та круглі дужки: `print(...)`. Це називається **викликом** (*call*). Якщо функції потрібні дані, їх вказують у дужках — це **аргументи** (*arguments*).

Функції бувають трьох видів:

- **вбудовані** — доступні одразу, наприклад `print` і `len`;
- **з модулів** — їх спершу підключають, наприклад функції з модуля `math`;
- **власні** — їх пишете ви (тема одного з наступних уроків).

Для будь-якої функції корисно знати три речі: який вона має **ефект** (що робить), які приймає **аргументи** і який повертає **результат**. Для `print`:

- ефект: виводить аргументи в термінал;
- аргументи: значення будь-яких типів (текст, числа, інші);
- результат: немає. Функція повертає спеціальне значення `None`.

![Виклик print: ефект у терміналі та результат None](/images/python/core/first-program-print/01-function-call.png){.diagram-img}

Перевірте це самостійно:

```python
result = print("x")
print(result)
print(type(print))
```

```text
x
None
<class 'builtin_function_or_method'>
```

Перший `print` виводить `x`, а його результат `None` зберігається в `result`. Другий виводить цей результат. Третій показує, що `print` — це об'єкт-функція, а `print(...)` — її виклик. Ім'я без дужок функцію не запускає.

## Аргументи print: позиційні та ключові

`print` приймає два види аргументів.

**Позиційні** (*positional*) — звичайні значення. Їх можна передати скільки завгодно, порядок має значення. `print` виводить їх через пробіл:

```python
print("My", "name", "is", "Monty", "Python.")
print(1, 2.5, True, None)
```

```text
My name is Monty Python.
1 2.5 True None
```

**Ключові** (*keyword*) — аргументи з іменем: `ім'я=значення`. Вони завжди йдуть після позиційних, їхній порядок не важливий. У `print` їх два:

- `sep` (*separator*) — що вставити між аргументами. За замовчуванням пробіл.
- `end` — що вивести в кінці. За замовчуванням символ нового рядка `\n`, тому кожен `print` починає з нового рядка.

```python
print("My", "name", "is", "Monty", "Python.", sep="-")
```

```text
My-name-is-Monty-Python.
```

![Параметри sep і end у виклику print](/images/python/core/first-program-print/02-sep-end.png){.diagram-img}

Параметр `end` дозволяє залишити вивід у тому самому рядку:

```python
print("My name is", end=" ")
print("Monty Python.")
```

```text
My name is Monty Python.
```

`print()` без аргументів виводить порожній рядок.

Ключові аргументи не можна ставити перед позиційними: `print(sep="-", "a", "b")` викличе помилку. Для `sep` і `end` допустимі лише рядки або `None`: `print("a", sep=1)` завершиться помилкою `TypeError: sep must be None or a string, not int`.

## Коментарі

Текст після знака `#` Python ігнорує до кінця рядка. Такі **коментарі** (*comments*) пояснюють код людям:

```python
# Виводимо привітання
print("Привіт!")  # коментар можна писати й у кінці рядка
```

```text
Привіт!
```

Коментар пояснює, **чому** код написано так, а не повторює те, що видно з самого коду.

## Рядки: лапки та спеціальні символи

Рядок можна записати в подвійних або одинарних лапках: `"текст"` і `'текст'` — це одне й те саме. Це дозволяє вставити один вид лапок усередину іншого:

```python
print("Дон'т")
print('Він сказав "привіт"')
```

```text
Дон'т
Він сказав "привіт"
```

Якщо потрібні ті самі лапки, їх **екранують** (*escape*): ставлять перед ними зворотний слеш `\`.

```python
print("Лапки: \"так\" і 'так'")
```

```text
Лапки: "так" і 'так'
```

Зворотний слеш вводить **керувальні послідовності** (*escape sequences*):

| Запис | Що означає |
|---|---|
| `\n` | новий рядок |
| `\t` | табуляція |
| `\"` | подвійні лапки |
| `\'` | одинарні лапки |
| `\\` | сам символ `\` |

```python
print("Рядок1\nРядок2")
print("Табуляція:\tтут")
print("Слеш: C:\\Users")
```

```text
Рядок1
Рядок2
Табуляція:	тут
Слеш: C:\Users
```

Важлива деталь: у коді `\n` — це два знаки, але Python читає їх як **один символ** нового рядка. Перевірка:

```python
print(len("\n"))
```

```text
1
```

![У коді \n займає два знаки, у рядку це один символ](/images/python/core/first-program-print/03-escape.png){.diagram-img}

Для шляхів у Windows зручний **сирий рядок** (*raw string*) з літерою `r` перед лапками: слеші в ньому не обробляються.

```python
print(r"C:\new\table")
print(len(r"\n"))
```

```text
C:\new\table
2
```

Рядок на кілька рядків записують у потрійних лапках:

```python
print("""Три
рядки""")
```

```text
Три
рядки
```

## Перші помилки

Помилки неминучі. Python повідомляє, що пішло не так, і показує місце помилки. Повідомлення містить назву типу помилки та пояснення. Розглянемо два найчастіших типи.

### SyntaxError: код записано неправильно

**SyntaxError** (синтаксична помилка) виникає, коли Python не може розібрати код. Програма не виконується взагалі, навіть рядки до помилки. Причина в тому, що Python компілює весь файл перед виконанням.

Не закритий рядок:

```python
print("Hello)
```

```text
  File "hello.py", line 1
    print("Hello)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Відсутні дужки:

```python
print "Hello"
```

```text
  File "hello.py", line 1
    print "Hello"
    ^^^^^^^^^^^^^
SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?
```

### NameError: ім'я не існує

**NameError** виникає, коли код використовує ім'я, яке Python не знає. Помилка з'являється під час виконання, тому рядки до неї встигають спрацювати. Приклад з помилкою в назві функції:

```python
prnt("Hello")
```

![Структура повідомлення про помилку NameError](/images/python/core/first-program-print/04-traceback.png){.diagram-img}

Повідомлення читають знизу вгору:

1. Останній рядок — тип помилки та пояснення. Python 3.15 часто додає підказку `Did you mean: 'print'?`.
2. Вище — рядок коду з підкресленням місця помилки.
3. Ще вище — файл і номер рядка.

Інші типові причини `NameError`:

```python
Print("Hello")
```

```text
NameError: name 'Print' is not defined. Did you mean: 'print'?
```

Python розрізняє великі й малі літери, тому `Print` і `print` — різні імена.

```python
print(Hello)
```

```text
NameError: name 'Hello' is not defined
```

Без лапок `Hello` вважається іменем, а не текстом.

## Підсумок

1. `print(...)` — виклик функції: ім'я знаходить функцію, дужки її запускають.
2. `print` виводить текст, а її результат — `None`.
3. Позиційні аргументи виводяться через `sep` (пробіл за замовчуванням), після них вставляється `end` (`\n` за замовчуванням).
4. Коментар починається з `#` і ігнорується.
5. `\n` у коді — два знаки, у рядку — один символ.
6. `SyntaxError` виникає до запуску програми, `NameError` — під час виконання. Повідомлення читають знизу вгору.

## Типові хибні уявлення

::::accordion

:::accordion-item{label="⚠️ «print повертає текст»" icon="i-lucide-alert-triangle"}

`print` лише виводить текст у термінал. Результат виклику — `None`. Щоб зберегти текст, його записують в іншу конструкцію (тема наступних уроків), а не в `print`.

:::

:::accordion-item{label="⚠️ «Символ нового рядка — це два символи»" icon="i-lucide-alert-triangle"}

У коді `\n` записано двома знаками, а в рядку це один символ. `len("\n")` дорівнює 1. У сирому рядку `r"\n"` слеш не обробляється, тому його довжина 2.

:::

:::accordion-item{label="⚠️ «print — це команда без дужок»" icon="i-lucide-alert-triangle"}

У Python 3 `print` — функція, її викликають з дужками. Запис `print "Hello"` дає `SyntaxError`.

:::

:::accordion-item{label="⚠️ «Помилка означає, що я не здатний програмувати»" icon="i-lucide-alert-triangle"}

Помилки є в кожного програмиста. Повідомлення Python вказує рядок і причину, тому виправлення зазвичай займає хвилину.

:::
