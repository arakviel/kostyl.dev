## Вирази та інструкції

**Вираз** (*expression*) — частина коду, яка має **значення**: `2 + 3`, `x * 4`, `len("abc")`. Python обчислює вираз і отримує об'єкт.

**Інструкція** (*statement*) — рядок, який щось виконує: `x = 2 + 3`, `print(x)`. Інструкція може містити вирази. Правило для розрізнення: вираз можна вставити всередину `print(...)`, а інструкцію — ні.

```python
print(2 + 3)
x = 2 + 3
print(x)
```

```text
5
5
```

## Арифметичні оператори

| Оператор | Дія | Приклад | Результат |
|---|---|---|---|
| `+` | додавання | `7 + 2` | `9` |
| `-` | віднімання | `7 - 2` | `5` |
| `*` | множення | `7 * 2` | `14` |
| `/` | ділення | `7 / 2` | `3.5` |
| `//` | ділення націло | `7 // 2` | `3` |
| `%` | остача від ділення | `7 % 2` | `1` |
| `**` | піднесення до степеня | `7 ** 2` | `49` |

Оператор `/` **завжди** повертає `float`, навіть коли ділення без остачі: `10 / 2` дорівнює `5.0`. Для цілого результату використовують `//`.

### Пріоритет операторів

Вираз Python будує як дерево: спершу виконуються операції з вищим **пріоритетом**. Порядок такий:

1. `**` (степінь);
2. унарний мінус (`-x`);
3. `*`, `/`, `//`, `%`;
4. `+`, `-`.

![Дерево виразу 2 + 3 * 4: множення виконується першим](/images/python/core/expressions-input-types/01-expression-tree.png){.diagram-img}

Дужки змінюють порядок:

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(-2 ** 2, (-2) ** 2)
```

```text
14
20
512
-4 4
```

Дві особливості: `**` виконується справа наліво (`2 ** 3 ** 2` це `2 ** 9`), а мінус нижчий за степінь: `-2 ** 2` — це `-(2 ** 2)`. Якщо порядок неочевидний, ставте дужки.

## Ділення націло і остача

Оператор `//` повертає **цілу частку**, `%` — **остачу**. Для додатних чисел це очевидно: `7 // 2` дорівнює `3`, `7 % 2` дорівнює `1`. Корисні застосування:

- парність: `n % 2` дорівнює `0` для парних чисел;
- розбиття на одиниці й десятки: `47 // 10` дає `4`, `47 % 10` дає `7`;
- перерахунок одиниць: секунди в години, хвилини й секунди.

З від'ємними числами Python ділить із **округленням униз** (до меншого цілого), а не до нуля:

```python
print(-7 // 2, -7 % 2)
print(7 // -2, 7 % -2)
print(divmod(-7, 2))
```

```text
-4 1
-4 -1
(-4, 1)
```

Результат `-7 / 2` дорівнює `-3.5`, і округлення вниз дає `-4`, а не `-3`. Остача підбирається так, щоб виконувалась рівність `-7 = 2 · (-4) + 1`.

![Числова пряма: -7 // 2 округлює -3.5 вниз до -4](/images/python/core/expressions-input-types/02-floor-division.png){.diagram-img}

Функція `divmod(a, b)` повертає частку й остачу разом. Знак остачі збігається зі знаком дільника: `-7 % 2` дорівнює `1`, а `7 % -2` дорівнює `-1`.

::warning
Ділення на нуль викликає `ZeroDivisionError` для `/`, `//` і `%`: `10 / 0` завершується повідомленням `ZeroDivisionError: division by zero`.
::

## Скорочені оператори

Дію над змінною та присвоєння результату тій самій змінній записують коротко:

| Скорочено | Те саме, що |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 3` | `x = x - 3` |
| `x *= 2` | `x = x * 2` |
| `x //= 5` | `x = x // 5` |
| `x **= 2` | `x = x ** 2` |
| `x %= 7` | `x = x % 7` |

Для незмінних типів (`int`, `float`, `str`) такий запис **створює новий об'єкт**, як і `x = x + 1` з минулого уроку. Перевірте на рядках: `+=` склеює рядки, але другу змінну не змінює.

## Введення: input()

Функція `input()` зупиняє програму, чекає, поки користувач введе рядок і натисне Enter, і повертає введене як **рядок** (`str`). Аргумент `input` — підказка, яка виводиться перед введенням:

```python
name = input("Ваше ім'я: ")
print("Привіт,", name)
```

::terminal-preview{title="python hello_name.py"}

<div class="line">Ваше ім'я: <strong class="font-bold">Олена</strong></div>
<div class="line">Привіт, Олена</div>

::

Головна особливість: `input()` **завжди** повертає `str`, навіть якщо користувач ввів число. Тому арифметика над введенням без перетворення не працює:

```python
x = input("n: ")
print(x + 1)
```

```text
TypeError: can only concatenate str (not "int") to str
```

Для рядка `"5"` оператор `+` означає склеювання, а склеїти рядок із числом Python не може. Оператор `*` із рядком означає повторення: `"5" * 3` дає `"555"`.

## Перетворення типів

Щоб отримати число з рядка, використовують функції-перетворювачі: `int()`, `float()`, `str()`, `bool()`. Кожна **створює новий об'єкт** потрібного типу, а початковий не змінює.

![Перетворення між str, int і float функціями int(), str(), float()](/images/python/core/expressions-input-types/03-conversions.png){.diagram-img}

```python
print(int("42"), int(" 42 "), float("3.14"), float(3), str(42))
print(int(3.9), int(-3.9))
```

```text
42 42 3.14 3.0 42
3 -3
```

- Пробіли навколо числа в рядку допустимі.
- `int()` від дробу **відкидає дробову частину** (до нуля), а не округлює: `int(3.9)` дорівнює `3`.
- `round(x)` округлює до найближчого цілого, `round(x, n)` — до `n` знаків.

### Що може піти не так

Не кожен рядок можна перетворити. Якщо вміст не схожий на число, Python викликає `ValueError`:

```python
int("3.5")
```

```text
ValueError: invalid literal for int() with base 10: '3.5'
```

Рядок `"3.5"` — це не ціле число, тому `int` його відхиляє, і це правильна поведінка: Python не здогадується, що користувач мав на увазі. Правильний шлях для дробу: `float("3.5")`, а потім за потреби `int(...)`. Інші типові помилки:

| Код | Результат |
|---|---|
| `int("abc")` | `ValueError: invalid literal for int() with base 10: 'abc'` |
| `int("")` | `ValueError: invalid literal for int() with base 10: ''` |
| `float("1,5")` | `ValueError: could not convert string to float: '1,5'` |
| `int(None)` | `TypeError: int() argument must be a string, a bytes-like object or a real number, not 'NoneType'` |

Для дробів Python чекає крапку, а не кому. Як перехоплювати такі помилки й просити користувача ввести дані ще раз, розглянемо в уроці про винятки.

### bool() і неявні перетворення

`bool()` повертає `False` для нуля, порожнього рядка та порожніх колекцій, а в решті випадків `True`. Важлива деталь: непорожній рядок завжди істинний, навіть `"0"` та `"False"`:

```python
print(bool(0), bool(0.0), bool(""), bool("0"), bool("False"))
```

```text
False False False True True
```

Іноді Python перетворює типи **сам**. Це **неявне перетворення**, і воно відбувається лише там, де результат однозначний:

```python
print(1 + 2.0)
print(True + 1)
```

```text
3.0
2
```

`int` у змішаному виразі з `float` перетворюється на `float`, `bool` — на `int`. Рядок із числом так не змішується: `"5" + 5` завершується `TypeError`.

## f-рядки

**f-рядок** (*f-string*) — рядок із літерою `f` перед лапками. Вирази у фігурних дужках обчислюються й підставляються:

```python
name, age = "Олена", 20
print(f"{name} має {age} років")
print(f"Через рік: {age + 1}")
print(f"{age=}")
```

```text
Олена має 20 років
Через рік: 21
age=20
```

Після двокрапки в дужках задають **формат**:

| Запис | Результат | Опис |
|---|---|---|
| `{3.14159:.2f}` | `3.14` | два знаки після крапки |
| `{1234567:,}` | `1,234,567` | роздільник розрядів |
| `{42:05d}` | `00042` | ширина 5, нулі зліва |
| `{0.256:.1%}` | `25.6%` | відсотки |
| `{"Олена":>8}` | `   Олена` | вирівнювання праворуч |
| `{"Олена":<8}` | `Олена   ` | ліворуч |
| `{"Олена":^8}` | ` Олена  ` | по центру |

Щоб вивести фігурну дужку, її подвоюють: `f"{{текст}}"` дає `{текст}`.

## Приклад: калькулятор гіпотенузи

Об'єднаємо все: введення, перетворення, вираз і форматований вивід.

```python
a = float(input("Катет a: "))
b = float(input("Катет b: "))
c = (a ** 2 + b ** 2) ** 0.5
print(f"Гіпотенуза: {c:.2f}")
```

<div class="line">Гіпотенуза: 5.00</div>

::

Порядок дій: `input` повертає рядки, `float` перетворює їх на числа, вираз обчислює корінь через степінь `0.5`, f-рядок виводить результат із двома знаками.

## Підсумок

1. Вираз має значення, інструкція виконує дію. Пріоритет: `**`, унарний `-`, `* / // %`, `+ -`.
2. `/` завжди дає `float`, `//` ділить націло з округленням **вниз**, `%` дає остачу зі знаком дільника.
3. Скорочені оператори (`+=` та інші) для незмінних типів створюють новий об'єкт.
4. `input()` завжди повертає `str`.
5. `int()`, `float()`, `str()`, `bool()` створюють новий об'єкт. `int("3.5")` — `ValueError`, `int(3.9)` — `3`.
6. f-рядок підставляє вирази й форматує вивід: `{x:.2f}`, `{n:05d}`.

## Типові хибні уявлення

::::accordion

:::accordion-item{label="⚠️ «input() повертає число, якщо ввести цифри»" icon="i-lucide-alert-triangle"}

`input()` завжди повертає `str`. Число отримують через `int()` або `float()`.

:::

:::accordion-item{label="⚠️ «int() округлює»" icon="i-lucide-alert-triangle"}

`int()` відкидає дробову частину: `int(3.9)` дорівнює `3`, `int(-3.9)` дорівнює `-3`. Для округлення використовують `round()`.

:::

:::accordion-item{label="⚠️ «Ціле ділення -7 // 2 дає -3»" icon="i-lucide-alert-triangle"}

`//` округлює вниз, тому результат `-4`.

:::

:::accordion-item{label="⚠️ «Рядок з нулем — хибний»" icon="i-lucide-alert-triangle"}

Непорожній рядок завжди істинний, навіть `"0"` та `"False"`: `bool("0")` дорівнює `True`.

:::

```text
3 2 -4 3
```

`17 = 5 · 3 + 2`, а `-17 = 5 · (-4) + 3`.

:::accordion-item{label="📋 Передбачення 2" icon="i-lucide-clipboard-list"}

```python
print(2 + 3 * 4 ** 2)
```

:::

:::accordion-item{label="✅ Відповідь 2" icon="i-lucide-check-circle"}

```text
50
```

Спершу `4 ** 2` дорівнює 16, потім `3 * 16` дорівнює 48, потім `2 + 48` дорівнює 50.

:::

:::accordion-item{label="📋 Передбачення 3" icon="i-lucide-clipboard-list"}

Користувач вводить `5`:

```python
x = input()

print(int(x) * 3)
```

```text
555
15
```

Рядок `"5"` повторюється тричі, а число `5` множиться.

```python
print(int("7") + float("0.5"))
```

:::

```text
7.5
```

Сума `int` і `float` — це `float`.

## Практичні завдання

::::accordion

:::accordion-item{label="📋 Завдання 1: вартість покупки" icon="i-lucide-clipboard-list"}

Запитайте ціну товару та кількість. Виведіть вартість із двома знаками після крапки у форматі `Разом: 149.97 грн`.

:::

:::accordion-item{label="✅ Розв'язок 1" icon="i-lucide-check-circle"}

```python
price = float(input("Ціна: "))
qty = int(input("Кількість: "))
print(f"Разом: {price * qty:.2f} грн")
```

:::

:::accordion-item{label="📋 Завдання 2: секунди в години, хвилини, секунди" icon="i-lucide-clipboard-list"}

Користувач вводить кількість секунд. Виведіть її у форматі `01:02:05`. Для `3725` результат має бути `01:02:05`.

:::

:::accordion-item{label="✅ Розв'язок 2" icon="i-lucide-check-circle"}

```python
total = int(input("Секунд: "))
hours, rest = divmod(total, 3600)
minutes, seconds = divmod(rest, 60)
print(f"{hours:02d}:{minutes:02d}:{seconds:02d}")
```

```text
01:02:05
```

:::

:::accordion-item{label="📋 Завдання 3: сума цифр двоцифрового числа" icon="i-lucide-clipboard-list"}

Користувач вводить двоцифрове число. Виведіть суму його цифр. Для `47` результат `11`.

:::

:::accordion-item{label="✅ Розв'язок 3" icon="i-lucide-check-circle"}

```python
n = int(input("Число: "))
print(n // 10 + n % 10)
```

:::

:::accordion-item{label="📋 Завдання 4*: парність" icon="i-lucide-clipboard-list"}

Виведіть `0`, якщо введене число парне, і `1`, якщо непарне. Умовні конструкції не використовуйте.

:::

:::accordion-item{label="✅ Розв'язок 4*" icon="i-lucide-check-circle"}

```python
n = int(input("Число: "))
print(n % 2)
```

Для від'ємних чисел результат теж правильний: `-3 % 2` дорівнює `1`.
