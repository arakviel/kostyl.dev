# Логіка та розгалуження

## Програма, що приймає рішення

До цього уроку програма виконувала рядки один за одним, завжди в одному порядку. Реальні програми реагують на дані: перевіряють пароль, визначають оцінку, обирають дію. Для цього потрібні **умови**: вирази, результат яких `True` або `False`, і **розгалуження**, яке за умовою вибирає, який код виконувати.

## Порівняння

Оператори порівняння дають результат типу `bool`: `True` або `False`.

| Оператор | Значення | Приклад | Результат |
|---|---|---|---|
| `==` | дорівнює | `5 == 5.0` | `True` |
| `!=` | не дорівнює | `5 != 4` | `True` |
| `<` | менше | `3 < 2` | `False` |
| `>` | більше | `3 > 2` | `True` |
| `<=` | менше або дорівнює | `3 <= 3` | `True` |
| `>=` | більше або дорівнює | `2 >= 3` | `False` |

Числа різних типів порівнюються за значенням: `5 == 5.0` дає `True`. Порівняти число з рядком за порядком не можна:

```python
print(5 > "3")
```

```text
TypeError: '>' not supported between instances of 'int' and 'str'
```

Рядки порівнюються за кодами символів, посимвольно зліва направо. Тому результат не завжди збігається з людською інтуїцією:

```python
print("apple" < "banana", "Ab" < "ab", "10" < "9", 10 < 9)
```

```text
True True True False
```

Великі літери мають менші коди, ніж малі, а `"10"` менше за `"9"`, бо перший символ `"1"` менший за `"9"`. Для чисел у рядках спершу використовують `int()`.

### Ланцюжки порівнянь

Python дозволяє записати подвійну умову як у математиці:

```python
x = 7
print(0 < x < 10)
print(0 < x < 5)
```

```text
True
False
```

Запис `0 < x < 10` означає `0 < x and x < 10`, причому `x` обчислюється один раз.

![Ланцюжок 0 < x < 10 на числовій прямій: x = 7 належить інтервалу](/images/python/core/logic-branching/01-comparison-chain.png){.diagram-img}

::warning
Не плутайте `=` та `==`. Один знак дорівнює **присвоює** значення, два — **порівнюють**. Дробові числа через `==` порівнювати не слід (урок про типи): `0.1 + 0.2 == 0.3` дає `False`.
::

## Логічні оператори

Умови об'єднують трьома операторами:

| Оператор | Значення | Приклад |
|---|---|---|
| `and` | обидві умови істинні | `x > 0 and x < 10` |
| `or` | хоча б одна істинна | `x < 0 or x > 10` |
| `not` | заперечення | `not x > 5` |

```python
print(True and False, True or False, not True)
```

```text
False True False
```

Пріоритет: `not` вищий за `and`, а `and` вищий за `or`. Вираз `1 == 2 or 3 == 3 and 4 == 4` обчислюється як `1 == 2 or (3 == 3 and 4 == 4)` і дає `True`. Для читабельності складні умови беруть у дужки.

Перевірка належності через `in`:

```python
print("a" in "abc", "z" not in "abc", 3 in [1, 2, 3])
```

```text
True True True
```

### Коротке замикання

Python обчислює `and` та `or` **зліва направо і зупиняється**, щойно результат відомий:

- `A and B`: якщо `A` хибне, результат уже відомий, `B` не обчислюється;
- `A or B`: якщо `A` істинне, результат відомий, `B` не обчислюється.

```python
def f():
    print("f викликана")
    return 1

print(0 and f())
print(1 and f())
print(1 or f())
print(0 or f())
```

```text
0
f викликана
1
1
f викликана
1
```

![Коротке замикання: 0 and f() не викликає f, а 1 and f() викликає](/images/python/core/logic-branching/03-short-circuit.png){.diagram-img}

Це корисно для захисту від помилок: у виразі `n != 0 and 10 / n > 1` ділення виконується, лише якщо `n` не нуль.

### and і or повертають операнд

Важлива особливість Python: `and` і `or` повертають не `True` чи `False`, а **один зі своїх операндів**:

- `A or B` повертає `A`, якщо `A` істинне, інакше `B`;
- `A and B` повертає `A`, якщо `A` хибне, інакше `B`.

```python
print(0 or "default", "" or "Гість", "a" or "b")
print(5 and 7, 0 and 7)
```

```text
default Гість a
7 0
```

Тому `name or "Гість"` — поширений спосіб задати значення за замовчуванням. Простежте це в трасувальнику:

Після рядка `shown = name or "Гість"` змінна `shown` вказує на об'єкт `'Гість'`, бо порожній рядок хибний. Рядок `count and 10 / count` не викликає ділення на нуль: `count` дорівнює `0`, тож `and` повертає його одразу.

## Істинність значень

Умову можна записати не лише як порівняння: будь-яке значення Python вважає **істинним** або **хибним**. Хибні такі значення:

| Значення | Тип |
|---|---|
| `False` | `bool` |
| `0`, `0.0` | `int`, `float` |
| `""` | порожній рядок |
| `[]`, `()`, `{}`, `set()` | порожні колекції |
| `None` | `NoneType` |

Усі інші значення істинні. Функція `bool()` показує це:

```python
print(bool(0), bool(0.0), bool(""), bool([]), bool(None))
print(bool("0"), bool([0]), bool(-1))
```

```text
False False False False False
True True True
```

Рядок `"0"` і список `[0]` не порожні, тому істинні. Завдяки цьому можна писати `if name:` замість `if name != "":`.

## Розгалуження if, elif, else

Інструкція `if` виконує блок коду, лише якщо умова істинна:

```python
age = 17
if age >= 18:
    print("Доступ дозволено")
else:
    print("Доступ заборонено")
```

```text
Доступ заборонено
```

Синтаксис має три обов'язкові елементи:

1. після умови стоїть **двокрапка** `:`;
2. рядки блоку мають **відступ** (4 пробіли), і лише відступ показує, що рядок належить блоку;
3. `else` не має умови: він виконується, коли жодна умова вище не спрацювала.

Щоб перевірити кілька варіантів, між `if` і `else` ставлять `elif` (від *else if*):

```python
score = 82
if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "F"
print(grade)
```

```text
B
```

Python перевіряє умови **зверху вниз** і виконує перший блок, умова якого істинна. Решта пропускаються, навіть якщо їхні умови теж були б істинними. Бал `82` задовольняє і `>= 75`, і `>= 60`, але виконується лише `B`.

У трасувальнику видно, що рядок `grade = "A"` пропущений, а після перевірки `score >= 75` виконується `grade = "B"`.

::warning
Кілька окремих `if` поспіль — це **незалежні** перевірки, а `if` + `elif` — одна перевірка, у якій спрацює лише одна галузь. Для `x = 5` код `if x > 3: ...` і `if x > 1: ...` виведе обидві галузі, а з `elif` — лише першу.
::

### Вкладені умови та pass

Блок може містити інші `if`. Кожен рівень вкладеності додає відступ:

```python
age = 20
has_ticket = True
if age >= 18:
    if has_ticket:
        print("Прохід дозволено")
    else:
        print("Потрібен квиток")
```

```text
Прохід дозволено
```

Глибоку вкладеність краще замінювати об'єднанням умов: `if age >= 18 and has_ticket:`. Порожній блок записують словом `pass` (інструкція, що нічого не робить).

### Умовний вираз

Коли потрібно вибрати між двома значеннями, зручний **умовний вираз** (*conditional expression*):

```python
age = 17
status = "дорослий" if age >= 18 else "неповнолітній"
print(status)
```

```text
неповнолітній
```

Форма: `значення_якщо_істина if умова else значення_якщо_хиба`. Це **вираз**, тому його можна підставити будь-де, де потрібне значення.

## match: вибір за шаблоном

Коли одне й те саме значення порівнюють з багатьма варіантами, ланцюжок `elif` повторює порівняння знову й знову:

```python
command = "stop"
if command == "go":
    print("їдемо")
elif command == "stop" or command == "halt":
    print("зупиняємось")
elif command == "back":
    print("назад")
else:
    print("невідома команда")
```

```text
зупиняємось
```

Для таких випадків у Python є інструкція **`match`**. Вона бере одне значення й порівнює його зі **шаблонами** (*patterns*) по черзі. Розглянемо її поступово, від найпростішого до складнішого.

### Простий match

Той самий приклад із `match`:

```python
command = "stop"
match command:
    case "go":
        print("їдемо")
    case "stop" | "halt":
        print("зупиняємось")
    case "back":
        print("назад")
    case _:
        print("невідома команда")
```

```text
зупиняємось
```

Будова інструкції:

- `match command:` — значення, яке перевіряємо, і двокрапка;
- кожен `case шаблон:` — один варіант, після нього блок з відступом;
- Python порівнює значення з шаблонами **зверху вниз** і виконує блок **першого збігу**; решта пропускаються;
- шаблон `_` (підкреслення) збігається з **будь-яким** значенням, тому його ставлять останнім як «усе інше» (аналог `else`).

Простежте виконання в трасувальнику:

::code-trace{src="/traces/python-core/05-match.json" title="Вибір за шаблоном"}
::

Шаблон `"go"` не збігся, шаблон `"stop" | "halt"` збігся, тому виконано лише його блок, а `case _` пропущено.

### Що буде, якщо збігу немає

Блок `case _` не обов'язковий. Якщо жоден шаблон не підійшов, `match` нічого не робить, і програма йде далі:

```python
day = 3
match day:
    case 1:
        print("понеділок")
    case 6:
        print("субота")
print("після match")
```

```text
після match
```

Для `day = 6` вивід був би `субота`, а потім `після match`.

### Кілька значень в одному case

Знак `|` читається як «або». Він об'єднує кілька шаблонів в один блок:

```python
for d in (1, 5, 6, 7):
    match d:
        case 6 | 7:
            print(d, "вихідний")
        case _:
            print(d, "робочий")
```

```text
1 робочий
5 робочий
6 вихідний
7 вихідний
```

Це коротше за `if d == 6 or d == 7:`.

### Захоплення значення

Шаблон може бути **ім'ям**. Тоді він збігається з будь-яким значенням і записує його в цю змінну:

```python
point = 42
match point:
    case 0:
        print("нуль")
    case n:
        print("число", n)
```

```text
число 42
```

Тут `n` — не порівняння з наявною змінною, а **нова змінна**, яку створює шаблон. Відмінність від `_`: підкреслення значення не зберігає, а ім'я зберігає.

Оскільки ім'я збігається з усім, шаблон з голим іменем має бути **останнім**. Інакше Python відхиляє код:

```python
match 5:
    case x:
        print(x)
    case 1:
        print(1)
```

```text
SyntaxError: name capture 'x' makes remaining patterns unreachable
```

### Додаткова умова (guard)

Після шаблону можна дописати `if` з умовою. Блок виконається, лише якщо шаблон збігся **і** умова істинна:

```python
for t in (-5, 0, 20, 35):
    match t:
        case n if n < 0:
            print(n, "мороз")
        case 0:
            print(n, "нуль")
        case n if n <= 25:
            print(n, "тепло")
        case _:
            print(t, "спека")
```

```text
-5 мороз
0 нуль
20 тепло
35 спека
```

Ім'я `n` захоплює значення, а `if` перевіряє його. Якщо умова хибна, Python переходить до наступного `case`.

### Шаблони для кортежів

**Кортеж** (*tuple*) — впорядкований набір значень у круглих дужках, наприклад `("move", 3)`. Докладно кортежі розглянемо в уроці про колекції. Тут вони потрібні, бо `match` уміє порівнювати **структуру** значення і витягувати з неї частини.

Команда складається з назви й, можливо, параметрів. Шаблон описує форму кортежу:

```python
for cmd in (("stop",), ("move", 3), ("move", 3, 4), ("jump",)):
    match cmd:
        case ("stop",):
            print(cmd, "стоп")
        case ("move", steps):
            print(cmd, "крок", steps)
        case ("move", x, y):
            print(cmd, "до точки", x, y)
        case _:
            print(cmd, "невідома команда")
```

```text
('stop',) стоп
('move', 3) крок 3
('move', 3, 4) до точки 3 4
('jump',) невідома команда
```

Правила:

- літерали (`"move"`) мають збігтися точно;
- імена (`steps`, `x`, `y`) захоплюють відповідні елементи;
- **кількість елементів** теж має збігтися: `("move", steps)` не підходить для кортежу з трьох значень, тому для нього спрацював третій `case`.

Ще один приклад: положення точки на площині.

```python
point = (3, 0)
match point:
    case (0, 0):
        print("початок координат")
    case (x, 0):
        print("на осі X, x =", x)
    case (0, y):
        print("на осі Y, y =", y)
    case (x, y):
        print("точка", x, y)
```

```text
на осі X, x = 3
```

Шаблони перевіряються по черзі: `(0, 0)` не збігся, а `(x, 0)` збігся, бо другий елемент дорівнює нулю, а перший захоплено в `x`.

### Перевірка типу

Шаблон `тип()` збігається, якщо значення має цей тип. Дужки обов'язкові:

```python
for v in (7, 3.5, "текст", True, None):
    match v:
        case bool():
            print(repr(v), "логічне")
        case int():
            print(repr(v), "ціле")
        case float():
            print(repr(v), "дробове")
        case str():
            print(repr(v), "рядок")
        case None:
            print(repr(v), "None")
```

```text
7 ціле
3.5 дробове
'текст' рядок
True логічне
None None
```

Порядок важливий: `bool` — підтип `int` (урок про типи), тому `True` збігся б і з `int()`. Тому `bool()` стоїть **перед** `int()`. Шаблон `None` пишеться без дужок: це літерал.

Тип можна поєднати з іменем через `as` усередині структури:

```python
match ("move", 5):
    case ("move", int() as steps):
        print("кроків:", steps)
```

```text
кроків: 5
```

### Пастка: ім'я в case не порівнюється зі змінною

Найпоширеніша помилка: спроба порівняти значення зі **змінною** через `case ім'я`. Python сприймає ім'я як шаблон захоплення, а не як порівняння:

```python
RED = 1
color = 2
match color:
    case RED:
        print("RED тепер дорівнює", RED)
```

```text
RED тепер дорівнює 2
```

Хоча `color` не дорівнює `1`, блок виконався, а змінну `RED` **перезаписано**. Порівнювати зі змінною в `case` напряму не можна: використовують літерали або умову `case n if n == RED`.

### Приклад: калькулятор

Об'єднаємо введення, перетворення та `match`:

```python
a = float(input("a: "))
b = float(input("b: "))
op = input("Операція (+ - * /): ")
match op:
    case "+":
        print(a + b)
    case "-":
        print(a - b)
    case "*":
        print(a * b)
    case "/":
        print(a / b)
    case _:
        print("невідома операція")
```

### Коли що вибирати

| Ситуація | Інструмент |
|---|---|
| Умова з діапазонами й порівняннями (`score >= 75`) | `if` / `elif` |
| Складна логіка з `and`, `or`, `not` | `if` / `elif` |
| Одне значення проти кількох точних варіантів | `match` |
| Потрібно розібрати структуру (кортеж, тип) і витягти частини | `match` |

::note
Помилки синтаксису в `match` схожі на помилки в `if`: пропущена двокрапка дає `SyntaxError: expected ':'`, а `case` без відступу — `IndentationError: expected an indented block after 'match' statement on line 2`. Альтернативи, що прив'язують різні імена (`case (a, b) | (a,):`), заборонені: `SyntaxError: alternative patterns bind different names`.
::

## Підсумок

1. Порівняння (`==`, `!=`, `<`, `>`, `<=`, `>=`) дають `bool`. Ланцюжок `0 < x < 10` — дві перевірки разом.
2. `and`, `or`, `not` об'єднують умови. Пріоритет: `not`, `and`, `or`.
3. `and` та `or` зупиняються, коли результат відомий, і **повертають один з операндів**.
4. Хибні значення: `False`, `0`, `0.0`, `""`, порожні колекції, `None`. Решта істинні.
5. `if` / `elif` / `else` перевіряють умови зверху вниз і виконують перший істинний блок. Блок позначає відступ.
6. `a if умова else b` — умовний вираз.
7. `match` порівнює значення з шаблонами по черзі: літерали, `|`, імена-захоплення, умова `if`, кортежі, типи. `_` означає «усе інше».

## Типові хибні уявлення

::::accordion

:::accordion-item{label="⚠️ «and та or повертають True чи False»" icon="i-lucide-alert-triangle"}

Вони повертають один з операндів: `0 or "x"` дає `"x"`, а не `True`.

:::

:::accordion-item{label="⚠️ «Усі елементи ланцюжка elif перевіряються»" icon="i-lucide-alert-triangle"}

Перевірка зупиняється на першій істинній умові. Решта `elif` та `else` пропускаються.

:::

:::accordion-item{label="⚠️ «if x = 5 перевіряє, чи x дорівнює 5»" icon="i-lucide-alert-triangle"}

Один знак дорівнює — присвоєння, і в умові він викликає `SyntaxError`. Порівняння записують через `==`.

:::

:::accordion-item{label="⚠️ «Рядок із нулем хибний»" icon="i-lucide-alert-triangle"}

Лише порожній рядок хибний. `"0"` і `"False"` — непорожні, тому істинні.

:::
