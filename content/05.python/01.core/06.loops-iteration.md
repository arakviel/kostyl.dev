# Цикли та ітерація

## Як змусити комп'ютер повторювати

Комп'ютер добре виконує одну й ту саму дію багато разів. Щоб вивести числа від 1 до 1000, не треба писати тисячу рядків: достатньо **циклу** (*loop*), який повторює блок коду. У Python є два цикли: `while` повторює код, поки виконується умова, а `for` проходить по елементах якогось об'єкта.

## Цикл while

Цикл `while` **перевіряє умову**, і поки вона істинна, повторює тіло. Перевірка відбувається перед кожною ітерацією, зокрема першою:

```python
n = 1
while n <= 3:
    print("ітерація", n)
    n += 1
print("після циклу, n =", n)
```

```text
ітерація 1
ітерація 2
ітерація 3
після циклу, n = 4
```

Порядок виконання:

1. Перевірити умову `n <= 3`.
2. Якщо істинна, виконати тіло (рядки з відступом) і повернутися до пункту 1.
3. Якщо хибна, перейти до першого рядка після циклу.

![Блок-схема циклу while: перевірка умови, тіло, повернення до перевірки](/images/python/core/loops-iteration/01-while-flow.png){.diagram-img}

Для коректної роботи цикл має містити три частини: **початкове значення** (`n = 1`), **умову** (`n <= 3`) і **зміну**, яка наближає завершення (`n += 1`). Без зміни умова ніколи не стане хибною.

### Нескінченний цикл і вихід через break

Якщо умова ніколи не стає хибною, цикл **не завершується**. Це може бути помилкою (забули змінити лічильник) або наміром: тоді умову записують як `while True`, а вихід роблять через `break`:

```python
tries = 0
while True:
    tries += 1
    guess = ["abc", "123", "python"][tries - 1]
    if guess == "python":
        print("вірно за", tries, "спроби")
        break
```

```text
вірно за 3 спроби
```

Список у прикладі лише імітує три введення. Так працює більшість програм із меню або перевіркою пароля: цикл триває, поки не виконається умова виходу.

Щоб зупинити програму, яка зависла в нескінченному циклі, натисніть :kbd{value="Ctrl"} + :kbd{value="C"} у терміналі. Python перерве виконання винятком `KeyboardInterrupt`:

```python
while True:
    pass
```

```text
Traceback (most recent call last):
  File "inf.py", line 2, in <module>
    pass
KeyboardInterrupt
```

::warning
Типова причина нескінченного циклу — зміна, яку забули написати: `while n > 0:` без `n -= 1`. Якщо програма «зависла», перевірте, чи змінюється в тілі циклу величина з умови.
::

## Цикл for

Цикл `for` бере **елементи об'єкта по одному** й для кожного виконує тіло. Змінна циклу на кожній ітерації вказує на черговий елемент:

```python
for ch in "кіт":
    print(ch, end=" ")
```

```text
к і т 
```

Об'єкт, елементи якого можна перебирати, називається **ітерованим** (*iterable*). Рядок — один з таких об'єктів, інші (списки, словники) з'являться в наступних уроках. Важливо: `for` у Python — це **не** лічильник «від і до», як у C. Це перебір елементів об'єкта.

### Як працює for: iter і next

Цикл `for` виконує три кроки:

1. Просить об'єкт створити **ітератор** (*iterator*) функцією `iter()`. Ітератор пам'ятає, який елемент наступний.
2. Бере наступний елемент функцією `next()` і присвоює змінній циклу.
3. Коли елементи закінчились, `next()` викликає виняток `StopIteration`, і цикл тихо завершується.

Те саме можна зробити вручну (для останнього рядка показано лише кінець повідомлення про помилку):

```python
it = iter("ab")
print(next(it), next(it))
next(it)
```

```text
a b
StopIteration
```

Другий аргумент `next(it, значення)` дозволяє отримати значення за замовчуванням замість винятку. Перевірте це в трасувальнику:

Змінна `it` вказує на єдиний об'єкт-ітератор, який пам'ятає позицію. Кожен `next` посуває його на один символ. Коли символи закінчились, `next` повертає `"кінець"`.

## range

Щоб повторити дію задану кількість разів, використовують функцію **`range`**. Вона створює послідовність цілих чисел:

| Виклик | Числа |
|---|---|
| `range(5)` | `0, 1, 2, 3, 4` |
| `range(2, 8)` | `2, 3, 4, 5, 6, 7` |
| `range(10, 0, -3)` | `10, 7, 4, 1` |
| `range(5, 2)` | порожня |

Форма `range(start, stop, step)`: починаємо зі `start`, рухаємося кроком `step`, **не доходячи до `stop`**. Початок за замовчуванням `0`, крок `1`. Верхня межа **не входить** у результат.

```python
for i in range(3):
    print(i, end=" ")
print()
for i in range(3, 0, -1):
    print(i, end=" ")
print("старт")
```

```text
0 1 2 
3 2 1 старт
```

Простежте цикл `for` з `range` у трасувальнику:

::code-trace{src="/traces/python-core/06-for-range.json" title="for i in range(3)"}
::

На кожній ітерації змінна `i` вказує на наступне число (0, 1, 2), а `total` накопичує суму. Після останньої ітерації `i` лишається рівною `2`.

### range не зберігає числа

Функція `range` не створює список з усіма числами. Вона зберігає лише три значення: початок, кінець і крок, а потрібне число обчислює, коли про нього просять:

```python
r = range(10**12)
print(len(r), 999_999_999_999 in r)
```

```text
1000000000000 True
```

Мільйон мільйонів чисел перевіряється миттєво. Якби вони зберігались у списку, знадобилось би щонайменше 8 ТБ пам'яті лише на посилання. Тому `for i in range(1000000)` не витрачає пам'ять на мільйон чисел.

![range зберігає три числа, а список із 10**12 елементів зберігав би їх усі](/images/python/core/loops-iteration/02-range-not-list.png){.diagram-img}

::note
Дробів `range` не приймає: `range(3.5)` завершується `TypeError: 'float' object cannot be interpreted as an integer`. Для проходу по числу теж не годиться `for i in 5`: це `TypeError: 'int' object is not iterable`. Число не є набором елементів, перебирати можна `range(5)`.
::

## break, continue і else

Три інструкції змінюють звичайний хід циклу:

- **`break`** одразу завершує цикл;
- **`continue`** пропускає залишок поточної ітерації й переходить до наступної;
- **`else`** після циклу виконується, **якщо цикл завершився без `break`**.

```python
for i in range(1, 6):
    if i == 2:
        continue
    if i == 5:
        break
    print(i, end=" ")
```

```text
1 3 4 
```

Число `2` пропущено через `continue`, а на `5` цикл перервано через `break`, тому `5` теж не виведено.

Блок `else` у циклі найкорисніший для пошуку: він спрацьовує, коли шуканого не знайшли.

```python
n = 17
for d in range(2, n):
    if n % d == 0:
        print(n, "складене, дільник", d)
        break
else:
    print(n, "просте")
```

```text
17 просте
```

Якби `break` спрацював, `else` було б пропущено. Простежте це в трасувальнику:

::code-trace{src="/traces/python-core/06-break-else.json" title="break і else"}

::note
`else` у циклі — це не «інакше», а «якщо без `break`». Якщо `break` у циклі немає взагалі, `else` виконається завжди. Те саме стосується `while`.

## Вкладені цикли

Усередині циклу може бути інший цикл. Зовнішній виконує **один** крок, а внутрішній щоразу **повністю** проходить усі свої кроки:

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end="\t")
    print()
```

```text
1	2	3	
2	4	6	
3	6	9	
```

Внутрішній цикл рухається швидко (як хвилинна стрілка), зовнішній повільно (як годинна). Для `i = 1` внутрішній цикл виконує три ітерації, потім `print()` переводить рядок, і зовнішній цикл переходить до `i = 2`. Усього `3 × 3 = 9` ітерацій тіла.

![Вкладені цикли: таблиця множення 3 на 3](/images/python/core/loops-iteration/03-nested-loops.png){.diagram-img}

::tip
`break` у вкладеному циклі виходить лише з **найближчого** циклу. Зовнішній продовжить роботу.
::

## Деталі, які варто знати

**Змінна циклу залишається після циклу.** Після `for i in range(1, 4)` змінна `i` дорівнює `3`. Якщо цикл не виконався жодного разу, змінна не створюється:

```python
for k in range(0):
    pass
print(k)
```

```text
NameError: name 'k' is not defined
```

**Зміна змінної циклу не впливає на ітерації.** Наступне значення береться з `range`, а не з попереднього:

```python
for i in range(5):
    i = i * 10
    print(i, end=" ")
```

```text
0 10 20 30 40 
```

**Ім'я `_`** за угодою означає, що значення не використовується: `for _ in range(3): print("hi")`.

**Типові помилки синтаксису:**

```python
for i in range(3)
    print(i)
```

```text
SyntaxError: expected ':'
```

```python
n = 5
while n > 0:
print(n)
```

```text
IndentationError: expected an indented block after 'while' statement on line 2
```

## Підсумок

1. `while` перевіряє умову перед кожною ітерацією. Потрібні початкове значення, умова й зміна.
2. `for` бере елементи ітерованого об'єкта по одному: створює ітератор через `iter()` і викликає `next()` до `StopIteration`.
3. `range(start, stop, step)` не зберігає числа, а обчислює їх; `stop` не входить.
4. `break` завершує цикл, `continue` пропускає ітерацію, `else` виконується, якщо `break` не спрацював.
5. У вкладених циклах внутрішній цикл проходить повністю на кожну ітерацію зовнішнього.
6. Нескінченний цикл зупиняє :kbd{value="Ctrl"} + :kbd{value="C"}.

## Типові хибні уявлення

::::accordion

:::accordion-item{label="⚠️ «for рахує від і до, як у C»" icon="i-lucide-alert-triangle"}

`for` у Python перебирає елементи об'єкта. Лічильник у циклі створює `range`, а не сам `for`.

:::

:::accordion-item{label="⚠️ «range(5) створює список із п'яти чисел»" icon="i-lucide-alert-triangle"}

`range` зберігає лише початок, кінець і крок. Числа обчислюються по одному.

:::

:::accordion-item{label="⚠️ «range(1, 5) включає число 5»" icon="i-lucide-alert-triangle"}

Верхня межа не входить: `range(1, 5)` дає `1, 2, 3, 4`.

:::

:::accordion-item{label="⚠️ «else виконується, коли цикл не пройшов жодної ітерації»" icon="i-lucide-alert-triangle"}

`else` виконується, коли цикл завершився **без `break`**, зокрема коли ітерацій не було зовсім.

:::

:::accordion-item{label="📋 Завдання 4*: вгадай число" icon="i-lucide-clipboard-list"}

Програма загадує число `7`. Користувач вводить здогадки, доки не вгадає. Після кожної неправильної здогадки програма підказує «менше» або «більше». Наприкінці виведіть кількість спроб.

:::

:::accordion-item{label="✅ Розв'язок 4*" icon="i-lucide-check-circle"}

```python
secret = 7
tries = 0
while True:
    guess = int(input("Здогадка: "))
    tries += 1
    if guess == secret:
        print("Вгадали за", tries, "спроб")
        break
    elif guess < secret:
        print("більше")
    else:
        print("менше")
```
