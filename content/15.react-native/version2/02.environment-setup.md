# Налаштування середовища розробки

## Перш ніж писати перший рядок коду

На відміну від веб-розробки, де достатньо браузера та текстового редактора, мобільна розробка вимагає ретельнішого налаштування середовища. Це пов'язано з природою платформи: ваш код має виконуватися на iOS або Android, а не в браузері.

Проте React Native разом з Expo суттєво спростив цю задачу. Якщо раніше початківці витрачали дні на боротьбу з Xcode, Android Studio та нативними залежностями, то сьогодні перший робочий застосунок можна запустити за 15 хвилин — навіть без встановлення Xcode чи Android Studio.

У цій статті ми пройдемо весь шлях: від чистої машини до запущеного застосунку на реальному телефоні.

::note
**Що таке Expo?** Expo — це фреймворк та платформа над React Native, що надає набір готових інструментів, бібліотек і сервісів. Він суттєво знижує поріг входу та прискорює розробку. У цьому курсі ми починаємо з Expo Managed Workflow, а в окремій статті розглянемо, коли і як перейти на bare workflow з повним доступом до нативного коду.
::

## Крок 1: Node.js та менеджер пакетів

React Native — це JavaScript-екосистема, тому Node.js є обов'язковою передумовою. Expo CLI, `npx`, всі залежності проєкту — все це працює через Node.js.

**npm чи yarn?** Expo офіційно підтримує обидва. У цьому курсі використовується `npm` — він встановлюється разом з Node.js і не вимагає додаткових кроків. Якщо ви надаєте перевагу yarn, замінюйте `npm install` на `yarn add` та `npx` на `yarn`.

## Крок 2: Expo CLI vs React Native CLI

Перш ніж створити проєкт, розберемось з фундаментальним вибором: **Expo** чи **React Native CLI**.

### Два шляхи у React Native

::card-group

::card{title="Expo Managed Workflow" icon="i-lucide-rocket"}

**Рекомендований старт.** Expo бере на себе всю нативну конфігурацію: Xcode, Android Studio, Gradle, CocoaPods. Ви пишете лише JavaScript/TypeScript. Доступ до нативних API — через Expo SDK.

**Ідеальний для:** навчання, прототипів, більшості реальних застосунків, команд без досвіду в iOS/Android розробці.

::

::card{title="React Native CLI (bare)" icon="i-lucide-wrench"}

**Повний контроль.** Ви самостійно управляєте нативними проєктами (ios/ та android/ директорії). Можна підключити будь-яку нативну бібліотеку, змінити нативний код, інтегрувати RN у існуючий нативний застосунок.

**Ідеальний для:** коли потрібні нативні модулі, яких немає в Expo SDK, або коли RN додається до існуючого нативного проєкту.

::

::

::note
**Важливо:** ці два шляхи не є взаємовиключними. Expo Managed Workflow можна «відкрити» (eject) у будь-який момент за допомогою `npx expo prebuild`, отримавши повний доступ до нативного коду. Це вирішує проблему «я обрав Expo, але тепер потребую нативний модуль». Детально це розглянуто у статті про bare workflow.
::

### Чому ми починаємо з Expo?

| Аспект | Expo Managed | React Native CLI |
| ------ | :----------: | :--------------: |
| Потрібен Xcode/Android Studio | Ні | Так |
| Час до першого запуску | ~10 хвилин | 1–3 години |
| Перегляд на телефоні (без кабелю) | Так (Expo Go) | Ні |
| OTA (over-the-air) оновлення | Так | Потрібна конфігурація |
| Push-сповіщення | Так (Expo) | Ручна конфігурація |
| Доступ до нативного коду | Обмежений (але є prebuild) | Повний |
| Підходить для цього курсу | **✓** | Окрема стаття |

## Крок 3: Створення першого проєкту

Expo надає утиліту `create-expo-app`, аналогічну `create-react-app` у веб-світі. Вам не потрібно встановлювати Expo CLI глобально — достатньо `npx`:

::terminal-preview{title="Створення Expo-проєкту"}

<div class="line"><span class="opacity-40">$</span> <strong>npx create-expo-app@latest my-first-app</strong></div>
<div class="line"></div>
<div class="line">✔ Which template would you like to use? › <span class="text-blue-400">Default</span></div>
<div class="line">  (A TypeScript app with file-based routing)</div>
<div class="line"></div>
<div class="line"><span class="text-green-400">✓ Your project is ready!</span></div>
<div class="line"></div>
<div class="line">To get started:</div>
<div class="line">  <span class="opacity-40">-</span> <strong>cd my-first-app</strong></div>
<div class="line">  <span class="opacity-40">-</span> <strong>npx expo start</strong></div>

::

::tip
**Шаблони create-expo-app:** `Default` (рекомендований — TypeScript + Expo Router + файлова навігація), `Blank` (мінімальний, без навігації), `Blank (TypeScript)`. Для цього курсу використовуйте `Default` — він налаштовує Expo Router, який ми вивчаємо у модулі 4.
::

### Структура згенерованого проєкту

Після створення ви отримаєте таку структуру:

::code-tree

```text [app/_layout.tsx]
import { Stack } from 'expo-router';

export default function RootLayout() {
  return <Stack />;
}
```

```text [app/(tabs)/index.tsx]
import { Text, View } from 'react-native';

export default function HomeScreen() {
  return (
    <View>
      <Text>Welcome!</Text>
    </View>
  );
}
```

```text [app/(tabs)/_layout.tsx]
import { Tabs } from 'expo-router';

export default function TabLayout() {
  return <Tabs />;
}
```

```text [constants/Colors.ts]
const tintColorLight = '#0a7ea4';
const tintColorDark = '#fff';

export const Colors = {
  light: { tint: tintColorLight },
  dark: { tint: tintColorDark },
};
```

```json [package.json]
{
  "name": "my-first-app",
  "main": "expo-router/entry",
  "scripts": {
    "start": "expo start",
    "android": "expo start --android",
    "ios": "expo start --ios",
    "web": "expo start --web"
  },
  "dependencies": {
    "expo": "~52.0.0",
    "expo-router": "~4.0.0",
    "react": "18.3.1",
    "react-native": "0.76.0"
  }
}
```

```json [app.json]
{
  "expo": {
    "name": "my-first-app",
    "slug": "my-first-app",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/images/icon.png",
    "scheme": "myapp",
    "userInterfaceStyle": "automatic",
    "splash": {
      "image": "./assets/images/splash-icon.png"
    },
    "ios": { "supportsTablet": true },
    "android": { "adaptiveIcon": { "foregroundImage": "./assets/images/adaptive-icon.png" } }
  }
}
```

::

**Ключові елементи структури:**

::field-group

::field{name="app/" type="директорія"}
Серце проєкту з Expo Router. Кожен файл тут — це маршрут. `_layout.tsx` визначає спільний layout (навігацію) для вкладених маршрутів. `(tabs)/` — група маршрутів з Tab-навігацією. Детально — у статті про Expo Router.
::

::field{name="app.json" type="конфіг"}
Конфігурація Expo застосунку: назва, іконка, splash screen, орієнтація, дозволи, платформо-специфічні налаштування. Альтернатива — `app.config.ts` (TypeScript-конфіг з динамічними значеннями).
::

::field{name="assets/" type="директорія"}
Статичні ресурси: іконки, зображення, шрифти. Expo автоматично обробляє та оптимізує їх під різні density екранів (1x, 2x, 3x).
::

::field{name="constants/" type="директорія"}
Загальні константи проєкту: кольори, розміри, конфігурація. Конвенція, яка не є обов'язковою, але корисна для організації коду.
::

::field{name="hooks/" type="директорія"}
Кастомні хуки, зокрема `useColorScheme` для роботи з темою. Expo генерує кілька готових хуків для роботи з темою та кольорами.
::

::field{name="tsconfig.json" type="конфіг"}
TypeScript-конфіг. Expo автоматично включає необхідні типи для React Native та Expo. Зверніть увагу на `"extends": "expo/tsconfig.base"` — це базова конфігурація від Expo з оптимальними налаштуваннями.
::

::

Expo Dev Server — це **Metro bundler**, основний інструмент збірки React Native. Він компілює ваш TypeScript/JSX у JavaScript і обслуговує бандл для клієнтів (телефон, емулятор). Metro підтримує **Hot Module Replacement (HMR)** — зміни у коді з'являються на екрані майже миттєво без повного перезавантаження.

### Спосіб 1: Expo Go — реальний пристрій без кабелю

**Expo Go** — безкоштовний застосунок, який дозволяє запускати ваш Expo-проєкт на реальному телефоні без будь-якої збірки. Достатньо відсканувати QR-код.

::steps

### Встановіть Expo Go

- **iOS**: [App Store → Expo Go](https://apps.apple.com/app/expo-go/id982107779)
- **Android**: [Google Play → Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)

### Переконайтесь, що телефон та комп'ютер в одній Wi-Fi мережі

Metro bundler обслуговує бандл локально. Телефон має досягти IP-адреси вашого комп'ютера.

### Відскануйте QR-код

- **iOS**: відкрийте стандартну Camera app і наведіть на QR-код у терміналі
- **Android**: відкрийте Expo Go → натисніть «Scan QR code»

### Застосунок завантажується і запускається

Expo Go завантажує JavaScript-бандл, виконує його і відображає ваш застосунок. Перше завантаження займає 10–30 секунд.

::

::caution
**Обмеження Expo Go:** Expo Go підтримує лише бібліотеки зі стандартного Expo SDK. Якщо ви додаєте бібліотеку з нативним кодом (наприклад, `react-native-maps` або кастомний нативний модуль), Expo Go не зможе їх завантажити — потрібна **Development Build** (власна збірка Expo Go з вашими нативними залежностями). Для більшості завдань цього курсу Expo Go є достатнім.
::

## Крок 5: VS Code та розширення

VS Code — де-факто стандартний редактор для React Native розробки. Налаштуйте його правильно від самого початку.

### Обов'язкові розширення

::card-group

::card{title="Expo Tools" icon="i-simple-icons-expo"}

Офіційне розширення від Expo. Підсвічує `app.json`, автодоповнення для Expo SDK, інтеграція з EAS. **ID:** `expo.vscode-expo-tools`

::

::card{title="React Native Tools" icon="i-simple-icons-react"}

Офіційне від Microsoft. Налагодження React Native застосунків прямо у VS Code, breakpoints, перегляд стану. **ID:** `msjsdiag.vscode-react-native`

::

::card{title="ESLint" icon="i-simple-icons-eslint"}

Статичний аналіз коду. Expo включає `.eslintrc.js` з базовою конфігурацією. **ID:** `dbaeumer.vscode-eslint`

::

::card{title="Prettier" icon="i-lucide-align-left"}

Форматування коду. Налаштуйте «Format on Save» для автоматичного форматування при збереженні. **ID:** `esbenp.prettier-vscode`

::

::

### Налаштування VS Code для React Native

Додайте до `.vscode/settings.json` у корені проєкту:

```json [.vscode/settings.json]
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "typescript.tsdk": "node_modules/typescript/lib",
  "emmet.includeLanguages": {
    "javascript": "javascriptreact",
    "typescript": "typescriptreact"
  }
}
```

### Fast Refresh: гаряче перезавантаження

React Native підтримує **Fast Refresh** — зміни у коді миттєво відображаються на екрані без перезапуску застосунку та без втрати стану компонента. Це значно прискорює розробку порівняно з традиційним mobile-розробкою.

::note
**Як працює Fast Refresh:** Metro відстежує зміни у файлах. При зміні компонента він пересилає лише оновлений модуль на пристрій/емулятор. React замінює компонент «гарячо», зберігаючи стан хуків. Якщо змінено файл поза компонентом (утиліта, константа) — відбувається повне перезавантаження.
::

## Практика

::accordion

::accordion-item{label="Завдання 1 — Перший запущений застосунок" icon="i-lucide-rocket"}

1. Встановіть Node.js 20 LTS (перевірте: `node --version`)
2. Створіть новий Expo-проєкт: `npx create-expo-app@latest my-rn-course`
3. Запустіть його: `cd my-rn-course && npx expo start`
4. Відкрийте у Expo Go на телефоні АБО у симуляторі/емуляторі
5. Знайдіть файл `app/(tabs)/index.tsx` і змініть текст «Welcome!» на своє ім'я
6. Переконайтесь, що Fast Refresh відобразив зміну без перезапуску

**Очікуваний результат:** ваш застосунок запущено і відображає оновлений текст.

::

::accordion-item{label="Завдання 2 — Дослідіть структуру" icon="i-lucide-folder-open"}

Відкрийте проєкт у VS Code і дайте відповіді на питання:

1. Де знаходиться точка входу застосунку? (підказка: поле `"main"` у `package.json`)
2. Що таке `expo-router/entry`? Чому тут не `./app/_layout.tsx`?
3. Що означає `(tabs)` у назві директорії? Чому дужки?
4. Як змінити назву застосунку, що відображається на home screen телефону?

::

::accordion-item{label="Питання для роздумів — Expo Go та безпека" icon="i-lucide-shield"}

Expo Go завантажує JavaScript-бандл з вашого комп'ютера через локальну мережу. Які потенційні проблеми це може створити у production-сценарії? Чому для публікації у App Store/Google Play використовується EAS Build, а не Expo Go?
