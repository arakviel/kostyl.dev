## Навіщо передбачати завтра, коли є вчора?

Уявіть: ви власник кав'ярні. Щоранку потрібно замовляти молоко. Замало — залишите клієнтів без кави. Забагато — молоко скисне.

Ви вирішуєте вивчити історію. Записуєте, скільки літрів молока витрачається щодня протягом 100 днів. Отримуєте масив чисел:

```
[42, 38, 45, 41, 43, 39, 44, 40, 42, 41, ...]
```

Тепер питання: **скільки замовити завтра?** Середнє — 41.5 літра. Але чи достатньо знати лише середнє?

Ні. Вам потрібно знати **розподіл** — як часто трапляються різні значення:
- Чи майже завжди витрачається 40–43 літри (стабільно)?
- Чи бувають різкі стрибки до 60 літрів (непередбачувано)?
- Чи є дні з мінімальним споживанням 20 літрів (вихідні)?

**Розподіл** дає вам повну картину, а не лише одну цифру (середнє).

::jupyter-notebook{title="coffee_shop_distribution.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Аналіз споживання молока за 100 днів
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Симулюємо споживання молока (нормальний розподіл)
milk_consumption = np.random.normal(loc=41.5, scale=3.5, size=100)
milk_consumption = np.clip(milk_consumption, 30, 55)  # реалістичні межі

# Статистика
mean = milk_consumption.mean()
std = milk_consumption.std()

print(f"Середнє споживання: {mean:.1f} літрів")
print(f"Стандартне відхилення: {std:.1f} літрів")
print(f"\nПередбачення на завтра:")
print(f"  З ймовірністю 68%: {mean - std:.1f} — {mean + std:.1f} літрів")
print(f"  З ймовірністю 95%: {mean - 2*std:.1f} — {mean + 2*std:.1f} літрів")

# Візуалізація розподілу
plt.figure(figsize=(10, 5))
plt.hist(milk_consumption, bins=15, edgecolor='black', alpha=0.7, color='steelblue')
plt.axvline(mean, color='red', linestyle='--', linewidth=2, label=f'Середнє = {mean:.1f}')
plt.axvline(mean - std, color='orange', linestyle='--', linewidth=1.5, label=f'±1σ')
plt.axvline(mean + std, color='orange', linestyle='--', linewidth=1.5)
plt.xlabel('Споживання молока (літри)')
plt.ylabel('Частота (кількість днів)')
plt.title('Розподіл споживання молока за 100 днів', fontweight='bold')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

#output
```
Середнє споживання: 41.8 літрів
Стандартне відхилення: 3.4 літрів

Передбачення на завтра:
  З ймовірністю 68%: 38.4 — 45.2 літрів
  З ймовірністю 95%: 35.0 — 48.6 літрів
```

Тепер ви знаєте: якщо замовите 45 літрів, ви покриєте потребу в ~84% днів. Якщо 49 літрів — у ~95% днів. Це і є сила розуміння розподілу.

> Аналогія: Розподіл — це як прогноз погоди. Недостатньо знати «середня температура +15°C». Вам потрібен **діапазон ймовірностей**: «з ймовірністю 70% буде +12–18°C, з ймовірністю 95% — +8–22°C». Це допомагає вирішити, брати парасольку чи ні.

## Що таке розподіл випадкової величини?

**Розподіл випадкової величини** (*probability distribution*) — це математичне правило, яке описує, **наскільки ймовірне** кожне можливе значення випадкової величини.

Замість того, щоб дивитись на окремі числа (`[42, 38, 45, 41...]`), розподіл дає нам:
- Які значення **найчастіші** (пік розподілу)
- Наскільки **розкидані** дані (ширина розподілу)
- Чи є **асиметрія** (довгий хвіст з одного боку)
- Яка **ймовірність** потрапити в певний діапазон

### Два способи описати розподіл

#### 1. Для дискретних величин: Функція ймовірності (PMF)

**Функція ймовірності** (*Probability Mass Function*, PMF) — показує ймовірність кожного окремого значення.

Приклад: кидок чесного кубика

| Значення | 1   | 2   | 3   | 4   | 5   | 6   |
| :------: | :-: | :-: | :-: | :-: | :-: | :-: |
| P(X = x) | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |

Сума всіх ймовірностей = 1 (100%)

#### 2. Для неперервних величин: Функція щільності (PDF)

**Функція щільності ймовірності** (*Probability Density Function*, PDF) — показує **відносну ймовірність** значень у неперервному діапазоні.

::warning
**Критична різниця:** Для неперервної величини ймовірність **точного** значення завжди дорівнює нулю!

P(зріст = ровно 170.00000... см) = 0

Натомість ми розглядаємо ймовірність **діапазонів**:

P(169 ≤ зріст ≤ 171) = площа під кривою PDF на цьому інтервалі
::

### Візуальна різниця: PMF vs PDF

::jupyter-notebook{title="pmf_vs_pdf.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Порівняння PMF (дискретна) та PDF (неперервна)
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Графік 1: PMF для кидка двох кубиків (сума очок)
dice_sums = []
for i in range(1, 7):
    for j in range(1, 7):
        dice_sums.append(i + j)

values, counts = np.unique(dice_sums, return_counts=True)
probabilities = counts / len(dice_sums)

ax1.bar(values, probabilities, edgecolor='black', color='steelblue', alpha=0.7)
ax1.set_title('PMF: Сума двох кубиків (дискретна)', fontweight='bold', fontsize=12)
ax1.set_xlabel('Сума очок')
ax1.set_ylabel('Ймовірність P(X = x)')
ax1.set_xticks(values)
ax1.grid(axis='y', alpha=0.3)

# Графік 2: PDF для нормального розподілу
x = np.linspace(60, 140, 1000)
pdf = stats.norm.pdf(x, loc=100, scale=15)

ax2.plot(x, pdf, color='coral', linewidth=2)
ax2.fill_between(x, pdf, alpha=0.3, color='coral')
ax2.set_title('PDF: Зріст людей (неперервна)', fontweight='bold', fontsize=12)
ax2.set_xlabel('Зріст (см)')
ax2.set_ylabel('Щільність ймовірності')
ax2.grid(alpha=0.3)

# Позначимо діапазон P(90 ≤ X ≤ 110)
mask = (x >= 90) & (x <= 110)
ax2.fill_between(x[mask], pdf[mask], alpha=0.6, color='green', label='P(90 ≤ X ≤ 110)')
ax2.legend()

plt.tight_layout()
plt.show()

print("PMF (дискретна):")
print("  Кожен стовпець = ймовірність конкретного значення")
print("  Сума всіх стовпців = 1.0")
print("\nPDF (неперервна):")
print("  Висота кривої ≠ ймовірність (це щільність)")
print("  Ймовірність = площа під кривою на інтервалі")
prob_range = stats.norm.cdf(110, 100, 15) - stats.norm.cdf(90, 100, 15)
print(f"  P(90 ≤ зріст ≤ 110) = {prob_range:.3f} (зелена область)")
```

#output
```
PMF (дискретна):
  Кожен стовпець = ймовірність конкретного значення
  Сума всіх стовпців = 1.0

PDF (неперервна):
  Висота кривої ≠ ймовірність (це щільність)
  Ймовірність = площа під кривою на інтервалі
  P(90 ≤ зріст ≤ 110) = 0.495 (зелена область)
```
::

::

::note
**Ключові властивості будь-якого розподілу:**
1. Всі ймовірності **невід'ємні** (≥ 0)
2. Сума всіх ймовірностей (або інтеграл PDF) дорівнює **1** (100%)
3. Розподіл повністю визначає поведінку випадкової величини
::

## Рівномірний розподіл (Uniform Distribution)

**Рівномірний розподіл** (*uniform distribution*) — це розподіл, у якому **всі значення в діапазоні рівноймовірні**. Немає «улюблених» чи «рідкісних» значень — кожне має однакову ймовірність.

> Аналогія: Рівномірний розподіл — це як ідеальна рулетка з нескінченною кількістю секторів. Кожна точка на колі має однакову ймовірність. Немає «гарячих» чи «холодних» зон.

### Дискретний рівномірний розподіл

Найпростіший приклад — кидок чесного кубика. Кожна грань (1, 2, 3, 4, 5, 6) випадає з однаковою ймовірністю 1/6 ≈ 0.167.

::jupyter-notebook{title="discrete_uniform.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Дискретний рівномірний: симуляція 1000 кидків кубика
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Симулюємо 1000 кидків кубика
rolls = np.random.randint(1, 7, size=1000)

# Підрахунок частот
values, counts = np.unique(rolls, return_counts=True)
frequencies = counts / len(rolls)

# Візуалізація
plt.figure(figsize=(8, 5))
plt.bar(values, frequencies, edgecolor='black', color='steelblue', alpha=0.7)
plt.axhline(1/6, color='red', linestyle='--', linewidth=2, label='Теоретична ймовірність (1/6 ≈ 0.167)')
plt.xlabel('Результат кидка')
plt.ylabel('Частота (емпірична ймовірність)')
plt.title('Дискретний рівномірний розподіл: 1000 кидків кубика', fontweight='bold')
plt.xticks(values)
plt.ylim(0, 0.25)
plt.legend()
plt.grid(axis='y', alpha=0.3)
plt.show()

print("Частоти кожної грані:")
for v, f in zip(values, frequencies):
    diff = (f - 1/6) * 100
    print(f"  {v}: {f:.3f} (відхилення від теорії: {diff:+.1f}%)")
```

```
Частоти кожної грані:
  1: 0.161 (відхилення від теорії: -0.6%)
  2: 0.171 (відхилення від теорії: +0.4%)
  3: 0.162 (відхилення від теорії: -0.5%)
  4: 0.169 (відхилення від теорії: +0.2%)
  5: 0.169 (відхилення від теорії: +0.2%)
  6: 0.168 (відхилення від теорії: +0.1%)
```
::

::

**Властивості дискретного рівномірного розподілу:**

- **Кожне значення має однакову ймовірність**: P(X = k) = 1/n
- **Середнє**: :math-formula{tex="\\mu = \\frac{\\text{min} + \\text{max}}{2}" inline} (для кубика: (1+6)/2 = 3.5)
- **Застосування**: моделювання випадкового вибору, генерація випадкових ID, lottery systems

### Неперервний рівномірний розподіл

Для неперервних даних рівномірний розподіл означає, що **кожен інтервал однакової ширини** має однакову ймовірність.

**Позначення**: :math-formula{tex="X \\sim \\text{Uniform}(a, b)" inline} або :math-formula{tex="X \\sim U(a, b)" inline}

**Функція щільності**:

::math-formula
f(x) = \\begin{cases}
\\frac{1}{b - a}, & a \\leq x \\leq b \\\\
0, & \\text{інакше}
\\end{cases}
::

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Генеруємо 10000 випадкових чисел від 0 до 10
data = np.random.uniform(0, 10, size=10000)

# Візуалізація
plt.figure(figsize=(10, 5))
plt.hist(data, bins=50, edgecolor='black', alpha=0.7, color='coral', density=True)
plt.axhline(1/10, color='red', linestyle='--', linewidth=2, label='Теоретична щільність (1/10 = 0.1)')
plt.xlabel('Значення')
plt.ylabel('Щільність ймовірності')
plt.title('Неперервний рівномірний розподіл: Uniform(0, 10)', fontweight='bold')
plt.xlim(-1, 11)
plt.ylim(0, 0.15)
plt.legend()
plt.grid(alpha=0.3)
plt.show()

# Теоретичні vs емпіричні характеристики
theoretical_mean = (0 + 10) / 2
theoretical_std = (10 - 0) / np.sqrt(12)

print("Порівняння теорії та практики:")
print(f"  Середнє:")
print(f"    Теоретичне: {theoretical_mean:.2f}")
print(f"    Емпіричне:  {data.mean():.2f}")
print(f"  Стандартне відхилення:")
print(f"    Теоретичне: {theoretical_std:.2f}")
print(f"    Емпіричне:  {data.std():.2f}")
```

## Нормальний розподіл (Normal / Gaussian Distribution)

**Нормальний розподіл** (також **розподіл Гауса**) — найважливіший розподіл у статистиці та Machine Learning. Його форма — знаменита **дзвоноподібна крива**.

### Чому нормальний розподіл такий важливий?

**1. Центральна гранична теорема (Central Limit Theorem, CLT)**

Якщо взяти **суму** (або **середнє**) багатьох незалежних випадкових величин, результат **наближається** до нормального розподілу, **незалежно** від початкового розподілу цих величин.

> Аналогія: Уявіть, що 100 людей кидають монети. Підрахуйте загальну кількість «орлів». Повторіть експеримент 1000 разів. Розподіл цих сум буде дзвоноподібним, навіть якщо монета має лише два стани (0 або 1).

**2. Природність**

Багато явищ у природі мають нормальний або близький до нормального розподіл:
- Зріст людей (чоловіки: μ ≈ 175 см, σ ≈ 7 см)
- Вага при народженні
- IQ тести (спеціально калібровані: μ = 100, σ = 15)
- Похибки вимірювань (якщо прилад правильно відкалібрований)
- Результати тестів у великій групі студентів

**3. Математична зручність**

Нормальний розподіл легко описувати математично. Багато статистичних тестів та ML-алгоритмів припускають нормальність даних.

### Параметри нормального розподілу

Нормальний розподіл **повністю визначається** двома параметрами:

- **μ** (мю) — **середнє** (математичне сподівання), центр розподілу
- **σ** (сігма) — **стандартне відхилення**, розкид даних навколо центру

**Позначення**: :math-formula{tex="X \\sim \\mathcal{N}(\\mu, \\sigma^2)" inline} (читається: «X має нормальний розподіл з параметрами μ та σ²»)

**Функція щільності PDF**:

::math-formula
f(x) = \\frac{1}{\\sigma\\sqrt{2\\pi}} e^{-\\frac{1}{2}\\left(\\frac{x - \\mu}{\\sigma}\\right)^2}
::

Не лякайтеся формули — NumPy зробить все за вас!

### Візуальний вплив параметрів

::jupyter-notebook{title="normal_parameters.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Вплив μ (середнє) та σ (std) на форму розподілу
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

x = np.linspace(-10, 20, 1000)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Графік 1: Різні μ (центр), однакове σ
ax1.plot(x, stats.norm.pdf(x, 0, 2), label='μ=0, σ=2', linewidth=2)
ax1.plot(x, stats.norm.pdf(x, 5, 2), label='μ=5, σ=2', linewidth=2)
ax1.plot(x, stats.norm.pdf(x, 10, 2), label='μ=10, σ=2', linewidth=2)
ax1.set_title('Вплив μ: зсув центру розподілу', fontweight='bold')
ax1.set_xlabel('x')
ax1.set_ylabel('Щільність ймовірності')
ax1.legend()
ax1.grid(alpha=0.3)

# Графік 2: Однакове μ (центр), різні σ (розкид)
ax2.plot(x, stats.norm.pdf(x, 5, 1), label='μ=5, σ=1', linewidth=2)
ax2.plot(x, stats.norm.pdf(x, 5, 2), label='μ=5, σ=2', linewidth=2)
ax2.plot(x, stats.norm.pdf(x, 5, 4), label='μ=5, σ=4', linewidth=2)
ax2.set_title('Вплив σ: ширина розподілу', fontweight='bold')
ax2.set_xlabel('x')
ax2.set_ylabel('Щільність ймовірності')
ax2.legend()
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

print("Висновки:")
print("  μ (середнє) → зміщує центр кривої вліво/вправо")
print("  σ (стд. відхилення) → робить криву вужчою (σ↓) або ширшою (σ↑)")
print("  Більше σ → більша варіація → менша передбачуваність")
```

### Правило 68-95-99.7 (Емпіричне правило)

Це **найважливіше** правило для нормального розподілу, яке потрібно вивчити напам'ять:

::math-formula
\\begin{aligned}
P(\\mu - 1\\sigma \\leq X \\leq \\mu + 1\\sigma) &\\approx 68\\% \\\\
P(\\mu - 2\\sigma \\leq X \\leq \\mu + 2\\sigma) &\\approx 95\\% \\\\
P(\\mu - 3\\sigma \\leq X \\leq \\mu + 3\\sigma) &\\approx 99.7\\%
\\end{aligned}
::

**Інтерпретація:**
- **68%** даних лежать у межах **±1σ** від середнього
- **95%** даних лежать у межах **±2σ** від середнього
- **99.7%** даних лежать у межах **±3σ** від середнього

> Аналогія: Якщо зріст людей має нормальний розподіл з μ = 170 см, σ = 10 см, то:
> - **68%** людей мають зріст **160–180 см** (±1σ)
> - **95%** людей мають зріст **150–190 см** (±2σ)
> - **99.7%** людей мають зріст **140–200 см** (±3σ)
> 
> Людина з зростом 210 см (4σ) — екстремально рідкісна (0.003% населення, або 3 на 100 000)!

```python
ax.plot(x, pdf, 'r-', linewidth=2, label='Теоретична крива')

    ax.fill_between(x[mask], pdf[mask], alpha=alphas[i-1], color=colors[i-1], label=labels[i-1])

# Позначення меж σ
for i in range(1, 4):
    ax.axvline(mu - i*sigma, color='orange', linestyle=':', linewidth=1.5, alpha=0.7)
    ax.axvline(mu + i*sigma, color='orange', linestyle=':', linewidth=1.5, alpha=0.7)

ax.set_xlabel('Значення', fontsize=12)
ax.set_ylabel('Щільність ймовірності', fontsize=12)
ax.set_title(f'Правило 68-95-99.7 для N({mu}, {sigma}²)', fontweight='bold', fontsize=14)
ax.legend(loc='upper right')
ax.grid(alpha=0.3)
plt.show()

# Емпірична перевірка правила
within_1sigma = np.sum((data >= mu - sigma) & (data <= mu + sigma)) / len(data)
within_2sigma = np.sum((data >= mu - 2*sigma) & (data <= mu + 2*sigma)) / len(data)
within_3sigma = np.sum((data >= mu - 3*sigma) & (data <= mu + 3*sigma)) / len(data)

print("Емпірична перевірка правила 68-95-99.7:")
print(f"  μ±1σ ({mu-sigma}–{mu+sigma}): {within_1sigma:.1%} (теоретично 68%)")
print(f"  μ±2σ ({mu-2*sigma}–{mu+2*sigma}): {within_2sigma:.1%} (теоретично 95%)")
print(f"  μ±3σ ({mu-3*sigma}–{mu+3*sigma}): {within_3sigma:.1%} (теоретично 99.7%)")
```

### Стандартний нормальний розподіл та Z-оцінка

**Стандартний нормальний розподіл** (*standard normal distribution*) — це спеціальний випадок з **μ = 0** та **σ = 1**.

Позначення: :math-formula{tex="Z \\sim \\mathcal{N}(0, 1)" inline}

**Z-оцінка** (*Z-score*, стандартизація) — перетворення будь-якого нормального розподілу на стандартний:

::math-formula
z = \\frac{x - \\mu}{\\sigma}
::

**Інтерпретація Z-оцінки:**
- z = 0 → значення дорівнює середньому
- z = 1 → значення на 1 стандартне відхилення вище середнього
- z = −2 → значення на 2 стандартні відхилення нижче середнього

```python
        interpret = f"{z:.2f}σ вище середнього"
    elif z < 0:
        interpret = f"{abs(z):.2f}σ нижче середнього"
    else:
        interpret = "дорівнює середньому"
    
    print(f"{h:<12} {z:>+6.2f}       {interpret}")

print(f"\nСереднє: {mean_height:.1f} см")
print(f"Стандартне відхилення: {std_height:.2f} см")

# Приклад: яка людина вища?
person_a_height = 185  # 185 см
person_b_iq = 130      # IQ 130 (μ=100, σ=15 для IQ тестів)

z_height = (person_a_height - mean_height) / std_height
z_iq = (person_b_iq - 100) / 15

print(f"\nПорівняння відносних показників:")
print(f"  Людина A: зріст {person_a_height} см → Z = {z_height:+.2f}")
print(f"  Людина B: IQ {person_b_iq} → Z = {z_iq:+.2f}")
```

## Розподіл Пуассона (Poisson Distribution)

**Розподіл Пуассона** моделює **кількість подій**, що відбуваються за фіксований інтервал часу або простору, коли події:
- Відбуваються **незалежно** одна від одної
- Мають **постійну середню частоту** (λ)
- **Не можуть** відбутися одночасно

**Параметр:** λ (лямбда) — середня кількість подій за інтервал

**Формула PMF:**

::math-formula
P(X = k) = \\frac{\\lambda^k e^{-\\lambda}}{k!}
::

Де k = 0, 1, 2, 3, ... (кількість подій)

### Приклади з реального світу

1. **Кількість дзвінків у call-центр за годину** (λ = 5 дзвінків/год)
2. **Кількість відвідувачів сайту за хвилину** (λ = 12 відвідувачів/хв)
3. **Кількість помилок на сторінці коду** (λ = 0.5 помилок/сторінка)
4. **Кількість аварій на ділянці дороги за рік** (λ = 3 аварії/рік)
5. **Кількість радіоактивних розпадів за секунду** (λ = 50 розпадів/сек)

> Аналогія: Ви працюєте в піцерії. У середньому приходить 4 замовлення на годину. Розподіл Пуассона дає відповідь: «Яка ймовірність, що прийде ровно 6 замовлень за наступну годину?» або «З якою ймовірністю не буде жодного замовлення (0)?»

### Властивості розподілу Пуассона

| Властивість               | Значення                          |
| :------------------------ | :-------------------------------- |
| Середнє (μ)               | λ                                 |
| Дисперсія (σ²)            | λ                                 |
| Стандартне відхилення (σ) | √λ                                |
| Можливі значення          | 0, 1, 2, 3, ... (невід'ємні цілі)|

**Унікальна властивість:** середнє = дисперсія = λ

::tip
**Коли використовувати Пуассона:**
- ✅ Лічимо **рідкісні події** (аварії, помилки, відмови)
- ✅ Події відбуваються **незалежно**
- ✅ Середня частота **постійна** протягом часу
- ✅ Не може бути **більше однієї події одночасно**

**Приклад застосування в ML:**
- Прогнозування попиту (кількість замовлень)
- Моделювання кліків на рекламу
- Аналіз частоти відмов обладнання
::

## Інші важливі розподіли (короткий огляд)

### Експоненціальний розподіл

Моделює **час між подіями** у процесі Пуассона. Якщо події відбуваються з частотою λ (Пуассон), то час очікування наступної події має експоненціальний розподіл.

**Приклад:** Якщо дзвінки приходять зі швидкістю 5/год (Пуассон), то час між дзвінками — експоненціальний (середній час = 12 хв).

**Генерація:** `np.random.exponential(scale=1/lambda, size)`

### Біноміальний розподіл

Моделює **кількість успіхів** у серії **n** незалежних експериментів, кожен з ймовірністю успіху **p**.

**Приклад:** Кидаємо монету 10 разів (n=10, p=0.5). Скільки разів випаде «орел»?

**Генерація:** `np.random.binomial(n, p, size)`

### Логнормальний розподіл

Якщо **логарифм** величини має нормальний розподіл, то сама величина має логнормальний розподіл.

**Приклад:** Доходи населення, ціни на акції, розміри файлів — часто логнормальні (позитивні дані зі скошенням вправо).

**Генерація:** `np.random.lognormal(mean, sigma, size)`

## Резюме: ключові takeaways

::card-group

::card{title="Розподіл = повна картина даних" icon="i-lucide-map"}
Розподіл описує не лише центр (середнє), а й форму, розкид та ймовірності всіх можливих значень.
::

::card{title="Нормальний — король розподілів" icon="i-lucide-crown"}
Дзвоноподібна крива. Параметри: μ (центр), σ (ширина). **Правило 68-95-99.7** — найважливіше правило статистики. Z-оцінка для стандартизації.
::

::card{title="Рівномірний — всі рівні" icon="i-lucide-equal"}
Кожне значення однаково ймовірне. Рідко в природі, часто в симуляціях та ініціалізації.
::

::card{title="Пуассона — лічильник рідкісних подій" icon="i-lucide-activity"}
Моделює кількість подій за час. Параметр λ = середнє = дисперсія. При великому λ наближається до нормального.
::

::card{title="Центральна гранична теорема" icon="i-lucide-trending-up"}
Сума/середнє багатьох випадкових величин → нормальний розподіл (незалежно від початкового розподілу). Фундамент статистики!
::

::card{title="Застосування в ML" icon="i-lucide-brain-circuit"}
- Припущення алгоритмів (лінійна регресія припускає нормальність залишків)
- Ініціалізація ваг нейромереж (нормальний або рівномірний)
- Виявлення аномалій (|z| > 3)
- Генерація синтетичних даних
::
