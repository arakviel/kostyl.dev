## Що таке викид (Outlier)?

**Викид** (*outlier*) — це спостереження, яке **значно відрізняється** від решти даних. Воно лежить далеко від основної маси значень.

### Види викидів

1. **Природні викиди** (*natural outliers*) — реальні, але рідкісні значення
   - Білл Гейтс у датасеті доходів американців
   - Землетрус магнітудою 9.0 (99.9% землетрусів < 5.0)
   - Геніальний студент з IQ 160 у класі

2. **Помилки вимірювання** (*measurement errors*) — технічні збої, людські помилки
   - Сенсор записав температуру −999°C (фізично неможливо)
   - Оператор ввів 1,000,000 замість 1,000 (зайва цифра)
   - Вік людини = 200 років (помилка введення)

3. **Помилки обробки даних** (*data processing errors*)
   - Об'єднання датасетів з різними одиницями вимірювання (метри + сантиметри)
   - Дублювання запису

### Чому викиди важливі?

::card-group

::card{title="❌ Шкода від викидів" icon="i-lucide-alert-triangle"}

- **Спотворюють середнє** та стандартне відхилення
- **Порушують припущення** ML-алгоритмів (нормальність, лінійність)
- **Погіршують якість моделей** (особливо лінійна регресія, KNN)
- **Вводять в оману** при інтерпретації даних

::

::card{title="✅ Цінність викидів" icon="i-lucide-sparkles"}

- **Сигнал аномалій** (шахрайство, несправність обладнання)
- **Рідкісні, але важливі події** (епідемія, фінансова криза)
- **Нові знання** про систему (екстремальні умови)

::

::

::warning
**Критична помилка:** Автоматичне видалення всіх викидів без аналізу!

Перед видаленням викиду запитайте:
1. Це **помилка вимірювання** (можна видалити) чи **реальне значення** (потрібно зберегти)?
2. Чи це **цільова аномалія** (наприклад, шахрайство у фінансових даних)?
3. Чи модель має бути **робастною** до екстремальних значень?

**Золоте правило:** Розумійте **природу** викиду перед його обробкою!

## Метод 1: IQR (Міжквартильний розмах)

**Метод IQR** (*Interquartile Range*) — найпопулярніший робастний метод виявлення викидів, заснований на квартилях.

### Крок за кроком

1. Обчислити **Q1** (25-й перцентиль) та **Q3** (75-й перцентиль)
2. Обчислити **IQR** = Q3 − Q1 (міжквартильний розмах)
3. Визначити **межі**:
   - Нижня межа: Q1 − 1.5 × IQR
   - Верхня межа: Q3 + 1.5 × IQR
4. Значення **поза межами** = викиди

::math-formula
\\begin{aligned}
\\text{IQR} &= Q_3 - Q_1 \\\\
\\text{Нижня межа} &= Q_1 - 1.5 \\times \\text{IQR} \\\\
\\text{Верхня межа} &= Q_3 + 1.5 \\times \\text{IQR}
\\end{aligned}
::

> Чому 1.5? Це емпіричне правило, запропоноване Джоном Тьюкі. Воно виявляє ~0.7% найекстремальніших значень у нормальному розподілі. Іноді використовують 3.0 для більш консервативного виявлення.

::jupyter-notebook{title="iqr_method.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Метод IQR: виявлення викидів
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Генеруємо дані з викидами
data = np.concatenate([
    np.random.normal(50, 10, 95),  # Основна маса
    np.array([10, 15, 90, 95, 100])  # Викиди
])

# Крок 1: Обчислюємо квартилі
Q1 = np.percentile(data, 25)
Q3 = np.percentile(data, 75)
IQR = Q3 - Q1

# Крок 2: Обчислюємо межі
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# Крок 3: Виявляємо викиди
outliers = data[(data < lower_bound) | (data > upper_bound)]
inliers = data[(data >= lower_bound) & (data <= upper_bound)]

# Візуалізація
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Графік 1: Гістограма з межами
ax1.hist(data, bins=30, edgecolor='black', alpha=0.7, color='lightblue')
ax1.axvline(Q1, color='orange', linestyle='--', linewidth=2, label=f'Q1 = {Q1:.1f}')
ax1.axvline(Q3, color='orange', linestyle='--', linewidth=2, label=f'Q3 = {Q3:.1f}')
ax1.axvline(lower_bound, color='red', linestyle='-', linewidth=2, label=f'Нижня межа = {lower_bound:.1f}')
ax1.axvline(upper_bound, color='red', linestyle='-', linewidth=2, label=f'Верхня межа = {upper_bound:.1f}')
ax1.set_xlabel('Значення', fontsize=12)
ax1.set_ylabel('Частота', fontsize=12)
ax1.set_title('Метод IQR: межі викидів', fontweight='bold')
ax1.legend(loc='upper left')
ax1.grid(alpha=0.3)

# Графік 2: Точки (inliers vs outliers)
ax2.scatter(range(len(inliers)), inliers, c='green', alpha=0.6, s=50, edgecolors='black', linewidths=0.5, label='Нормальні')
ax2.scatter(range(len(inliers), len(data)), outliers, c='red', s=100, edgecolors='black', linewidths=1, label='Викиди', marker='^')
ax2.axhline(lower_bound, color='red', linestyle='--', linewidth=1.5, alpha=0.7)
ax2.axhline(upper_bound, color='red', linestyle='--', linewidth=1.5, alpha=0.7)
ax2.set_xlabel('Індекс', fontsize=12)
ax2.set_ylabel('Значення', fontsize=12)
ax2.set_title('Виявлені викиди', fontweight='bold')
ax2.legend()
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

print("📊 Результати методу IQR:\n")
print(f"  Q1 (25-й перцентиль): {Q1:.2f}")
print(f"  Q3 (75-й перцентиль): {Q3:.2f}")
print(f"  IQR: {IQR:.2f}")
print(f"  Нижня межа: {lower_bound:.2f}")
print(f"  Верхня межа: {upper_bound:.2f}")
print(f"\n🔍 Виявлено викидів: {len(outliers)} / {len(data)} ({len(outliers)/len(data)*100:.1f}%)")
print(f"  Викиди: {sorted(outliers)}")
```

### Box Plot (діаграма «ящик з вусами»)

**Box plot** — найкращий спосіб візуалізувати викиди методом IQR. Він показує:
- **Ящик** (box) — від Q1 до Q3 (50% середніх даних)
- **Лінія всередині ящика** — медіана (Q2)
- **Вуса** (whiskers) — від Q1 − 1.5×IQR до Q3 + 1.5×IQR
- **Точки поза вусами** — викиди

::jupyter-notebook{title="box_plot_visualization.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}

::

::jupyter-cell{executionCount="1"}

## Метод 2: Z-Score (Стандартизація)

**Метод Z-score** виявляє викиди через **стандартні відхилення** від середнього. Підходить для **нормально розподілених** даних.

### Алгоритм

1. Обчислити **Z-оцінку** для кожного значення:

::math-formula
z = \\frac{x - \\mu}{\\sigma}
::

2. Визначити **поріг** (зазвичай |z| > 3)
3. Значення з |z| > поріг = викиди

**Інтуїція:** Згадайте правило 68-95-99.7:
- 99.7% даних лежать у межах μ ± 3σ
- Отже, |z| > 3 → значення екстремально рідкісне (< 0.3% ймовірність)

::jupyter-notebook{title="z_score_method.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Метод Z-score: виявлення викидів
::

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Генеруємо нормально розподілені дані з викидами
data = np.concatenate([
    np.random.normal(100, 15, 95),  # Основна маса N(100, 15²)
    np.array([40, 45, 160, 165, 170])  # Викиди
])

# Обчислюємо Z-оцінки
mean = data.mean()
std = data.std()
z_scores = (data - mean) / std

# Визначаємо поріг (зазвичай 3)
threshold = 3
outliers_mask = np.abs(z_scores) > threshold

outliers = data[outliers_mask]
inliers = data[~outliers_mask]
z_outliers = z_scores[outliers_mask]
z_inliers = z_scores[~outliers_mask]

# Візуалізація
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Графік 1: Оригінальні дані
ax1.scatter(range(len(inliers)), inliers, c='green', alpha=0.6, s=50, edgecolors='black', linewidths=0.5, label='Нормальні')
ax1.scatter(np.where(outliers_mask)[0], outliers, c='red', s=100, edgecolors='black', linewidths=1, label='Викиди', marker='^')
ax1.axhline(mean, color='blue', linestyle='--', linewidth=2, label=f'μ = {mean:.1f}')
ax1.axhline(mean + 3*std, color='red', linestyle='--', linewidth=1.5, alpha=0.7, label=f'μ+3σ = {mean + 3*std:.1f}')
ax1.axhline(mean - 3*std, color='red', linestyle='--', linewidth=1.5, alpha=0.7, label=f'μ-3σ = {mean - 3*std:.1f}')
ax1.set_xlabel('Індекс', fontsize=12)
ax1.set_ylabel('Значення', fontsize=12)
ax1.set_title('Оригінальні дані з межами ±3σ', fontweight='bold')
ax1.legend()
ax1.grid(alpha=0.3)

# Графік 2: Z-оцінки
ax2.scatter(range(len(z_inliers)), z_inliers, c='green', alpha=0.6, s=50, edgecolors='black', linewidths=0.5, label='Нормальні')
ax2.scatter(np.where(outliers_mask)[0], z_outliers, c='red', s=100, edgecolors='black', linewidths=1, label='Викиди', marker='^')
ax2.axhline(0, color='blue', linestyle='--', linewidth=2, label='z = 0 (середнє)')
ax2.axhline(3, color='red', linestyle='--', linewidth=1.5, alpha=0.7, label='z = +3')
ax2.axhline(-3, color='red', linestyle='--', linewidth=1.5, alpha=0.7, label='z = -3')
ax2.set_xlabel('Індекс', fontsize=12)
ax2.set_ylabel('Z-оцінка', fontsize=12)
ax2.set_title('Z-оцінки (стандартизовані)', fontweight='bold')
ax2.legend()
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

print("📊 Результати методу Z-score:\n")
print(f"  Середнє (μ): {mean:.2f}")
print(f"  Стандартне відхилення (σ): {std:.2f}")
print(f"  Поріг: |z| > {threshold}")
print(f"\n🔍 Виявлено викидів: {outliers_mask.sum()} / {len(data)} ({outliers_mask.sum()/len(data)*100:.1f}%)")
print(f"\n  Викиди (значення → Z-оцінка):")
for val, z in zip(outliers, z_outliers):
    print(f"    {val:.1f} → z = {z:+.2f}")
```

::warning
**Важлива пастка методу Z-score:**

Метод Z-score **сам залежить від викидів**! Викиди впливають на середнє та стандартне відхилення, що може **приховати** екстремальні значення.

**Приклад:** Якщо є один дуже великий викид, він збільшує μ та σ. Тоді його власна Z-оцінка може виявитися < 3, і він **не буде виявлений**!

**Рішення:**
- Використовуйте **робастні оцінки** (медіану замість середнього, MAD замість σ)
- Або спочатку застосуйте метод IQR, потім Z-score на очищених даних

### Порівняння порогів Z-score

::jupyter-notebook{title="z_score_thresholds.ipynb" kernel="Python 3 (ipykernel)" executionCount="1"}

```python
import numpy as np
from scipy import stats

np.random.seed(42)
data = np.random.normal(100, 15, 1000)

thresholds = [2, 2.5, 3, 3.5]

print("📊 Вплив порогу Z-score на виявлення викидів:\n")
print(f"{'Поріг |z|':<12} {'Викидів':<10} {'%':<8} Теоретично (для N(0,1))")
print("-" * 60)

for thresh in thresholds:
    z_scores = np.abs((data - data.mean()) / data.std())
    outliers_count = (z_scores > thresh).sum()
    outliers_pct = outliers_count / len(data) * 100
    
    # Теоретична ймовірність для нормального розподілу
    theoretical_pct = (1 - stats.norm.cdf(thresh)) * 2 * 100
    
    print(f"  >{thresh:<10} {outliers_count:<10} {outliers_pct:>5.1f}%   ~{theoretical_pct:.2f}%")

print("\n💡 Висновок:")
print("  Більший поріг → менше викидів (консервативний підхід)")
print("  Менший поріг → більше викидів (агресивний підхід)")
print("  Стандарт: |z| > 3 (виявляє ~0.3% найекстремальніших значень)")
```

## Стратегії обробки викидів

Після виявлення викидів постає питання: **що з ними робити?** Універсального рішення немає — залежить від контексту, типу даних та цілей аналізу.

### 1. Видалення (Removal)

**Ідея:** Просто видалити рядки з викидами з датасету.

**Коли використовувати:**
- ✅ Викид — **явна помилка** (сенсор показав −999°C, вік = 200 років)
- ✅ Викидів **мало** (< 5% даних)
- ✅ Видалення не зменшує датасет критично

**Обережно:**
- ❌ Втрата інформації
- ❌ Може спотворити розподіл (якщо викидів багато)
- ❌ Не підходить, якщо викид — **цільова аномалія** (шахрайство, несправність)

::jupyter-notebook{title="outlier_removal.ipynb" kernel="Python 3 (ipykernel)" executionCount="1"}

```python
import numpy as np

np.random.seed(42)

# Генеруємо дані
data = np.concatenate([
    np.random.normal(50, 10, 95),
    np.array([10, 15, 90, 95, 100])  # 5 викидів
])

# Видалення через IQR
Q1 = np.percentile(data, 25)
Q3 = np.percentile(data, 75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

data_clean = data[(data >= lower_bound) & (data <= upper_bound)]

print("📊 Результати видалення викидів:\n")
print(f"  Розмір до:  {len(data)} зразків")
print(f"  Розмір після: {len(data_clean)} зразків")
print(f"  Видалено: {len(data) - len(data_clean)} зразків ({(len(data) - len(data_clean))/len(data)*100:.1f}%)")
print(f"\n  Середнє до:  {data.mean():.2f}")
print(f"  Середнє після: {data_clean.mean():.2f}")
print(f"  Різниця: {abs(data.mean() - data_clean.mean()):.2f}")
```

### 2. Обрізання (Capping / Winsorization)

**Ідея:** Замінити викиди на **граничні допустимі значення** (нижню/верхню межу).

**Приклад:** Якщо верхня межа = 80, всі значення > 80 стають 80.

**Коли використовувати:**
- ✅ Важливо **зберегти всі рядки** датасету
- ✅ Викид — реальне значення, але екстремальне
- ✅ Модель чутлива до викидів (лінійна регресія)

::jupyter-notebook{title="outlier_capping.ipynb" kernel="Python 3 (ipykernel)" executionCount="1"}

```python
import numpy as np

data_capped = np.copy(data)
data_capped[data_capped < lower_bound] = lower_bound
data_capped[data_capped > upper_bound] = upper_bound
```

### 3. Трансформація (Transformation)

**Ідея:** Застосувати математичну трансформацію, яка **зменшує вплив** викидів.

**Популярні трансформації:**
- **Логарифм:** `log(x)` — стискає великі значення
- **Квадратний корінь:** `√x` — м'якша, ніж логарифм
- **Box-Cox** — автоматичний вибір оптимальної трансформації

**Коли використовувати:**
- ✅ Дані **скошені** (довгий хвіст)
- ✅ Викиди — **природні**, але екстремальні (доходи, ціни на акції)
- ✅ Потрібно наблизити до нормального розподілу

### 4. Заміна на імпутацію (Imputation)

**Ідея:** Замінити викиди на **середнє**, **медіану** або **передбачене значення**.

**Коли використовувати:**
- ✅ Викид — помилка, але видалити рядок не можна (мало даних)
- ✅ Важливіша повнота датасету, ніж точність окремих значень

**Методи:**
- Середнє / Медіана
- Інтерполяція (для часових рядів)
- Модельна імпутація (KNN, регресія)

### 5. Залишити як є

**Ідея:** Нічого не робити з викидами.

**Коли використовувати:**
- ✅ Викид — **цільова аномалія** (виявлення шахрайства, несправностей)
- ✅ Використовуєте **робастні алгоритми** (дерева рішень, Random Forest, Gradient Boosting)
- ✅ Викид несе **важливу інформацію**

::tip
**Рекомендації за типом ML-моделі:**

**Чутливі до викидів:**

- KNN → стандартизуйте + видаліть екстремальні
- SVM → стандартизуйте

**Робастні (стійкі) до викидів:**
- Дерева рішень → можна залишити
- Random Forest → можна залишити
- Gradient Boosting → можна залишити
- Медіанна регресія → спеціально для викидів

## Порівняння методів IQR vs Z-Score

::jupyter-notebook{title="iqr_vs_zscore_comparison.ipynb" kernel="Python 3 (ipykernel)" executionCount="1"}

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Генеруємо три типи даних
data_normal = np.random.normal(50, 10, 100)
data_skewed = np.random.exponential(20, 100)
data_with_outliers = np.concatenate([np.random.normal(50, 10, 95), np.array([10, 15, 90, 95, 100])])

datasets = [data_normal, data_skewed, data_with_outliers]
titles = ['Нормальний розподіл', 'Скошений розподіл', 'З викидами']

fig, axes = plt.subplots(3, 2, figsize=(14, 10))

for row, (data, title) in enumerate(zip(datasets, titles)):
    # Метод IQR
    Q1 = np.percentile(data, 25)
    Q3 = np.percentile(data, 75)
    IQR = Q3 - Q1
    iqr_lower = Q1 - 1.5 * IQR
    iqr_upper = Q3 + 1.5 * IQR
    iqr_outliers = (data < iqr_lower) | (data > iqr_upper)
    
    # Метод Z-score
    mean = data.mean()
    std = data.std()
    z_scores = np.abs((data - mean) / std)
    z_outliers = z_scores > 3
    
    # Графік IQR
    axes[row, 0].scatter(range(len(data)), data, c=['red' if o else 'green' for o in iqr_outliers], 
                         s=50, alpha=0.6, edgecolors='black', linewidths=0.5)
    axes[row, 0].axhline(iqr_lower, color='red', linestyle='--', linewidth=1.5, label='IQR межі')
    axes[row, 0].axhline(iqr_upper, color='red', linestyle='--', linewidth=1.5)
    axes[row, 0].set_title(f'{title} — Метод IQR', fontweight='bold')
    axes[row, 0].set_ylabel('Значення')
    axes[row, 0].legend()
    axes[row, 0].grid(alpha=0.3)
    axes[row, 0].text(0.02, 0.98, f'Викидів: {iqr_outliers.sum()} ({iqr_outliers.sum()/len(data)*100:.0f}%)', 
                      transform=axes[row, 0].transAxes, va='top', fontsize=10,
                      bbox=dict(boxstyle='round', facecolor='yellow', alpha=0.7))
    
    # Графік Z-score
    axes[row, 1].scatter(range(len(data)), data, c=['red' if o else 'green' for o in z_outliers], 
                         s=50, alpha=0.6, edgecolors='black', linewidths=0.5)
    axes[row, 1].axhline(mean + 3*std, color='red', linestyle='--', linewidth=1.5, label='±3σ межі')
    axes[row, 1].axhline(mean - 3*std, color='red', linestyle='--', linewidth=1.5)
    axes[row, 1].set_title(f'{title} — Метод Z-score', fontweight='bold')
    axes[row, 1].set_ylabel('Значення')
    axes[row, 1].legend()
    axes[row, 1].grid(alpha=0.3)
    axes[row, 1].text(0.02, 0.98, f'Викидів: {z_outliers.sum()} ({z_outliers.sum()/len(data)*100:.0f}%)', 
                      transform=axes[row, 1].transAxes, va='top', fontsize=10,
                      bbox=dict(boxstyle='round', facecolor='yellow', alpha=0.7))

plt.tight_layout()
plt.show()

print("📊 Висновки порівняння:\n")
print("  IQR (Міжквартильний розмах):")
print("    ✅ Робастний — не залежить від викидів")
print("    ✅ Працює для будь-яких розподілів")
print("    ✅ Візуалізація через box plot")
print("    ❌ Може виявити більше 'хибних' викидів у довгих хвостах\n")
print("  Z-Score (Стандартизація):")
print("    ✅ Інтуїтивний (скільки σ від середнього)")
print("    ✅ Підходить для нормальних розподілів")
print("    ❌ Не робастний — залежить від викидів")
print("    ❌ Не підходить для скошених розподілів")
```

```python
from sklearn.tree import DecisionTreeRegressor

ax1.grid(alpha=0.3)

# Дерево рішень
ax2.scatter(X_clean, y_clean, c='green', alpha=0.6, s=50, edgecolors='black', linewidths=0.5, label='Чисті дані')
ax2.scatter(X_outliers, y_outliers, c='red', s=150, marker='^', edgecolors='black', linewidths=1, label='Викиди')
ax2.plot(X_test, y_tree_clean, 'b-', linewidth=2, label='Модель (без викидів)')
ax2.plot(X_test, y_tree_outliers, 'r--', linewidth=2, label='Модель (з викидами)')
ax2.set_xlabel('X', fontsize=12)
ax2.set_ylabel('Y', fontsize=12)
ax2.set_title('Дерево рішень: РОБАСТНЕ до викидів', fontweight='bold')
ax2.legend()
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

print("📊 Вплив викидів на моделі:\n")
print("  Лінійна регресія:")
print("    ❌ Викиди драматично змінили нахил лінії")
print("    ❌ Модель намагається 'підлаштуватися' під викиди")
print("    ❌ Погіршилася якість передбачень для основної маси даних\n")
print("  Дерево рішень:")
print("    ✅ Модель майже не змінилася")
print("    ✅ Викиди потрапили в окремі листи дерева")
print("    ✅ Не впливають на передбачення для основної маси даних")
```

## Резюме: ключові takeaways

::card-group

::card{title="Викид = екстремальне значення" icon="i-lucide-alert-triangle"}
Викид — спостереження, що значно відрізняється від решти даних. Може бути помилкою або цінною аномалією.
::

::card{title="Метод IQR — робастний" icon="i-lucide-box"}
Виявлення через квартилі: Q1 − 1.5×IQR та Q3 + 1.5×IQR. Не залежить від викидів. Box plot — ідеальна візуалізація.
::

::card{title="Метод Z-score — для нормальних даних" icon="i-lucide-activity"}
Виявлення через стандартні відхилення: |z| > 3. Інтуїтивний, але НЕ робастний (сам залежить від викидів).
::

::card{title="5 стратегій обробки" icon="i-lucide-settings"}
Видалення, обрізання, трансформація, імпутація, залишити як є. Вибір залежить від контексту та цілей.
::

::card{title="Вплив на ML" icon="i-lucide-brain"}
Лінійна регресія, KNN, SVM — чутливі. Дерева, Random Forest, Gradient Boosting — робастні. Завжди аналізуйте викиди перед тренуванням!
::

::card{title="Золоте правило" icon="i-lucide-lightbulb"}
Розумійте **природу** викиду перед обробкою. Помилка вимірювання (видалити) ≠ реальна аномалія (зберегти).
::
