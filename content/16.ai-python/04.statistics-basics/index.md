# Основи статистики для Machine Learning

::note{icon="i-lucide-info"}
**Про цей розділ:** Статистика — це мова даних. Без розуміння середнього, медіани, дисперсії та розподілів неможливо аналізувати дані та будувати ML-моделі. Цей модуль дає необхідний мінімум для впевненої роботи з даними.
::

---

## Чому статистика критична для ML?

Кожен алгоритм машинного навчання побудований на статистичних принципах:

- **Лінійна регресія** мінімізує середньоквадратичну помилку
- **Логістична регресія** використовує функцію ймовірності
- **Нормалізація даних** спирається на середнє та стандартне відхилення
- **Виявлення аномалій** — це пошук викидів у розподілі
- **Відбір ознак** ґрунтується на кореляції

Без статистики ви можете **запустити** модель, але не зможете **зрозуміти**, чому вона працює або чому ні.
