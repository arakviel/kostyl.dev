- **Гістограма (histogram)** — графік розподілу неперервної змінної
- **Bins** — інтервали (стовпці), на які розбивається діапазон даних
- **Box plot** — діаграма «ящик з вусами» для візуалізації квартилів та викидів
- **Квартилі** — значення, що ділять дані на 4 рівні частини (Q1, Q2=медіана, Q3)
- **IQR** — міжквартильний розмах (Q3 - Q1)

## Перша гістограма за 10 секунд: «Hello World» у візуалізації розподілів

Коли інженер працює з великим масивом числових даних, перше завдання — не рахувати складні статистичні формули, а **побачити форму даних на власні очі**. Таблиця з тисячі чисел створює інформаційний хаос. Гістограма здатна розкрити структуру всієї вибірки всього за 3 рядки коду.

> **Сюжетна лінія (Етап 1: Первинний аудит метрик сервісу):**  
> Уявіть, що ви відповідаєте за стабільність бекенду веб-застосунку. Кожен HTTP-запит має свій час обробки (затримку або *latency* у мілісекундах). У логах сервера накопичилися тисячі записів: `95, 110, 102, 105, 520, 108...`  
> Тімлід запитує: *«Чи стабільно працює система? Який типовий час очікування для більшості клієнтів і чи є критичні зависання?»*. Щоб миттєво відповісти на це питання, ми будуємо першу гістограму.

### Рівень 0: Абсолютний мінімум (3 рядки коду)

Щоб побудувати гістограму, достатньо передати сирий список чисел у функцію `plt.hist()`:

```python
import matplotlib.pyplot as plt

raw_data = [1, 2, 2, 3, 3, 3, 4, 4, 5]
plt.hist(raw_data)
plt.show()
```

Вам не довелося вручну рахувати, скільки разів зустрічається кожне число. Matplotlib самостійно розбив діапазон на інтервали (*bins*), підрахував частоту появи значень і накреслив вертикальні стовпці.

### Рівень 1: Реальні дані (семпл часу відповіді сервера)

Перейдемо до реальних метрик: згенеруємо 200 вимірів часу відповіді сервера (у мілісекундах) із середнім значенням 120 мс:

```python
import numpy as np

rng = np.random.default_rng(seed=42)
latency = rng.normal(loc=120, scale=25, size=200)

plt.hist(latency)
plt.show()
```

Стовпці графіка одразу показують центр скупчення більшості запитів.

### Рівень 2: Додаємо контекст (інтервали, підписи та орієнтири)

Щоб перетворити швидкий нарис на зрозумілий інженерний звіт, зафіксуємо кількість інтервалів (`bins=15`), додамо підписи осей та вертикальні лінії середнього значення й медіани:

```python
plt.hist(latency, bins=15, color="#059669", edgecolor="black", alpha=0.7)
plt.axvline(np.mean(latency), color="red", linestyle="--", linewidth=2, label="Середнє")
plt.axvline(np.median(latency), color="gold", linestyle="-", linewidth=2, label="Медіана")
plt.title("Розподіл затримки сервера (Latency)")
plt.xlabel("Час відповіді (мс)")
plt.ylabel("Кількість запитів")
plt.legend()
plt.grid(axis="y", alpha=0.3)
plt.show()
```

## Історія про вимірювання зросту

Уявіть: медична клініка виміряла зріст 500 пацієнтів. Директор хоче зрозуміти:

1. Який **типовий** зріст? (не середнє — воно може бути спотворене)
2. Чи є **аномалії** (наприклад, дитину виміряли разом з дорослими)?
3. Як розподілені дані — **симетрично** чи є перекіс?

Перший інстинкт — подивитися на таблицю з 500 числами. Але це марно. **Гістограма** показує це за 3 секунди.

### Розподіл зросту 500 пацієнтів
Візуалізація допомагає побачити паттерни, невидимі в таблиці

```python
import matplotlib.pyplot as plt
import numpy as np

# Генеруємо реалістичні дані: зріст дорослих (нормальний розподіл)
rng = np.random.default_rng(seed=42)
heights = rng.normal(loc=170, scale=10, size=500)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Ліворуч: спроба показати дані текстом (нечитабельно)

# Праворуч: гістограма (одразу видно розподіл!)
ax2.hist(heights, bins=30, color="steelblue", edgecolor="black", alpha=0.7)
ax2.axvline(heights.mean(), color="red", linestyle="--", linewidth=2,

              fontsize=12, fontweight="bold")
ax2.set_xlabel("Зріст (см)", fontsize=11)
ax2.set_ylabel("Кількість пацієнтів", fontsize=11)

ax2.grid(axis="y", alpha=0.3)
```

- Гістограма **візуалізує** те, що описують статистичні показники (середнє, дисперсія, медіана)
- Якщо ви бачите «дзвін» на гістограмі — це **нормальний розподіл**
- Якщо пік зсунутий вліво або вправо — **асиметричний розподіл** (skewed)
- Якщо два піки — **бімодальний розподіл** (дві підгрупи в даних)

## Гістограми — візуалізація розподілу неперервних даних

### Що таке гістограма?

**Гістограма (histogram)** — це графік, що показує, як часто зустрічаються значення у певних **інтервалах** (bins).

> Аналогія: уявіть, що ви сортуєте монети за номіналом у коробки. Перша коробка — монети 1–10 коп., друга — 11–25 коп., третя — 26–50 коп. тощо. Гістограма — це **графік кількості монет у кожній коробці**.

**Відмінність від bar chart:**
- **Гістограма** — для **неперервних** даних (зріст, вага, вік). Стовпці **стикаються** — бо між ними немає розривів
- **Bar chart** — для **категорій** (країни, продукти). Стовпці **розділені** — бо категорії дискретні

::jupyter-notebook{title="histogram_basics.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: результати іспиту 200 студентів (0–100 балів)
rng = np.random.default_rng(seed=123)
scores = rng.normal(loc=70, scale=15, size=200)
scores = np.clip(scores, 0, 100)  # Обмежуємо діапазон [0, 100]

fig, ax = plt.subplots(figsize=(10, 6))

# Будуємо гістограму
counts, bins, patches = ax.hist(scores, bins=20, color="coral", 
                                 edgecolor="black", alpha=0.7)

ax.set_title("Розподіл балів на іспиті (200 студентів)", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Бали (0–100)", fontsize=12)
ax.set_ylabel("Кількість студентів", fontsize=12)
ax.grid(axis="y", alpha=0.3)

# Додаємо вертикальні лінії для статистики
mean_score = scores.mean()
median_score = np.median(scores)

ax.axvline(mean_score, color="red", linestyle="--", linewidth=2,
           label=f"Середнє: {mean_score:.1f}")
ax.axvline(median_score, color="green", linestyle="--", linewidth=2,
           label=f"Медіана: {median_score:.1f}")
ax.legend(fontsize=11)

plt.tight_layout()
plt.show()
```

### Сигнатура методу ax.hist() та параметричні варіації

Метод `ax.hist()` розбиває числову послідовність на вказану кількість інтервалів, підраховує кількість точок у кожному стовпці та малює стовпчикову діаграму. Він повертає кортеж із трьох елементів: `(counts, bins, patches)`.

```python [Сигнатура ax.hist]
Axes.hist(
    x: ArrayLike | Sequence[ArrayLike],
    bins: int | Sequence[float] | str | None = None,
    range: tuple[float, float] | None = None,
    density: bool = False,
    weights: ArrayLike | None = None,
    cumulative: bool | float = False,
    bottom: ArrayLike | float | None = None,
    histtype: Literal['bar', 'barstacked', 'step', 'stepfilled'] = 'bar',
    align: Literal['left', 'mid', 'right'] = 'mid',
    orientation: Literal['vertical', 'horizontal'] = 'vertical',
    rwidth: float | None = None,
    log: bool = False,
    color: ColorType | None = None,
    label: str | Sequence[str] | None = None,
    stacked: bool = False,
    **kwargs
) -> tuple[np.ndarray | list[np.ndarray], np.ndarray, BarContainer | Polygon | list[BarContainer | Polygon]]
```

**Аналіз ключових параметрів:**
- `x`: вхідні дані (одновимірний масив або список кількох масивів для спільної побудови).
- `bins`: кількість інтервалів (ціле число), конкретні координати меж інтервалів (масив чисел) або автоматичний алгоритм оцінки (`'auto'`, `'sturges'`, `'fd'`, `'scott'`).
- `density`: якщо `True`, висота стовпців нормується так, що загальна площа під усією гістограмою дорівнює `1.0`. Це перетворює гістограму на емпіричну функцію щільності ймовірності (PDF), що дозволяє порівнювати вибірки різного обсягу або накладати аналітичні криві розподілів.
- `cumulative`: якщо `True`, будується кумулятивна функція розподілу (CDF), де кожен наступний стовпець включає суму всіх попередніх частот від 0 до 1 (або від 0 до $N$). Дозволяє миттєво визначити процентилі або SLA-поріг.
- `histtype`: геометричний стиль:
  - `'bar'` — класичні зафарбовані стовпчики.
  - `'step'` — контурна лінія без внутрішньої заливки (незамінна для накладання 3–4 розподілів без візуального конфлікту).
  - `'stepfilled'` — ступінчастий контур із напівпрозорою заливкою.
- `log`: якщо `True`, вісь частот переводиться в логарифмічний масштаб. Це критично для виявлення одиничних аномальних сплесків, які на лінійній шкалі губляться на рівні нуля.
- `orientation`: напрямок стовпців (`'vertical'` — за замовчуванням, `'horizontal'` — для розташування поруч із графіками розсіювання).

::jupyter-notebook{title="hist_signature_variations.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

fig, axes = plt.subplots(2, 2, figsize=(14, 9), layout="constrained")
rng = np.random.default_rng(seed=42)
sample = rng.normal(loc=100, scale=20, size=1000)

# 1. density=True (щільність імовірності vs частоти)
ax = axes[0, 0]
ax.hist(sample, bins=25, density=True, color="#2563EB", edgecolor="black", alpha=0.6, label="density=True (PDF)")
# Додаємо теоретичну криву Гаусса
x_grid = np.linspace(30, 170, 200)
pdf = (1 / (20 * np.sqrt(2 * np.pi))) * np.exp(-0.5 * ((x_grid - 100) / 20) ** 2)
ax.plot(x_grid, pdf, color="#DC2626", lw=2.5, label="Теоретичний нормальний розподіл")
ax.set_title("1. Нормалізація площі: density=True (площа під кривою = 1)", fontsize=11, fontweight="bold")
ax.legend(fontsize=8.5)
ax.grid(axis="y", alpha=0.25, ls="--")

# 2. cumulative=True (кумулятивна емпірична функція розподілу CDF)
ax = axes[0, 1]
ax.hist(sample, bins=30, cumulative=True, density=True, color="#7C3AED", edgecolor="black", alpha=0.6)
ax.axhline(0.5, color="red", ls="--", label="Медіана (50% спостережень)")
ax.axhline(0.95, color="orange", ls=":", label="95-й процентиль (SLA поріг)")
ax.set_title("2. Кумулятивна функція: cumulative=True (CDF від 0 до 1)", fontsize=11, fontweight="bold")
ax.legend(fontsize=8.5, loc="lower right")
ax.grid(True, alpha=0.25, ls="--")

# 3. histtype ('bar', 'step', 'stepfilled')
ax = axes[1, 0]
sample2 = rng.normal(loc=115, scale=18, size=1000)
ax.hist(sample, bins=25, histtype="stepfilled", color="#059669", alpha=0.5, label="Модель A (stepfilled)")
```

## Правило вибору кількості bins

**Найчастіше питання:** скільки стовпців (bins) потрібно для гістограми?

**Відповідь:** немає «правильного» числа — це баланс між деталізацією та узагальненням.

> **Сюжетна лінія (Етап 2: Баланс деталізації при моніторингу черги):**  
> Коли ви налаштовуєте моніторинг сервісу, вибір кількості інтервалів (`bins`) має прямий вплив на швидкість і правильність діагностики. Якщо стовпців замало (наприклад, 5) — ви пропустите небезпечний «другий горб» (окрему групу запитів із великою затримкою). Якщо стовпців забагато (100) — графік перетвориться на гребінець випадкового шуму, де неможливо розгледіти загальну закономірність.

## Інтерпретація форми розподілу

Форма гістограми розповідає **історію про дані**.

> **Сюжетна лінія (Етап 3: Діагностика поведінки бекенду за формою кривої):**  
> Форма гістограми — це кардіограма здоров'я вашого сервісу:  
> - **Дзвін (нормальний розподіл)**: стандартна штатна робота алгоритму з природними випадковими коливаннями довкола цільового часу.  
> - **Правий перекіс (довгий хвіст праворуч)**: типова ситуація для веб-серверів — 90% запитів обробляються за 50 мс, але через черги до бази даних 10% клієнтів очікують до 1–2 секунд.  
> - **Бімодальний розподіл (два піки)**: класичний симптом роботи дворівневої системи (наприклад, кешування). Перший пік на 10 мс — це попадання в оперативний кеш (*cache hit*), а другий пік на 150 мс — промах повз кеш і повне звернення до диска чи бази даних (*cache miss*).

## Box Plots — діаграми «ящик з вусами»

Box plot (або box-and-whisker plot) — це компактний спосіб показати **п'ять ключових статистичних показників** одночасно:

> **Сюжетна лінія (Етап 4: Полювання на приховані аномалії — Outlier Detection):**  
> Гістограма дала загальну картину, але в продакшені є найнебезпечніша категорія проблем — «хвостові затримки» (*tail latency*). Це 0.5–1% користувачів, чиї запити зависають на 10–30 секунд через взаємне блокування транзакцій у базі даних або таймаут зовнішнього платіжного шлюзу.  
> На гістограмі з 100 000 запитів цей один відсоток майже невидимий (стовпчик висотою в пару пікселів на далекому краї). Але для бізнесу це втрачені замовлення та незадоволені клієнти.  
> **Box plot** виводить ці аномалії на перший план у вигляді окремих точок-викидів (*outliers*), дозволяючи інженеру негайно локалізувати збій.

1. Мінімум (без викидів)
2. Q1 (перший квартиль, 25%)
3. Медіана (Q2, 50%)
4. Q3 (третій квартиль, 75%)
5. Максимум (без викидів)
6. Викиди (outliers) — окремими точками

::jupyter-notebook{title="boxplot_anatomy.ipynb"}

::jupyter-cell{type="markdown"}
### Анатомія box plot
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)
data = rng.normal(100, 15, 100)
# Додаємо кілька викидів
data = np.append(data, [150, 155, 45, 40])

fig, ax = plt.subplots(figsize=(8, 10))

bp = ax.boxplot(data, vert=True, patch_artist=True, widths=0.5,
                boxprops=dict(facecolor="lightblue", edgecolor="navy", linewidth=2),
                medianprops=dict(color="red", linewidth=3),
                whiskerprops=dict(color="navy", linewidth=2),
                capprops=dict(color="navy", linewidth=2),
                flierprops=dict(marker="o", markerfacecolor="red", markersize=8, 
                                markeredgecolor="darkred"))

# Обчислюємо статистику
q1, median, q3 = np.percentile(data, [25, 50, 75])
iqr = q3 - q1
lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr

# Анотації
ax.annotate("Викиди (outliers)\nзначення > Q3 + 1.5·IQR", 
            xy=(1, 150), xytext=(1.4, 150),
            fontsize=10, color="darkred", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkred", lw=2))

ax.annotate(f"Максимум (без викидів)\n≈ {upper_fence:.1f}", 
            xy=(1, upper_fence), xytext=(1.4, upper_fence+5),
            fontsize=10, color="navy", weight="bold",
            arrowprops=dict(arrowstyle="->", color="navy"))

ax.annotate(f"Q3 (75% даних нижче)\n≈ {q3:.1f}", 
            xy=(1, q3), xytext=(1.4, q3),
            fontsize=10, color="darkblue", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkblue"))

ax.annotate(f"Медіана (Q2, 50%)\n≈ {median:.1f}", 
            xy=(1, median), xytext=(0.3, median+10),
            fontsize=11, color="red", weight="bold",
            arrowprops=dict(arrowstyle="->", color="red", lw=2))

ax.annotate(f"Q1 (25% даних нижче)\n≈ {q1:.1f}", 
            xy=(1, q1), xytext=(1.4, q1-5),
            fontsize=10, color="darkblue", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkblue"))

ax.annotate(f"Мінімум (без викидів)\n≈ {lower_fence:.1f}", 
            xy=(1, lower_fence), xytext=(1.4, lower_fence-10),
            fontsize=10, color="navy", weight="bold",
            arrowprops=dict(arrowstyle="->", color="navy"))

ax.annotate(f"IQR = Q3 - Q1\n= {iqr:.1f}", 
            xy=(1.15, (q1+q3)/2), xytext=(0.5, (q1+q3)/2-15),
            fontsize=11, color="green", weight="bold",
            bbox=dict(boxstyle="round,pad=0.5", facecolor="lightgreen", alpha=0.8))

ax.set_title("Анатомія Box Plot", fontsize=14, fontweight="bold")
ax.set_ylabel("Значення", fontsize=12)
ax.set_xlim(0.5, 2)
ax.set_xticks([])
ax.grid(axis="y", alpha=0.3)

plt.tight_layout()
plt.show()
```

### Сигнатура методу ax.boxplot() та параметричні варіації

Метод `ax.boxplot()` обчислює квантилі, міжквартильний розмах і координати викидів, після чого створює сукупність графічних примітивів (ліній, прямокутників та маркерів).

```python [Сигнатура ax.boxplot]
Axes.boxplot(
    x: ArrayLike | Sequence[ArrayLike],
    notch: bool | None = None,
    sym: str | None = None,
    vert: bool | None = None,
    whis: float | tuple[float, float] | None = None,
    positions: Sequence[float] | None = None,
    widths: float | Sequence[float] | None = None,
    patch_artist: bool | None = None,
    bootstrap: int | None = None,
    usermedians: Sequence[float] | None = None,
    conf_intervals: ArrayLike | None = None,
    meanline: bool | None = None,
    showmeans: bool | None = None,
    showcaps: bool | None = None,
    showbox: bool | None = None,
    showfliers: bool | None = None,
    boxprops: dict[str, Any] | None = None,
    tick_labels: Sequence[str] | None = None,  # У Matplotlib 3.9+ замість застарілого labels
    flierprops: dict[str, Any] | None = None,
    medianprops: dict[str, Any] | None = None,
    meanprops: dict[str, Any] | None = None,
    capprops: dict[str, Any] | None = None,
    whiskerprops: dict[str, Any] | None = None,
    **kwargs
) -> dict[str, list[Line2D | PathPatch]]
```

::note
**Сучасний API (Matplotlib 3.9+):** Параметр `labels` перейменовано на `tick_labels`, щоб уніфікувати роботу з мітками осей. Старий параметр `labels` все ще підтримується для зворотної сумісності.
::

**Аналіз ключових параметрів:**
- `notch`: якщо `True`, навколо медіани формується V-подібний виріз, що візуалізує 95% довірчий інтервал. Якщо вирізи двох ящиків не перетинаються по висоті, різниця між медіанами є статистично значущою.
- `whis`: коефіцієнт множення $IQR$ для граничних вусів (за замовчуванням `1.5`). Якщо передати кортеж відсотків `(0, 100)`, вуса простягнуться до абсолютних мінімуму та максимуму без окремих точок-викидів.
- `showmeans` та `meanline`: відображення середнього арифметичного. При `meanline=True` середнє малюється пунктирною лінією на всю ширину ящика, а при `meanline=False` — точковим маркером.
- `patch_artist`: обов'язковий прапорець (`True`), якщо ви бажаєте зафарбувати тіло ящика кольором через параметр `boxprops=dict(facecolor=...)`.
- `flierprops`: словник стилізації викидів (`marker`, `markersize`, `markerfacecolor`, `markeredgecolor`).
- `vert`: орієнтація діаграми (`True` — вертикальна, `False` — горизонтальна).

## Violin Plots — скрипкові діаграми для оцінки форми та щільності

Хоча Box Plot чудово виявляє викиди та показує квартилі, він має фундаментальне обмеження: **він повністю приховує внутрішню форму розподілу**.

> **Парадокс прихованої структури:**  
> Уявіть, що ви порівнюєте два сервіси:  
> 1. Перший має нормальний розподіл затримок довкола 60 мс.  
> 2. Другий — бімодальний (половина запитів обробляється за 20 мс завдяки кешу, а інша половина — за 100 мс через базу даних).  
> Звичайний Box Plot для обох вибірок покаже майже ідентичний прямокутник із медіаною ~60 мс! Інженер вирішить, що системи працюють однаково, і пропустить критичну особливість архітектури.

**Violin Plot (скрипкова діаграма)** розв'язує цю проблему, поєднуючи інформативність Box Plot із плавною ядерною оцінкою щільності (*Kernel Density Estimation, KDE*). Ширина «скрипки» в кожній точці показує, наскільки часто зустрічається це значення.

```python [Сигнатура ax.violinplot]
Axes.violinplot(
    dataset: ArrayLike | Sequence[ArrayLike],
    positions: Sequence[float] | None = None,
    vert: bool = True,
    widths: float | Sequence[float] = 0.5,
    showmeans: bool = False,
    showextrema: bool = True,
    showmedians: bool = False,
    quantiles: Sequence[float] | Sequence[Sequence[float]] | None = None,
    points: int = 100,
    bw_method: str | float | Callable | None = None,
    *,
    side: Literal['both', 'low', 'high'] = 'both',
    **kwargs
) -> dict[str, Any]
```

**Ключові параметри методу `violinplot()`:**
- `dataset`: одновимірний масив або список вибірок для порівняння.
- `showmedians`, `showmeans`: малювання горизонтальних позначок для медіани та середнього значення.
- `showextrema`: малювання вертикальної осі від абсолютного мінімуму до максимуму.
- `quantiles`: список квантилів, які слід накреслити всередині скрипки (наприклад, `[0.25, 0.75]` для відображення міжквартильного розмаху).
- `bw_method`: метод обчислення ширини вікна згладжування оцінки щільності (*bandwidth*). Можна передати правило Скотта `'scott'`, Сільвермана `'silverman'` або скалярне число.
- `vert`: орієнтація (`True` — вертикальні скрипки, `False` — горизонтальні).

::jupyter-notebook{title="violinplot_variations.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

fig, axes = plt.subplots(1, 3, figsize=(16, 5), layout="constrained")
rng = np.random.default_rng(seed=42)

# Згенеруємо бімодальний розподіл (де boxplot приховує суть)
data1 = np.concatenate([rng.normal(40, 6, 200), rng.normal(80, 8, 200)])
data2 = rng.normal(60, 16, 400)
data_list = [data1, data2]

# 1. Звичайний boxplot (приховує бімодальність data1!)
axes[0].boxplot(data_list, tick_labels=["Група 1 (Бімодальна)", "Група 2 (Нормальна)"],
                patch_artist=True, boxprops=dict(facecolor="#DBEAFE"))
axes[0].set_title("Box Plot: виглядають майже однаково!\n(приховує внутрішню форму та два піки)", 
                  fontsize=10, fontweight="bold", color="#991B1B")
axes[0].grid(axis="y", alpha=0.25, ls="--")

# 2. Violin Plot (одразу розкриває два піки!)
vp = axes[1].violinplot(data_list, positions=[1, 2], showmeans=True, showmedians=True)
for body in vp['bodies']:
    body.set_facecolor('#059669')
    body.set_edgecolor('#065F46')
    body.set_alpha(0.6)
vp['cmeans'].set_color('blue')
vp['cmedians'].set_color('red')
axes[1].set_xticks([1, 2], labels=["Група 1 (два піки!)", "Група 2 (один пік)"])
axes[1].set_title("Violin Plot: чітко видно різницю форм!\n(зелений контур = оцінка щільності KDE)", 
                  fontsize=10, fontweight="bold", color="#065F46")
axes[1].grid(axis="y", alpha=0.25, ls="--")

# 3. Варіації параметрів violinplot (quantiles, bw_method)
vp2 = axes[2].violinplot(data_list, positions=[1, 2], quantiles=[[0.25, 0.75], [0.1, 0.9]],
                         showextrema=True)
for body in vp2['bodies']:
    body.set_facecolor('#7C3AED')
    body.set_edgecolor('#5B21B6')
    body.set_alpha(0.6)
axes[2].set_xticks([1, 2], labels=["quantiles=[0.25, 0.75]", "quantiles=[0.1, 0.9]"])
axes[2].set_title("Квантилі та екстремуми: quantiles=[...]\n(лінії всередині скрипки показують квартилі)", 
                  fontsize=10, fontweight="bold")
axes[2].grid(axis="y", alpha=0.25, ls="--")

fig.suptitle("Порівняння Box Plot vs Violin Plot та варіації параметрів ax.violinplot()", fontsize=14, fontweight="bold")
plt.show()
```

## Комбіновані графіки: гістограма + box plot

Іноді корисно показати **обидва** типи візуалізації одночасно.

> **Сюжетна лінія (Етап 5: Створення фінального інженерного дашборду):**  
> Досвідчені SRE та DevOps інженери не обирають між гістограмою та box plot — вони поєднують їх на одному вертикальному дашборді. Верхня гістограма детально показує форму розподілу та піки навантаження, а нижній box plot під нею на спільній шкалі дає точну оцінку медіани, квартилів і рідкісних екстремальних викидів.

::jupyter-notebook{title="combined_hist_box.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)
data = rng.gamma(2, 2, 500)

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8), 
                                gridspec_kw={'height_ratios': [3, 1]})

# Верхній графік: гістограма
ax1.hist(data, bins=30, color="mediumseagreen", edgecolor="black", alpha=0.7)
ax1.set_title("Розподіл часу відповіді сервера (мс)", 
              fontsize=14, fontweight="bold")
ax1.set_ylabel("Частота", fontsize=11)
ax1.grid(axis="y", alpha=0.3)

# Додаємо статистичні лінії на гістограму
median_val = np.median(data)
q1_val, q3_val = np.percentile(data, [25, 75])
ax1.axvline(median_val, color="red", linestyle="--", linewidth=2, 
            label=f"Медіана: {median_val:.1f} мс")
ax1.axvline(q1_val, color="orange", linestyle=":", linewidth=2, 
            label=f"Q1: {q1_val:.1f} мс")
ax1.axvline(q3_val, color="orange", linestyle=":", linewidth=2, 
            label=f"Q3: {q3_val:.1f} мс")
ax1.legend()

# Нижній графік: box plot (той самий датасет)
bp = ax2.boxplot(data, vert=False, patch_artist=True, widths=0.6,
                 boxprops=dict(facecolor="mediumseagreen", alpha=0.7),
                 medianprops=dict(color="red", linewidth=2))

ax2.set_xlabel("Час відповіді (мс)", fontsize=11)
ax2.set_yticks([])
ax2.grid(axis="x", alpha=0.3)

plt.tight_layout()
plt.show()
```

![Комбінована візуалізація](/images/ai-python/data-visualization/distributions/11.png){.diagram-img}

::note
**Коли використовувати кожен тип:**

| Гістограма | Box Plot |
|:-----------|:---------|
| Показує **форму** розподілу (симетрія, піки, хвости) | Показує **статистичні показники** (медіана, квартилі, викиди) |
| Добре для **одного датасету** | Відмінно для **порівняння груп** |
| Візуально «багатий» | Компактний, займає мало місця |
| Потребує вибору bins | Не залежить від bins |

**Золоте правило:** якщо потрібно **зрозуміти структуру** даних → гістограма. Якщо потрібно **порівняти групи** або **знайти викиди** → box plot.

## Резюме підтеми

::card-group

::card{title="📊 Гістограми" icon="i-lucide-bar-chart-2"}

- `ax.hist(data, bins=30)` — візуалізація розподілу
- `bins` — кількість інтервалів (`"auto"`, число, або ["sturges", "scott"])
- Форма показує: симетрію, асиметрію, піки, хвости
- Для асиметричних даних: медіана > середнє

::

::card{title="📦 Box Plots" icon="i-lucide-package"}

- `ax.boxplot(data)` — компактний показ 5 статистичних величин
- Ящик = IQR (Q1–Q3), лінія всередині = медіана
- Вуса = діапазон без викидів (Q1 - 1.5·IQR, Q3 + 1.5·IQR)
- Точки = викиди (outliers)
- Ідеально для порівняння груп

::

::card{title="🎯 Коли що використовувати" icon="i-lucide-target"}

- **Один датасет, потрібна форма** → гістограма
- **Кілька груп, потрібне порівняння** → box plots
- **Підозра на викиди** → box plot їх покаже
- **Презентація для нетехнічної аудиторії** → гістограма (інтуїтивніша)
- **Технічний звіт, багато груп** → box plots (компактніші)

::

::

::tip
**Чек-лист аналізу розподілу:**

1. [ ] Побудували гістограму → побачили **форму**
2. [ ] Перевірили: симетричний чи асиметричний?
3. [ ] Якщо асиметричний → використовуємо **медіану**, не середнє
4. [ ] Побудували box plot → знайшли **викиди**
5. [ ] Якщо потрібно порівняти групи → box plots поруч
6. [ ] Інтерпретували: широкий ящик = великий розкид, вузький = стабільні дані
