- **Bins** — інтервали (стовпці), на які розбивається діапазон даних
- **Box plot** — діаграма «ящик з вусами» для візуалізації квартилів та викидів
- **Квартилі** — значення, що ділять дані на 4 рівні частини (Q1, Q2=медіана, Q3)
- **IQR** — міжквартильний розмах (Q3 - Q1)

## Історія про вимірювання зросту

Уявіть: медична клініка виміряла зріст 500 пацієнтів. Директор хоче зрозуміти:

1. Який **типовий** зріст? (не середнє — воно може бути спотворене)
2. Чи є **аномалії** (наприклад, дитину виміряли разом з дорослими)?
3. Як розподілені дані — **симетрично** чи є перекіс?

Перший інстинкт — подивитися на таблицю з 500 числами. Але це марно. **Гістограма** показує це за 3 секунди.

::jupyter-notebook{title="height_distribution.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Розподіл зросту 500 пацієнтів
Візуалізація допомагає побачити паттерни, невидимі в таблиці
::

::jupyter-cell{executionCount="1" executionTime="0.22s"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Генеруємо реалістичні дані: зріст дорослих (нормальний розподіл)
rng = np.random.default_rng(seed=42)
heights = rng.normal(loc=170, scale=10, size=500)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Ліворуч: спроба показати дані текстом (нечитабельно)
ax1.text(0.05, 0.5, f"Перші 50 значень:\n{heights[:50].round(1)}", 
         fontsize=7, family="monospace", verticalalignment="center")
ax1.set_title("Дані у вигляді чисел\n(неможливо зрозуміти структуру)", 
              fontsize=12, fontweight="bold")
ax1.axis("off")

# Праворуч: гістограма (одразу видно розподіл!)
ax2.hist(heights, bins=30, color="steelblue", edgecolor="black", alpha=0.7)
ax2.axvline(heights.mean(), color="red", linestyle="--", linewidth=2, 
            label=f"Середнє: {heights.mean():.1f} см")
ax2.axvline(np.median(heights), color="green", linestyle="--", linewidth=2,
            label=f"Медіана: {np.median(heights):.1f} см")

ax2.set_title("Гістограма розподілу зросту\n(структура видна одразу)", 
              fontsize=12, fontweight="bold")
ax2.set_xlabel("Зріст (см)", fontsize=11)
ax2.set_ylabel("Кількість пацієнтів", fontsize=11)
ax2.legend()
ax2.grid(axis="y", alpha=0.3)

plt.tight_layout()
plt.show()
```

::jupyter-cell{type="markdown"}
**Висновки з гістограми:**

1. Розподіл **майже симетричний** (форма дзвона) → нормальний розподіл
2. Пік близько **170 см** → типовий зріст
3. Середнє ≈ Медіана → немає сильних викидів
4. Діапазон: ~145–195 см → відсутні аномальні значення

Це те, що **неможливо побачити** в таблиці з 500 чисел!

::note
**Зв'язок зі статистикою (модуль 2.2):**

- Гістограма **візуалізує** те, що описують статистичні показники (середнє, дисперсія, медіана)
- Якщо ви бачите «дзвін» на гістограмі — це **нормальний розподіл**
- Якщо пік зсунутий вліво або вправо — **асиметричний розподіл** (skewed)
- Якщо два піки — **бімодальний розподіл** (дві підгрупи в даних)

## Гістограми — візуалізація розподілу неперервних даних

### Що таке гістограма?

**Гістограма (histogram)** — це графік, що показує, як часто зустрічаються значення у певних **інтервалах** (bins).

> Аналогія: уявіть, що ви сортуєте монети за номіналом у коробки. Перша коробка — монети 1–10 коп., друга — 11–25 коп., третя — 26–50 коп. тощо. Гістограма — це **графік кількості монет у кожній коробці**.

**Відмінність від bar chart:**
- **Гістограма** — для **неперервних** даних (зріст, вага, вік). Стовпці **стикаються** — бо між ними немає розривів
- **Bar chart** — для **категорій** (країни, продукти). Стовпці **розділені** — бо категорії дискретні

::jupyter-notebook{title="histogram_basics.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: результати іспиту 200 студентів (0–100 балів)
rng = np.random.default_rng(seed=123)
scores = rng.normal(loc=70, scale=15, size=200)
scores = np.clip(scores, 0, 100)  # Обмежуємо діапазон [0, 100]

fig, ax = plt.subplots(figsize=(10, 6))

# Будуємо гістограму
counts, bins, patches = ax.hist(scores, bins=20, color="coral", 
                                 edgecolor="black", alpha=0.7)

ax.set_title("Розподіл балів на іспиті (200 студентів)", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Бали (0–100)", fontsize=12)
ax.set_ylabel("Кількість студентів", fontsize=12)
ax.grid(axis="y", alpha=0.3)

# Додаємо вертикальні лінії для статистики
mean_score = scores.mean()
median_score = np.median(scores)

ax.axvline(mean_score, color="red", linestyle="--", linewidth=2,
           label=f"Середнє: {mean_score:.1f}")
ax.axvline(median_score, color="green", linestyle="--", linewidth=2,
           label=f"Медіана: {median_score:.1f}")
ax.legend(fontsize=11)

plt.tight_layout()
plt.show()
```

## Правило вибору кількості bins

**Найчастіше питання:** скільки стовпців (bins) потрібно для гістограми?

**Відповідь:** немає «правильного» числа — це баланс між деталізацією та узагальненням.

::jupyter-notebook{title="bins_comparison.ipynb"}

::jupyter-cell{type="markdown"}
### Вплив кількості bins на читабельність
Той самий датасет з різною кількістю інтервалів
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)
data = rng.exponential(scale=2, size=500)

fig, axes = plt.subplots(2, 3, figsize=(15, 8))
fig.suptitle("Той самий датасет з різною кількістю bins", 
             fontsize=15, fontweight="bold")

bins_values = [5, 10, 20, 30, 50, 100]

for ax, bins in zip(axes.flat, bins_values):
    ax.hist(data, bins=bins, color="teal", edgecolor="black", alpha=0.7)
    ax.set_title(f"bins={bins}", fontsize=12, fontweight="bold")
    ax.set_xlabel("Значення")
    ax.set_ylabel("Частота")
    ax.grid(axis="y", alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Порівняння різної кількості bins](/images/ai-python/data-visualization/distributions/04.png){.diagram-img}
::

::jupyter-cell{type="markdown"}
**Висновки:**

- **bins=5** — занадто грубо, втрачаються деталі розподілу
- **bins=10–20** — оптимально для більшості випадків, видно форму
- **bins=50–100** — занадто детально, виникає «шум», важко побачити тренд

**Золоте правило:** для n спостережень використовуйте `bins ≈ √n` або `bins ≈ log₂(n)`
::

::

::tip
**Автоматичні методи вибору bins:**

Matplotlib підтримує автоматичні алгоритми:

```python
# Правило Стерджеса (для нормального розподілу)
ax.hist(data, bins="sturges")

# Правило Скотта (враховує розкид даних)
ax.hist(data, bins="scott")

# Правило Фрідмана-Діакона (robust метод)
ax.hist(data, bins="fd")

# Автоматичний вибір (рекомендовано)
ax.hist(data, bins="auto")
```

![Порівняння автоматичних методів вибору bins](/images/ai-python/data-visualization/distributions/05.png){.diagram-img}

Для більшості випадків `bins="auto"` дає чудовий результат!

## Інтерпретація форми розподілу

Форма гістограми розповідає **історію про дані**.

::jupyter-notebook{title="distribution_shapes.ipynb"}

::jupyter-cell{type="markdown"}
### Види розподілів та їх інтерпретація
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

fig, axes = plt.subplots(2, 3, figsize=(15, 8))
fig.suptitle("Типові форми розподілів та їх значення", 
             fontsize=15, fontweight="bold")

# 1. Нормальний (симетричний)
data_normal = rng.normal(50, 10, 1000)
axes[0, 0].hist(data_normal, bins=30, color="steelblue", edgecolor="black", alpha=0.7)
axes[0, 0].set_title("Нормальний (Gaussian)\nЗріст людей, IQ, помилки вимірювань", 
                     fontsize=10, fontweight="bold")
axes[0, 0].axvline(np.mean(data_normal), color="red", linestyle="--", label="Середнє")
axes[0, 0].legend()

# 2. Лівий перекіс (right-skewed)
data_right_skew = rng.exponential(2, 1000)
axes[0, 1].hist(data_right_skew, bins=30, color="coral", edgecolor="black", alpha=0.7)
axes[0, 1].set_title("Правий перекіс (Right-skewed)\nДоходи населення, ціни нерухомості", 
                     fontsize=10, fontweight="bold")
axes[0, 1].axvline(np.median(data_right_skew), color="green", linestyle="--", label="Медіана")
axes[0, 1].legend()

# 3. Правий перекіс (left-skewed)
data_left_skew = 100 - rng.exponential(2, 1000)
axes[0, 2].hist(data_left_skew, bins=30, color="gold", edgecolor="black", alpha=0.7)
axes[0, 2].set_title("Лівий перекіс (Left-skewed)\nВік виходу на пенсію, тривалість життя", 
                     fontsize=10, fontweight="bold")
axes[0, 2].axvline(np.median(data_left_skew), color="green", linestyle="--", label="Медіана")
axes[0, 2].legend()

# 4. Рівномірний
data_uniform = rng.uniform(0, 100, 1000)
axes[1, 0].hist(data_uniform, bins=20, color="lightgreen", edgecolor="black", alpha=0.7)
axes[1, 0].set_title("Рівномірний (Uniform)\nРезультат кидка кубика, випадкові числа", 
                     fontsize=10, fontweight="bold")

# 5. Бімодальний (два піки)
data_bimodal = np.concatenate([rng.normal(30, 5, 500), 
                                rng.normal(70, 5, 500)])
axes[1, 1].hist(data_bimodal, bins=30, color="orchid", edgecolor="black", alpha=0.7)
axes[1, 1].set_title("Бімодальний (Bimodal)\nЗріст чоловіків та жінок разом", 
                     fontsize=10, fontweight="bold")

# 6. З викидами
data_outliers = np.concatenate([rng.normal(50, 5, 950),
                                 rng.uniform(90, 110, 50)])
axes[1, 2].hist(data_outliers, bins=40, color="crimson", edgecolor="black", alpha=0.7)
axes[1, 2].set_title("З викидами (Outliers)\nДані з помилками вимірювань", 
                     fontsize=10, fontweight="bold")

for ax in axes.flat:
    ax.grid(axis="y", alpha=0.3)
    ax.set_xlabel("Значення")
    ax.set_ylabel("Частота")

plt.tight_layout()
plt.show()
```

#output
![Типові форми розподілів](/images/ai-python/data-visualization/distributions/06.png){.diagram-img}

::

::warning
**Коли середнє вводить в оману:**

Для **асиметричних** розподілів (skewed) середнє **не репрезентує** типове значення!

Приклад: зарплати в компанії [20k, 22k, 25k, 23k, 21k, **500k** (CEO)]

- Середнє: **101.8k** ← спотворене викидом
- Медіана: **22.5k** ← типова зарплата

**Правило:** якщо гістограма асиметрична або має викиди → використовуйте **медіану**, не середнє.
::

## Box Plots — діаграми «ящик з вусами»

Box plot (або box-and-whisker plot) — це компактний спосіб показати **п'ять ключових статистичних показників** одночасно:

1. Мінімум (без викидів)
2. Q1 (перший квартиль, 25%)
3. Медіана (Q2, 50%)
4. Q3 (третій квартиль, 75%)
5. Максимум (без викидів)
6. Викиди (outliers) — окремими точками

::jupyter-notebook{title="boxplot_anatomy.ipynb"}

::jupyter-cell{type="markdown"}
### Анатомія box plot
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)
data = rng.normal(100, 15, 100)
# Додаємо кілька викидів
data = np.append(data, [150, 155, 45, 40])

fig, ax = plt.subplots(figsize=(8, 10))

bp = ax.boxplot(data, vert=True, patch_artist=True, widths=0.5,
                boxprops=dict(facecolor="lightblue", edgecolor="navy", linewidth=2),
                medianprops=dict(color="red", linewidth=3),
                whiskerprops=dict(color="navy", linewidth=2),
                capprops=dict(color="navy", linewidth=2),
                flierprops=dict(marker="o", markerfacecolor="red", markersize=8, 
                                markeredgecolor="darkred"))

# Обчислюємо статистику
q1, median, q3 = np.percentile(data, [25, 50, 75])
iqr = q3 - q1
lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr

# Анотації
ax.annotate("Викиди (outliers)\nзначення > Q3 + 1.5·IQR", 
            xy=(1, 150), xytext=(1.4, 150),
            fontsize=10, color="darkred", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkred", lw=2))

ax.annotate(f"Максимум (без викидів)\n≈ {upper_fence:.1f}", 
            xy=(1, upper_fence), xytext=(1.4, upper_fence+5),
            fontsize=10, color="navy", weight="bold",
            arrowprops=dict(arrowstyle="->", color="navy"))

ax.annotate(f"Q3 (75% даних нижче)\n≈ {q3:.1f}", 
            xy=(1, q3), xytext=(1.4, q3),
            fontsize=10, color="darkblue", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkblue"))

ax.annotate(f"Медіана (Q2, 50%)\n≈ {median:.1f}", 
            xy=(1, median), xytext=(0.3, median+10),
            fontsize=11, color="red", weight="bold",
            arrowprops=dict(arrowstyle="->", color="red", lw=2))

ax.annotate(f"Q1 (25% даних нижче)\n≈ {q1:.1f}", 
            xy=(1, q1), xytext=(1.4, q1-5),
            fontsize=10, color="darkblue", weight="bold",
            arrowprops=dict(arrowstyle="->", color="darkblue"))

ax.annotate(f"Мінімум (без викидів)\n≈ {lower_fence:.1f}", 
            xy=(1, lower_fence), xytext=(1.4, lower_fence-10),
            fontsize=10, color="navy", weight="bold",
            arrowprops=dict(arrowstyle="->", color="navy"))

ax.annotate(f"IQR = Q3 - Q1\n= {iqr:.1f}", 
            xy=(1.15, (q1+q3)/2), xytext=(0.5, (q1+q3)/2-15),
            fontsize=11, color="green", weight="bold",
            bbox=dict(boxstyle="round,pad=0.5", facecolor="lightgreen", alpha=0.8))

ax.set_title("Анатомія Box Plot", fontsize=14, fontweight="bold")
ax.set_ylabel("Значення", fontsize=12)
ax.set_xlim(0.5, 2)
ax.set_xticks([])
ax.grid(axis="y", alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Детальна анатомія box plot](/images/ai-python/data-visualization/distributions/07.png){.diagram-img}

::note
**Зв'язок з модулем статистики (04.statistics-basics/06.outliers):**

- Box plot використовує **метод IQR** для виявлення викидів
- Викид: значення < Q1 - 1.5·IQR або > Q3 + 1.5·IQR
- «Вуса» (whiskers) показують діапазон даних **без** викидів
- Чим більший «ящик» — тим більший розкид даних (дисперсія)
::



### Порівняння груп за допомогою box plots

Box plots особливо корисні для **порівняння** кількох груп.

::jupyter-notebook{title="boxplot_comparison.ipynb"}

::jupyter-cell{type="markdown"}
### Порівняння балів трьох груп студентів
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

# Три групи студентів з різними характеристиками
group_a = rng.normal(75, 10, 80)   # Середня група
group_b = rng.normal(85, 7, 80)    # Сильна група
group_c = rng.normal(65, 15, 80)   # Слабка група (великий розкид)

data_to_plot = [group_a, group_b, group_c]

fig, ax = plt.subplots(figsize=(10, 6))

bp = ax.boxplot(data_to_plot, labels=["Група A", "Група B", "Група C"],
                patch_artist=True, notch=True, showmeans=True,
                boxprops=dict(facecolor="skyblue", edgecolor="navy", linewidth=1.5),
                medianprops=dict(color="red", linewidth=2),
                meanprops=dict(marker="D", markerfacecolor="green", markersize=8),
                whiskerprops=dict(linestyle="--", linewidth=1.5),
                flierprops=dict(marker="o", markerfacecolor="orange", markersize=6, alpha=0.5))

ax.set_title("Порівняння балів трьох груп студентів", 
             fontsize=14, fontweight="bold")
ax.set_ylabel("Бали (0–100)", fontsize=12)
ax.set_xlabel("Група", fontsize=12)
ax.grid(axis="y", alpha=0.3)

# Легенда для пояснення символів
from matplotlib.lines import Line2D
custom_lines = [Line2D([0], [0], color="red", linewidth=2),
                Line2D([0], [0], marker="D", color="w", markerfacecolor="green", markersize=8)]
ax.legend(custom_lines, ["Медіана", "Середнє"], loc="lower right")

plt.tight_layout()
plt.show()
```

## Комбіновані графіки: гістограма + box plot

Іноді корисно показати **обидва** типи візуалізації одночасно.

::jupyter-notebook{title="combined_hist_box.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)
data = rng.gamma(2, 2, 500)

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8), 
                                gridspec_kw={'height_ratios': [3, 1]})

# Верхній графік: гістограма
ax1.hist(data, bins=30, color="mediumseagreen", edgecolor="black", alpha=0.7)
ax1.set_title("Розподіл часу відповіді сервера (мс)", 
              fontsize=14, fontweight="bold")
ax1.set_ylabel("Частота", fontsize=11)
ax1.grid(axis="y", alpha=0.3)

# Додаємо статистичні лінії на гістограму
median_val = np.median(data)
q1_val, q3_val = np.percentile(data, [25, 75])
ax1.axvline(median_val, color="red", linestyle="--", linewidth=2, 
            label=f"Медіана: {median_val:.1f} мс")
ax1.axvline(q1_val, color="orange", linestyle=":", linewidth=2, 
            label=f"Q1: {q1_val:.1f} мс")
ax1.axvline(q3_val, color="orange", linestyle=":", linewidth=2, 
            label=f"Q3: {q3_val:.1f} мс")
ax1.legend()

# Нижній графік: box plot (той самий датасет)
bp = ax2.boxplot(data, vert=False, patch_artist=True, widths=0.6,
                 boxprops=dict(facecolor="mediumseagreen", alpha=0.7),
                 medianprops=dict(color="red", linewidth=2))

ax2.set_xlabel("Час відповіді (мс)", fontsize=11)
ax2.set_yticks([])
ax2.grid(axis="x", alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Комбінована візуалізація](/images/ai-python/data-visualization/distributions/11.png){.diagram-img}
::

::

::note
**Коли використовувати кожен тип:**

| Гістограма | Box Plot |
|:-----------|:---------|
| Показує **форму** розподілу (симетрія, піки, хвости) | Показує **статистичні показники** (медіана, квартилі, викиди) |
| Добре для **одного датасету** | Відмінно для **порівняння груп** |
| Візуально «багатий» | Компактний, займає мало місця |
| Потребує вибору bins | Не залежить від bins |

**Золоте правило:** якщо потрібно **зрозуміти структуру** даних → гістограма. Якщо потрібно **порівняти групи** або **знайти викиди** → box plot.
::

## Резюме підтеми

::card-group

::card{title="📊 Гістограми" icon="i-lucide-bar-chart-2"}

- `ax.hist(data, bins=30)` — візуалізація розподілу
- `bins` — кількість інтервалів (`"auto"`, число, або ["sturges", "scott"])
- Форма показує: симетрію, асиметрію, піки, хвости
- Для асиметричних даних: медіана > середнє

::

::card{title="📦 Box Plots" icon="i-lucide-package"}

- `ax.boxplot(data)` — компактний показ 5 статистичних величин
- Ящик = IQR (Q1–Q3), лінія всередині = медіана
- Вуса = діапазон без викидів (Q1 - 1.5·IQR, Q3 + 1.5·IQR)
- Точки = викиди (outliers)
- Ідеально для порівняння груп

::

::card{title="🎯 Коли що використовувати" icon="i-lucide-target"}

- **Один датасет, потрібна форма** → гістограма
- **Кілька груп, потрібне порівняння** → box plots
- **Підозра на викиди** → box plot їх покаже
- **Презентація для нетехнічної аудиторії** → гістограма (інтуїтивніша)
- **Технічний звіт, багато груп** → box plots (компактніші)

::
