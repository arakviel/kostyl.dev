## Плавний старт: Scatter plot за 3 рядки коду

Коли перед дата-аналітиком чи інженером постає фундаментальне питання: *«Чи існує зв'язок між параметром X та показником Y?»*, найперший та найінформативніший інструмент — це **точкова діаграма (scatter plot)**.

Погляньмо, як від трьох мінімальних рядків коду перейти до повноцінного інженерного графіка з лінією тренду:

::jupyter-notebook{title="hello_scatter.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Три рівні створення точкової діаграми
Від миттєвої побудови сирих точок до інформативного графіка з оцінкою тренду
::

::jupyter-cell{executionCount="1" executionTime="0.21s"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Змодельовані дані навантаження сервера: паралельні з'єднання vs затримка (мс)
rng = np.random.default_rng(42)
connections = rng.uniform(10, 200, 45)
latency = 25 + 0.35 * connections + rng.normal(0, 12, 45)

# --- РІВЕНЬ 0: Мінімальний код (3 рядки) ---
plt.scatter(connections, latency)
plt.show()

# --- РІВЕНЬ 1: Додавання контексту та одиниць виміру ---
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(connections, latency, color='#2563eb', s=45)
ax.set_xlabel("Паралельні з'єднання (conn)")
ax.set_ylabel("Затримка відповіді Latency (ms)")
ax.set_title("Навантаження vs Затримка")
plt.show()

# --- РІВЕНЬ 2: Професійний інженерний графік з лінією тренду ---
fig, ax = plt.subplots(figsize=(7, 4.5))
ax.scatter(connections, latency, s=70, color='#3b82f6', 
           edgecolor='#1e3a8a', linewidth=1, alpha=0.75, label="Логи запитів")

# Розрахунок та візуалізація лінійного тренду (y = ax + b)
z = np.polyfit(connections, latency, 1)
p = np.poly1d(z)
x_line = np.linspace(connections.min(), connections.max(), 100)
ax.plot(x_line, p(x_line), color='#ef4444', linestyle='--', linewidth=2,
        label=f"Тренд: {z[0]:.2f}x + {z[1]:.1f}")

ax.set_title("Діагностика затримки API-шлюзу", fontsize=12, fontweight='bold')
ax.set_xlabel("Паралельні з'єднання (conn)", fontsize=10)
ax.set_ylabel("Затримка відповіді Latency (ms)", fontsize=10)
ax.grid(True, linestyle=':', alpha=0.6)
ax.legend(frameon=True, facecolor='#f8fafc', edgecolor='#cbd5e1')
plt.show()
```

### Чому Scatter Plot незамінний у дослідженні даних?

1. **Миттєве зчитування кореляції:** людське око за частки секунди визначає напрямок нахилу хмари точок (вгору-вправо — зв'язок прямий, вниз-вправо — зворотний).
2. **Збереження кожного спостереження:** на відміну від усереднених метрик (mean, median), scatter plot демонструє *кожне окреме вимірювання*, уможливлюючи виявлення прихованих викидів.
3. **Виявлення кластерів та нелінійності:** розриви між групами або параболічні вигини неможливо зафіксувати однією цифрою — їх видно лише на графіку.

## Історія про рієлтора та площу квартир

Рієлтор Олена хоче зрозуміти, чи **справді** ціна квартири залежить від площі. У неї є дані по 100 квартирах: площа та ціна.

Перший інстинкт — подивитися на таблицю:

```
Площа (м²) | Ціна ($)
-----------|----------
45         | 35 000
72         | 52 000
110        | 89 000
38         | 28 000
...        | ...
```

Важко побачити закономірність. А тепер — **один графік**:

::jupyter-notebook{title="housing_scatter.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Залежність ціни квартири від площі
Один графік показує більше, ніж 100 рядків таблиці
::

::jupyter-cell{executionCount="1" executionTime="0.19s"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Генеруємо реалістичні дані: ціна приблизно пропорційна площі + шум
rng = np.random.default_rng(seed=42)
area = rng.uniform(30, 150, 100)  # Площа 30–150 м²
price = 500 * area + rng.normal(0, 8000, 100)  # ~500$/м² + шум

fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(area, price, alpha=0.6, s=80, color="steelblue", edgecolor="navy")

ax.set_title("Залежність ціни квартири від площі", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Площа (м²)", fontsize=12)
ax.set_ylabel("Ціна ($)", fontsize=12)
ax.grid(True, alpha=0.3)

# Додаємо лінію тренду для наочності
z = np.polyfit(area, price, 1)  # Лінійна регресія
p = np.poly1d(z)
ax.plot(area, p(area), color="red", linestyle="--", linewidth=2, 
        label=f"Trend: ціна ≈ {z[0]:.0f}·площа + {z[1]:.0f}")
ax.legend(fontsize=11)

plt.tight_layout()
plt.show()
```

::jupyter-cell{type="markdown"}
**Висновки одразу видно:**

1. Чіткий **позитивний** зв'язок: більша площа → вища ціна
2. Зв'язок майже **лінійний** (точки близько до прямої)
3. Є розкид (шум): не всі квартири однакової площі коштують однаково (впливають інші фактори)
4. Лінія тренду показує: **~500$ за кожен м²**

Це неможливо побачити в таблиці з 100 рядків!
::

::

::note
**Зв'язок з модулем статистики (04.statistics-basics/05.correlation):**

- Scatter plot **візуалізує** те, що описує коефіцієнт кореляції Пірсона
- Якщо точки йдуть «вгору вправо» — **позитивна кореляція** (r > 0)
- Якщо «вниз вправо» — **негативна кореляція** (r < 0)
- Якщо хаос — **немає лінійного зв'язку** (r ≈ 0)
- Чим щільніше точки до прямої — тим сильніша кореляція (|r| ближче до 1)

## Scatter Plots — точкові діаграми для двох змінних

### Що таке scatter plot?

**Scatter plot** — це графік, де кожна точка представляє одне спостереження з двома координатами: значення змінної X та значення змінної Y.

> Аналогія: уявіть, що ви вимірювали зріст та вагу 100 людей. Кожна людина — це одна точка на графіку: по горизонталі — зріст, по вертикалі — вага. Якщо точки йдуть «вгору вправо» — вищі люди зазвичай важчі (позитивна кореляція).

### Базовий scatter plot

::jupyter-notebook{title="scatter_basics.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: годин навчання → бали на іспиті (50 студентів)
rng = np.random.default_rng(seed=123)
hours_studied = rng.uniform(1, 10, 50)
exam_scores = 40 + 5 * hours_studied + rng.normal(0, 5, 50)

fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(hours_studied, exam_scores, s=100, alpha=0.6, 
           color="coral", edgecolor="darkred", linewidth=1.5)

ax.set_title("Залежність балів на іспиті від годин навчання", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Години навчання", fontsize=12)
ax.set_ylabel("Бали на іспиті (0–100)", fontsize=12)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### Повна сигнатура та анатомія параметрів `ax.scatter()`

Метод `ax.scatter()` створює об'єкт `PathCollection`, оптимізований для індивідуального керування кожною точкою (на відміну від `ax.plot()`, де всі маркери мають однаковий стиль).

```python
ax.scatter(
    x, y,
    s=None,
    c=None,
    marker=None,
    cmap=None,
    norm=None,
    vmin=None,
    vmax=None,
    alpha=None,
    linewidths=None,
    edgecolors=None,
    plotnonfinite=False,
    data=None,
    **kwargs
) -> PathCollection
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `x`, `y` | `ArrayLike` | *обов'язкові* | Координати точок (одновимірні масиви або Series однакової довжини). |
| `s` | `float \| ArrayLike` | `rcParams['lines.markersize']**2` (~36) | **Розмір точок у $pt^2$ (площа, а не радіус!)**. Може бути масивом для Bubble chart. |
| `c` | `color \| ArrayLike` | `None` | Колір точок. Якщо передати числовий масив — значення відображаються через `cmap`. |
| `marker` | `str \| MarkerStyle` | `'o'` (коло) | Форма маркера: `'o'` (коло), `'s'` (квадрат), `'^'` (трикутник), `'D'` (ромб), `'X'` (хрест), `'*'` (зірка). |
| `cmap` | `str \| Colormap` | `None` (rcParams) | Назва колірної карти (`'viridis'`, `'plasma'`, `'coolwarm'`), якщо `c` — числовий масив. |
| `norm` | `Normalize` | `None` | Нормалізатор числових значень (наприклад, `Normalize(vmin, vmax)` або `LogNorm()`). |
| `vmin`, `vmax` | `float` | `None` | Явні межі значень для прив'язки кольорів палітри. |
| `alpha` | `float` | `None` (1.0) | Прозорість від 0.0 (повністю прозорий) до 1.0 (непрозорий). Ключ до боротьби з перекриттям. |
| `linewidths` | `float \| Sequence` | `1.5` | Товщина обведення контуру маркера. |
| `edgecolors` | `color \| 'none' \| 'face'` | `'face'` | Колір контуру маркера. Контрастний контур (наприклад, темно-синій або чорний) відділяє накладені точки. |

### Візуальне дослідження параметрів ax.scatter()
Порівняння розмірів, типів маркерів, прозорості з обведенням та колірного кодування

::jupyter-cell{executionCount="1" executionTime="0.25s"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
fig, axes = plt.subplots(2, 2, figsize=(13, 9.5))

# 1. Параметр s: малі, середні та великі маркери
x_s = np.linspace(1, 10, 20)
y_s = 2 * x_s + rng.normal(0, 1, 20)
axes[0, 0].scatter(x_s[:7], y_s[:7], s=25, color='#0284c7', label="s = 25 (малі)")
axes[0, 0].scatter(x_s[7:14], y_s[7:14], s=90, color='#0ea5e9', edgecolor='#0369a1', linewidth=1, label="s = 90 (середні)")
axes[0, 0].scatter(x_s[14:], y_s[14:], s=220, color='#38bdf8', edgecolor='#0284c7', linewidth=1.5, alpha=0.8, label="s = 220 (великі)")
axes[0, 0].set_title("Параметр s: фіксований або змінний розмір", fontweight='bold')
axes[0, 0].legend()
axes[0, 0].grid(True, linestyle=':', alpha=0.6)

# 2. Параметр marker: спектр геометричних форм
markers = [('o', 'Коло "o"'), ('s', 'Квадрат "s"'), ('^', 'Трикутник "^"'), 
           ('D', 'Ромб "D"'), ('X', 'Хрестик "X"'), ('*', 'Зірка "*"')]
for i, (m, lbl) in enumerate(markers):
    xm = np.linspace(1, 10, 6) + rng.uniform(-0.15, 0.15, 6)
    ym = np.full(6, i + 1) + rng.uniform(-0.1, 0.1, 6)
    axes[0, 1].scatter(xm, ym, marker=m, s=110, color='#8b5cf6', edgecolor='#4c1d95', linewidth=1)
axes[0, 1].set_yticks(range(1, 7))
axes[0, 1].set_yticklabels([m[1] for m in markers])
axes[0, 1].set_title("Параметр marker: форма точок", fontweight='bold')
axes[0, 1].grid(True, linestyle=':', alpha=0.6)

# 3. Параметри alpha та edgecolors: читабельність скупчень
x_c = rng.normal(5, 1.2, 120)
y_c = rng.normal(5, 1.2, 120)
axes[1, 0].scatter(x_c - 1.5, y_c, s=110, color='#ef4444', alpha=1.0, edgecolor='none', label="alpha=1.0 (злипання)")
axes[1, 0].scatter(x_c + 1.5, y_c, s=110, color='#10b981', alpha=0.45, edgecolor='#064e3b', linewidth=1.5, label="alpha=0.45 + контур")
axes[1, 0].set_title("Параметри alpha та edgecolors: розрізнення густини", fontweight='bold')
axes[1, 0].legend(loc='upper left')
axes[1, 0].grid(True, linestyle=':', alpha=0.6)

# 4. Параметри c та cmap: відображення третього виміру
x_d = rng.uniform(0, 10, 60)
y_d = 1.5 * x_d + rng.normal(0, 2, 60)
c_vals = x_d * 2.5 + y_d
sc = axes[1, 1].scatter(x_d, y_d, c=c_vals, cmap='viridis', s=85, edgecolor='black', linewidth=0.5, alpha=0.9)
cbar = fig.colorbar(sc, ax=axes[1, 1], fraction=0.046, pad=0.04)
cbar.set_label("Значення метрики (c)")
axes[1, 1].set_title("Параметри c та cmap: числовий колірний градієнт", fontweight='bold')
axes[1, 1].grid(True, linestyle=':', alpha=0.6)

plt.tight_layout()
plt.show()
```

## Види кореляцій та їх візуалізація

Scatter plot одразу показує **тип зв'язку** між змінними.

::jupyter-notebook{title="correlation_types.ipynb"}

::jupyter-cell{type="markdown"}
### Чотири типи залежностей
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Типи кореляцій та їх візуалізація", fontsize=16, fontweight="bold")

# 1. Сильна позитивна кореляція (r ≈ +0.95)
x1 = np.linspace(0, 10, 100)
y1 = 2 * x1 + 3 + rng.normal(0, 1, 100)
r1 = np.corrcoef(x1, y1)[0, 1]
axes[0, 0].scatter(x1, y1, alpha=0.6, color="green", s=60)
axes[0, 0].set_title(f"Сильна позитивна кореляція\nr = {r1:.2f}", 
                     fontsize=12, fontweight="bold", color="darkgreen")
axes[0, 0].set_xlabel("Змінна X")
axes[0, 0].set_ylabel("Змінна Y")
axes[0, 0].grid(True, alpha=0.3)

# 2. Сильна негативна кореляція (r ≈ −0.92)
x2 = np.linspace(0, 10, 100)
y2 = 50 - 3 * x2 + rng.normal(0, 1.5, 100)
r2 = np.corrcoef(x2, y2)[0, 1]
axes[0, 1].scatter(x2, y2, alpha=0.6, color="red", s=60)
axes[0, 1].set_title(f"Сильна негативна кореляція\nr = {r2:.2f}", 
                     fontsize=12, fontweight="bold", color="darkred")
axes[0, 1].set_xlabel("Змінна X")
axes[0, 1].set_ylabel("Змінна Y")
axes[0, 1].grid(True, alpha=0.3)

# 3. Слабка кореляція (r ≈ +0.3)
x3 = rng.uniform(0, 10, 100)
y3 = 0.5 * x3 + rng.normal(0, 4, 100)
r3 = np.corrcoef(x3, y3)[0, 1]
axes[1, 0].scatter(x3, y3, alpha=0.6, color="orange", s=60)
axes[1, 0].set_title(f"Слабка позитивна кореляція\nr = {r3:.2f}",

axes[1, 0].set_xlabel("Змінна X")
axes[1, 0].set_ylabel("Змінна Y")
axes[1, 0].grid(True, alpha=0.3)

# 4. Немає кореляції (r ≈ 0)
x4 = rng.uniform(0, 10, 100)
y4 = rng.uniform(0, 10, 100)
r4 = np.corrcoef(x4, y4)[0, 1]

axes[1, 1].set_xlabel("Змінна X")
```

::warning
**Кореляція ≠ причинно-наслідковий зв'язок!**

Класичні приклади **хибної кореляції** (spurious correlation):

1. **Продажі морозива ↔ Кількість утоплень** (r ≈ +0.9)
   - Причина: обидві зростають влітку (третя змінна — температура)
   - Морозиво **не спричиняє** утоплення!

2. **Кількість пожежників на місці ↔ Збитки від пожежі** (r ≈ +0.85)
   - Більше пожежників → більші збитки? НІ!
   - Третя змінна: розмір пожежі (на велику пожежу відправляють більше людей)

**Правило:** scatter plot показує **асоціацію**, але не **каузальність**. Для причинно-наслідкового зв'язку потрібні експерименти, а не просто спостереження.
::

**Anscombe's Quartet** — класичний приклад

У 1973 році статистик Френсіс Енскомб створив 4 датасети, де:
- Середнє X ≈ 9.0
- Середнє Y ≈ 7.5
- Кореляція r ≈ 0.816
- Регресійна лінія **ідентична**

Але scatter plots **радикально різні**! Один — лінійний, другий — параболічний, третій — з викидом, четвертий — вертикальна лінія + одна точка.

**Висновок:** статистичні показники без візуалізації = сліпе водіння автомобіля.

```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: досвід роботи (роки) → зарплата ($)
rng = np.random.default_rng(seed=42)
experience = rng.uniform(0, 15, 80)
salary = 30000 + 3500 * experience + rng.normal(0, 8000, 80)

ax.plot(x_trend, p(x_trend), color="red", linestyle="--", linewidth=2.5, 
        label=f"Trend: зарплата ≈ {z[0]:.0f}·досвід + {z[1]:.0f}")

ax.set_title("Залежність зарплати від досвіду роботи", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Досвід роботи (роки)", fontsize=12)
ax.set_ylabel("Зарплата ($)", fontsize=12)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### Математичний апарат трендів: сигнатура `np.polyfit` та вибір ступеня полінома

Лінія тренду є результатом підгонки математичної моделі за **методом найменших квадратів (OLS — Ordinary Least Squares)**. Функція `np.polyfit()` обчислює коефіцієнти полінома $p(x) = c_d x^d + c_{d-1} x^{d-1} + \dots + c_1 x + c_0$, що мінімізує суму квадратичних відхилень від точок даних.

```python
np.polyfit(
    x, y,
    deg: int,
    rcond: float | None = None,
    full: bool = False,
    w: np.ndarray | None = None,
    cov: bool | str = False
) -> np.ndarray | tuple
```

| Параметр | Тип | За замовчуванням | Опис та інженерне значення |
| :--- | :--- | :--- | :--- |
| `x`, `y` | `ArrayLike` | *обов'язкові* | Масиви координат спостережень однакового розміру. |
| `deg` | `int` | *обов'язковий* | **Степінь апроксимуючого полінома**: `1` — пряма, `2` — парабола, `3` — кубічна крива. |
| `w` | `ArrayLike \| None` | `None` | Ваги для точок даних ($w_i = 1/\sigma_i$). Дозволяє враховувати точність окремих вимірів. |
| `full` | `bool` | `False` | Якщо `True`, повертає додаткову діагностику: нев'язки (residuals), ранг матриці, сингулярні числа. |
| `cov` | `bool \| str` | `False` | Якщо `True`, повертає коваріаційну матрицю оцінених коефіцієнтів (для побудови довірчих інтервалів). |

::jupyter-notebook{title="polyfit_degrees.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Дослідження степенів полінома: від наближення до оверфіттінгу
Порівняння лінійної апроксимації (deg=1), параболи (deg=2), кубічного тренду (deg=3) та небезпеки перенавчання (deg=10)

::jupyter-cell{executionCount="1" executionTime="0.28s"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
x = np.linspace(1, 10, 40)
# Нелінійний процес із шумом: сповільнений логарифмічний ріст + прискорення наприкінці
y = 3.5 * np.log(x) + 0.15 * (x - 4)**2 + rng.normal(0, 0.4, 40)
x_dense = np.linspace(1, 10, 200)

fig, axes = plt.subplots(2, 2, figsize=(13, 9.5))
degs = [1, 2, 3, 10]
configs = [
    ("deg=1 (Лінійний тренд)", "Підходить для строго лінійних залежностей", '#dc2626'),
    ("deg=2 (Квадратична парабола)", "Враховує прискорення росту або вигин", '#2563eb'),
    ("deg=3 (Кубічний поліном)", "Гнучка апроксимація складної траєкторії", '#16a34a'),
    ("deg=10 (Оверфіттінг / Перенавчання)", "Небезпека: модель апроксимує випадковий шум!", '#d97706')
]

for idx, (deg, (t_main, t_sub, col)) in enumerate(zip(degs, configs)):
    ax = axes[idx // 2, idx % 2]
    ax.scatter(x, y, color='#475569', s=55, alpha=0.75, edgecolor='#0f172a', label="Виміри")
    
    # Розрахунок полінома
    coefs = np.polyfit(x, y, deg)
    poly = np.poly1d(coefs)
    y_dense = poly(x_dense)
    
    if deg == 10:
        ax.set_ylim(y.min() - 1.5, y.max() + 1.5)
        
    ax.plot(x_dense, y_dense, color=col, linewidth=2.2, label=f"polyfit(deg={deg})")
    ax.set_title(f"{t_main}\n{t_sub}", fontweight='bold')
    ax.set_xlabel("Навантаження (X)")
    ax.set_ylabel("Час виконання (Y)")
    ax.grid(True, linestyle=':', alpha=0.6)
    ax.legend()

plt.tight_layout()
plt.show()
```

### Повна сигнатура `fig.colorbar()` та мультивимірне кодування (Bubble Chart)

Коли кольоровий градієнт кодує неперервну метрику, графік **обов'язково** повинен супроводжуватися шкалою відповідності значень кольорам — **Colorbar**. Метод `fig.colorbar()` підключається до об'єкта `ScalarMappable` (який повертає `ax.scatter()` або `ax.imshow()`).

```python
fig.colorbar(
    mappable,
    cax=None,
    ax=None,
    use_gridspec=True,
    location=None,
    orientation='vertical',  # або 'horizontal'
    fraction=0.15,
    shrink=1.0,
    aspect=20,
    pad=0.04,
    label='',
    **kwargs
) -> Colorbar
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `mappable` | `ScalarMappable` | *обов'язковий* | Графічний об'єкт, з якого беруться колірна карта та межі `vmin/vmax` (результат `ax.scatter()` або `ax.imshow()`). |
| `ax` | `Axes \| Sequence[Axes]` | `None` | Вісь (або список осей), від якої відбирається простір для розміщення смуги шкали. |

## Подолання оверплотингу: ax.hexbin() та 2D-густина

Коли обсяг даних сягає десятків або сотень тисяч записів (наприклад, реальні логи веб-сервера чи транзакції банку), класичний `ax.scatter()` стикається з критичною проблемою — **оверплотингом (Overplotting)**. Точки накладаються одна на одну, утворюючи суцільну темну пляму, де неможливо зрозуміти, чи в центрі 100 точок, чи 100 000.

Найефективніший інструмент розв'язання цієї проблеми в Matplotlib — **гексагональний біннінг (`ax.hexbin()`)**. Площина графіка розбивається на сітку правильних шестикутників (стільників), а колір кожного шестикутника відображає кількість точок, що потрапили всередину.

```python
ax.hexbin(
    x, y,
    C=None,
    gridsize=100,
    bins=None,
    xscale='linear',
    yscale='linear',
    cmap=None,
    norm=None,
    vmin=None,
    vmax=None,
    alpha=None,
    linewidths=None,
    edgecolors='none',
    reduce_C_function=np.mean,
    mincnt=None,
    marginals=False,
    **kwargs
) -> PolyCollection
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `x`, `y` | `ArrayLike` | *обов'язкові* | Масиви спостережень великого обсягу (тисячі або мільйони точок). |
| `gridsize` | `int \| tuple[int, int]` | `100` | Кількість шестикутників по осі X. Чим більше значення, тим дрібніша сітка і вища деталізація. |
| `bins` | `None \| 'log' \| Sequence` | `None` | Метод підрахунку щільності. При `'log'` значення сортуються за шкалою $\log_{10}(N)$, що рятує при наявності екстремальних піків. |
| `mincnt` | `int \| None` | `None` | Мінімальна кількість точок для відображення стільника. Якщо `mincnt=1`, порожні стільники залишаються прозорими фоновими. |
| `cmap` | `str \| Colormap` | `rcParams['image.cmap']` | Палітра градієнта щільності (`'inferno'`, `'Blues'`, `'viridis'`). |
| `edgecolors` | `color \| 'none'` | `'none'` | Колір меж стільників (часто `'none'` або тонка світло-сіра сітка). |

**Як читати scatter matrix:**

Він дозволяє візуалізувати двовимірний масив як матрицю кольорових пікселів із повним контролем над кожною клітинкою.

```python
fig.colorbar(im4, ax=axes[1, 1], fraction=0.046, pad=0.04)
axes[1, 1].set_xticks(range(len(metrics)))
axes[1, 1].set_yticks(range(len(metrics)))
axes[1, 1].set_xticklabels(metrics, rotation=35, ha='right')
axes[1, 1].set_yticklabels(metrics)
for i in range(len(metrics)):
    for j in range(len(metrics)):
        if mask[i, j]:
            val = corr[i, j]
            txt_col = 'white' if abs(val) > 0.65 else 'black'
            axes[1, 1].text(j, i, f"{val:.2f}", ha='center', va='center', 
                            color=txt_col, fontweight='bold', fontsize=9.5)
axes[1, 1].set_title("Трикутна маска (np.triu):\nусунення дублювання пар і тривіальної діагоналі", fontweight='bold')

plt.tight_layout()
plt.show()
```

### Професійний прийом: Маскування верхнього трикутника
Матриця кореляцій симетрична відносно головної діагоналі ($r_{ij} = r_{ji}$), а на самій діагоналі завжди стоять тривіальні одиниці ($r_{ii} = 1.0$). 
Використання `np.triu()` або `np.tril()` у поєднанні з `np.ma.masked_where()` зменшує візуальне навантаження на людину вдвічі, залишаючи лише унікальні співвідношення пар змінних.

## Резюме підтеми

::card-group

::card{title="📊 Scatter Plots" icon="i-lucide-scatter-chart"}

- `ax.scatter(x, y)` — візуалізація залежності між двома змінними
- Форма хмари точок показує тип кореляції:
  - Вгору вправо → позитивна (r > 0)
  - Вниз вправо → негативна (r < 0)
  - Хаос → немає лінійного зв'язку (r ≈ 0)
- Завжди **будуйте scatter перед обчисленням r**!

::

::card{title="🎯 Кореляція vs Каузальність" icon="i-lucide-alert-triangle"}

- **Кореляція** — це асоціація (A та B змінюються разом)
- **Каузальність** — причинно-наслідковий зв'язок (A спричиняє B)
- Scatter показує кореляцію, але **не доводить каузальність**
- Завжди шукайте третю змінну (confounder)

::

::card{title="🎨 Багатовимірна візуалізація" icon="i-lucide-layers"}

- Третя змінна → колір точок (`c=values, cmap="viridis"`)
- Четверта змінна → розмір точок (`s=sizes`)
- Scatter matrix → всі пари змінних одразу
- Кореляційна heatmap → компактна альтернатива
