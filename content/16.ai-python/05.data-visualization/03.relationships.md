## Історія про рієлтора та площу квартир

Рієлтор Олена хоче зрозуміти, чи **справді** ціна квартири залежить від площі. У неї є дані по 100 квартирах: площа та ціна.

Перший інстинкт — подивитися на таблицю:

```
Площа (м²) | Ціна ($)
-----------|----------
45         | 35 000
72         | 52 000
110        | 89 000
38         | 28 000
...        | ...
```

Важко побачити закономірність. А тепер — **один графік**:

::jupyter-notebook{title="housing_scatter.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Залежність ціни квартири від площі
Один графік показує більше, ніж 100 рядків таблиці
::

::jupyter-cell{executionCount="1" executionTime="0.19s"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Генеруємо реалістичні дані: ціна приблизно пропорційна площі + шум
rng = np.random.default_rng(seed=42)
area = rng.uniform(30, 150, 100)  # Площа 30–150 м²
price = 500 * area + rng.normal(0, 8000, 100)  # ~500$/м² + шум

fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(area, price, alpha=0.6, s=80, color="steelblue", edgecolor="navy")

ax.set_title("Залежність ціни квартири від площі", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Площа (м²)", fontsize=12)
ax.set_ylabel("Ціна ($)", fontsize=12)
ax.grid(True, alpha=0.3)

# Додаємо лінію тренду для наочності
z = np.polyfit(area, price, 1)  # Лінійна регресія
p = np.poly1d(z)
ax.plot(area, p(area), color="red", linestyle="--", linewidth=2, 
        label=f"Trend: ціна ≈ {z[0]:.0f}·площа + {z[1]:.0f}")
ax.legend(fontsize=11)

plt.tight_layout()
plt.show()
```

#output
![Scatter plot: площа vs ціна](/images/ai-python/data-visualization/relationships/01.png){.diagram-img}
::

::jupyter-cell{type="markdown"}
**Висновки одразу видно:**

1. Чіткий **позитивний** зв'язок: більша площа → вища ціна
2. Зв'язок майже **лінійний** (точки близько до прямої)
3. Є розкид (шум): не всі квартири однакової площі коштують однаково (впливають інші фактори)
4. Лінія тренду показує: **~500$ за кожен м²**

Це неможливо побачити в таблиці з 100 рядків!
::

::

::note
**Зв'язок з модулем статистики (04.statistics-basics/05.correlation):**

- Scatter plot **візуалізує** те, що описує коефіцієнт кореляції Пірсона
- Якщо точки йдуть «вгору вправо» — **позитивна кореляція** (r > 0)
- Якщо «вниз вправо» — **негативна кореляція** (r < 0)
- Якщо хаос — **немає лінійного зв'язку** (r ≈ 0)
- Чим щільніше точки до прямої — тим сильніша кореляція (|r| ближче до 1)
::

## Scatter Plots — точкові діаграми для двох змінних

### Що таке scatter plot?

**Scatter plot** — це графік, де кожна точка представляє одне спостереження з двома координатами: значення змінної X та значення змінної Y.

> Аналогія: уявіть, що ви вимірювали зріст та вагу 100 людей. Кожна людина — це одна точка на графіку: по горизонталі — зріст, по вертикалі — вага. Якщо точки йдуть «вгору вправо» — вищі люди зазвичай важчі (позитивна кореляція).

### Базовий scatter plot

::jupyter-notebook{title="scatter_basics.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: годин навчання → бали на іспиті (50 студентів)
rng = np.random.default_rng(seed=123)
hours_studied = rng.uniform(1, 10, 50)
exam_scores = 40 + 5 * hours_studied + rng.normal(0, 5, 50)

fig, ax = plt.subplots(figsize=(10, 6))

ax.scatter(hours_studied, exam_scores, s=100, alpha=0.6, 
           color="coral", edgecolor="darkred", linewidth=1.5)

ax.set_title("Залежність балів на іспиті від годин навчання", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Години навчання", fontsize=12)
ax.set_ylabel("Бали на іспиті (0–100)", fontsize=12)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Види кореляцій та їх візуалізація

Scatter plot одразу показує **тип зв'язку** між змінними.

::jupyter-notebook{title="correlation_types.ipynb"}

::jupyter-cell{type="markdown"}
### Чотири типи залежностей
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Типи кореляцій та їх візуалізація", fontsize=16, fontweight="bold")

# 1. Сильна позитивна кореляція (r ≈ +0.95)
x1 = np.linspace(0, 10, 100)
y1 = 2 * x1 + 3 + rng.normal(0, 1, 100)
r1 = np.corrcoef(x1, y1)[0, 1]
axes[0, 0].scatter(x1, y1, alpha=0.6, color="green", s=60)
axes[0, 0].set_title(f"Сильна позитивна кореляція\nr = {r1:.2f}", 
                     fontsize=12, fontweight="bold", color="darkgreen")
axes[0, 0].set_xlabel("Змінна X")
axes[0, 0].set_ylabel("Змінна Y")
axes[0, 0].grid(True, alpha=0.3)

# 2. Сильна негативна кореляція (r ≈ −0.92)
x2 = np.linspace(0, 10, 100)
y2 = 50 - 3 * x2 + rng.normal(0, 1.5, 100)
r2 = np.corrcoef(x2, y2)[0, 1]
axes[0, 1].scatter(x2, y2, alpha=0.6, color="red", s=60)
axes[0, 1].set_title(f"Сильна негативна кореляція\nr = {r2:.2f}", 
                     fontsize=12, fontweight="bold", color="darkred")
axes[0, 1].set_xlabel("Змінна X")
axes[0, 1].set_ylabel("Змінна Y")
axes[0, 1].grid(True, alpha=0.3)

# 3. Слабка кореляція (r ≈ +0.3)
x3 = rng.uniform(0, 10, 100)
y3 = 0.5 * x3 + rng.normal(0, 4, 100)
r3 = np.corrcoef(x3, y3)[0, 1]
axes[1, 0].scatter(x3, y3, alpha=0.6, color="orange", s=60)
axes[1, 0].set_title(f"Слабка позитивна кореляція\nr = {r3:.2f}", 
                     fontsize=12, fontweight="bold", color="darkorange")
axes[1, 0].set_xlabel("Змінна X")
axes[1, 0].set_ylabel("Змінна Y")
axes[1, 0].grid(True, alpha=0.3)

# 4. Немає кореляції (r ≈ 0)
x4 = rng.uniform(0, 10, 100)
y4 = rng.uniform(0, 10, 100)
r4 = np.corrcoef(x4, y4)[0, 1]
axes[1, 1].scatter(x4, y4, alpha=0.6, color="gray", s=60)
axes[1, 1].set_title(f"Немає лінійної кореляції\nr = {r4:.2f}", 
                     fontsize=12, fontweight="bold", color="black")
axes[1, 1].set_xlabel("Змінна X")
axes[1, 1].set_ylabel("Змінна Y")
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Чотири типи кореляцій](/images/ai-python/data-visualization/relationships/04.png){.diagram-img}

::

::warning
**Кореляція ≠ причинно-наслідковий зв'язок!**

Класичні приклади **хибної кореляції** (spurious correlation):

1. **Продажі морозива ↔ Кількість утоплень** (r ≈ +0.9)
   - Причина: обидві зростають влітку (третя змінна — температура)
   - Морозиво **не спричиняє** утоплення!

2. **Кількість пожежників на місці ↔ Збитки від пожежі** (r ≈ +0.85)
   - Більше пожежників → більші збитки? НІ!
   - Третя змінна: розмір пожежі (на велику пожежу відправляють більше людей)

**Правило:** scatter plot показує **асоціацію**, але не **каузальність**. Для причинно-наслідкового зв'язку потрібні експерименти, а не просто спостереження.
::

## Лінійні vs нелінійні залежності

Коефіцієнт кореляції Пірсона вимірює **лише лінійний** зв'язок. Scatter plot може показати **нелінійні** залежності, які кореляція не бачить.

::jupyter-notebook{title="linear_vs_nonlinear.ipynb"}

::jupyter-cell{type="markdown"}
### Коли коефіцієнт кореляції вводить в оману
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

fig, axes = plt.subplots(1, 3, figsize=(16, 5))
fig.suptitle("Лінійні vs нелінійні залежності", fontsize=15, fontweight="bold")

# 1. Лінійна залежність (r показує правильно)
x1 = np.linspace(0, 10, 100)
y1 = 2 * x1 + rng.normal(0, 2, 100)
r1 = np.corrcoef(x1, y1)[0, 1]

axes[0].scatter(x1, y1, alpha=0.6, color="blue", s=50)
axes[0].set_title(f"Лінійна залежність\nr = {r1:.2f} (адекватно)", fontweight="bold")
axes[0].set_xlabel("X")
axes[0].set_ylabel("Y")
axes[0].grid(True, alpha=0.3)

# 2. Квадратична залежність (r близький до 0, але зв'язок очевидний!)
x2 = np.linspace(-5, 5, 100)
y2 = x2**2 + rng.normal(0, 2, 100)
r2 = np.corrcoef(x2, y2)[0, 1]

axes[1].scatter(x2, y2, alpha=0.6, color="red", s=50)
axes[1].set_title(f"Квадратична залежність\nr = {r2:.2f} (вводить в оману!)", 
                  fontweight="bold", color="darkred")
axes[1].set_xlabel("X")
axes[1].set_ylabel("Y = X²")
axes[1].grid(True, alpha=0.3)

# 3. Синусоїдальна залежність (r ≈ 0, але чіткий паттерн)
x3 = np.linspace(0, 4*np.pi, 100)
y3 = np.sin(x3) + rng.normal(0, 0.1, 100)
r3 = np.corrcoef(x3, y3)[0, 1]

axes[2].scatter(x3, y3, alpha=0.6, color="green", s=50)
axes[2].set_title(f"Періодична залежність\nr = {r3:.2f} (не бачить паттерн)", 
                  fontweight="bold", color="darkgreen")
axes[2].set_xlabel("X")
axes[2].set_ylabel("Y = sin(X)")
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Лінійні vs нелінійні залежності](/images/ai-python/data-visualization/relationships/05.png){.diagram-img}
::

::jupyter-cell{type="markdown"}
**Мораль:** завжди **будуйте scatter plot** перед обчисленням кореляції! Число (r) може бути оманливим, графік — ніколи.
::

::

::note
**Anscombe's Quartet** — класичний приклад

У 1973 році статистик Френсіс Енскомб створив 4 датасети, де:
- Середнє X ≈ 9.0
- Середнє Y ≈ 7.5
- Кореляція r ≈ 0.816
- Регресійна лінія **ідентична**

Але scatter plots **радикально різні**! Один — лінійний, другий — параболічний, третій — з викидом, четвертий — вертикальна лінія + одна точка.

**Висновок:** статистичні показники без візуалізації = сліпе водіння автомобіля.
::

## Додавання лінії тренду (regression line)

Лінія тренду допомагає побачити **загальну тенденцію** навіть у розкиданих даних.

::jupyter-notebook{title="trend_line.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані: досвід роботи (роки) → зарплата ($)
rng = np.random.default_rng(seed=42)
experience = rng.uniform(0, 15, 80)
salary = 30000 + 3500 * experience + rng.normal(0, 8000, 80)

fig, ax = plt.subplots(figsize=(10, 6))

# Scatter plot
ax.scatter(experience, salary, alpha=0.6, s=70, color="purple", 
           edgecolor="darkviolet", label="Дані")

# Лінія тренду (лінійна регресія)
z = np.polyfit(experience, salary, 1)  # Поліном 1-го ступеня (пряма)
p = np.poly1d(z)

x_trend = np.linspace(experience.min(), experience.max(), 100)
ax.plot(x_trend, p(x_trend), color="red", linestyle="--", linewidth=2.5, 
        label=f"Trend: зарплата ≈ {z[0]:.0f}·досвід + {z[1]:.0f}")

ax.set_title("Залежність зарплати від досвіду роботи", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Досвід роботи (роки)", fontsize=12)
ax.set_ylabel("Зарплата ($)", fontsize=12)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Scatter з лінією тренду](/images/ai-python/data-visualization/relationships/06.png){.diagram-img}

::tip
**Як додати лінію тренду:**

```python
# Метод 1: NumPy polyfit (універсальний)
z = np.polyfit(x, y, deg=1)  # deg=1 → пряма, deg=2 → парабола
p = np.poly1d(z)
ax.plot(x_sorted, p(x_sorted), color="red", linestyle="--")

# Метод 2: SciPy linregress (більше статистики)
from scipy.stats import linregress
slope, intercept, r_value, p_value, std_err = linregress(x, y)
ax.plot(x_sorted, slope * x_sorted + intercept, color="red")
print(f"R²= {r_value**2:.3f}")  # Коефіцієнт детермінації

# Метод 3: Seaborn regplot (найпростіше, але потребує seaborn)
import seaborn as sns
sns.regplot(x=x, y=y, ax=ax, scatter_kws={"alpha": 0.5})
```

## Колірне кодування третьої змінної

Іноді потрібно показати **три** змінні на одному scatter plot. Третю змінну можна закодувати **кольором** або **розміром** точок.

::jupyter-notebook{title="color_coding.ipynb"}

::jupyter-cell{type="markdown"}
### Візуалізація трьох змінних одночасно
Розмір точок = ціна, колір = район
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані про квартири: площа, кімнати, район (0=Схід, 1=Центр, 2=Захід)
rng = np.random.default_rng(seed=42)
n = 150
area = rng.uniform(30, 120, n)
rooms = rng.integers(1, 5, n)
district = rng.choice([0, 1, 2], n, p=[0.4, 0.3, 0.3])

# Ціна залежить від площі та району
price_per_sqm = np.array([400, 600, 500])  # Центр дорожчий
price = price_per_sqm[district] * area + rng.normal(0, 5000, n)

fig, ax = plt.subplots(figsize=(12, 7))

# Scatter з кольоровим кодуванням району
colors = ["#FF6B6B", "#4ECDC4", "#95E1D3"]  # Схід, Центр, Захід
district_names = ["Схід", "Центр", "Захід"]

for i, (color, name) in enumerate(zip(colors, district_names)):
    mask = district == i
    ax.scatter(area[mask], price[mask], c=color, s=80, alpha=0.7, 
               edgecolor="black", linewidth=0.5, label=name)

ax.set_title("Ціна квартир: площа vs район", fontsize=14, fontweight="bold")
ax.set_xlabel("Площа (м²)", fontsize=12)
ax.set_ylabel("Ціна ($)", fontsize=12)
ax.legend(title="Район", fontsize=11)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### Розмір точок як четверта змінна

::jupyter-notebook{title="size_coding.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Дані про міста: населення, ВВП на душу, регіон, площа міста
rng = np.random.default_rng(seed=123)
n = 50
population = rng.uniform(100, 5000, n)  # тисяч людей
gdp_per_capita = rng.uniform(5000, 50000, n)  # $
city_area = rng.uniform(50, 500, n)  # км²

fig, ax = plt.subplots(figsize=(12, 7))

# Розмір точок пропорційний площі міста
scatter = ax.scatter(population, gdp_per_capita, s=city_area, alpha=0.6, 
                     c=city_area, cmap="viridis", edgecolor="black", linewidth=1)

ax.set_title("Населення vs ВВП на душу (розмір точки = площа міста)", 
             fontsize=14, fontweight="bold")
ax.set_xlabel("Населення (тис. осіб)", fontsize=12)
ax.set_ylabel("ВВП на душу ($)", fontsize=12)
ax.grid(True, alpha=0.3)

# Додаємо colorbar для пояснення кольорів
cbar = plt.colorbar(scatter, ax=ax)
cbar.set_label("Площа міста (км²)", fontsize=11)

# Легенда для розміру точок
sizes = [100, 300, 500]
labels = ["100 км²", "300 км²", "500 км²"]
legend_handles = [plt.scatter([], [], s=size, c="gray", alpha=0.6, edgecolor="black") 
                  for size in sizes]
ax.legend(legend_handles, labels, title="Площа міста", 
          loc="upper left", frameon=True, fontsize=10)

plt.tight_layout()
plt.show()
```

## Scatter Matrix — всі пари змінних одразу

Коли у датасеті багато змінних, корисно побачити **всі можливі пари** scatter plots одночасно.

::jupyter-notebook{title="scatter_matrix.ipynb"}

::jupyter-cell{type="markdown"}
### Scatter Matrix для багатовимірного датасету
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Створюємо датасет з 4 змінними
rng = np.random.default_rng(seed=42)
n = 200

data = pd.DataFrame({
    "Зріст (см)": rng.normal(170, 10, n),
    "Вага (кг)": rng.normal(70, 15, n),
    "Вік (роки)": rng.uniform(18, 65, n),
    "Дохід ($)": rng.lognormal(10, 0.5, n)
})

# Додаємо кореляцію між зростом та вагою
data["Вага (кг)"] = 0.4 * data["Зріст (см)"] + rng.normal(0, 8, n)

# Scatter matrix
from pandas.plotting import scatter_matrix

fig, axes = plt.subplots(4, 4, figsize=(14, 14))
scatter_matrix(data, ax=axes, alpha=0.6, figsize=(14, 14), 
               diagonal="hist", color="steelblue", edgecolor="navy", 
               linewidth=0.5, hist_kwds={"bins": 20, "edgecolor": "black"})

plt.suptitle("Scatter Matrix: всі пари змінних", fontsize=16, fontweight="bold", y=0.995)
plt.tight_layout()
plt.show()
```

::jupyter-cell{type="markdown"}
**Як читати scatter matrix:**

- **Діагональ** — гістограми розподілу кожної змінної
- **Поза діагоналлю** — scatter plots для пар змінних
- Клітинка (i, j) = scatter(змінна_i vs змінна_j)
- Симетрія: клітинка (i, j) = клітинка (j, i), але осі поміняні місцями

**Що шукати:**
- Сильні кореляції (точки вздовж прямої)
- Нелінійні залежності (викривлені паттерни)
- Викиди (самотні точки далеко від кластера)
::

::

::note
**Альтернатива — heatmap кореляційної матриці:**

Якщо змінних дуже багато (>8), scatter matrix стає нечитабельним. Використовуйте **кореляційну матрицю**:


## Резюме підтеми

::card-group

::card{title="📊 Scatter Plots" icon="i-lucide-scatter-chart"}

- `ax.scatter(x, y)` — візуалізація залежності між двома змінними
- Форма хмари точок показує тип кореляції:
  - Вгору вправо → позитивна (r > 0)
  - Вниз вправо → негативна (r < 0)
  - Хаос → немає лінійного зв'язку (r ≈ 0)
- Завжди **будуйте scatter перед обчисленням r**!

::

::card{title="🎯 Кореляція vs Каузальність" icon="i-lucide-alert-triangle"}

- **Кореляція** — це асоціація (A та B змінюються разом)
- **Каузальність** — причинно-наслідковий зв'язок (A спричиняє B)
- Scatter показує кореляцію, але **не доводить каузальність**
- Завжди шукайте третю змінну (confounder)

::

::card{title="🎨 Багатовимірна візуалізація" icon="i-lucide-layers"}

- Третя змінна → колір точок (`c=values, cmap="viridis"`)
- Четверта змінна → розмір точок (`s=sizes`)
- Scatter matrix → всі пари змінних одразу
- Кореляційна heatmap → компактна альтернатива

::
