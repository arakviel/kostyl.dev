## Історія про аналітика та квартальний звіт

Аналітик Ганна готує квартальний звіт для CEO. Їй потрібно показати:
1. Динаміку продажів за 12 місяців
2. Розподіл клієнтів за віком
3. Топ-5 продуктів за виручкою
4. Кореляцію між витратами на маркетинг та продажами

Вона може створити 4 окремі файли з графіками. Але CEO хоче **одну сторінку** — щоб порівняти все одним поглядом.

Рішення: **subplots** — 4 графіки на одній фігурі.

::jupyter-notebook{title="dashboard_example.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Квартальний дашборд: чотири ключові метрики
::

::jupyter-cell{executionCount="1" executionTime="0.35s"}
```python
import matplotlib.pyplot as plt
import numpy as np

np.random.seed(42)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Квартальний звіт Q4 2026 — Ключові метрики", 
             fontsize=16, fontweight="bold")

# 1. Динаміка продажів (лінійний графік)
months = ["Січ", "Лют", "Бер", "Кві", "Тра", "Чер", 
          "Лип", "Сер", "Вер", "Жов", "Лис", "Гру"]
sales = [120, 135, 150, 145, 160, 180, 190, 185, 200, 220, 240, 260]

axes[0, 0].plot(months, sales, marker="o", linewidth=2.5, color="steelblue")
axes[0, 0].fill_between(range(len(months)), sales, alpha=0.3, color="steelblue")
axes[0, 0].set_title("Динаміка продажів (тис. грн)", fontweight="bold")
axes[0, 0].set_ylabel("Продажі")
axes[0, 0].grid(True, alpha=0.3)
axes[0, 0].tick_params(axis="x", rotation=45)

# 2. Розподіл клієнтів за віком (гістограма)
ages = np.random.normal(35, 12, 500)
axes[0, 1].hist(ages, bins=25, color="coral", edgecolor="black", alpha=0.7)
axes[0, 1].axvline(np.mean(ages), color="red", linestyle="--", linewidth=2, 
                   label=f"Середнє: {np.mean(ages):.1f}")
axes[0, 1].set_title("Розподіл клієнтів за віком", fontweight="bold")
axes[0, 1].set_xlabel("Вік (роки)")
axes[0, 1].set_ylabel("Кількість клієнтів")
axes[0, 1].legend()
axes[0, 1].grid(axis="y", alpha=0.3)

# 3. Топ-5 продуктів (bar chart)
products = ["Продукт A", "Продукт B", "Продукт C", "Продукт D", "Продукт E"]
revenue = [450, 380, 320, 280, 210]

axes[1, 0].barh(products, revenue, color="mediumseagreen", edgecolor="black")
axes[1, 0].set_title("Топ-5 продуктів за виручкою (тис. грн)", fontweight="bold")
axes[1, 0].set_xlabel("Виручка")
axes[1, 0].grid(axis="x", alpha=0.3)

# 4. Кореляція маркетинг — продажі (scatter)
marketing = np.array([10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60, 65])
sales_vs_marketing = 3 * marketing + 80 + np.random.normal(0, 10, 12)

axes[1, 1].scatter(marketing, sales_vs_marketing, s=100, alpha=0.7, 
                   color="purple", edgecolor="black")

# Лінія тренду
z = np.polyfit(marketing, sales_vs_marketing, 1)
p = np.poly1d(z)
axes[1, 1].plot(marketing, p(marketing), "r--", linewidth=2, 
                label=f"r = {np.corrcoef(marketing, sales_vs_marketing)[0,1]:.2f}")

axes[1, 1].set_title("Маркетинг vs Продажі", fontweight="bold")
axes[1, 1].set_xlabel("Витрати на маркетинг (тис. грн)")
axes[1, 1].set_ylabel("Продажі (тис. грн)")
axes[1, 1].legend()
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

#output

::

::jupyter-cell{type="markdown"}
**Переваги композиції:**

1. **Одна сторінка** замість чотирьох окремих файлів
2. **Швидке порівняння** — CEO бачить усі метрики одночасно
3. **Контекст** — динаміка продажів зрозуміліша поруч з маркетингом
4. **Професійний вигляд** — єдиний загальний заголовок, узгоджені кольори
::

::note
**Правило дашбордів:**

Кількість графіків на одній фігурі: **3–6 оптимально**, 9 максимум. Більше — розділіть на кілька сторінок.

Причина: когнітивне навантаження. Людина може утримати в уваіу ~5–7 об'єктів одночасно.

## Базові subplots — регулярна сітка

### Створення сітки 2×2

::jupyter-notebook{title="subplots_basic.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Створюємо сітку 2x2
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# axes — це масив NumPy розміром (2, 2)
print(f"Тип axes: {type(axes)}")
print(f"Форма axes: {axes.shape}")

# Звертаємося до конкретних осей через індекси
axes[0, 0].plot([1, 2, 3], [1, 4, 9], 'r-o')
axes[0, 0].set_title("Графік 1: Квадрати")

axes[0, 1].hist(np.random.normal(0, 1, 500), bins=30, color="green", alpha=0.7)
axes[0, 1].set_title("Графік 2: Гістограма")

axes[1, 0].scatter(np.random.rand(50), np.random.rand(50), s=100, alpha=0.6)
axes[1, 0].set_title("Графік 3: Scatter")

axes[1, 1].bar(["A", "B", "C"], [10, 25, 15], color=["red", "blue", "green"])
axes[1, 1].set_title("Графік 4: Bar Chart")

plt.tight_layout()
plt.show()
```

Форма axes: (2, 2)

::tip
**Основні параметри `plt.subplots()`:**

```python
fig, axes = plt.subplots(nrows=2,        # Кількість рядків
                         ncols=3,        # Кількість стовпців
                         figsize=(12,8), # Розмір фігури (ширина, висота)
                         sharex=False,   # Спільна вісь X?
                         sharey=False,   # Спільна вісь Y?
                         squeeze=True)   # Якщо 1 Axes, повернути його (не масив)
```

![Демонстрація параметрів plt.subplots](/images/ai-python/data-visualization/subplots-styling/03.png){.diagram-img}

**Повернене значення:**
- Якщо `nrows=1, ncols=1` → `axes` — один об'єкт Axes
- Якщо один вимір > 1 → `axes` — одновимірний масив
- Якщо обидва виміри > 1 → `axes` — двовимірний масив

## Доступ до осей у різних конфігураціях

::jupyter-notebook{title="axes_access.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt

# Конфігурація 1: один рядок, три стовпці
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# axes — одновимірний масив [ax0, ax1, ax2]
axes[0].plot([1, 2, 3])
axes[1].bar(["A", "B"], [5, 10])
axes[2].scatter([1, 2], [3, 4])

plt.tight_layout()
plt.show()

# Конфігурація 2: три рядки, один стовпець
fig, axes = plt.subplots(3, 1, figsize=(8, 10))

# axes — одновимірний масив [ax0, ax1, ax2]
axes[0].plot([1, 2, 3])
axes[1].bar(["A", "B"], [5, 10])
axes[2].scatter([1, 2], [3, 4])

plt.tight_layout()
plt.show()

# Конфігурація 3: 2x3 сітка
fig, axes = plt.subplots(2, 3, figsize=(15, 8))

# axes — двовимірний масив (2, 3)
axes[0, 0].plot([1, 2])
axes[1, 2].bar(["X"], [7])

plt.tight_layout()
plt.show()
```

fig, axes = plt.subplots(2, 3)
axes_flat = axes.flatten()  # Тепер завжди одновимірний масив [ax0, ax1, ..., ax5]

## GridSpec — нестандартні компоновки

Іноді потрібна **асиметрична** сітка: один великий графік зліва + два маленькі справа.

::jupyter-notebook{title="gridspec_example.ipynb"}

::jupyter-cell{type="markdown"}
### GridSpec для складних композицій
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec
import numpy as np

fig = plt.figure(figsize=(12, 8))
gs = gridspec.GridSpec(2, 2, figure=fig, width_ratios=[2, 1], height_ratios=[1, 1])

# Лівий графік — займає два рядки
ax_left = fig.add_subplot(gs[:, 0])  # Всі рядки (:), перший стовпець (0)
x = np.linspace(0, 10, 100)
ax_left.plot(x, np.sin(x), label="sin(x)", linewidth=2)
ax_left.plot(x, np.cos(x), label="cos(x)", linewidth=2)
ax_left.set_title("Основний графік (великий)", fontsize=13, fontweight="bold")
ax_left.legend()
ax_left.grid(True, alpha=0.3)

# Правий верхній
ax_top_right = fig.add_subplot(gs[0, 1])
ax_top_right.hist(np.random.normal(0, 1, 300), bins=20, color="coral", edgecolor="black")
ax_top_right.set_title("Деталь 1", fontweight="bold")

# Правий нижній
ax_bottom_right = fig.add_subplot(gs[1, 1])
ax_bottom_right.scatter(np.random.rand(50), np.random.rand(50), s=80, alpha=0.7, c="purple")
ax_bottom_right.set_title("Деталь 2", fontweight="bold")

plt.tight_layout()
plt.show()
```

#output
![GridSpec асиметрична композиція](/images/ai-python/data-visualization/subplots-styling/05.png){.diagram-img}
::

::

::tip
**Синтаксис GridSpec:**

```python
gs = gridspec.GridSpec(nrows, ncols, 
                       figure=fig,
                       width_ratios=[2, 1],   # Співвідношення ширини стовпців
                       height_ratios=[1, 2],  # Співвідношення висоти рядків
                       wspace=0.3,            # Горизонтальний проміжок
                       hspace=0.4)            # Вертикальний проміжок

# Додавання осей:
ax = fig.add_subplot(gs[row, col])         # Одна клітинка
ax = fig.add_subplot(gs[row1:row2, col])   # Кілька рядків
ax = fig.add_subplot(gs[:, col1:col2])     # Кілька стовпців
```

**Зрізи (slicing):**
- `gs[0, 1]` — рядок 0, стовпець 1
- `gs[:, 0]` — всі рядки, стовпець 0
- `gs[1:3, :]` — рядки 1–2, всі стовпці
::

## Спільні осі (sharex, sharey)

Коли графіки порівнюються, корисно мати спільні осі для вирівнювання масштабу.

::jupyter-notebook{title="shared_axes.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)

fig, axes = plt.subplots(3, 1, figsize=(10, 10), sharex=True, sharey=True)

# Три різні функції з однаковим діапазоном X
axes[0].plot(x, np.sin(x), color="blue")
axes[0].set_title("sin(x)")
axes[0].grid(True, alpha=0.3)

axes[1].plot(x, np.sin(2*x), color="red")
axes[1].set_title("sin(2x)")
axes[1].set_ylabel("Амплітуда (спільна вісь Y)", fontsize=12, fontweight="bold")
axes[1].grid(True, alpha=0.3)

axes[2].plot(x, np.sin(3*x), color="green")
axes[2].set_title("sin(3x)")
axes[2].set_xlabel("X (спільна вісь)", fontsize=12, fontweight="bold")
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

#output
![Графіки зі спільною віссю X](/images/ai-python/data-visualization/subplots-styling/06.png){.diagram-img}
::

::

::note
**Переваги `sharex` та `sharey`:**

1. **Автоматична синхронізація масштабу** — зум на одному графіку → зум на всіх
2. **Економія місця** — мітки осі показуються лише на крайніх графіках
3. **Легше порівнювати** — однаковий масштаб дозволяє бачити різницю у величині

**Коли використовувати:**
- `sharex` — часові серії (усі мають однаковий діапазон дат)
- `sharey` — графіки з однаковими одиницями виміру
- Обидва — порівняння подібних метрик (продажі в різних регіонах)
::

## Кольорові схеми та теми

Matplotlib підтримує готові теми (styles) для швидкої зміни вигляду графіків.

::jupyter-notebook{title="styles_demo.ipynb"}

::jupyter-cell{type="markdown"}
### Порівняння стилів matplotlib
::

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

styles = ["default", "seaborn-v0_8-darkgrid", "ggplot", "bmh"]
x = np.linspace(0, 10, 100)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Порівняння стилів matplotlib", fontsize=16, fontweight="bold")

for ax, style in zip(axes.flat, styles):
    with plt.style.context(style):  # Тимчасово застосовуємо стиль
        ax.plot(x, np.sin(x), label="sin(x)", linewidth=2)
        ax.plot(x, np.cos(x), label="cos(x)", linewidth=2)
        ax.set_title(f"Стиль: {style}", fontweight="bold")
        ax.legend()
        ax.grid(True)

plt.tight_layout()
plt.show()
```

#output
![Порівняння 4 стилів](/images/ai-python/data-visualization/subplots-styling/07.png){.diagram-img}

::tip
**Популярні стилі matplotlib:**

```python
# Застосувати стиль глобально
plt.style.use("seaborn-v0_8-darkgrid")

# Застосувати тимчасово (context manager)
with plt.style.context("ggplot"):
    plt.plot([1, 2, 3])
    plt.show()
```

| Стиль | Опис | Коли використовувати |
|:------|:-----|:---------------------|
| `default` | Класичний matplotlib | Технічна документація |
| `seaborn-v0_8-darkgrid` | Світлий фон + сітка | Статистичні звіти |
| `ggplot` | Стиль R ggplot2 | Наукові статті |
| `bmh` | Bayesian Methods for Hackers | Презентації |
| `fivethirtyeight` | Стиль сайту FiveThirtyEight | Журналістика даних |
| `dark_background` | Темний фон | Презентації в темряві |

Список всіх: `print(plt.style.available)`

## Кастомізація кольорових палітр

::jupyter-notebook{title="color_palettes.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Створюємо дані: 5 категорій
categories = ["A", "B", "C", "D", "E"]
values = [23, 45, 56, 78, 32]

fig, axes = plt.subplots(2, 3, figsize=(16, 9))
fig.suptitle("Кольорові палітри для категорій", fontsize=15, fontweight="bold")

# 1. Дефолтні кольори matplotlib (C0, C1, ...)
axes[0, 0].bar(categories, values, color=[f"C{i}" for i in range(5)], edgecolor="black")
axes[0, 0].set_title("Default (C0–C9)")

# 2. Tab10 (10 розрізнюваних кольорів)
colors_tab10 = plt.cm.tab10(np.linspace(0, 1, 5))
axes[0, 1].bar(categories, values, color=colors_tab10, edgecolor="black")
axes[0, 1].set_title("Tab10 (рекомендовано)")

# 3. Viridis (послідовна палітра)
colors_viridis = plt.cm.viridis(np.linspace(0, 1, 5))
axes[0, 2].bar(categories, values, color=colors_viridis, edgecolor="black")
axes[0, 2].set_title("Viridis")

# 4. Pastel (м'які кольори)
colors_pastel = plt.cm.Pastel1(np.linspace(0, 1, 5))
axes[1, 0].bar(categories, values, color=colors_pastel, edgecolor="black")
axes[1, 0].set_title("Pastel1")

# 5. Set3 (категоріальні)
colors_set3 = plt.cm.Set3(np.linspace(0, 1, 5))
axes[1, 1].bar(categories, values, color=colors_set3, edgecolor="black")
axes[1, 1].set_title("Set3")

# 6. Кастомна палітра (власні HEX кольори)
custom_colors = ["#FF6B6B", "#4ECDC4", "#95E1D3", "#FFD93D", "#C7CEEA"]
axes[1, 2].bar(categories, values, color=custom_colors, edgecolor="black")
axes[1, 2].set_title("Кастомна (HEX)")

plt.tight_layout()
plt.show()
```

#output
![Порівняння кольорових палітр](/images/ai-python/data-visualization/subplots-styling/08.png){.diagram-img}
::

::

::warning
**Accessibility: Колірна сліпота**

~8% чоловіків та ~0.5% жінок мають порушення кольорового зору (найчастіше — червоний/зелений).

**Безпечні палітри (colorblind-safe):**
- `viridis`, `plasma`, `cividis` — послідовні
- `tab10`, `Paired` — категоріальні
- Використовуйте **різні стилі ліній** (`linestyle`) як додатковий канал

**Уникайте:** червоний + зелений для критичних розрізнень (як стоп/іти).

Перевірити: [Color Blindness Simulator](https://www.color-blindness.com/coblis-color-blindness-simulator/)
::

## Анотації та текстові підписи

::jupyter-notebook{title="annotations.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = np.sin(x) * np.exp(-x/10)

fig, ax = plt.subplots(figsize=(12, 7))

ax.plot(x, y, linewidth=2.5, color="darkblue")

# Знаходимо максимум
max_idx = np.argmax(y)
max_x, max_y = x[max_idx], y[max_idx]

# Анотація зі стрілкою
ax.annotate("Локальний максимум", 
            xy=(max_x, max_y),                    # Точка, на яку вказуємо
            xytext=(max_x + 2, max_y + 0.3),      # Розташування тексту
            fontsize=12, fontweight="bold", color="darkred",
            arrowprops=dict(arrowstyle="->", color="red", lw=2),
            bbox=dict(boxstyle="round,pad=0.5", facecolor="yellow", alpha=0.8))

# Точка на максимумі
ax.plot(max_x, max_y, "ro", markersize=12, label=f"Max: ({max_x:.2f}, {max_y:.2f})")

# Горизонтальна лінія через максимум
ax.axhline(max_y, color="gray", linestyle="--", alpha=0.5)

# Вертикальна лінія
ax.axvline(max_x, color="gray", linestyle="--", alpha=0.5)

# Текст без стрілки
ax.text(7, -0.2, "Загасаюча амплітуда", fontsize=11, 
        style="italic", bbox=dict(boxstyle="round", facecolor="lightblue", alpha=0.6))

ax.set_title("Загасаюча синусоїда з анотаціями", fontsize=14, fontweight="bold")
ax.set_xlabel("X")
ax.set_ylabel("Y")
ax.legend(loc="upper right")
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Резюме підтеми

::card-group

::card{title="🎨 Subplots" icon="i-lucide-layout-grid"}

- `plt.subplots(nrows, ncols)` → регулярна сітка
- GridSpec → асиметричні композиції
- `sharex`, `sharey` → спільні осі для порівняння
- `tight_layout()` → автоматичне вирівнювання
- Оптимально: 3–6 графіків на одній фігурі

::

::card{title="🎨 Стилізація" icon="i-lucide-palette"}

- `plt.style.use("seaborn")` → готові теми
- Кольорові палітри: `tab10`, `viridis`, `Pastel1`
- Colorblind-safe: `viridis`, `plasma`, `tab10`
- Анотації: `ax.annotate()`, `ax.text()`
- Zones: `ax.axvspan()`, `ax.axhspan()`

::

::card{title="🎯 Дашборди" icon="i-lucide-monitor"}

- Один заголовок для всієї фігури: `fig.suptitle()`
- Єдина кольорова схема для узгодженості
- Логічна компоновка: головне → великим, деталі → малим
- Збереження: PNG (веб, звіти), PDF (друк, публікації)
- Роздільна здатність: 150 dpi (екран), 300 dpi (друк)

::
