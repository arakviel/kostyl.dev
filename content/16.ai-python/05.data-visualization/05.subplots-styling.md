## Плавний старт: Subplots за 3 рядки коду

Коли для повноти аналізу одного графіка недостатньо, інженери об'єднують кілька панелей на одній фігурі — створюють **subplots**. Це дозволяє порівнювати метрики різних систем в одному візуальному контексті.

Погляньмо, як від трьох мінімальних рядків перейти до повноцінного центру моніторингу:

::jupyter-notebook{title="hello_subplots.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Три рівні створення багатопанельних композицій
Від створення сітки 1×2 у 3 рядки до інженерного дашборду з пороговими лініями SLA
::

::jupyter-cell{executionCount="1" executionTime="0.21s"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Синтетичні дані моніторингу сервера: 60 хвилин роботи
rng = np.random.default_rng(42)
t = np.linspace(0, 60, 60)
cpu = 35 + 20 * np.sin(t / 8) + rng.normal(0, 3, 60)
ram = 4 + 0.05 * t + rng.normal(0, 0.1, 60)

# --- РІВЕНЬ 0: Мінімальний код (3 рядки) ---
fig, (ax1, ax2) = plt.subplots(1, 2)
plt.show()

# --- РІВЕНЬ 1: Розділені осі та фізичні одиниці виміру ---
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(7, 4.5))
ax1.plot(t, cpu, color='#2563eb')
ax1.set_ylabel("CPU (%)")
ax1.set_title("Навантаження обчислювального вузла")
ax1.grid(True, linestyle=':', alpha=0.5)

ax2.plot(t, ram, color='#10b981')
ax2.set_xlabel("Час моніторингу (хв)")
ax2.set_ylabel("RAM (GB)")
ax2.grid(True, linestyle=':', alpha=0.5)
plt.tight_layout()
plt.show()

# --- РІВЕНЬ 2: Професійний NOC-дашборд з SLA та зонами заповнення ---
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(8, 5))
fig.suptitle("NOC Оперативний моніторинг: Node Alpha", fontsize=13, fontweight='bold')

# Панель процесора
ax1.plot(t, cpu, color='#ef4444', linewidth=1.8, label="CPU Core 0")
ax1.axhline(50, color='#dc2626', linestyle='--', linewidth=1.2, label="SLA поріг (50%)")
ax1.fill_between(t, cpu, alpha=0.15, color='#ef4444')
ax1.set_ylabel("CPU (%)")
ax1.legend(loc='upper right', frameon=True, facecolor='#f8fafc')
ax1.grid(True, linestyle=':', alpha=0.5)

# Панель оперативної пам'яті
ax2.plot(t, ram, color='#3b82f6', linewidth=1.8, label="RAM Total")
ax2.fill_between(t, ram, alpha=0.15, color='#3b82f6')
ax2.set_xlabel("Час моніторингу (хв)")
ax2.set_ylabel("RAM (GB)")
ax2.legend(loc='lower right', frameon=True, facecolor='#f8fafc')
ax2.grid(True, linestyle=':', alpha=0.5)

plt.tight_layout()
plt.show()
```

### Чому багатопанельні композиції незамінні в інженерії?

1. **Єдиний контекст порівняння:** зіставлення піку процесора з одночасним зростанням пам'яті або мережевого трафіку дозволяє за секунди знайти причину системного збою.
2. **Усунення плутанини одиниць виміру:** замість нагромадження ліній із відсотками (%) та гігабайтами (GB) на одних осях, subplots надають кожній метриці власний чистий простір.
3. **Економія уваги людини:** структурований звіт на одній сторінці читається в рази швидше, ніж перемикання між окремими вікнами чи вкладками.
::

::

::card{title="🧭 Наскрізна інженерна історія: Побудова центру оперативного моніторингу (NOC Dashboard)" icon="i-lucide-activity"}

Уявіть, що ви керуєте надійністю інфраструктури (Lead SRE) у хмарному провайдері. Перед запуском нового регіону дата-центру команді потрібен централізований екран моніторингу (NOC Dashboard), який у реальному часі відображатиме здоров'я кластера:
- **Крок 1 (Subplots):** Створити базову сітку синхронізованих панелей для ключових ресурсів сервера (CPU vs RAM).
- **Крок 2 (Анатомія `plt.subplots` та `subplot_mosaic`):** Опанувати гнучку адресацію підграфіків у циклі через `.flatten()` та декларативний синтаксис мозаїки для швидкого прототипування.
- **Крок 3 (Асиметричний `GridSpec`):** Побудувати професійний діагностичний Jointplot (основне поле розсіювання + бічні та верхні маргінальні гістограми розподілу).
- **Крок 4 (Спільні осі `sharex` / `sharey`):** Забезпечити безшовну часову синхронізацію: масштабування одного графіка автоматично вирівнює всі інші панелі.
- **Крок 5 (Теми та стилізація):** Налаштувати темну тему (`dark_background`) для моніторів чергової зміни та чистий стиль (`seaborn-v0_8-whitegrid`) для звітів керівництву.
- **Крок 6 (Інженерні анотації та зони `axvspan` / `axhspan`):** Підсвітити часові інтервали DDoS-атак та порогові коридори SLA (Normal, Warning, Critical).

Розгляньмо кожен із цих аналітичних інструментів послідовно.

## Історія про аналітика та квартальний звіт

Аналітик Ганна готує квартальний звіт для CEO. Їй потрібно показати:
1. Динаміку продажів за 12 місяців
2. Розподіл клієнтів за віком
3. Топ-5 продуктів за виручкою
4. Кореляцію між витратами на маркетинг та продажами

Вона може створити 4 окремі файли з графіками. Але CEO хоче **одну сторінку** — щоб порівняти все одним поглядом.

Рішення: **subplots** — 4 графіки на одній фігурі.

::jupyter-notebook{title="dashboard_example.ipynb" kernel="Python 3 (ipykernel)"}

::jupyter-cell{type="markdown"}
### Квартальний дашборд: чотири ключові метрики
::

::jupyter-cell{executionCount="1" executionTime="0.35s"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(seed=42)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Квартальний звіт Q4 2026 — Ключові метрики", 
             fontsize=16, fontweight="bold")

# 1. Динаміка продажів (лінійний графік)
months = ["Січ", "Лют", "Бер", "Кві", "Тра", "Чер", 
          "Лип", "Сер", "Вер", "Жов", "Лис", "Гру"]
sales = [120, 135, 150, 145, 160, 180, 190, 185, 200, 220, 240, 260]

axes[0, 0].plot(months, sales, marker="o", linewidth=2.5, color="steelblue")
axes[0, 0].fill_between(range(len(months)), sales, alpha=0.3, color="steelblue")
axes[0, 0].set_title("Динаміка продажів (тис. грн)", fontweight="bold")
axes[0, 0].set_ylabel("Продажі")
axes[0, 0].grid(True, alpha=0.3)
axes[0, 0].tick_params(axis="x", rotation=45)

# 2. Розподіл клієнтів за віком (гістограма)
ages = rng.normal(35, 12, 500)
axes[0, 1].hist(ages, bins=25, color="coral", edgecolor="black", alpha=0.7)
axes[0, 1].axvline(np.mean(ages), color="red", linestyle="--", linewidth=2, 
                   label=f"Середнє: {np.mean(ages):.1f}")
axes[0, 1].set_title("Розподіл клієнтів за віком", fontweight="bold")
axes[0, 1].set_xlabel("Вік (роки)")
axes[0, 1].set_ylabel("Кількість клієнтів")
axes[0, 1].legend()
axes[0, 1].grid(axis="y", alpha=0.3)

# 3. Топ-5 продуктів (bar chart)
products = ["Продукт A", "Продукт B", "Продукт C", "Продукт D", "Продукт E"]
revenue = [450, 380, 320, 280, 210]

axes[1, 0].barh(products, revenue, color="mediumseagreen", edgecolor="black")
axes[1, 0].set_title("Топ-5 продуктів за виручкою (тис. грн)", fontweight="bold")
axes[1, 0].set_xlabel("Виручка")
axes[1, 0].grid(axis="x", alpha=0.3)

# 4. Кореляція маркетинг — продажі (scatter)
marketing = np.array([10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60, 65])
sales_vs_marketing = 3 * marketing + 80 + rng.normal(0, 10, 12)

axes[1, 1].scatter(marketing, sales_vs_marketing, s=100, alpha=0.7, 
                   color="purple", edgecolor="black")

# Лінія тренду
z = np.polyfit(marketing, sales_vs_marketing, 1)
p = np.poly1d(z)
axes[1, 1].plot(marketing, p(marketing), "r--", linewidth=2, 
                label=f"r = {np.corrcoef(marketing, sales_vs_marketing)[0,1]:.2f}")

axes[1, 1].set_title("Маркетинг vs Продажі", fontweight="bold")
axes[1, 1].set_xlabel("Витрати на маркетинг (тис. грн)")
axes[1, 1].set_ylabel("Продажі (тис. грн)")
axes[1, 1].legend()
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Базові subplots — регулярна сітка

### Створення сітки 2×2

::jupyter-notebook{title="subplots_basic.ipynb"}

::jupyter-cell{executionCount="1"}
```python
import matplotlib.pyplot as plt
import numpy as np

# Створюємо сітку 2x2
rng = np.random.default_rng(seed=42)
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# axes — це масив NumPy розміром (2, 2)
print(f"Тип axes: {type(axes)}")
print(f"Форма axes: {axes.shape}")

# Звертаємося до конкретних осей через індекси
axes[0, 0].plot([1, 2, 3], [1, 4, 9], 'r-o')
axes[0, 0].set_title("Графік 1: Квадрати")

axes[0, 1].hist(rng.normal(0, 1, 500), bins=30, color="green", alpha=0.7)
axes[0, 1].set_title("Графік 2: Гістограма")

axes[1, 0].scatter(rng.random(50), rng.random(50), s=100, alpha=0.6)
axes[1, 0].set_title("Графік 3: Scatter")

axes[1, 1].bar(["A", "B", "C"], [10, 25, 15], color=["red", "blue", "green"])
axes[1, 1].set_title("Графік 4: Bar Chart")

plt.tight_layout()
plt.show()
```

## Доступ до осей у різних конфігураціях

::jupyter-notebook{title="axes_access.ipynb"}

```python
import matplotlib.pyplot as plt

# Конфігурація 1: один рядок, три стовпці
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# axes — одновимірний масив [ax0, ax1, ax2]
axes[0].plot([1, 2, 3])
axes[1].bar(["A", "B"], [5, 10])
axes[2].scatter([1, 2], [3, 4])

plt.tight_layout()
plt.show()

# Конфігурація 2: три рядки, один стовпець
fig, axes = plt.subplots(3, 1, figsize=(8, 10))

# axes — одновимірний масив [ax0, ax1, ax2]
axes[0].plot([1, 2, 3])
axes[1].bar(["A", "B"], [5, 10])
axes[2].scatter([1, 2], [3, 4])

plt.tight_layout()
plt.show()

# Конфігурація 3: 2x3 сітка
fig, axes = plt.subplots(2, 3, figsize=(15, 8))

# axes — двовимірний масив (2, 3)
axes[0, 0].plot([1, 2])
axes[1, 2].bar(["X"], [7])

plt.tight_layout()
plt.show()
```

**Пастка: flatten() для універсальності**

```python
fig, axes = plt.subplots(2, 3)
axes_flat = axes.flatten()  # Тепер завжди одновимірний масив [ax0, ax1, ..., ax5]

```

### Повна сигнатура `plt.subplots()` та сучасний `fig.subplot_mosaic()`

Функція `plt.subplots()` є основним високорівневим фабричним методом створення фігури разом із сіткою осей:

```python
plt.subplots(
    nrows=1,
    ncols=1,
    *,
    sharex=False,
    sharey=False,
    squeeze=True,
    width_ratios=None,
    height_ratios=None,
    subplot_kw=None,
    gridspec_kw=None,
    **fig_kw
) -> tuple[Figure, Axes | np.ndarray]
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `nrows`, `ncols` | `int` | `1`, `1` | Кількість рядків і стовпців у регулярній сітці. |
| `sharex`, `sharey` | `bool \| {'all', 'row', 'col'}` | `False` | Синхронізація меж та шкали осей X або Y між підграфіками. |
| `squeeze` | `bool` | `True` | Якщо `True`, скасовує зайві виміри (повертає окремий `Axes` для 1×1 або 1D масив для 1×N). Якщо `False`, **завжди** повертає 2D-масив форми `(nrows, ncols)`. |
| `width_ratios` | `Sequence[float]` | `None` | Пропорції ширини стовпців (наприклад, `[2, 1]` робить перший стовпець удвічі ширшим). |
| `height_ratios` | `Sequence[float]` | `None` | Пропорції висоти рядків (наприклад, `[3, 1]` для головного графіка та підвалу). |
| `subplot_kw` | `dict` | `None` | Словник аргументів, що передаються в кожен окремий `Axes` (наприклад, `{'projection': 'polar'}`). |
| `gridspec_kw` | `dict` | `None` | Словник додаткових параметрів для базового `GridSpec` (`wspace`, `hspace`). |

::tip
**Революційний метод `fig.subplot_mosaic()` (Matplotlib 3.3+)**

Для побудови нестандартних екранів більше не обов'язково вручну вираховувати зрізи індексів `gs[:, 0]`! Метод `subplot_mosaic()` дозволяє задавати макет візуально у вигляді текстової матриці:

```python
mosaic = [
    ["main", "main"],
    ["bar",  "hist"]
]
fig, ax_dict = plt.subplot_mosaic(mosaic, figsize=(10, 7))

# Звернення напряму за семантичними назвами:
ax_dict["main"].plot(t, cpu)
ax_dict["bar"].bar(cats, vals)
ax_dict["hist"].hist(errors)
```

Символ `.` у рядку mosaic означає порожній простір (пустий слот).
::

::jupyter-cell{type="markdown"}
### Дослідження компоновок: 1×3, 2×2, subplot_mosaic та ітерація flatten()
Порівняння одновимірних і двовимірних осей, декларативної мозаїки та пакетного опрацювання в циклі
::

::jupyter-cell{executionCount="1" executionTime="0.27s"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
t = np.linspace(0, 20, 40)

# Приклад 1: Використання subplot_mosaic для асиметричного NOC-екрана
mosaic = [
    ["monitor", "monitor"],
    ["summary", "events"]
]
fig, ax_dict = plt.subplot_mosaic(mosaic, figsize=(11, 7))
fig.suptitle("NOC Дашборд через fig.subplot_mosaic()", fontsize=14, fontweight='bold')
```

```python
gs = gridspec.GridSpec(nrows, ncols, 
                       figure=fig,
                       width_ratios=[2, 1],   # Співвідношення ширини стовпців
                       height_ratios=[1, 2],  # Співвідношення висоти рядків
```

### Повна сигнатура `GridSpec` та архітектура інженерного Jointplot

Клас `matplotlib.gridspec.GridSpec` є низькорівневим координатором геометрії. Він дозволяє будувати довільні асиметричні компоновки, коли кожен підграфік займає кілька комірок віртуальної матриці.

```python
matplotlib.gridspec.GridSpec(
    nrows,
    ncols,
    figure=None,
    left=None,
    bottom=None,
    right=None,
    top=None,
    wspace=None,
    hspace=None,
    width_ratios=None,
    height_ratios=None
)
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `nrows`, `ncols` | `int` | *обов'язкові* | Кількість рядків і стовпців віртуальної координатної сітки. |
| `width_ratios` | `Sequence[float]` | `None` | Співвідношення ширини стовпців (наприклад, `[4, 1]` для великої зони аналізу та вузької бічної панелі). |
| `height_ratios` | `Sequence[float]` | `None` | Співвідношення висоти рядків (наприклад, `[1, 4]` для компактної шапки та головного полотна). |
| `wspace` | `float` | `None` (rcParams) | Горизонтальний проміжок між сусідніми стовпцями (для злитих графіків jointplot ставлять `0.05–0.08`). |
| `hspace` | `float` | `None` (rcParams) | Вертикальний проміжок між сусідніми рядками. |
| `left`, `right`, `bottom`, `top` | `float` | `None` | Межі розміщення сітки відносно країв полотна у частках від 0.0 до 1.0. |

### Професійний патерн: Створення класичного Jointplot через GridSpec

```python
plt.setp(ax_top.get_xticklabels(), visible=False)

# 3. Права маргінальна гістограма (спільна вісь Y з ax_main)
ax_right = fig.add_subplot(gs[1, 1], sharey=ax_main)
ax_right.hist(y, bins=30, orientation='horizontal', color='#34d399', edgecolor='#065f46', alpha=0.7)
```

### Системні налаштування `plt.style` та `plt.rcParams` для корпоративних звітів

У великих проєктах замість ручного задавання параметрів кожного графіка використовують **глобальні файли конфігурації стилів** або контекстні менеджери:

1. **Глобальне перемикання теми:** `plt.style.use("seaborn-v0_8-whitegrid")` — застосовує набір кольорів, сіток та шрифтів до всіх наступних графіків у сесії.
2. **Локальне ізольоване застосування:** конструкція `with plt.style.context("dark_background"):` змінює стиль виключно всередині блоку `with`, не впливаючи на інші візуалізації.
3. **Глибока кастомізація через `plt.rcParams`:** глобальний словник параметрів Matplotlib, що керує абсолютно всіма властивостями рендерингу (розміри шрифтів, товщини ліній, роздільна здатність `figure.dpi` тощо).

```python
# Приклад корпоративного налаштування rcParams
plt.rcParams.update({
    "font.family": "sans-serif",
    "font.size": 11,
    "figure.titlesize": 14,
    "axes.titlesize": 12,
    "axes.labelsize": 11,
    "axes.edgecolor": "#cbd5e1",
    "axes.grid": True,
    "grid.linestyle": ":",
    "grid.alpha": 0.6,
    "figure.dpi": 150
})
```

| Параметр rcParams | Тип | Приклад значення | Інженерне призначення |
| :--- | :--- | :--- | :--- |
| `font.family` | `str` | `'sans-serif'`, `'Inter'` | Сімейство шрифтів для всіх текстових написів. |
| `figure.dpi` | `float` | `150` (екран), `300` (друк) | Роздільна здатність полотна у точках на дюйм (DPI). |
| `axes.edgecolor` | `color` | `'#cbd5e1'`, `'#334155'` | Колір рамок координатних осей (spines). |
| `axes.grid` | `bool` | `True` | Автоматичне увімкнення сітки для всіх осей без виклику `ax.grid()`. |
| `savefig.bbox` | `str` | `'tight'` | Автоматичне обрізання зайвих полів при збереженні через `fig.savefig()`. |

```python
            xy=(max_x, max_y),                    # Точка, на яку вказуємо
            xytext=(max_x + 2, max_y + 0.3),      # Розташування тексту
            fontsize=12, fontweight="bold", color="darkred",
            arrowprops=dict(arrowstyle="->", color="red", lw=2),

# Вертикальна лінія
ax.axvline(max_x, color="gray", linestyle="--", alpha=0.5)

        style="italic", bbox=dict(boxstyle="round", facecolor="lightblue", alpha=0.6))
```

### Повна сигнатура `ax.annotate()` та інженерне зонування (`axvspan` / `axhspan`)

Метод `ax.annotate()` надає найбільш прецизійний контроль над інженерними підписами, дозволяючи зв'язувати пояснювальний текст із конкретною точкою даних за допомогою векторних стрілок із кастомною кривизною.

```python
ax.annotate(
    text,
    xy,
    xytext=None,
    xycoords='data',
    textcoords=None,
    arrowprops=None,
    annotation_clip=None,
    **kwargs
) -> Annotation
```

| Параметр | Тип | За замовчуванням | Опис та інженерне призначення |
| :--- | :--- | :--- | :--- |
| `text` | `str` | *обов'язковий* | Текст пояснення або числового значення. |
| `xy` | `tuple[float, float]` | *обов'язковий* | **Цільова точка**, на яку вказує стрілка (наприклад, координати локального максимуму). |
| `xytext` | `tuple[float, float]` | `None` (`xy`) | **Координати розташування тексту**. Якщо задано, від `xytext` до `xy` малюється стрілка. |
| `xycoords` | `str \| Transform` | `'data'` | Система координат для точки `xy`: `'data'` (шкала графіка), `'axes fraction'` (від 0 до 1 відносно осі). |
| `textcoords` | `str \| Transform` | `xycoords` | Система координат для тексту: `'offset points'` (зсув у пунктах від цілі) або `'data'`. |
| `arrowprops` | `dict \| None` | `None` | Словник параметрів стрілки: `arrowstyle` (`'->'`, `'fancy'`), `connectionstyle` (`'arc3,rad=0.3'`), `color`. |
| `bbox` | `dict \| None` | `None` | Словник рамки навколо тексту: `boxstyle` (`'round'`, `'sawtooth'`), `facecolor`, `alpha`. |

::tip
**Інженерне зонування та статусний коридор SLA**

Для візуалізації інцидентів та регламентів використовують комбінацію діапазонів і ліній:
- **`ax.axvspan(t_start, t_end)`** — вертикальна зона: маркує часовий інтервал аварії, релізу або нічного резервного копіювання.
- **`ax.axhspan(val_min, val_max)`** — горизонтальна зона: наочно показує допустимі діапазони метрики (зелена зона стабільності, жовта зона ризику, червона зона відмови).
- **`ax.axvline(x)` / `ax.axhline(y)`** — точкові граничні лінії регламенту.
::

### Дослідження анотацій: стилі стрілок, кривизна, хронологія інциденту та зони SLA
Порівняння arrowstyle, connectionstyle, виділення вікна атаки через axvspan та коридорів через axhspan

::jupyter-cell{executionCount="1" executionTime="0.28s"}
```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
time_hours = np.linspace(0, 24, 120)
latency = 40 + 5 * np.sin(time_hours / 3) + rng.normal(0, 3, 120)

# Моделюємо стрибок затримки під час інциденту з 14:00 по 18:00
mask_incident = (time_hours >= 14) & (time_hours <= 18)
latency[mask_incident] += 120 + 40 * np.sin((time_hours[mask_incident] - 14) * 0.8)

fig, axes = plt.subplots(1, 2, figsize=(14, 5.5))

# 1. Хронологія інциденту з вертикальним зонуванням
axes[0].plot(time_hours, latency, color='#0f172a', linewidth=1.8, label="Latency P99")
axes[0].axvspan(14, 18, color='#fca5a5', alpha=0.35, label="Вікно інциденту (DDoS)")
axes[0].axvline(14, color='#dc2626', linestyle='--', linewidth=1.5)
axes[0].axvline(18, color='#16a34a', linestyle='--', linewidth=1.5)

# Додаємо анотацію зі стрілкою та рамкою
axes[0].annotate("Пікове навантаження: 215 ms\nПочаток міграції трафіку", 
                xy=(16, 215), xytext=(8, 230),
                arrowprops=dict(arrowstyle="->", connectionstyle="arc3,rad=-0.2", color='#dc2626', lw=2),
                fontweight='bold', fontsize=9, color='#7f1d1d',
                bbox=dict(boxstyle="round,pad=0.4", facecolor='#fef2f2', edgecolor='#dc2626'))

axes[0].set_title("Хронологія збою: ax.axvspan() та ax.annotate()", fontweight='bold')
axes[0].set_xlabel("Час доби (години)")
axes[0].set_ylabel("Затримка (ms)")
axes[0].set_ylim(20, 260)
axes[0].legend(loc='upper left')
axes[0].grid(True, linestyle=':', alpha=0.5)

# 2. Коридори статусу системи через axhspan
axes[1].plot(time_hours, latency, color='#0f172a', linewidth=1.8)
axes[1].axhspan(0, 80, color='#bbf7d0', alpha=0.3, label="Нормальний стан SLA (< 80 ms)")
axes[1].axhspan(80, 150, color='#fef08a', alpha=0.3, label="Попередження Warning (80–150 ms)")
axes[1].axhspan(150, 260, color='#fecaca', alpha=0.3, label="Критична деградація Critical (> 150 ms)")
axes[1].axhline(80, color='#16a34a', linestyle=':', linewidth=1.5)
axes[1].axhline(150, color='#dc2626', linestyle=':', linewidth=1.5)

axes[1].set_title("Статусні коридори працездатності: ax.axhspan()", fontweight='bold')
axes[1].set_xlabel("Час доби (години)")
axes[1].set_ylabel("Затримка (ms)")
axes[1].set_ylim(20, 260)
axes[1].legend(loc='upper left')
axes[1].grid(True, linestyle=':', alpha=0.5)

plt.tight_layout()
plt.show()
```

::card{title="🎨 Subplots" icon="i-lucide-layout-grid"}

- `plt.subplots(nrows, ncols)` → регулярна сітка

- Оптимально: 3–6 графіків на одній фігурі

- Colorblind-safe: `viridis`, `plasma`, `tab10`
- Анотації: `ax.annotate()`, `ax.text()`
- Zones: `ax.axvspan()`, `ax.axhspan()`

- Логічна компоновка: головне → великим, деталі → малим
- Збереження: PNG (веб, звіти), PDF (друк, публікації)
- Роздільна здатність: 150 dpi (екран), 300 dpi (друк)
