## Рівень 1: Базові завдання

Ці завдання перевіряють розуміння основних концепцій.

### Завдання 1.1: Обчислення передбачення вручну

Дано модель лінійної регресії з параметрами:
- **w = 450** ($/м²)
- **b = 15000** ($)

**Питання:**
1. Обчисліть передбачену ціну для квартири площею **65 м²**
2. Обчисліть передбачену ціну для квартири площею **120 м²**
3. На скільки зросте ціна при збільшенні площі з 50 до 51 м²?

::collapsible{title="💡 Показати розв'язок"}

**Розв'язок:**

Формула: **ŷ = w · x + b = 450x + 15000**

1. Для 65 м²:
   - ŷ = 450 × 65 + 15000 = 29250 + 15000 = **44 250$**

2. Для 120 м²:
   - ŷ = 450 × 120 + 15000 = 54000 + 15000 = **69 000$**

3. Зростання ціни при +1 м²:
   - Ціна(50) = 450 × 50 + 15000 = 37 500$
   - Ціна(51) = 450 × 51 + 15000 = 37 950$
   - Різниця = 37 950 - 37 500 = **450$** (саме коефіцієнт w!)

**Висновок:** коефіцієнт w показує, на скільки змінюється y при зміні x на 1 одиницю.

::

### Завдання 1.2: Обчислення метрик якості

Дано три спостереження:

| Реальна ціна (y) | Передбачення (ŷ) |
|------------------|------------------|
| 30 000$          | 31 000$          |
| 45 000$          | 44 000$          |
| 60 000$          | 58 000$          |

**Завдання:** обчисліть вручну (з калькулятором):
1. **MAE** (Mean Absolute Error)
2. **MSE** (Mean Squared Error)
3. **RMSE** (Root Mean Squared Error)

::collapsible{title="💡 Показати розв'язок"}

**Розв'язок:**

**Крок 1:** Обчислюємо залишки (residuals):

| y       | ŷ      | e = y - ŷ | \|e\| | e² |
|---------|--------|-----------|-------|----|
| 30 000  | 31 000 | -1 000    | 1 000 | 1 000 000 |
| 45 000  | 44 000 | +1 000    | 1 000 | 1 000 000 |
| 60 000  | 58 000 | +2 000    | 2 000 | 4 000 000 |

**Крок 2:** Обчислюємо метрики:

1. **MAE** = (1000 + 1000 + 2000) / 3 = 4000 / 3 ≈ **1333.33$**

2. **MSE** = (1000000 + 1000000 + 4000000) / 3 = 6000000 / 3 = **2 000 000$²**

3. **RMSE** = √MSE = √2000000 ≈ **1414.21$**

**Інтерпретація:**
- MAE: в середньому модель помиляється на 1333$
- RMSE: із врахуванням "штрафу" за великі помилки — 1414$

### Завдання 1.3: Реалізація передбачення на NumPy

Напишіть функцію `predict(X, w, b)`, яка приймає:
- **X**: масив ознак (одна або кілька)
- **w**: вага або вектор вагів
- **b**: bias

і повертає передбачення **ŷ**.

::collapsible{title="💡 Показати розв'язок"}

```python
import numpy as np

def predict(X, w, b):
    """
    Обчислює передбачення лінійної регресії.
    
    Параметри:
        X: np.array, форма (n_samples, n_features) або (n_samples,)
        w: np.array, форма (n_features,) або скаляр
        b: float, bias
    
    Повертає:
        np.array, форма (n_samples,) — передбачення
    """
    # Якщо X одновимірний (проста регресія)
    if X.ndim == 1:
        return w * X + b
    
    # Якщо X двовимірний (множинна регресія)
    return X @ w + b  # або np.dot(X, w) + b

# Тест 1: проста регресія
X1 = np.array([50, 70, 90])
w1, b1 = 500, 10000
print("Тест 1 (проста регресія):")
print(f"X = {X1}")
print(f"ŷ = {predict(X1, w1, b1)}")

# Тест 2: множинна регресія
X2 = np.array([
    [70, 2],    # 70 м², 2 кімнати
    [100, 3],   # 100 м², 3 кімнати
])
w2 = np.array([500, 3000])
b2 = 10000
print("\nТест 2 (множинна регресія):")
print(f"X =\n{X2}")
print(f"ŷ = {predict(X2, w2, b2)}")
```

**Очікуваний вивід:**
```
Тест 1 (проста регресія):
X = [50 70 90]
ŷ = [35000 45000 55000]

Тест 2 (множинна регресія):
X =
[[ 70   2]
 [100   3]]
ŷ = [51000 69000]
```

### Завдання 2.1: Реалізація градієнтного спуску для простої регресії

Реалізуйте функцію `gradient_descent_simple(X, y, lr, epochs)`, яка:
1. Ініціалізує w та b нулями
2. Виконує `epochs` ітерацій градієнтного спуску
3. Повертає фінальні w, b та історію втрат

**Формули градієнтів для однієї змінної:**

::math-formula
\frac{\partial L}{\partial w} = -\frac{2}{n} \sum_{i=1}^{n} x_i (y_i - \hat{y}_i)
::

::math-formula
\frac{\partial L}{\partial b} = -\frac{2}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)
::

::collapsible{title="💡 Показати шаблон коду"}

```python
import numpy as np
import matplotlib.pyplot as plt

def gradient_descent_simple(X, y, lr=0.01, epochs=1000):
    """
    Градієнтний спуск для простої лінійної регресії.
    
    Параметри:
        X: np.array (n_samples,) — одна ознака
        y: np.array (n_samples,) — ціль
        lr: float — learning rate
        epochs: int — кількість епох
    
    Повертає:
        w, b, loss_history
    """
    n = len(X)
    w, b = 0.0, 0.0
    loss_history = []
    
    for epoch in range(epochs):
        # 1. Передбачення
        y_pred = w * X + b
        
        # 2. Обчислення втрат (MSE)
        loss = np.mean((y - y_pred) ** 2)
        loss_history.append(loss)
        
        # 3. Градієнти
        dw = -(2/n) * np.sum(X * (y - y_pred))
        db = -(2/n) * np.sum(y - y_pred)
        
        # 4. Оновлення параметрів
        w = w - lr * dw
        b = b - lr * db
    
    return w, b, loss_history

# Тестові дані
np.random.seed(42)
X = np.array([50, 60, 70, 80, 90, 100])
y = 500 * X + 10000 + np.random.normal(0, 2000, len(X))

# Навчання
w_final, b_final, losses = gradient_descent_simple(X, y, lr=0.0001, epochs=1000)

print(f"Фінальні параметри:")
print(f"  w = {w_final:.2f}")
print(f"  b = {b_final:.2f}")
print(f"  Фінальний Loss = {losses[-1]:.2f}")

# Візуалізація
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Крива навчання
ax1.plot(losses, linewidth=2)
ax1.set_title('Крива навчання')
ax1.set_xlabel('Епоха')
ax1.set_ylabel('MSE Loss')
ax1.grid(True, alpha=0.3)

# Модель
ax2.scatter(X, y, label='Дані', s=100)
ax2.plot(X, w_final * X + b_final, 'r-', linewidth=2, label=f'ŷ = {w_final:.0f}x + {b_final:.0f}')
ax2.set_title('Навчена модель')
ax2.set_xlabel('X')
ax2.set_ylabel('y')
ax2.legend()
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Підсумкове резюме модуля

::card-group

::card{title="📌 Регресійна задача" icon="i-lucide-target"}

- **Регресія** — передбачення неперервного числового значення
- Відмінність від класифікації: число vs категорія
- Приклади: ціна квартири, зарплата, температура

::

::card{title="📐 Лінійна регресія" icon="i-lucide-ruler"}

- **Формула:** ŷ = w·x + b (для 1 ознаки)
- **w** (weight) — нахил, вплив ознаки на результат
- **b** (bias) — зсув, базове значення
- **Геометрія:** пряма лінія (1D), площина (2D), гіперплощина (nD)

::

::card{title="📊 Метрики якості" icon="i-lucide-bar-chart"}

- **MAE** — середня абсолютна помилка (інтуїтивна)
- **MSE** — середня квадратична помилка (штрафує великі помилки)
- **RMSE** — корінь з MSE (зручні одиниці)
- **R²** — частка поясненої варіації (0–1, нормалізована)

::

::card{title="⚙️ Градієнтний спуск" icon="i-lucide-zap"}

- **Функція втрат** — міра помилки моделі (MSE)
- **Градієнт** — вектор похідних, напрямок зростання
- **Алгоритм:** рухатися проти градієнта до мінімуму
- **Learning rate** — розмір кроку (критичний гіперпараметр)

::

::card{title="🔢 Множинна регресія" icon="i-lucide-layers"}

- **Формула:** ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
- **Векторна форма:** ŷ = w^T X + b
- **Матрична форма:** ŷ = Xw + b (для батчу)
- **Feature importance** — які ознаки найвпливовіші

::

::card{title="⚠️ Обмеження та застереження" icon="i-lucide-alert-triangle"}

- Працює лише для **лінійних** залежностей
- Чутлива до **викидів** (outliers)
- **Мультиколінеарність** — проблема корельованих ознак
- Припущення: нормальність залишків, гомоскедастичність

## Перевірочні питання

Перед переходом до наступного модуля переконайтеся, що ви можете відповісти на ці питання:

::accordion

::accordion-item{label="❓ Що таке регресія і чим вона відрізняється від класифікації?" icon="i-lucide-help-circle"}

**Регресія** — передбачення **неперервного числового значення** (ціна, температура, вага).  
**Класифікація** — передбачення **категорії** з фіксованого набору (спам/не спам, кішка/собака).

**Приклад:**
- Регресія: "Ця квартира коштує **45 123$**" (будь-яке число)
- Класифікація: "Цей лист — **спам**" (одна з двох категорій)

::

::accordion-item{label="❓ Що показує коефіцієнт w у рівнянні ŷ = w·x + b?" icon="i-lucide-help-circle"}

**w (weight)** — це **нахил прямої**, який показує, **на скільки зміниться y при зміні x на 1 одиницю**.

**Інтерпретація:**
- w = 500: кожен додатковий м² додає 500$ до ціни
- w = -200: кожен км від метро **віднімає** 200$

::

::accordion-item{label="❓ Яка різниця між MAE і RMSE?" icon="i-lucide-help-circle"}

- **MAE** (Mean Absolute Error) — середня абсолютна помилка. Всі помилки рівноцінні.
- **RMSE** (Root Mean Squared Error) — корінь з середньої квадратичної помилки. **Штрафує великі помилки сильніше** через квадрат.

**Коли використовувати:**
- MAE: коли всі помилки однаково важливі
- RMSE: коли великі помилки критичні (медицина, фінанси)

::

::accordion-item{label="❓ Що робить градієнтний спуск?" icon="i-lucide-help-circle"}

**Градієнтний спуск** — це ітеративний алгоритм оптимізації, який:
1. Обчислює **градієнт** функції втрат (напрямок зростання)
2. Робить крок у **протилежному напрямку** (проти градієнта)
3. Повторює до досягнення **мінімуму** функції втрат

**Аналогія:** спуск з гори в тумані, де градієнт — це нахил під ногами.

::

::accordion-item{label="❓ Що станеться, якщо learning rate занадто великий?" icon="i-lucide-help-circle"}

Алгоритм робить **занадто великі кроки** і **перестрибує через мінімум**. Функція втрат може:
- Коливатися навколо мінімуму (не збігається)
- Зростати (розбіжність, divergence)

**Ознака:** втрати на графіку хаотично стрибають або зростають.

**Рішення:** зменшити learning rate (наприклад, з 0.1 до 0.01).

::

::accordion-item{label="❓ Як інтерпретувати R² = 0.85?" icon="i-lucide-help-circle"}

**R² = 0.85** означає, що модель **пояснює 85% варіації даних**.

**Простими словами:**
- 85% відмінностей у цінах квартир пояснюється обраними ознаками (площа, поверх тощо)
- 15% варіації залишається **не поясненою** (випадковий шум, фактори, яких ми не врахували)

**Оцінка:**
- R² > 0.7 — хороша модель
- R² > 0.9 — відмінна модель (але можливе перенавчання)

## Фінальне резюме у вигляді карток

::card-group

::card{title="✅ MAE (Mean Absolute Error)" icon="i-lucide-trending-up"}
Середня абсолютна помилка  
Формула: :math-formula{tex="\frac{1}{n}\sum|y_i - \hat{y}_i|" inline}  
Інтерпретація: «На скільки в середньому помиляємося»
::

::card{title="✅ MSE (Mean Squared Error)" icon="i-lucide-trending-up"}
Середня квадратична помилка  
Формула: :math-formula{tex="\frac{1}{n}\sum(y_i - \hat{y}_i)^2" inline}  
Особливість: штрафує великі помилки
::

::card{title="✅ R² (Коефіцієнт детермінації)" icon="i-lucide-percent"}
Частка поясненої варіації  
Діапазон: 0–1 (чим більше — тим краще)  
Інтерпретація: R²=0.85 → модель пояснює 85% даних
::

::card{title="✅ Градієнтний спуск" icon="i-lucide-arrow-down"}
Алгоритм оптимізації параметрів  
Формула: :math-formula{tex="w := w - \alpha \frac{\partial L}{\partial w}" inline}  
Ключовий параметр: α (learning rate)
::

::card{title="✅ Функція втрат" icon="i-lucide-activity"}
Міра помилки моделі (MSE)  
Формула: :math-formula{tex="L(w,b) = \frac{1}{n}\sum(y_i - \hat{y}_i)^2" inline}  
Мета: мінімізувати
::

::card{title="✅ Множинна регресія" icon="i-lucide-layers"}
n ознак → 1 передбачення  
Формула: :math-formula{tex="\hat{y} = \mathbf{w}^T\mathbf{X} + b" inline}  
Геометрія: гіперплощина
::
