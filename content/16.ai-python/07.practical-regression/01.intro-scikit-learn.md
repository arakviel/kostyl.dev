## Excel + калькулятор vs scikit-learn

Уявіть, що вам потрібно обчислити лінійну регресію для датасету з 1000 рядків та 10 ознак. Якби ви робили це "вручну", код виглядав би приблизно так:

::code-group

```python [Ручна реалізація (~50 рядків)]
import numpy as np

def fit_linear_regression(X, y, learning_rate=0.01, epochs=1000):
    """Навчання лінійної регресії через градієнтний спуск"""
    n_samples, n_features = X.shape
    
    # Ініціалізація параметрів
    weights = np.zeros(n_features)
    bias = 0
    
    # Градієнтний спуск
    for epoch in range(epochs):
        # Передбачення
        y_pred = np.dot(X, weights) + bias
        
        # Обчислення градієнтів
        dw = (1 / n_samples) * np.dot(X.T, (y_pred - y))
        db = (1 / n_samples) * np.sum(y_pred - y)
        
        # Оновлення параметрів
        weights -= learning_rate * dw
        bias -= learning_rate * db
    
    return weights, bias

def predict(X, weights, bias):
    """Передбачення"""
    return np.dot(X, weights) + bias

# Використання
X_train = np.array([[1], [2], [3], [4], [5]])
y_train = np.array([2, 4, 6, 8, 10])

weights, bias = fit_linear_regression(X_train, y_train)
predictions = predict(np.array([[6], [7]]), weights, bias)
```

```python [scikit-learn (3 рядки)]
from sklearn.linear_model import LinearRegression

# Використання
X_train = np.array([[1], [2], [3], [4], [5]])
y_train = np.array([2, 4, 6, 8, 10])

model = LinearRegression()
model.fit(X_train, y_train)
predictions = model.predict([[6], [7]])
```

::

Різниця очевидна: **3 рядки замість 50!** При цьому scikit-learn працює **швидше** (оптимізований C-код), **надійніше** (перевірений мільйонами користувачів) і **зручніше** (єдиний інтерфейс для всіх алгоритмів).

> Аналогія: scikit-learn — це як кухонний комбайн для машинного навчання. Замість того, щоб різати, місити та збивати вручну (писати алгоритми з нуля), ви просто натискаєте кнопку `.fit()`. Усередині — та сама математика, але упакована у зручний інструмент.

## Що таке scikit-learn?

**scikit-learn** (sklearn) — найпопулярніша бібліотека машинного навчання для Python. Вона надає простий та ефективний інструментарій для аналізу даних та побудови прогнозних моделей.

::card-group

::card{title="🎯 Основні переваги" icon="i-lucide-check-circle"}

- **Єдиний API** для всіх алгоритмів
- **Open-source** з активною спільнотою
- **Відмінна документація** з прикладами
- **Швидкість** (оптимізований C/Cython код)
- **Стабільність** (v1.0+ — зворотна сумісність)

::

::card{title="🔧 Що входить у scikit-learn?" icon="i-lucide-package"}

- Алгоритми **регресії** та **класифікації**
- Методи **кластеризації**
- Інструменти **preprocessing** (масштабування, кодування)
- **Метрики** оцінки моделей
- **Cross-validation** та підбір гіперпараметрів
- Інтеграція з **NumPy**, **pandas**, **matplotlib**

::

::

::note
scikit-learn **не включає** глибоке навчання (deep learning). Для нейронних мереж використовуються інші бібліотеки: TensorFlow, PyTorch, Keras. Але для класичного ML (регресія, дерева рішень, SVM, тощо) scikit-learn — це стандарт індустрії.
::

## Філософія scikit-learn — універсальний API

Ключова ідея scikit-learn — **єдиний інтерфейс для всіх моделей**. Будь-яка модель машинного навчання (від простої лінійної регресії до складного градієнтного бустингу) має три основні методи:

::card-group

::card{title=".fit(X, y)" icon="i-lucide-brain"}
**Навчити** модель на даних. Модель знаходить оптимальні параметри на основі тренувальних даних.
::

::card{title=".predict(X)" icon="i-lucide-target"}
**Передбачити** значення для нових даних. Використовує навчені параметри для генерації прогнозів.
::

::card{title=".score(X, y)" icon="i-lucide-chart-line"}
**Оцінити** якість моделі. Для регресії повертає R² (коефіцієнт детермінації).
::

::

Це означає, що навчившись працювати з `LinearRegression`, ви автоматично знаєте, як працювати з `Ridge`, `RandomForest`, `GradientBoosting` та іншими моделями — API однаковий!

> Аналогія: всі автомобілі мають руль, педалі газу та гальма, коробку передач — незалежно від марки. Так само всі моделі scikit-learn мають `.fit()`, `.predict()`, `.score()` — незалежно від алгоритму.

Додатково для **трансформерів** (preprocessing: scaler, encoder) є методи:

- **`.transform(X)`** — перетворити дані (після навчання)
- **`.fit_transform(X)`** — навчити + перетворити за один виклик

## Перша модель — ідеальні дані

Почнемо з найпростішого прикладу: ідеальна лінійна залежність `y = 2x`. Створимо дані вручну та навчимо модель їх розпізнати.

### Формат даних у scikit-learn

::warning
**Важливо!** scikit-learn очікує, що `X` (ознаки) буде **двовимірним масивом** (матрицею), навіть якщо у вас лише одна ознака. Це пов'язано з тим, що scikit-learn розроблений для роботи з багатовимірними даними.

- ✅ **Правильно:** `X = [[1], [2], [3]]` — двовимірний масив (3 рядки, 1 стовпець)
- ❌ **Неправильно:** `X = [1, 2, 3]` — одновимірний масив (викличе помилку)
::

::jupyter-notebook{title="first_model.ipynb" kernel="Python 3.11"}

::jupyter-cell{type="markdown"}

::

::jupyter-cell{executionCount="1"}

```python
import numpy as np

X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 6, 8, 10])

print("X (ознаки):")
print(X)
print(f"\nФорма X: {X.shape}")  # (5, 1) — 5 рядків, 1 стовпець
print(f"\ny (цільова змінна): {y}")
```

## Метрики якості моделі

Як зрозуміти, наскільки добре модель працює? Для цього використовуються **метрики якості**. У попередній статті ми розглянули три основні метрики для регресії:

- **MAE (Mean Absolute Error)** — середня абсолютна помилка
- **MSE (Mean Squared Error)** — середня квадратична помилка
- **R² (R-squared)** — коефіцієнт детермінації

### Метод `.score()` — швидка оцінка

Найпростіший спосіб оцінити модель — метод `.score(X, y)`, який повертає **R²**:

::jupyter-cell{executionCount="5"}

```python
# Оцінка якості на тренувальних даних
r2 = model.score(X, y)

print(f"R² (коефіцієнт детермінації): {r2:.4f}")
```

#output
R² (коефіцієнт детермінації): 1.0000
::

**R² = 1.0** означає **ідеальну модель** — вона на 100% пояснює варіацію даних. Це логічно, адже дані ідеальні (без шуму), і модель точно знайшла закономірність.

### Обчислення всіх трьох метрик

Для детальної оцінки можна обчислити всі три метрики окремо:

::jupyter-cell{executionCount="6"}

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# Передбачення на тренувальних даних
y_pred = model.predict(X)

# Обчислення метрик
mae = mean_absolute_error(y, y_pred)
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print("Метрики якості:")
print(f"  MAE:  {mae:.6f}")
print(f"  MSE:  {mse:.6f}")
print(f"  R²:   {r2:.6f}")
```

#output
<div class="line">Метрики якості:</div>
<div class="line">  MAE:  0.000000</div>
<div class="line">  MSE:  0.000000</div>
<div class="line">  R²:   1.000000</div>
::

Усі метрики підтверджують: модель **ідеальна**. MAE та MSE дорівнюють нулю (жодної помилки), R² дорівнює 1.0 (пояснює 100% варіації).

::note
**Інтерпретація метрик:**

- **MAE = 0** → в середньому помилка 0 (ідеально)
- **MSE = 0** → квадратична помилка 0 (ідеально)
- **R² = 1.0** → модель пояснює 100% варіації (ідеально)

У реальних задачах такі результати неможливі через шум у даних. Типові значення:
- R² > 0.7 — добра модель
- R² > 0.5 — прийнятна модель
- R² < 0.3 — погана модель (потрібно покращувати)
::

## Приклад з реальнішими даними — Зріст vs Вага

Тепер розглянемо приклад, ближчий до реальності: залежність ваги людини від зросту. Дані містять **шум** (індивідуальні відмінності), тому модель не буде ідеальною.

::jupyter-notebook{title="height_weight.ipynb"}

::jupyter-cell{type="markdown"}
### Створення датасету: Зріст (см) → Вага (кг)
::

::jupyter-cell{executionCount="1"}

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# Дані: 10 людей
heights = np.array([[150], [160], [165], [170], [175], 
                    [180], [185], [190], [195], [200]])  # см
weights = np.array([50, 58, 62, 68, 73, 78, 83, 88, 93, 98])  # кг

print(f"Кількість зразків: {len(heights)}")
print(f"Діапазон зросту: {heights.min()} - {heights.max()} см")
print(f"Діапазон ваги: {weights.min()} - {weights.max()} кг")
```

#output
<div class="line">Кількість зразків: 10</div>
<div class="line">Діапазон зросту: 150 - 200 см</div>
<div class="line">Діапазон ваги: 50 - 98 кг</div>
::

::jupyter-cell{type="markdown"}
### Навчання моделі
::

::jupyter-cell{executionCount="2"}

```python
# Створити та навчити модель

model.fit(heights, weights)

print(f"Зсув (b): {model.intercept_:.4f} кг")
print(f"\nРівняння: вага = {model.coef_[0]:.4f} * зріст + {model.intercept_:.4f}")
```

#output

<div class="line">Коефіцієнт (w): 0.9818 кг/см</div>
<div class="line">Зсув (b): -98.6818 кг</div>
<div class="line"></div>
<div class="line">Рівняння: вага = 0.9818 * зріст + -98.6818</div>

::

Модель знайшла залежність: **вага ≈ 0.98 × зріст - 98.7**. Це означає, що зі збільшенням зросту на 1 см вага зростає приблизно на 0.98 кг.

::tip
**Чи має сенс від'ємний зсув (b = -98.7)?**

Математично — так, це просто константа у рівнянні. Але **фізично** це означає, що людина зростом 0 см мала б від'ємну вагу, що безглуздо. Це підкреслює важливий принцип: **модель працює лише в діапазоні даних**, на яких вона навчалась (150-200 см). Екстраполяція за межі цього діапазону ненадійна.
::

### Оцінка якості моделі

::jupyter-cell{executionCount="4"}

```python
from sklearn.metrics import mean_absolute_error, r2_score

# Передбачення на всіх даних
y_pred = model.predict(heights)

# Метрики
mae = mean_absolute_error(weights, y_pred)
r2 = model.score(heights, weights)

print(f"\nІнтерпретація:")
print(f"  - Модель пояснює {r2*100:.2f}% варіації ваги")
print(f"  - Середня помилка: ±{mae:.2f} кг")
```

::warning
**Чому R² ≈ 0.998, а не рівно 1.0?** На відміну від першого ідеального прикладу, у цих даних є невеликі індивідуальні відхилення (шум). Хоча залежність дуже сильна і модель пояснює 99.81% варіації, середня похибка прогнозу становить близько 430 грамів.

**Важливо:** Оцінка на тих самих даних, на яких навчалась модель — це **погана практика**. У наступних статтях ми навчимося правильно розбивати дані на **тренувальну** та **тестову** вибірки.
::

## Порівняння: ручна реалізація vs scikit-learn

Підсумуємо переваги використання scikit-learn замість написання алгоритмів з нуля:

| Аспект | Ручна реалізація | scikit-learn |
|:-------|:-----------------|:-------------|
| **Кількість коду** | ~50 рядків | 3 рядки (`.fit()`, `.predict()`, `.score()`) |
| **Складність** | Потрібна математика (градієнти, матриці) | Не потрібна (абстрагована) |
| **Час розробки** | Години (написання + налагодження) | Хвилини |
| **Швидкість виконання** | Повільно (Python loops) | Швидко (C/Cython, оптимізовано) |
| **Надійність** | Легко зробити помилку | Перевірено мільйонами користувачів |
| **Підтримка** | Самостійна | Велика спільнота, документація |
| **Інші алгоритми** | Кожен треба писати з нуля | Доступно 50+ алгоритмів з тим самим API |

::tip
**Коли писати власну реалізацію?**

- Для **навчання** — щоб зрозуміти, як працює алгоритм (саме це ми робили у статті 3.1)
- Для **дослідження** — якщо потрібен унікальний алгоритм, якого немає в scikit-learn
- Для **оптимізації** — якщо стандартна реалізація не підходить під специфічні вимоги

У всіх інших випадках використовуйте **scikit-learn** — це стандарт індустрії.
::

## Резюме

::card-group

::card{title="scikit-learn" icon="i-lucide-package"}
Стандартна бібліотека машинного навчання для Python. Open-source, швидка, з єдиним API для всіх алгоритмів.
::

::card{title="Estimator" icon="i-lucide-box"}
Універсальний інтерфейс для всіх моделей ML. Будь-яка модель має методи `.fit()`, `.predict()`, `.score()`.
::

::card{title=".fit(X, y)" icon="i-lucide-brain"}
Навчити модель на даних. Модель знаходить оптимальні параметри (w, b).
::

::card{title=".predict(X)" icon="i-lucide-target"}
Зробити передбачення для нових даних X. Повертає масив передбачень.
::

::card{title=".score(X, y)" icon="i-lucide-chart-line"}
Оцінити якість моделі. Для регресії повертає R² (коефіцієнт детермінації, від 0 до 1).
::

::card{title="MAE" icon="i-lucide-ruler"}
Mean Absolute Error — середня абсолютна помилка. Показує, наскільки в середньому модель помиляється (в одиницях цільової змінної).
::

::card{title="MSE" icon="i-lucide-sigma"}
Mean Squared Error — середня квадратична помилка. Сильніше "карає" великі помилки через квадрат.
::

::card{title="R² (R-squared)" icon="i-lucide-percent"}
Коефіцієнт детермінації. Показує, яку частку варіації даних пояснює модель. R²=1.0 — ідеально, R²=0.0 — модель не краща за просте середнє.
::
