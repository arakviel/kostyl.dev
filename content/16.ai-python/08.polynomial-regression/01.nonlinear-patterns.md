## Коли пряма лінія не працює

У попередніх статтях ми навчились будувати лінійні регресійні моделі, які показували непогані результати на датасеті Housing Prices. Проте реальні дані часто мають **нелінійні** закономірності, які пряма лінія просто не може описати.

Розглянемо приклад. Припустимо, ми досліджуємо залежність зарплати від досвіду роботи. Завантажимо та візуалізуємо синтетичні дані:

::jupyter-notebook{title="nonlinear_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1"}
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# Генеруємо синтетичні дані з квадратичною залежністю
rng = np.random.default_rng(42)
experience = np.linspace(0, 10, 100)  # experience (досвід роботи, роки)
salary = 30000 + 5000 * experience + 800 * experience**2 + rng.normal(0, 5000, 100)  # salary (зарплата, $)

plt.figure(figsize=(10, 6))
plt.scatter(experience, salary, alpha=0.7, s=50, edgecolors='k', linewidths=0.5, color='#2A75D3', label='Спостереження')
plt.xlabel('Досвід роботи (роки)', fontsize=12, fontweight='bold')
plt.ylabel('Річна зарплата ($)', fontsize=12, fontweight='bold')
plt.title('Залежність зарплати від досвіду роботи (параболічний тренд)', fontsize=14, fontweight='bold')
plt.grid(alpha=0.3, linestyle='--')
plt.legend(fontsize=11)
plt.tight_layout()
plt.show()
```

**Характеристика досліджуваної вибірки:**
- 🔹 **Вхідна ознака:** `experience` (досвід роботи співробітника, діапазон від 0 до 10 років)
- 🔸 **Цільова змінна:** `salary` (рівень річної заробітної плати у доларах США)
- 📈 **Форма зв'язку:** прискорене зростання доходу з кожним додатковим роком стажу (квадратичний патерн)

::jupyter-cell{executionCount="2" executionTime="0.08s"}
```python
# Спроба побудувати лінійну регресію
X = experience.reshape(-1, 1)
y = salary

model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)

r2 = r2_score(y, y_pred)
print(f"R² для лінійної регресії: {r2:.4f}")

# Візуалізація
plt.figure(figsize=(10, 6))
plt.scatter(experience, salary, alpha=0.6, s=50, label='Реальні дані', edgecolors='k', linewidths=0.5)
plt.plot(experience, y_pred, color='red', linewidth=2.5, label=f'Лінійна регресія (R² = {r2:.2f})')
plt.xlabel('Досвід роботи (роки)', fontsize=12)
plt.ylabel('Зарплата ($)', fontsize=12)
plt.title('Лінійна регресія: погана якість для нелінійних даних', fontsize=14, fontweight='bold')
plt.legend(fontsize=11)
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()
```

Що ми бачимо? Коефіцієнт детермінації **R² = 0.81** — здавалося б, непогано. Але якщо уважно подивитись на графік, стає очевидно: пряма лінія **систематично помиляється** — занижує прогноз на початку та в кінці діапазону, завищує в середині. Модель **не здатна вловити криволінійну природу** залежності.

::warning
Високий R² не завжди означає хорошу модель! Якщо залишки (residuals) утворюють систематичний патерн, це сигнал, що модель **пропускає важливу закономірність**.
::

Питання: **як покращити модель, не змінюючи алгоритм?** Відповідь: додати **поліноміальні ознаки**.

## Обмеження лінійної регресії

Лінійна регресія будує модель у вигляді:

::math-formula
\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \ldots + w_n x_n
::

Цей підхід передбачає, що залежність між вхідними змінними та цільовою ознакою є **лінійною** (прямою). Іншими словами, зміна будь-якої ознаки :math-formula{tex="x_i" inline} на одиницю завжди призводить до однакової зміни :math-formula{tex="\hat{y}" inline}, незалежно від початкового значення :math-formula{tex="x_i" inline}.

Проте **реальні дані часто мають нелінійні залежності**:

- Зарплата зростає швидше зі збільшенням досвіду (квадратична залежність)
- Продажі морозива залежать від температури нелінійно (оптимум десь посередині, а при екстремальних значеннях — спад)
- Ціна нерухомості може зростати **прискорено** з площею у престижних районах
- Біологічні процеси часто описуються експоненціальними або логістичними кривими

> **Аналогія:** Уявіть, що ви їдете автомобілем дорогою. Якщо дорога пряма — лінійна регресія чудово справляється. Але якщо дорога **вигнута**, пряма лінія не зможе точно описати ваш маршрут. Вам потрібна **крива**, яка повторює форму дороги.

::card-group

::card{title="✅ Коли працює лінійна регресія" icon="i-lucide-trending-up"}

- Залежність між ознаками та цільовою змінною **приблизно лінійна**
- Дані не мають явних вигинів, параболічних патернів
- Приклад: зв'язок між площею квартири та ціною у стандартному сегменті ринку

::

::card{title="❌ Коли лінійна регресія не працює" icon="i-lucide-trending-down"}

- Дані утворюють **параболу**, **S-подібну криву** або інші нелінійні форми
- Лінійна модель систематично помиляється на певних ділянках
- Приклад: зв'язок між віком автомобіля та його вартістю (спочатку швидке падіння, потім сповільнення)

::

::

## Поліноміальна регресія: ідея та формула

**Ключова ідея:** замість того, щоб змінювати алгоритм регресії, ми **розширимо набір ознак**, додавши поліноміальні члени — квадрати, куби та інші степені вхідних змінних.

Припустимо, у нас є одна ознака :math-formula{tex="x" inline}. Замість моделі:

::math-formula
\hat{y} = w_0 + w_1 x
::

Ми створимо **нові ознаки** :math-formula{tex="x^2, x^3, \ldots, x^n" inline} та побудуємо модель:

::math-formula
\hat{y} = w_0 + w_1 x + w_2 x^2 + w_3 x^3 + \ldots + w_n x^n
::

Це називається **поліноміальною регресією ступеня** :math-formula{tex="n" inline}.

::tip
Поліноміальна регресія **залишається лінійною регресією** відносно параметрів :math-formula{tex="w_0, w_1, \ldots, w_n" inline}! Ми не змінюємо алгоритм навчання — лише **трансформуємо вхідні дані**.
::

### Приклад перетворення датасету

Початковий датасет:

| x   |
| --- |
| 1   |
| 2   |
| 3   |

Після застосування `PolynomialFeatures(degree=3)`:

| 1   | x   | x²  | x³  |
| --- | --- | --- | --- |
| 1   | 1   | 1   | 1   |
| 1   | 2   | 4   | 8   |
| 1   | 3   | 9   | 27  |

Перший стовпець — це :math-formula{tex="x^0 = 1" inline} (вільний член :math-formula{tex="w_0" inline}).

> **Аналогія:** Якщо лінійна регресія — це намагання описати дорогу **прямою лінією**, то поліноміальна регресія — це **гнучка лінійка**, яка може вигинатися, утворюючи плавні криві.

## PolynomialFeatures у scikit-learn

Бібліотека `scikit-learn` надає зручний інструмент для генерації поліноміальних ознак — клас `PolynomialFeatures`.

::jupyter-notebook{title="polynomial_features.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1"}
```python
from sklearn.preprocessing import PolynomialFeatures
import numpy as np

# Вхідні дані
X = np.array([[1], [2], [3], [4]])
print("Початкові дані:")
print(X)
```

### Побудова поліноміальної моделі через Pipeline

Зазвичай поліноміальну регресію будують через **Pipeline**, який послідовно виконує:
1. Генерацію поліноміальних ознак (`PolynomialFeatures`)
2. Масштабування даних (`StandardScaler`) — рекомендовано, бо :math-formula{tex="x^3" inline} може мати дуже великі значення
3. Навчання лінійної регресії (`LinearRegression`)

::jupyter-notebook{title="polynomial_regression_pipeline.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.15s"}
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_absolute_error
import numpy as np
import matplotlib.pyplot as plt

# Генеруємо ті самі дані (досвід-зарплата)
np.random.seed(42)
experience = np.linspace(0, 10, 100).reshape(-1, 1)
salary = 30000 + 5000 * experience.ravel() + 800 * experience.ravel()**2 + np.random.normal(0, 5000, 100)

# Побудова моделей різних ступенів
degrees = [1, 2, 3, 5]
results = {}

plt.figure(figsize=(14, 10))
for i, degree in enumerate(degrees, 1):
    # Створення Pipeline
    model = Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('scaler', StandardScaler()),
        ('regressor', LinearRegression())
    ])
    
    # Навчання
    model.fit(experience, salary)
    y_pred = model.predict(experience)
    
    # Метрики
    r2 = r2_score(salary, y_pred)
    mae = mean_absolute_error(salary, y_pred)
    results[degree] = {'R²': r2, 'MAE': mae}
    
    # Візуалізація
    plt.subplot(2, 2, i)
    plt.scatter(experience, salary, alpha=0.5, s=30, edgecolors='k', linewidths=0.5, label='Реальні дані')
    plt.plot(experience, y_pred, color='red', linewidth=2.5, label=f'Ступінь {degree}')
    plt.xlabel('Досвід (роки)', fontsize=11)
    plt.ylabel('Зарплата ($)', fontsize=11)
    plt.title(f'Поліном ступеня {degree} | R² = {r2:.4f}', fontsize=12, fontweight='bold')
    plt.legend(fontsize=10)
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()

print("\nПорівняння моделей:")
for degree, metrics in results.items():
    print(f"Ступінь {degree}: R² = {metrics['R²']:.4f}, MAE = {metrics['MAE']:.2f}")
```

Що ми бачимо?

- **Ступінь 1** (лінійна регресія): R² = 0.81 — пряма лінія не відповідає формі даних

- **Ступінь 3** та **5**: покращення мінімальне, крива майже не відрізняється від квадратичної

::tip

::

## Вибір ступеня полінома

Вибір ступеня полінома — критичне питання. Що станеться, якщо взяти **занадто низький** або **занадто високий** ступінь?

### Недонавчання (Underfitting)

**Ступінь 1** (пряма лінія) для параболічних даних:

- Модель **занадто проста**
- Не вловлює складну закономірність у даних
- R² на train та test — **обидва низькі**

> **Аналогія:** Намагатись описати вигнуту дорогу прямою лінією — ви систематично промахуєтесь на поворотах.

### Оптимальна складність

**Ступінь 2-3** для параболічних даних:

- Модель вловлює справжню закономірність
- R² на train та test — **обидва високі**
- Крива плавна, без надмірних вигинів

### Перенавчання (Overfitting)

А що станеться, якщо взяти **ступінь 15**?

::jupyter-notebook{title="overfitting_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.18s"}
```python
from sklearn.model_selection import train_test_split

# Розділимо дані на train/test
X_train, X_test, y_train, y_test = train_test_split(
    experience, salary, test_size=0.3, random_state=42
)

# Модель зі ступенем 15
model_overfit = Pipeline([
    ('poly', PolynomialFeatures(degree=15)),
    ('scaler', StandardScaler()),
    ('regressor', LinearRegression())
])

model_overfit.fit(X_train, y_train)

# Прогнози
y_train_pred = model_overfit.predict(X_train)
y_test_pred = model_overfit.predict(X_test)

# Метрики
r2_train = r2_score(y_train, y_train_pred)
r2_test = r2_score(y_test, y_test_pred)

print(f"Поліном ступеня 15:")
print(f"  R² (train): {r2_train:.4f}")
print(f"  R² (test):  {r2_test:.4f}")
print(f"\n⚠️ Величезна різниця! Модель перенавчилась!")

# Візуалізація
X_line = np.linspace(0, 10, 300).reshape(-1, 1)
y_line_pred = model_overfit.predict(X_line)

plt.figure(figsize=(12, 6))
plt.scatter(X_train, y_train, alpha=0.6, s=40, label='Train дані', edgecolors='k', linewidths=0.5)
plt.scatter(X_test, y_test, alpha=0.6, s=40, color='orange', label='Test дані', edgecolors='k', linewidths=0.5)
plt.plot(X_line, y_line_pred, color='red', linewidth=2.5, label=f'Поліном ступеня 15')
plt.xlabel('Досвід (роки)', fontsize=12)
plt.ylabel('Зарплата ($)', fontsize=12)
plt.title(f'Перенавчання: R² train = {r2_train:.2f}, R² test = {r2_test:.2f}', fontsize=14, fontweight='bold')
plt.legend(fontsize=11)
plt.grid(alpha=0.3)
plt.ylim(20000, 140000)
plt.tight_layout()
plt.show()
```

| :--- | :---: | :--- | :--- |
| **Навчальна (Train)** | `0.9912` | Майже 100% запам'ятовування випадкового шуму | ⚠️ Надвисока підгонка |
| **Тестова (Test)** | `0.8643` | Помітна втрата узагальнюючої здатності | 📉 Провал на контрольних точках |
| **Розрив ($\Delta R^2$)** | **`0.1269`** (12.7%) | Великий розрив між вибірками | ⚠️ **Overfitting (Перенавчання)** |
::

::

Що сталося?

- **R² train = 0.99** — модель майже ідеально описує тренувальні дані
- **R² test = 0.86** — на нових даних якість падає!
- Крива має **дикі вигини** між точками — модель **запам'ятала шум** у даних замість справжньої закономірності

> **Аналогія:** Уявіть, що ви вчитесь водити машину, запам'ятовуючи кожну вибоїну на тренувальному маршруті. Коли ви потрапите на іншу дорогу — ваші навички не спрацюють, бо ви запам'ятали деталі, а не **загальні принципи** водіння.

::warning
Перенавчання — це коли модель **занадто складна** для даних і починає моделювати випадковий шум замість справжньої закономірності. Ознака: великий розрив між метриками на train та test.
::

## Практичні приклади з різними функціями

Щоб краще зрозуміти, як поліноміальна регресія працює на різних типах даних, розглянемо кілька прикладів з різними функціональними залежностями.

### Приклад 1: Квадратична функція

::jupyter-notebook{title="quadratic_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.12s"}
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_absolute_error, mean_squared_error

# Генерація квадратичних даних
np.random.seed(123)
X_quad = np.linspace(-5, 5, 80).reshape(-1, 1)
y_quad = 100 + 20*X_quad.ravel() + 5*X_quad.ravel()**2 + np.random.normal(0, 15, 80)

# Побудова моделей різних ступенів
models_quad = {}
for degree in [1, 2, 3]:
    model = Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('scaler', StandardScaler()),
        ('regressor', LinearRegression())
    ])
    model.fit(X_quad, y_quad)
    y_pred = model.predict(X_quad)
    
    models_quad[degree] = {
        'model': model,
        'R²': r2_score(y_quad, y_pred),
        'MAE': mean_absolute_error(y_quad, y_pred),
        'MSE': mean_squared_error(y_quad, y_pred)
    }

# Візуалізація
plt.figure(figsize=(12, 4))
X_line = np.linspace(-5, 5, 200).reshape(-1, 1)

for i, degree in enumerate([1, 2, 3], 1):
    plt.subplot(1, 3, i)
    plt.scatter(X_quad, y_quad, alpha=0.5, s=25, edgecolors='k', linewidths=0.5)
    y_line = models_quad[degree]['model'].predict(X_line)
    plt.plot(X_line, y_line, color='red', linewidth=2.5)
    plt.xlabel('x', fontsize=11)
    plt.ylabel('y', fontsize=11)
    plt.title(f'Ступінь {degree} | R²={models_quad[degree]["R²"]:.3f}', fontsize=11, fontweight='bold')
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()

# Метрики
print("Квадратична функція y = 100 + 20x + 5x² + шум")
print(f"{'Ступінь':<10} {'R²':<10} {'MAE':<12} {'MSE':<12}")
print("-" * 50)
for degree, metrics in models_quad.items():
    print(f"{degree:<10} {metrics['R²']:<10.4f} {metrics['MAE']:<12.2f} {metrics['MSE']:<12.2f}")
```

## Проблема перенавчання у поліноміальній регресії

Ми побачили, що високий ступінь полінома призводить до перенавчання. Але що робити, якщо структура даних справді складна і **потрібен** високий ступінь?

Уявімо ситуацію: у нас є датасет з реальними будинками, де залежність ціни від площі має кілька вигинів (наприклад, через сегментацію ринку). Поліном ступеня 5 може бути виправданий, але він легко перенавчується.

**Питання до студента:** Що робити, якщо нам потрібен високий ступінь, але не хочемо перенавчання?

::note
Відповідь на це питання — **регуляризація** (Ridge, Lasso). Ця техніка дозволяє використовувати складні моделі, не допускаючи перенавчання. Детально розглянемо у наступній статті.
::

## Резюме

::card-group

::card{title="🔑 Ключові ідеї" icon="i-lucide-key"}

- **Лінійна регресія** описує лише прямі залежності
- **Реальні дані** часто мають криволінійні закономірності
- **Поліноміальна регресія** = лінійна регресія + нові ознаки :math-formula{tex="x^2, x^3, \ldots" inline}

::

::card{title="⚙️ Інструменти" icon="i-lucide-settings"}

- `PolynomialFeatures(degree=n)` — генерація поліноміальних ознак
- `Pipeline` — послідовне застосування трансформацій та моделі
- Завжди використовуйте `StandardScaler` після `PolynomialFeatures`

::

::card{title="⚖️ Вибір ступеня" icon="i-lucide-scale"}

- **Низький ступінь** → недонавчання (underfitting)
- **Оптимальний ступінь** → R² train ≈ R² test
- **Високий ступінь** → перенавчання (overfitting)

::

::card{title="⚠️ Обережно!" icon="i-lucide-alert-triangle"}

- Перенавчання = великий розрив між R² train та R² test
- Візуалізація обов'язкова — графік показує перенавчання навіть при високому R²
- Наступна тема: **регуляризація** — як боротись з перенавчанням

::
