## Короткий зміст

### 1. Hook: Як приборкати перенавчання?
- Повторення проблеми з попередньої статті: поліном ступеня 15 → overfitting
- Питання: чи можна використати високий ступінь, але уникнути перенавчання?
- Відповідь: регуляризація

### 2. Принцип регуляризації
- Ідея: додати **штраф за складність моделі** до функції втрат
- Loss = MSE + штраф за великі ваги
- Модель буде «економити» великі коефіцієнти w
- Аналогія: бюджет для моделі — вибирає лише найважливіші закономірності

### 3. Ridge регресія (L2-регуляризація)
- Формула функції втрат: Loss = MSE + α · Σwᵢ²
- α (alpha) — гіперпараметр, що контролює силу регуляризації
- α = 0 → звичайна лінійна регресія
- α → ∞ → всі ваги → 0
- Математична інтуїція: штраф за квадрат ваги
- **Властивість:** Ridge зменшує ваги, але **ніколи не обнулює** їх повністю

### 4. Lasso регресія (L1-регуляризація)
- Формула функції втрат: Loss = MSE + α · Σ|wᵢ|
- Штраф за **модуль** ваги (не квадрат!)
- **Властивість:** Lasso може **обнулювати** ваги → автоматичний відбір ознак
- Корисно, коли маємо багато зайвих ознак

### 5. Порівняння Ridge vs Lasso
- Таблиця порівняння:
  - Тип штрафу
  - Чи обнулює ваги?
  - Коли використовувати?
- Візуалізація: геометрична інтерпретація (круг vs ромб)

### 7. Вибір гіперпараметра alpha
- Що таке alpha? Сила регуляризації
- Малий alpha → слабка регуляризація → ризик overfitting
- Великий alpha → сильна регуляризація → ризик underfitting
- Метод: GridSearchCV з крос-валідацією
- Jupyter приклад: перебір alpha від 0.001 до 1000, графік R² vs alpha

### 8. RidgeCV та LassoCV
- Вбудована крос-валідація для автоматичного вибору alpha
- `RidgeCV(alphas=[0.1, 1, 10, 100])`
- Простіше, ніж GridSearchCV для цього конкретного випадку

### 9. Elastic Net — гібрид Ridge + Lasso
- Коротке згадування (детально не розглядається)
- Комбінує L1 і L2 штраф
- `ElasticNet(alpha=1.0, l1_ratio=0.5)`
