## Як приборкати перенавчання?

У попередній статті ми зіткнулись із проблемою: поліном ступеня 15 показував **відмінний** R² = 0.99 на тренувальних даних, але **погано працював** на тестових (R² = 0.86). Крива мала дикі вигини між точками — модель **запам'ятала шум** замість справжньої закономірності.

**Питання:** Чи можна використати високий ступінь полінома, але уникнути перенавчання?

**Відповідь:** Так, через **регуляризацію** (regularization).

> **Аналогія:** Уявіть, що ви навчаєте студента розв'язувати математичні задачі. Якщо дати йому **необмежений доступ** до калькулятора, шпаргалок та інтернету, він може отримати відмінні оцінки на домашніх завданнях (train), але **провалить іспит** (test). Регуляризація — це **обмеження ресурсів**, яке змушує модель вчитись **загальним принципам**, а не запам'ятовувати деталі.

## Принцип регуляризації

Ключова ідея регуляризації: **додати штраф за складність моделі** до функції втрат.

Згадаємо стандартну функцію втрат для лінійної регресії (Mean Squared Error):

::math-formula
\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
::

Під час навчання модель намагається **мінімізувати** цю функцію, підбираючи оптимальні ваги :math-formula{tex="w_0, w_1, \ldots, w_n" inline}.

При регуляризації ми **змінюємо цільову функцію**, додаючи **штраф за великі значення ваг**:

::math-formula
\text{Loss} = \text{MSE} + \alpha \cdot \text{Penalty}(w)
::

Де:
- :math-formula{tex="\text{MSE}" inline} — помилка моделі на даних (як раніше)
- :math-formula{tex="\text{Penalty}(w)" inline} — штраф за величину коефіцієнтів
- :math-formula{tex="\alpha" inline} (**alpha**) — **гіперпараметр**, що контролює силу регуляризації

> **Що це означає?** Модель тепер має **балансувати** між двома цілями:
> 1. Зменшити помилку на даних (перший доданок)
> 2. Зменшити величину ваг (другий доданок)

Якщо :math-formula{tex="\alpha = 0" inline}, регуляризація відсутня — ми отримуємо звичайну лінійну регресію.

Якщо :math-formula{tex="\alpha" inline} велике, модель буде **економити** великі ваги, обираючи лише найважливіші закономірності.

::note
Регуляризація **не змінює архітектуру моделі** — це лише зміна функції втрат. Ми досі використовуємо лінійну регресію!
::

## Ridge регресія (L2-регуляризація)

**Ridge регресія** (гребенева регресія) — це лінійна регресія з **L2-регуляризацією**.

### Формула функції втрат

::math-formula
\text{Loss}_{\text{Ridge}} = \text{MSE} + \alpha \cdot \sum_{j=1}^{n} w_j^2
::

**Штраф** = сума **квадратів** усіх ваг (окрім вільного члена :math-formula{tex="w_0" inline}).

### Що це означає?

- Модель **карається** за великі значення ваг
- Штраф за квадрат ваги означає: чим більша вага, тим **експоненційно дорожче** її збільшувати
- Ridge **зменшує** всі ваги, але **ніколи не обнулює** їх повністю (навіть дуже маленькі ваги залишаються ненульовими)

> **Аналогія з бюджетом:** Уявіть, що модель — це компанія з обмеженим бюджетом. Кожна ознака (вага) — це працівник, якому потрібна зарплата. Ridge каже: «Ви можете найняти всіх працівників, але **великі зарплати коштують дорого**. Тому платіть помірно всім, а не надмірно кільком обраним».

### Візуалізація впливу Ridge

::jupyter-notebook{title="ridge_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.22s"}
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge, LinearRegression
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import r2_score

# Генеруємо дані (квадратична залежність + шум)
rng = np.random.default_rng(42)
X = np.linspace(0, 10, 100).reshape(-1, 1)
y = 30 + 5*X.ravel() + 2*X.ravel()**2 + rng.normal(0, 10, 100)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Побудова моделей з різними alpha
alphas = [0, 0.1, 1, 10, 100]
results = {}

plt.figure(figsize=(15, 10))

for i, alpha in enumerate(alphas, 1):
    if alpha == 0:
        model = Pipeline([
            ('poly', PolynomialFeatures(degree=10)),
            ('scaler', StandardScaler()),
            ('regressor', LinearRegression())
        ])
        label = 'LinearRegression (без регуляризації)'
    else:
        model = Pipeline([
            ('poly', PolynomialFeatures(degree=10)),
            ('scaler', StandardScaler()),
            ('regressor', Ridge(alpha=alpha))
        ])
        label = f'Ridge (alpha={alpha})'
    
    model.fit(X_train, y_train)
    
    r2_train = model.score(X_train, y_train)
    r2_test = model.score(X_test, y_test)
    results[alpha] = {'R² train': r2_train, 'R² test': r2_test}
    
    # Візуалізація
    X_line = np.linspace(0, 10, 300).reshape(-1, 1)
    y_line = model.predict(X_line)
    
    plt.subplot(2, 3, i)
    plt.scatter(X_train, y_train, alpha=0.5, s=30, label='Train', edgecolors='k', linewidths=0.5)
    plt.scatter(X_test, y_test, alpha=0.5, s=30, color='orange', label='Test', edgecolors='k', linewidths=0.5)
    plt.plot(X_line, y_line, color='red', linewidth=2.5)
    plt.xlabel('X', fontsize=11)
    plt.ylabel('y', fontsize=11)
    plt.title(f'{label}\nR² train={r2_train:.3f}, test={r2_test:.3f}', fontsize=10, fontweight='bold')
    plt.legend(fontsize=9)
    plt.grid(alpha=0.3)
    plt.ylim(0, 250)

plt.tight_layout()
plt.show()

print("\nПорівняльна таблиця:")
print(f"{'Alpha':<10} {'R² train':<12} {'R² test':<12} {'Різниця':<10}")
print("-" * 50)
for alpha, metrics in results.items():
    diff = metrics['R² train'] - metrics['R² test']
    print(f"{alpha:<10} {metrics['R² train']:<12.4f} {metrics['R² test']:<12.4f} {diff:<10.4f}")
```

Що ми бачимо?

1. **Alpha = 0** (без регуляризації): R² train = 0.98, R² test = 0.92 — **перенавчання**, крива має зайві вигини
2. **Alpha = 0.1-1**: незначне покращення, крива стає трохи гладшою

4. **Alpha = 100**: R² test = 0.94, але R² train падає до 0.95 — модель стає **занадто простою**, починається **недонавчання**

### Властивості Ridge

::card-group

::card{title="✅ Переваги" icon="i-lucide-check-circle"}

- Зменшує перенавчання без видалення ознак
- Працює добре, коли **всі ознаки потенційно корисні**
- Стабільна модель навіть при мультиколінеарності (коли ознаки корельовані)

::

- **Не обнулює** ваги — усі ознаки залишаються в моделі
- Якщо багато ознак — **шум**, Ridge не відсіє їх автоматично
- Потрібен підбір :math-formula{tex="\alpha" inline} (але це загальна проблема регуляризації)

## Lasso регресія (L1-регуляризація)

**Lasso** (Least Absolute Shrinkage and Selection Operator) — це лінійна регресія з **L1-регуляризацією**.

### Формула функції втрат

::math-formula
\text{Loss}_{\text{Lasso}} = \text{MSE} + \alpha \cdot \sum_{j=1}^{n} |w_j|
::

**Штраф** = сума **модулів** усіх ваг.

### Що це означає?

- Замість квадрата ваги (Ridge) тут використовується **модуль** (абсолютне значення)
- Це здається дрібною зміною, але наслідки **фундаментальні**:
  - Lasso може **обнулювати** ваги — деякі ознаки отримують :math-formula{tex="w_j = 0" inline}
  - Це означає **автоматичний відбір ознак** (feature selection)

> **Аналогія з бюджетом:** Якщо Ridge каже «Платіть помірно всім працівникам», то Lasso каже: «**Звільніть** найменш продуктивних працівників, а решті платіть нормально». Lasso **приймає рішення**: ця ознака потрібна, а ця — ні.

### Візуалізація впливу Lasso

::jupyter-notebook{title="lasso_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.18s"}
```python
from sklearn.linear_model import Lasso
import pandas as pd

# Створимо датасет з багатьма ознаками, більшість з яких — шум
rng = np.random.default_rng(42)
n_samples = 200
n_features = 50

X_full = rng.standard_normal((n_samples, n_features))
# Тільки перші 5 ознак впливають на y, решта — шум
true_coefs = np.zeros(n_features)
true_coefs[:5] = [10, -5, 3, -2, 8]
y_full = X_full @ true_coefs + rng.normal(0, 5, n_samples)

X_train_full, X_test_full, y_train_full, y_test_full = train_test_split(
    X_full, y_full, test_size=0.3, random_state=42
)

# Порівняємо LinearRegression, Ridge та Lasso
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train_full)
X_test_scaled = scaler.transform(X_test_full)

models = {
    'LinearRegression': LinearRegression(),
    'Ridge (alpha=10)': Ridge(alpha=10),
    'Lasso (alpha=1)': Lasso(alpha=1, max_iter=10000)
}

results_comparison = []
coef_data = {}

for name, model in models.items():
    model.fit(X_train_scaled, y_train_full)
    r2_train = model.score(X_train_scaled, y_train_full)
    r2_test = model.score(X_test_scaled, y_test_full)
    
    # Скільки коефіцієнтів обнулено?
    n_nonzero = np.sum(np.abs(model.coef_) > 1e-5)
    
    results_comparison.append({
        'Модель': name,
        'R² train': f"{r2_train:.4f}",
        'R² test': f"{r2_test:.4f}",
        'Ненульових ваг': n_nonzero
    })
    
    coef_data[name] = model.coef_

df_results = pd.DataFrame(results_comparison)
print(df_results.to_string(index=False))
print("\n⚠️ Lasso обнулив більшість ознак!")
```

## Порівняння Ridge vs Lasso

| Характеристика         | Ridge (L2)                           | Lasso (L1)                               |
| :--------------------- | :----------------------------------- | :--------------------------------------- |
| Штраф                  | :math-formula{tex="\sum w_j^2" inline} | :math-formula{tex="\sum |w_j|" inline}     |
| Обнулення ваг          | Ні (лише зменшує)                    | Так (може обнулити)                      |
| Feature selection      | Немає                                | Автоматичний                             |
| Коли використовувати?  | Всі ознаки потенційно корисні        | Багато ознак, більшість — шум            |
| Стабільність при мультиколінеарності | Висока        | Може бути нестабільним                   |
| Інтерпретованість      | Складніше (всі ознаки в моделі)      | Простіше (лише важливі ознаки залишились)|

### Геометрична інтерпретація

Різниця між Ridge та Lasso стає очевидною через геометричну візуалізацію:

- **Ridge** (L2): область допустимих значень ваг — **коло/сфера**. Оптимальна точка рідко потрапляє на вісь координат → ваги не обнулюються
- **Lasso** (L1): область допустимих значень ваг — **ромб/октаедр**. Кути ромба лежать на осях → ваги часто обнулюються

::tip
Якщо не впевнені, який метод обрати — спробуйте **обидва** і порівняйте R² test через крос-валідацію.
::

## Вибір гіперпараметра alpha

Як підібрати оптимальне значення :math-formula{tex="\alpha" inline}?

### Метод 1: Перебір вручну (Manual Grid Search)

::jupyter-notebook{title="alpha_tuning.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.35s"}
```python
from sklearn.model_selection import cross_val_score

# Діапазон alpha для перебору
alphas = [0.001, 0.01, 0.1, 1, 10, 100, 1000]
ridge_scores = []
lasso_scores = []

for alpha in alphas:
    # Ridge
    ridge_model = Ridge(alpha=alpha)
    ridge_cv = cross_val_score(ridge_model, X_train_scaled, y_train_full, cv=5, scoring='r2')
    ridge_scores.append(ridge_cv.mean())
    
    # Lasso
    lasso_model = Lasso(alpha=alpha, max_iter=10000)
    lasso_cv = cross_val_score(lasso_model, X_train_scaled, y_train_full, cv=5, scoring='r2')
    lasso_scores.append(lasso_cv.mean())

# Візуалізація
plt.figure(figsize=(10, 6))
plt.plot(alphas, ridge_scores, marker='o', linewidth=2, label='Ridge', color='blue')
plt.plot(alphas, lasso_scores, marker='s', linewidth=2, label='Lasso', color='orange')
plt.xscale('log')
plt.xlabel('Alpha (логарифмічна шкала)', fontsize=12)
plt.ylabel('R² (крос-валідація, 5-fold)', fontsize=12)
plt.title('Підбір оптимального alpha', fontsize=14, fontweight='bold')
plt.legend(fontsize=11)
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

# Оптимальні значення
optimal_ridge_alpha = alphas[np.argmax(ridge_scores)]
optimal_lasso_alpha = alphas[np.argmax(lasso_scores)]

print(f"Оптимальний alpha для Ridge: {optimal_ridge_alpha} (R² CV = {max(ridge_scores):.4f})")
print(f"Оптимальний alpha для Lasso: {optimal_lasso_alpha} (R² CV = {max(lasso_scores):.4f})")
```

- **Малий alpha** (0.001-0.01): слабка регуляризація → перенавчання
- **Оптимальний alpha** (1-10): баланс між складністю та точністю
- **Великий alpha** (100-1000): надмірна регуляризація → недонавчання, модель стає занадто простою

## RidgeCV та LassoCV

scikit-learn надає зручні класи з **вбудованою крос-валідацією** для автоматичного підбору :math-formula{tex="\alpha" inline}:

::jupyter-notebook{title="ridge_lasso_cv.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.12s"}
```python
from sklearn.linear_model import RidgeCV, LassoCV

# RidgeCV — автоматичний підбір alpha через CV
ridge_cv = RidgeCV(alphas=[0.001, 0.01, 0.1, 1, 10, 100, 1000], cv=5)
ridge_cv.fit(X_train_scaled, y_train_full)

print(f"Оптимальний alpha для Ridge: {ridge_cv.alpha_}")
print(f"R² test: {ridge_cv.score(X_test_scaled, y_test_full):.4f}")

# LassoCV — автоматичний підбір alpha через CV
lasso_cv = LassoCV(alphas=[0.001, 0.01, 0.1, 1, 10, 100], cv=5, max_iter=10000)
lasso_cv.fit(X_train_scaled, y_train_full)

print(f"\nОптимальний alpha для Lasso: {lasso_cv.alpha_:.4f}")
print(f"R² test: {lasso_cv.score(X_test_scaled, y_test_full):.4f}")
```

## Elastic Net — гібрид Ridge + Lasso

Існує ще один метод регуляризації — **Elastic Net**, який комбінує L1 та L2 штрафи:

::math-formula
\text{Loss}_{\text{ElasticNet}} = \text{MSE} + \alpha \cdot \left( \rho \sum |w_j| + \frac{1-\rho}{2} \sum w_j^2 \right)
::

Де :math-formula{tex="\rho" inline} (`l1_ratio`) контролює баланс між L1 (Lasso) та L2 (Ridge):

- :math-formula{tex="\rho = 1" inline} → чистий Lasso
- :math-formula{tex="\rho = 0" inline} → чистий Ridge
- :math-formula{tex="\rho = 0.5" inline} → рівна вага обох штрафів

::note
Elastic Net корисний, коли ознаки **сильно корельовані** (мультиколінеарність) — Lasso може бути нестабільним у таких випадках, а Elastic Net додає стабільності Ridge.
::

```python
from sklearn.linear_model import ElasticNet

elastic_model = ElasticNet(alpha=1.0, l1_ratio=0.5, max_iter=10000)
elastic_model.fit(X_train_scaled, y_train_full)
```

У рамках цього курсу ми не будемо детально розглядати Elastic Net, але важливо знати про його існування.

## Практичні приклади регуляризації

Щоб краще зрозуміти, як Ridge та Lasso працюють на різних типах даних, розглянемо кілька практичних сценаріїв.

### Приклад 1: Регуляризація на поліноміальних ознаках

Повернемось до прикладу з попередньої статті — поліном високого ступеня, що перенавчується.

::jupyter-notebook{title="regularization_polynomial.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.28s"}
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import r2_score, mean_squared_error

# Генерація даних (квадратична залежність)
rng = np.random.default_rng(42)
X = np.linspace(0, 10, 100).reshape(-1, 1)
y = 30 + 5*X.ravel() + 2*X.ravel()**2 + rng.normal(0, 10, 100)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Порівняємо моделі на поліномі ступеня 12
degree = 12

models = {
    'LinearRegression': Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('scaler', StandardScaler()),
        ('regressor', LinearRegression())
    ]),
    'Ridge (α=10)': Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('scaler', StandardScaler()),
        ('regressor', Ridge(alpha=10))
    ]),
    'Lasso (α=1)': Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('scaler', StandardScaler()),
        ('regressor', Lasso(alpha=1, max_iter=10000))
    ])
}

# Навчання та оцінка
results = {}
plt.figure(figsize=(15, 5))

for i, (name, model) in enumerate(models.items(), 1):
    model.fit(X_train, y_train)
    
    y_train_pred = model.predict(X_train)
    y_test_pred = model.predict(X_test)
    
    r2_train = r2_score(y_train, y_train_pred)
    r2_test = r2_score(y_test, y_test_pred)
    
    results[name] = {
        'R² train': r2_train,
        'R² test': r2_test,
        'Gap': r2_train - r2_test
    }
    
    # Візуалізація
    X_line = np.linspace(0, 10, 300).reshape(-1, 1)
    y_line = model.predict(X_line)
    
    plt.subplot(1, 3, i)
    plt.scatter(X_train, y_train, alpha=0.5, s=30, label='Train', edgecolors='k', linewidths=0.5)
    plt.scatter(X_test, y_test, alpha=0.5, s=30, color='orange', label='Test', edgecolors='k', linewidths=0.5)
    plt.plot(X_line, y_line, color='red', linewidth=2.5)
    plt.xlabel('X', fontsize=11)
    plt.ylabel('y', fontsize=11)
    plt.title(f'{name}\nR² train={r2_train:.3f}, test={r2_test:.3f}', fontsize=11, fontweight='bold')
    plt.legend(fontsize=10)
    plt.grid(alpha=0.3)
    plt.ylim(0, 250)

plt.tight_layout()
plt.show()

# Порівняльна таблиця
print(f"\nПорівняння моделей на поліномі ступеня {degree}:")
print(f"{'Модель':<25} {'R² train':<12} {'R² test':<12} {'Gap':<10}")
print("-" * 65)
for name, metrics in results.items():
    print(f"{name:<25} {metrics['R² train']:<12.4f} {metrics['R² test']:<12.4f} {metrics['Gap']:<10.4f}")

print("\n✅ Ridge та Lasso успішно зменшили перенавчання!")
```

```python
import pandas as pd

# Створимо датасет: 20 ознак, але тільки 3 реально впливають на y

n_samples = 300
n_features = 20

plt.tight_layout()
plt.show()
```

### Приклад 3: Ridge vs Lasso при мультиколінеарності

::jupyter-notebook{title="multicollinearity_example.ipynb" kernel="Python 3.11 (ipykernel)"}

::jupyter-cell{executionCount="1" executionTime="0.18s"}
```python
# Створимо дані з сильно корельованими ознаками
rng = np.random.default_rng(999)
n = 200

# Базова ознака
X1 = rng.standard_normal(n)
# X2 майже ідентична X1 (сильна кореляція)
X2 = X1 + rng.normal(0, 0.1, n)
# X3 незалежна
X3 = rng.standard_normal(n)

X_corr = np.column_stack([X1, X2, X3])
y_corr = 5*X1 + 3*X3 + rng.normal(0, 2, n)

X_train_corr, X_test_corr, y_train_corr, y_test_corr = train_test_split(
    X_corr, y_corr, test_size=0.3, random_state=42
)

scaler_corr = StandardScaler()
X_train_corr_scaled = scaler_corr.fit_transform(X_train_corr)
X_test_corr_scaled = scaler_corr.transform(X_test_corr)

# Порівняємо LinearRegression, Ridge та Lasso
models_corr = {
    'LinearRegression': LinearRegression(),
    'Ridge (α=1)': Ridge(alpha=1),
    'Lasso (α=0.1)': Lasso(alpha=0.1, max_iter=10000)
}

print("Коефіцієнти моделей при мультиколінеарності:\n")
print(f"{'Модель':<20} {'Coef X1':<12} {'Coef X2':<12} {'Coef X3':<12} {'R² test':<10}")
print("-" * 70)

for name, model in models_corr.items():
    model.fit(X_train_corr_scaled, y_train_corr)
    r2 = model.score(X_test_corr_scaled, y_test_corr)
    coefs = model.coef_
    print(f"{name:<20} {coefs[0]:<12.4f} {coefs[1]:<12.4f} {coefs[2]:<12.4f} {r2:<10.4f}")

print("\n📊 Аналіз:")
print("- LinearRegression: нестабільні коефіцієнти для X1 та X2 (корельовані)")
print("- Ridge: стабілізує коефіцієнти, розподіляє вагу між X1 та X2")
print("- Lasso: обирає одну з корельованих ознак, обнулює іншу")
```

::card{title="🎯 Проблема" icon="i-lucide-alert-circle"}

**Перенавчання** — модель запам'ятовує шум замість закономірностей.

Ознака: великий розрив між R² train та R² test.

::

::card{title="💊 Рішення" icon="i-lucide-shield-check"}

**Регуляризація** — штраф за великі ваги у функції втрат.

Змушує модель обирати лише найважливіші закономірності.

::

::card{title="🔵 Ridge (L2)" icon="i-lucide-minimize-2"}

Штраф: :math-formula{tex="\sum w_j^2" inline}

- Зменшує всі ваги
- Не обнулює
- Коли: всі ознаки корисні

::

::card{title="🟠 Lasso (L1)" icon="i-lucide-scissors"}

Штраф: :math-formula{tex="\sum |w_j|" inline}

- Обнулює непотрібні ваги
- Feature selection
- Коли: багато шуму

::

::card{title="⚙️ Alpha (α)" icon="i-lucide-sliders-horizontal"}

Гіперпараметр сили регуляризації:

- α = 0 → без регуляризації
- α малий → слабка регуляризація
- α великий → сильна регуляризація

::

::card{title="🔍 Підбір alpha" icon="i-lucide-search"}

Методи:
- `RidgeCV` / `LassoCV` — вбудована CV
- `GridSearchCV` — універсальний підхід
- Візуалізація R² vs alpha

::
