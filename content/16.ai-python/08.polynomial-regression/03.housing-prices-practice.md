## Короткий зміст

### 1. Hook: Повернення до Housing Prices
- Пригадати датасет Housing Prices зі статті 3.2
- У попередній статті: LinearRegression дала R² ≈ 0.72
- Питання: чи можна покращити результат через поліноміальні ознаки?
- Проблема: 80 ознак → поліном ступеня 2 → тисячі ознак → overfitting

### 2. Експрес-аналіз даних (EDA)
- Завантаження датасету (посилання на датасет / код завантаження)
- Короткий огляд: `df.info()`, `df.head()`, пропуски
- Вибір підмножини найважливіших ознак (5-7 числових ознак за кореляцією)
- Візуалізація: scatter-plots для виявлення нелінійних залежностей

### 3. Feature Engineering з поліноміальними ознаками
- Вибір ознак для поліноміального перетворення
- Застосування PolynomialFeatures(degree=2) до обраних ознак
- Проблема dimension explosion: 7 ознак → 36 нових ознак
- Чому не degree=3? → тисячі ознак, гарантоване перенавчання

### 4. Підготовка пайплайну
- Побудова Pipeline з sklearn:
  1. SimpleImputer (заповнення пропусків)
  2. StandardScaler (масштабування)
  3. PolynomialFeatures(degree=2)
  4. Модель (LinearRegression / Ridge / Lasso)
- Jupyter notebook: код пайплайну

### 5. Базовий експеримент — LinearRegression
- Навчання LinearRegression на поліноміальних ознаках
- Метрики: R² train, R² test, MAE, MSE
- Очікуваний результат: R² train = 0.95, R² test = 0.60 → overfitting!

### 6. Ridge регресія — боремося з перенавчанням
- Заміна LinearRegression на Ridge(alpha=10)
- Порівняння результатів: R² train знижується, R² test зростає
- Підбір оптимального alpha через GridSearchCV
- Jupyter notebook: таблиця результатів для alpha = [0.1, 1, 10, 100]

### 7. Lasso регресія — автоматичний відбір ознак
- Заміна на Lasso(alpha=1)
- Аналіз коефіцієнтів: скільки ознак Lasso обнулив?
- Висновок: Lasso відсіяв неважливі поліноміальні взаємодії
- Порівняння Ridge vs Lasso на цьому датасеті

### 10. Інтерпретація моделі
- Які поліноміальні ознаки виявились найважливішими?
- Приклад: якщо важлива "площа²", це означає, що ціна зростає **нелінійно** з площею
- Бізнес-інтерпретація результатів

### 11. Резюме модуля 3.3
- Коли використовувати поліноміальну регресію? → дані мають нелінійні закономірності
- Коли використовувати Ridge? → багато ознак, всі потенційно корисні
- Коли використовувати Lasso? → багато ознак, більшість — шум
- Золоте правило: завжди перевіряйте R² на test, а не тільки на train

### 13. Картки для резюме (::card-group)
- **Поліноміальна регресія**: додавання x², x³ для моделювання нелінійностей
- **PolynomialFeatures**: трансформатор у sklearn
- **Ridge (L2)**: штраф за Σwᵢ², зменшує ваги, ніколи не обнулює
- **Lasso (L1)**: штраф за Σ|wᵢ|, може обнулювати ознаки
- **Alpha (α)**: гіперпараметр регуляризації (0 → без штрафу, ∞ → максимальний штраф)
- **GridSearchCV**: автоматичний пошук оптимальних гіперпараметрів
- **Pipeline**: послідовне виконання preprocessing + модель
