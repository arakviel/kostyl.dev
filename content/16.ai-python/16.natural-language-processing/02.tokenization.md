# Токенізація — розбиття тексту на слова й речення

::card-group

::card{title="🎯 Мета лекції" icon="i-lucide-target"}

- Пояснити, що таке токен і навіщо текст розбивають перед аналізом.
- Порівняти `split()`, регулярні вирази та `word_tokenize` з NLTK і вибрати метод для конкретних даних.
- Розпізнавати випадки, де розбиття за пробілами дає помилку: пунктуація, скорочення, числа, адреси, апострофи, емодзі.
- Розбити текст на речення й пояснити, чому крапка не завжди означає кінець речення.
- Відрізняти токени від типів і порахувати обидва.

::

::card{title="🔑 Ключові терміни" icon="i-lucide-key"}

- **Токен (token):** окрема одиниця тексту, з якою працює модель: слово, знак пунктуації, число.
- **Токенізація (tokenization):** розбиття тексту на токени.
- **Тип (type):** унікальне слово; кожен тип може зустрічатися багато разів.
- **Регулярний вираз (regular expression, regex):** шаблон для пошуку підрядків за правилом.
- **Сегментація речень (sentence segmentation):** розбиття тексту на речення.
- **Скорочення (abbreviation):** запис із крапкою всередині речення («Dr.», «т. зв.»).

::

## Задача, яка мотивує

Потрібно порахувати, як часто в відгуках трапляється слово «каву». Найпростіший спосіб — розбити рядок за пробілами методом `split()` і порівнювати слова.

::jupyter-notebook{title="split_problem.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="1"}

```python
a = "Я люблю каву."
b = "Каву, будь ласка!"

print(a.split())
print(b.split())
print("каву" in a.split(), "каву" in b.split())
```

#output
```text
['Я', 'люблю', 'каву.']
['Каву,', 'будь', 'ласка!']
False False
```

::

::

Слово «каву» є в обох реченнях, але перевірка повертає `False` двічі: до слова «приклеїлися» крапка і кома, а в другому реченні воно ще й починається з великої літери. Після розбиття за пробілами відрізнити слово від розділових знаків неможливо. Потрібен метод, який окремо виділяє слова і знаки.

## Що таке токен

**Токен** — це одиниця, з якою працює модель. Найчастіше токеном є слово або знак пунктуації, але це залежить від задачі. У лекції 16 ми побачимо токени-**частини слів**, а в 12–13 — послідовності слів.

**Токенізація** — це розбиття тексту на токени. Це перший крок будь-якої роботи з текстом, і від його якості залежить усе далі: якщо «каву.» і «каву» стали різними токенами, модель вважатиме їх різними словами.

::note
Слово «токен» вживають у кількох значеннях. У цьому модулі токен — одиниця тексту після розбиття. У лекціях про великі мовні моделі та їхню вартість «токен» означає майже те саме, лише межі проходять не по пробілах, а по частинах слів.
::

## Три способи розбити текст

Порівняємо три підходи на одному рядку: `Don't stop, it's 3.5 USD!`.

![Той самий рядок, розбитий трьома токенізаторами: split дає 5 токенів, word_tokenize — 9, wordpunct — 13](/images/ai-python/natural-language-processing/tokenization/01-tokenizers-compare.png){.diagram-img}

::jupyter-notebook{title="three_tokenizers.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="2"}

```python
from nltk.tokenize import word_tokenize, wordpunct_tokenize

text = "Don't stop, it's 3.5 USD!"

print(text.split())
print(word_tokenize(text))
print(wordpunct_tokenize(text))
```

#output
```text
["Don't", 'stop,', "it's", '3.5', 'USD!']
['Do', "n't", 'stop', ',', 'it', "'s", '3.5', 'USD', '!']
['Don', "'", 't', 'stop', ',', 'it', "'", 's', '3', '.', '5', 'USD', '!']
```

::

::

Різниця між методами:

- **`split()`** розбиває лише за пробілами. Розділові знаки залишаються в складі слів: `'stop,'`, `'USD!'`.
- **`word_tokenize`** відокремлює знаки пунктуації і розумно ділить англійські скорочення: `Don't` → `Do` + `n't`, `it's` → `it` + `'s`. Число `3.5` лишається цілим.
- **`wordpunct_tokenize`** розбиває за будь-якою зміною виду символів (літери, цифри, знаки). Він ламає число `3.5` на три токени і розриває апостроф.

Жоден результат не є універсально правильним. Мета токенізації — отримати одиниці, що мають змістовну форму для **вашої** задачі.

## Пастки токенізації

Розглянемо випадки, у яких результат залежить від методу. Для кожного важливо вирішити, що вважати правильним для вашої задачі.

::tabs
::tabs-item{label="Апострофи й дефіси"}

Українські слова з апострофом («м'ясо») і дефісом («інтернет-магазини») — це одне слово. Розбиття, яке розриває їх на частини, псує дані.

```python
import re
text = "Я люблю м'ясо та інтернет-магазини. Ціна — 25,5 грн!"
print(re.findall(r"\w+", text))
```

```text
['Я', 'люблю', 'м', 'ясо', 'та', 'інтернет', 'магазини', 'Ціна', '25', '5', 'грн']
```

Шаблон `\w+` шукає послідовності літер і цифр, тому розриває «м'ясо» на `м` і `ясо`, а число `25,5` — на `25` і `5`. «Ціна 25,5 грн» перетворюється на «ціна 25 5 грн» — це вже інша інформація.

::
::tabs-item{label="Адреси та хештеги"}

```python
from nltk.tokenize import word_tokenize
text = "Visit https://example.com/a?b=1 or mail me@site.org :) #nlp"
print(word_tokenize(text))
```

```text
['Visit', 'https', ':', '//example.com/a', '?', 'b=1', 'or', 'mail', 'me', '@', 'site.org', ':', ')', '#', 'nlp']
```

Посилання розпалося на `https`, `:`, `//example.com/a`, `?` і `b=1`. Така токенізація нічого не каже про те, що це була одна адреса. Якщо адреса несе значення (спам-фільтр), її замінюють на один токен `URL` ще до розбиття, регулярним виразом.

::
::tabs-item{label="Емодзі й повтори"}

```python
import re
text = "Чудово 😀😀 супеееер!!! Норм."
print(re.findall(r"\w+|[^\w\s]", text))
```

```text
['Чудово', '😀', '😀', 'супеееер', '!', '!', '!', 'Норм', '.']
```

Кожне емодзі й кожен знак оклику стали окремим токеном: тут це корисно, бо кількість знаків оклику й емодзі несе емоцію. Слово `супеееер` залишилося як є, і це інший токен, ніж `супер`. Розтягнуті літери можна скоротити заздалегідь: `re.sub(r"(.)\1{2,}", r"\1\1", text)` залишає не більше двох однакових літер підряд.

::
::

::tip
Правило вибору: **почніть із простого й перевірте на 20–30 реальних прикладах із ваших даних**. Якщо знайшли клас помилок, додайте правило для нього. Універсального токенізатора не існує.
::

## Регулярний вираз для української

NLTK не має окремих моделей для української мови, але `word_tokenize` працює й для неї, бо відокремлює пунктуацію від слів. Якщо потрібно точніше керувати результатом, пишуть власний шаблон. Збережемо апострофи, дефіси й числа з комою.

::jupyter-notebook{title="regexp_tokenizer.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="3"}

```python
from nltk.tokenize import RegexpTokenizer

text = "Я люблю м'ясо та інтернет-магазини. Ціна — 25,5 грн!"

words = RegexpTokenizer(r"\d+(?:[.,]\d+)*|\w+(?:['’ʼ-]\w+)*")
print(words.tokenize(text))
```

#output
```text
['Я', 'люблю', "м'ясо", 'та', 'інтернет-магазини', 'Ціна', '25,5', 'грн']
```

::

::

Шаблон складається з двох частин, розділених знаком `|` («або»):

- `\d+(?:[.,]\d+)*` — число: цифри, за якими можуть іти крапка або кома і ще цифри. Так `25,5` залишається одним токеном.
- `\w+(?:['’ʼ-]\w+)*` — слово: літери, за якими можуть іти апостроф чи дефіс і ще літери. Три різні символи апострофа (`'`, `’`, `ʼ`) трапляються в реальних текстах українською.

Знаки пунктуації цей шаблон відкидає. Якщо вони потрібні (наприклад, знаки оклику для аналізу тональності), додайте третю гілку `|[^\w\s]`.

## Нормалізація перед токенізацією

З лекції 01 відомо, що однаково виглядаючі рядки можуть відрізнятися. Тому перед розбиттям текст приводять до єдиного вигляду: складена форма Unicode (`NFC`) і малі літери. Складемо функцію, яка виконує обидва кроки і токенізацію.

::jupyter-notebook{title="tokenize_uk.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="4"}

```python
import unicodedata
from nltk.tokenize import RegexpTokenizer

PATTERN = r"\d+(?:[.,]\d+)*|\w+(?:['’ʼ-]\w+)*"
PUNCT = PATTERN + r"|[^\w\s]"

def tokenize_uk(text, keep_punct=False):
    text = unicodedata.normalize("NFC", text).casefold()
    return RegexpTokenizer(PUNCT if keep_punct else PATTERN).tokenize(text)

print(tokenize_uk("Мама МИЛА раму, а тато читав газету за 12,5 грн."))
print(tokenize_uk("Мама МИЛА раму!", keep_punct=True))
```

#output
```text
['мама', 'мила', 'раму', 'а', 'тато', 'читав', 'газету', 'за', '12,5', 'грн']
['мама', 'мила', 'раму', '!']
```

::

::

Функція `tokenize_uk` повертає список токенів у нижньому регістрі. Вона пройде через усі наступні лекції: у лекції 03 ми додамо до неї лемматизацію і стоп-слова, а в лекції 05 перетворимо її результат на числа.

## Розбиття на речення

Деякі задачі працюють із реченнями (переклад, стиснення тексту), тому текст потрібно розбити на речення. Просте правило — різати після крапки, знака оклику й питання. Крапка, однак, стоїть не лише в кінці речення.

::jupyter-notebook{title="sentences.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="5"}

```python
import re
from nltk.tokenize import sent_tokenize

text = "Dr. Smith moved to the U.S.A. in 2020. He likes it."

print(sent_tokenize(text))
print(re.split(r"(?<=[.!?])\s+", text))
```

#output
```text
['Dr. Smith moved to the U.S.A. in 2020.', 'He likes it.']
['Dr.', 'Smith moved to the U.S.A.', 'in 2020.', 'He likes it.']
```

::

::

Перший виклик `sent_tokenize` знає англійські скорочення й дає два речення. Регулярний вираз `(?<=[.!?])\s+` ріже після кожної крапки, за якою йде пробіл, і розірвав текст на чотири частини: «Dr.» і «U.S.A.» — не кінці речень.

Для української мови `sent_tokenize` не має окремої моделі: виклик із параметром `language="ukrainian"` повертає помилку `LookupError`, тому його використовують із англійською моделлю, і це працює для простих текстів.

::jupyter-notebook{title="sentences_uk.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="6"}

```python
from nltk.tokenize import sent_tokenize

text = "Звернулися до д-ра Петренка. Він, т. зв. експерт, відмовився. Ціна 3.5 грн."
for s in sent_tokenize(text):
    print(repr(s))
```

#output
```text
'Звернулися до д-ра Петренка.'
'Він, т. зв.'
'експерт, відмовився.'
'Ціна 3.5 грн.'
```

::

::

Скорочення «т. зв.» модель не знає, тому речення розірвано посередині. Для української практика така: для охайних текстів вистачає `sent_tokenize`, а для текстів зі скороченнями складають список винятків або використовують спеціалізовану бібліотеку (про них згадаємо в підсумку).

::warning
Розбиття на речення помилкове рідко, але помилки непомітні: програма не падає, а лише дає дрібніші «речення». Перевіряйте результат очима на невеликій вибірці.
::

## Токени й типи

Після токенізації тексту є два способи його порахувати. **Токенів** — скільки всього одиниць у тексті, з повторами. **Типів** — скільки різних слів серед них.

![Чотирнадцять токенів містять лише вісім унікальних типів: «the» повторюється чотири рази](/images/ai-python/natural-language-processing/tokenization/02-tokens-and-types.png){.diagram-img}

::jupyter-notebook{title="tokens_types.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="7"}

```python
from nltk.tokenize import word_tokenize

text = "the cat sat on the mat. the dog sat on the log."
tokens = word_tokenize(text)

print(len(tokens), "токенів")
print(len(set(tokens)), "типів")
print(sorted(set(tokens)))
```

#output
```text
14 токенів
8 типів
['.', 'cat', 'dog', 'log', 'mat', 'on', 'sat', 'the']
```

::

::

У реченні 14 токенів і 8 типів: слово `the` зустрічається чотири рази, `sat`, `on` та крапка — по два. Множина типів — це **словник** тексту. Розмір словника визначає, скільки різних слів мусить знати модель, і він знадобиться в лекції 05, коли кожне слово дістане свій номер.

## Підсумок

::card-group

::card{title="📌 Головне" icon="i-lucide-check"}

- Токен — одиниця тексту для моделі; токенізація розбиває рядок на токени, відокремлюючи слова від знаків.
- `split()` залишає пунктуацію в словах, `word_tokenize` відділяє її й обробляє англійські скорочення, регулярний вираз дозволяє керувати правилами самостійно.
- Апостроф, дефіс, число з комою, адреса й емодзі — типові джерела помилок; перевіряйте метод на реальних прикладах.
- Перед токенізацією текст нормалізують: `NFC` і нижній регістр.
- Крапка не завжди кінець речення: скорочення й числа ламають прості правила.
- Токенів — усі входження, типів — унікальні слова; множина типів утворює словник.

::

::card{title="➡️ Що далі" icon="i-lucide-arrow-right"}

У лекції 03 токени зводяться до початкової форми й очищаються від службових слів: «бігав» і «біжить» мають стати одним словом, а «і», «в», «на» — зникнути.
