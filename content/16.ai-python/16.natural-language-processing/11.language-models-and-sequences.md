::card{title="🔑 Ключові терміни" icon="i-lucide-key"}

- **Мовна модель (Language Model):** модель, що обчислює ймовірність послідовності слів *P*(*w*₁, *w*₂, ..., *wₙ*).
- **Біграма (bigram):** пара послідовних слів (*wᵢ*, *wᵢ₊₁*); використовується для передбачення наступного слова.
- **N-грама (N-gram):** послідовність *N* слів; біграма — окремий випадок (*N* = 2).
- **Послідовність (sequence):** впорядкований список індексів слів, що представляє речення.
- **Padding:** доповнення коротких послідовностей спеціальним токеном `<PAD>` (індекс 0) до однакової довжини.
- **Маска (mask):** булевий тензор, що вказує, які позиції послідовності реальні, а які — padding.

::

## Що таке мовна модель

**Мовна модель** — це модель, яка обчислює ймовірність послідовності слів. Наприклад, яка послідовність більш ймовірна:

- *«I love natural language processing»* — природне речення
- *«Processing natural I language love»* — випадкова перестановка

Формально мовна модель оцінює *P*(*w*₁, *w*₂, ..., *wₙ*) — ймовірність того, що слова *w*₁, *w*₂, ..., *wₙ* з'являться в такому порядку. За правилом ланцюга ймовірностей:

::math-formula{tex="P(w_1, w_2, \\ldots, w_n) = P(w_1) \\cdot P(w_2 | w_1) \\cdot P(w_3 | w_1, w_2) \\cdot \\ldots \\cdot P(w_n | w_1, \\ldots, w_{n-1})"}
::

Тобто ймовірність речення — це добуток ймовірностей кожного слова за умови всіх попередніх. На практиці обчислювати *P*(*wₙ* | *w*₁, ..., *wₙ₋₁*) для всіх попередніх слів важко (занадто багато комбінацій), тому використовують **спрощення**:

1. **Біграми:** *P*(*wₙ* | *wₙ₋₁*) — наступне слово залежить лише від одного попереднього.
2. **N-грами:** *P*(*wₙ* | *wₙ₋ₙ₊₁*, ..., *wₙ₋₁*) — залежить від *N*−1 попередніх слів.
3. **Нейронні моделі:** RNN, LSTM, Transformer навчають *P*(*wₙ* | *w*₁, ..., *wₙ₋₁*) через приховані стани, які «пам'ятають» контекст.

Мовні моделі корисні для:

- **Генерації тексту:** передбачаємо наступне слово, потім ще одне, отримуємо речення.
- **Автодоповнення:** підказки в пошукових системах, клавіатурах смартфонів.
- **Оцінки якості:** речення з високою *P* виглядають природно, з низькою — як помилка або машинний переклад.
- **Розуміння тексту:** модель, що вміє передбачати слова, «розуміє» зміст (GPT, BERT).

::note
ChatGPT, Copilot, Claude — це великі мовні моделі (Large Language Models, LLM), навчені передбачати наступний токен на трильйонах слів. Вони не «розуміють» у людському сенсі, але ймовірності настільки точні, що текст виглядає осмисленим.
::

## Біграми — найпростіша мовна модель

**Біграма** — це пара послідовних слів. Біграмна мовна модель передбачає наступне слово на основі лише попереднього:

::math-formula{tex="P(w_n | w_{n-1})"}
::

Наприклад, якщо в корпусі після слова `natural` часто йде `language`, то *P*(`language` | `natural`) висока. Якщо після `natural` ніколи не йде `car`, то *P*(`car` | `natural`) ≈ 0.

Обчислюємо ймовірності зі статистики корпусу:

::math-formula{tex="P(w_n | w_{n-1}) = \\frac{\\text{count}(w_{n-1}, w_n)}{\\text{count}(w_{n-1})}"}
::

Де count(*wₙ₋₁*, *wₙ*) — кількість разів, коли слова *wₙ₋₁* і *wₙ* з'явилися поруч.

::jupyter-notebook{title="bigram_language_model.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="1"}

```python
from collections import defaultdict, Counter
import numpy as np

# Невеликий корпус
corpus = [
    "I love natural language processing",
    "natural language is fascinating",
    "I love processing data",
    "language models predict next word",
    "processing text with models"
]

# Будуємо біграми
bigrams = []
for sentence in corpus:
    words = sentence.lower().split()
    for i in range(len(words) - 1):
        bigrams.append((words[i], words[i + 1]))

print(f"Всього біграм: {len(bigrams)}")
print("Перші 10 біграм:")
for bigram in bigrams[:10]:
    print(f"  {bigram[0]:12s} → {bigram[1]}")
```

```python
bigram_counts = Counter(bigrams)
```

```python
# Передбачення наступного слова
def predict_next_word(word, bigram_probs, word_counts):
    """Передбачає найймовірніше наступне слово."""
    candidates = [(w2, prob) for (w1, w2), prob in bigram_probs.items() if w1 == word]
    if not candidates:
        return None
    candidates.sort(key=lambda x: -x[1])
    return candidates

# Тестуємо
test_words = ["natural", "language", "processing", "i"]
for word in test_words:
    candidates = predict_next_word(word, bigram_probs, word_counts)
    if candidates:
        print(f"\nПісля '{word}':")
        for next_word, prob in candidates[:3]:
            print(f"  {next_word:15s} {prob:.3f}")
    else:
        print(f"\nПісля '{word}': [немає даних]")
```

## Від слів до індексів — представлення послідовностей

Щоб подати речення в нейромережу, перетворюємо слова на **індекси**. Спочатку будуємо **словник** (vocabulary) — таблицю відповідності `{слово: індекс}`. Зазвичай додаємо спеціальні токени:

- `<PAD>` (індекс 0) — padding, доповнення коротких речень
- `<UNK>` (індекс 1) — невідомі слова (OOV)
- `<SOS>` (індекс 2) — start-of-sequence (початок речення)
- `<EOS>` (індекс 3) — end-of-sequence (кінець речення)

::jupyter-notebook{title="word_to_index.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="4"}

```python
from collections import Counter

# Будуємо словник
def build_vocab(sentences, min_freq=1):
    word_counts = Counter()
    for sent in sentences:
        word_counts.update(sent.lower().split())
    
    # Спеціальні токени
    vocab = {"<PAD>": 0, "<UNK>": 1, "<SOS>": 2, "<EOS>": 3}
    
    # Додаємо слова з достатньою частотою
    for word, count in word_counts.items():
        if count >= min_freq:
            vocab[word] = len(vocab)
    
    return vocab

vocab = build_vocab(corpus)
print(f"Розмір словника: {len(vocab)} слів")
print("\nПерші 10 слів:")
for word, idx in list(vocab.items())[:10]:
    print(f"  {word:15s} → {idx}")
```

```text
Перші 10 слів:

  <UNK>           → 1
  <SOS>           → 2
  <EOS>           → 3
  i               → 4
  love            → 5
```

```python
# Перетворюємо речення на послідовності індексів
def sentence_to_indices(sentence, vocab):
    words = sentence.lower().split()
    indices = [vocab.get(word, vocab["<UNK>"]) for word in words]
    return indices

# Тестуємо
test_sentences = [
    "I love natural language processing",
    "processing is fascinating",
    "new words are unknown"
]

for sent in test_sentences:
    indices = sentence_to_indices(sent, vocab)
    print(f"Речення: {sent}")
    print(f"Індекси: {indices}")
    
    # Декодуємо назад
    idx_to_word = {i: w for w, i in vocab.items()}
    decoded = [idx_to_word.get(i, "<UNK>") for i in indices]
    print(f"Декодовано: {' '.join(decoded)}\n")
```

## Padding — вирівнювання довжин

Нейромережа обробляє батчі (групи прикладів) одночасно. Але речення мають різну довжину: одне — 5 слів, інше — 20. Тензор вимагає однакового розміру по всіх вимірах.

Рішення: **padding** — доповнення коротких речень токеном `<PAD>` (індекс 0) до довжини найдовшого речення в батчі.

::jupyter-notebook{title="padding_sequences.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="6"}

```python
import torch

# Три речення різної довжини
sentences = [
    "I love NLP",
    "Natural language processing is fascinating",
    "Text"
]

# Перетворюємо на індекси
sequences = [sentence_to_indices(s, vocab) for s in sentences]
print("Послідовності до padding:")
for i, seq in enumerate(sequences):
    print(f"  Речення {i+1}: {seq} (довжина {len(seq)})")

# Padding до максимальної довжини
max_len = max(len(seq) for seq in sequences)
padded = [seq + [vocab["<PAD>"]] * (max_len - len(seq)) for seq in sequences]

print(f"\nПослідовності після padding (max_len={max_len}):")
for i, seq in enumerate(padded):
    print(f"  Речення {i+1}: {seq}")

# Перетворюємо на тензор
tensor = torch.LongTensor(padded)
print(f"\nТензор: {tensor.shape}")
print(tensor)
```

#output
```text
Послідовності до padding:
  Речення 1: [4, 5, 1] (довжина 3)
  Речення 2: [6, 7, 8, 9, 10] (довжина 5)
  Речення 3: [1] (довжина 1)

Послідовності після padding (max_len=5):
  Речення 1: [4, 5, 1, 0, 0]
  Речення 2: [6, 7, 8, 9, 10]
  Речення 3: [1, 0, 0, 0, 0]

Тензор: torch.Size([3, 5])
tensor([[ 4,  5,  1,  0,  0],
        [ 6,  7,  8,  9, 10],
        [ 1,  0,  0,  0,  0]])
```

::

::

Тепер усі речення мають довжину 5. Речення 1 доповнено двома нулями, речення 3 — чотирма. Тензор має форму `(3, 5)` — 3 речення × 5 токенів.

Проблема: модель обробить `<PAD>` як звичайні токени. Це спотворить обчислення (наприклад, усереднення векторів враховує нулі). Рішення — **маска**.

## Маска — ігнорування padding

**Маска** (mask) — булевий тензор, що вказує, які позиції реальні (`True`), а які — padding (`False`). Модель використовує маску, щоб ігнорувати `<PAD>` під час обчислень.

::jupyter-notebook{title="sequence_mask.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="7"}

```python
# Створюємо маску: True для реальних токенів, False для padding
mask = tensor != vocab["<PAD>"]
print("Маска (True = реальний токен, False = padding):")
print(mask)

# Довжини речень (кількість True у кожному рядку)
lengths = mask.sum(dim=1)
print(f"\nДовжини речень: {lengths}")

# Приклад: усереднення векторів із маскою
# Замість простого mean, обчислюємо sum / length
embeddings = torch.randn(3, 5, 10)  # 3 речення × 5 токенів × 10 вимірів
print(f"\nEmbeddings: {embeddings.shape}")

# Без маски (неправильно)
mean_wrong = embeddings.mean(dim=1)
print(f"Усереднення без маски: {mean_wrong.shape} → {mean_wrong[0, :3]}")

# З маскою (правильно)
mask_expanded = mask.unsqueeze(-1).float()  # (3, 5, 1)
masked_embeddings = embeddings * mask_expanded
sum_embeddings = masked_embeddings.sum(dim=1)  # (3, 10)
mean_correct = sum_embeddings / lengths.unsqueeze(-1).float()
print(f"Усереднення з маскою: {mean_correct.shape} → {mean_correct[0, :3]}")
```

#output
```text
Маска (True = реальний токен, False = padding):
tensor([[ True,  True,  True, False, False],
        [ True,  True,  True,  True,  True],
        [ True, False, False, False, False]])

Довжини речень: tensor([3, 5, 1])

Embeddings: torch.Size([3, 5, 10])
Усереднення без маски: torch.Size([3, 10]) → tensor([ 0.1234, -0.3456,  0.5678])
Усереднення з маскою: torch.Size([3, 10]) → tensor([ 0.2058, -0.5760,  0.9463])
```

::

::

Без маски усереднення ділить на 5 (довжина з padding), з маскою — на 3 (справжня довжина). Це критично для коректних обчислень.

![Схема padding і маски: три речення різної довжини вирівнюються нулями, маска вказує реальні позиції](/images/ai-python/natural-language-processing/language-models-and-sequences/02-padding-and-mask.png){.diagram-img}

::tip
У PyTorch багато функцій підтримують маску: `nn.utils.rnn.pack_padded_sequence` для RNN, `torch.nn.functional.scaled_dot_product_attention` для Transformer. Ми використаємо їх у лекціях 12–15.

## collate_fn — створення батчів

PyTorch `DataLoader` збирає батчі за допомогою функції `collate_fn`. За замовчуванням вона просто стекає прикладі в тензор, але для послідовностей треба додати padding.

::jupyter-notebook{title="collate_function.ipynb" kernel="Python 3.13"}

::jupyter-cell{executionCount="8"}

```python
from torch.utils.data import Dataset, DataLoader
from torch.nn.utils.rnn import pad_sequence

class TextDataset(Dataset):
    def __init__(self, sentences, vocab):
        self.sentences = sentences
        self.vocab = vocab
    
    def __len__(self):
        return len(self.sentences)
    
    def __getitem__(self, idx):
        # Повертаємо тензор індексів
        indices = sentence_to_indices(self.sentences[idx], self.vocab)
        return torch.LongTensor(indices)

# Функція для створення батчів
def collate_batch(batch):
    """
    batch: список тензорів різної довжини
    Повертає: (padded_sequences, lengths)
    """
    # Сортуємо за довжиною (від найдовшого до найкоротшого)
    # RNN працює ефективніше з відсортованими послідовностями
    batch = sorted(batch, key=lambda x: len(x), reverse=True)
    lengths = torch.LongTensor([len(x) for x in batch])
    
    # Padding
    padded = pad_sequence(batch, batch_first=True, padding_value=0)
    
    return padded, lengths

# Створюємо датасет і DataLoader
dataset = TextDataset(corpus, vocab)
dataloader = DataLoader(dataset, batch_size=2, shuffle=False, collate_fn=collate_batch)

print("Батчі:")
for i, (sequences, lengths) in enumerate(dataloader):
    print(f"\nБатч {i+1}:")
    print(f"  Послідовності: {sequences.shape}")
    print(f"  {sequences}")
    print(f"  Довжини: {lengths}")
```

#output
```text
Батчі:

Батч 1:
  Послідовності: torch.Size([2, 5])
  tensor([[ 4,  5,  6,  7,  8],
          [ 6,  7,  9, 10,  0]])
  Довжини: tensor([5, 4])

Батч 2:
  Послідовності: torch.Size([2, 4])
  tensor([[ 7, 11, 12, 13],
          [ 4,  5,  8, 14]])
  Довжини: tensor([4, 4])

Батч 3:
  Послідовності: torch.Size([1, 4])
  tensor([[ 8, 15, 16, 11]])
  Довжини: tensor([4])
```

::

::

`collate_fn` автоматично вирівнює послідовності в батчі до довжини найдовшої. Батч 1: одне речення 5 слів, друге 4 → padding до 5. Батч 2: обидва по 4 слова → padding не потрібен.

::note
Функція `pad_sequence` додає padding **справа** (в кінець речення). Деякі моделі (GPT) використовують padding **зліва** (на початку), щоб останній токен завжди був реальним. Для RNN/LSTM напрямок не критичний, бо ми передаємо довжини.
::

## Розподіл довжин речень — чому це важливо

У реальних даних речення мають різну довжину. Якщо більшість речень короткі (5–10 слів), а кілька дуже довгі (100+ слів), padding неефективний: короткі речення отримують багато нулів, що сповільнює обчислення.

**Стратегії оптимізації:**

1. **Обрізання (truncation):** обмежити довжину 512 токенами (95-й перцентиль); довші речення обрізаємо.
2. **Динамічний padding:** padding до довжини найдовшого речення **в батчі**, а не в усьому датасеті.
3. **Сортування за довжиною:** групувати речення схожої довжини в один батч (мінімізує padding).
4. **Packed sequences:** `pack_padded_sequence` у PyTorch ігнорує padding під час обчислень RNN.

У лекції 12 ми використаємо `pack_padded_sequence` для ефективної обробки послідовностей у RNN.

::warning
Обрізання до 512 токенів — стандарт для BERT і багатьох моделей. Це компроміс: більшість речень вміщається, а дуже довгі втрачають хвіст. Для документів (книги, статті) використовують спеціальні моделі (Longformer, BigBird), які можуть обробляти тисячі токенів.

:::accordion-item{label="📋 Завдання 2: обчислити perplexity мовної моделі" icon="i-lucide-clipboard-list"}

**Perplexity** — метрика якості мовної моделі. Чим нижча, тим краще модель передбачає тестові дані. Формула:

::math-formula{tex="\\text{Perplexity} = 2^{-\\frac{1}{N} \\sum_{i=1}^{N} \\log_2 P(w_i | w_{i-1})}"}
::

Обчисліть perplexity біграмної моделі на тестовому реченні *«natural language processing is useful»*.

:::

:::accordion-item{label="✅ Розв'язок 2" icon="i-lucide-check-circle"}

```python
import math

def compute_perplexity(sentence, bigram_probs):
    """Обчислює perplexity біграмної моделі."""
    words = sentence.lower().split()
    log_prob_sum = 0
    count = 0
    
    for i in range(len(words) - 1):
        w1, w2 = words[i], words[i + 1]
        prob = bigram_probs.get((w1, w2), 1e-10)  # Згладжування для невідомих біграм
        log_prob_sum += math.log2(prob)
        count += 1
    
    # Perplexity = 2^(-average log prob)
    avg_log_prob = log_prob_sum / count if count > 0 else 0
    perplexity = 2 ** (-avg_log_prob)
    return perplexity

# Тестове речення
test_sentence = "natural language processing is useful"
perplexity = compute_perplexity(test_sentence, bigram_probs)

print(f"Речення: {test_sentence}")
print(f"Perplexity: {perplexity:.2f}")

# Для порівняння: добре речення (з навчання)
good_sentence = "i love natural language processing"
perplexity_good = compute_perplexity(good_sentence, bigram_probs)
print(f"\nРечення (з навчання): {good_sentence}")
print(f"Perplexity: {perplexity_good:.2f}")
```

```python
import random

def generate_text(start_word, bigram_probs, length=10):
    """Генерує текст за біграмною моделлю."""
    current_word = start_word
    generated = [current_word]
    
    for _ in range(length - 1):
        # Знаходимо всі можливі наступні слова
        candidates = [(w2, prob) for (w1, w2), prob in bigram_probs.items() if w1 == current_word]
        
        if not candidates:
            break  # Немає продовжень
        
        # Вибираємо випадково за ймовірностями
        words, probs = zip(*candidates)
        next_word = random.choices(words, weights=probs)[0]
        
        generated.append(next_word)
        current_word = next_word
    
    return " ".join(generated)

# Генеруємо 5 варіантів
random.seed(42)
print("Згенеровані речення (біграмна модель):\n")
for i in range(5):
    text = generate_text("i", bigram_probs, length=8)
    print(f"  {i+1}. {text}")
```

## Що далі

У лекції 12 навчимо **RNN (Recurrent Neural Network)** — першу послідовну модель, яка обробляє слова по черзі й зберігає **прихований стан** (hidden state). RNN «пам'ятає» контекст: після обробки слова `not` стан змінюється, і наступне слово `good` інтерпретується з урахуванням заперечення. Це вирішить проблему усереднення з лекції 10.

Ми побачимо, як RNN розгортається в часі (unrolling), як працює backpropagation through time (BPTT), і навчимо класифікатор sentiment на IMDB. RNN покаже покращення порівняно з усередненими векторами, але матиме проблему з довгими послідовностями (зникнення градієнта).

У лекції 13 це вирішить **LSTM** (Long Short-Term Memory) — архітектура з воротами, що дозволяє пам'ятати важливу інформацію на сотні кроків назад.
