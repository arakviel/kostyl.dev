# Лекція 12: Рекурентні нейронні мережі (RNN)

## Мотивація: Коли усереднення не працює

У [лекції 10](/16.ai-python/16.natural-language-processing/10.embeddings-for-classification) ми класифікували відгуки IMDB, усередняючи word embeddings:

::math-formula{tex="\text{sentence\_emb} = \frac{1}{n} \sum_{i=1}^{n} \text{emb}(w_i)"}
::

**Проблема**: усереднення втрачає порядок слів. "Not good" і "good not" дають однаковий вектор, але мають протилежний сенс.

::callout{type="warning" title="Обмеження bag-of-words"}
Усереднення (або сума) embeddings — це **bag-of-words** підхід. Він не враховує:

- Порядок слів ("not good" vs "good not")
- Контекст ("bank" біля "river" vs "bank" біля "money")
- Довгі залежності ("The movie, despite some flaws, was good")
::

**Ідея**: обробляти слова **послідовно**, зберігаючи інформацію про попередні кроки в **прихованому стані**.

---

## Рекурентна нейронна мережа: Основна ідея

### Архітектура

**Рекурентна нейронна мережа (RNN)** обробляє послідовність токенів :math-formula{tex="x_1, x_2, \ldots, x_n" inline} крок за кроком, підтримуючи **прихований стан** :math-formula{tex="h_t" inline}:

::math-formula{tex="h_t = \tanh(W_h h_{t-1} + W_x x_t + b)"}
::

де:

- :math-formula{tex="x_t \in \mathbb{R}^d" inline} — вхідний вектор (embedding) на кроці :math-formula{tex="t" inline}
- :math-formula{tex="h_t \in \mathbb{R}^{h}" inline} — прихований стан на кроці :math-formula{tex="t" inline}
- :math-formula{tex="h_{t-1}" inline} — прихований стан з попереднього кроку
- :math-formula{tex="W_h \in \mathbb{R}^{h \times h}" inline} — матриця переходу прихованого стану
- :math-formula{tex="W_x \in \mathbb{R}^{h \times d}" inline} — матриця вхідних даних
- :math-formula{tex="b \in \mathbb{R}^{h}" inline} — bias
- :math-formula{tex="\tanh" inline} — функція активації (обмежує значення в :math-formula{tex="[-1, 1]" inline})

**Початковий стан**: :math-formula{tex="h_0 = \mathbf{0}" inline} (або навчається як параметр).

### Візуалізація

![RNN згорнута і розгорнута схема](/images/16.ai-python/16.natural-language-processing/12.rnn/rnn-unfolding.png)

**Ліворуч** (згорнута форма): RNN як один блок з петлею — вихід :math-formula{tex="h_t" inline} повертається на вхід.

**Праворуч** (розгорнута в часі): та сама мережа, показана для кожного кроку. Зверніть увагу: **одні й ті ж ваги :math-formula{tex="W_h, W_x, b" inline}** використовуються на кожному кроці.

::callout{type="info" title="Чому це називається 'рекурентною'?"}
Слово **recurrent** означає "повторюваний". RNN застосовує ту саму операцію на кожному кроці часу, використовуючи результат попереднього кроку.

Це не рекурсія в програмуванні (функція викликає саму себе), а **рекурентне співвідношення**: :math-formula{tex="h_t" inline} залежить від :math-formula{tex="h_{t-1}" inline}.
::

## Математика RNN: Крок за кроком

### Приклад: Обробка речення

Нехай у нас є речення: "not good" → токени :math-formula{tex="[w_1, w_2]" inline}.

1. Початковий стан: :math-formula{tex="h_0 = \mathbf{0}" inline}
2. Крок 1 (:math-formula{tex="w_1" inline} = "not"):
   - :math-formula{tex="x_1 = \text{emb}(\text{not}) \in \mathbb{R}^{100}" inline} (припустимо, embedding size = 100)
   - :math-formula{tex="h_1 = \tanh(W_h h_0 + W_x x_1 + b) \in \mathbb{R}^{128}" inline} (hidden size = 128)
3. Крок 2 (:math-formula{tex="w_2" inline} = "good"):
   - :math-formula{tex="x_2 = \text{emb}(\text{good})" inline}
   - :math-formula{tex="h_2 = \tanh(W_h h_1 + W_x x_2 + b)" inline}

**Результат**: :math-formula{tex="h_2" inline} містить інформацію про **обидва** слова, причому порядок враховано (бо :math-formula{tex="h_2" inline} залежить від :math-formula{tex="h_1" inline}).

### Відмінність від усереднення

| Підхід | "not good" | "good not" |
|--------|-----------|-----------|
| **Усереднення** | :math-formula{tex="\frac{1}{2}(\text{emb}(\text{not}) + \text{emb}(\text{good}))" inline} | :math-formula{tex="\frac{1}{2}(\text{emb}(\text{good}) + \text{emb}(\text{not}))" inline} |
| **RNN** | :math-formula{tex="h_2 = f(h_1, \text{emb}(\text{good})), \; h_1 = f(h_0, \text{emb}(\text{not}))" inline} | :math-formula{tex="h_2 = f(h_1, \text{emb}(\text{not})), \; h_1 = f(h_0, \text{emb}(\text{good}))" inline} |

RNN дає **різні** :math-formula{tex="h_2" inline} для різного порядку слів! 🎉

## RNN у PyTorch

### Базовий forward pass

PyTorch має готовий модуль `nn.RNN`. Подивимося, як він працює:

::jupyter-notebook
```python
import torch
import torch.nn as nn

# Параметри
batch_size = 2
seq_len = 4
embed_dim = 10
hidden_dim = 16

# Приклад входу: (batch_size, seq_len, embed_dim)
x = torch.randn(batch_size, seq_len, embed_dim)

# Створюємо RNN
rnn = nn.RNN(input_size=embed_dim, hidden_size=hidden_dim, batch_first=True)

# Forward pass
output, h_n = rnn(x)

print(f"Вхід x: {x.shape}")
print(f"Виходи output: {output.shape}")  # (batch, seq_len, hidden_dim)
print(f"Останній стан h_n: {h_n.shape}")  # (1, batch, hidden_dim)
```

:::jupyter-cell
```json
{
  "output": {
    "type": "stream",
    "text": [
      "Вхід x: torch.Size([2, 4, 10])\n",
      "Виходи output: torch.Size([2, 4, 16])\n",
      "Останній стан h_n: torch.Size([1, 2, 16])\n"
    ]
  }
}
```
:::
::

**Інтерпретація**:

- `output[i, t, :]` = :math-formula{tex="h_t" inline} для :math-formula{tex="i" inline}-го елемента батча на кроці :math-formula{tex="t" inline}
- `h_n[0, i, :]` = :math-formula{tex="h_n" inline} (останній прихований стан) для :math-formula{tex="i" inline}-го елемента
- Для односпрямованого RNN: `output[i, -1, :] == h_n[0, i, :]`

::callout{type="info" title="batch_first=True"}
За замовчуванням `nn.RNN` очікує вхід у форматі `(seq_len, batch, embed_dim)`.

Опція `batch_first=True` змінює це на `(batch, seq_len, embed_dim)`, що зручніше для більшості задач.
::

## Класифікація sentiment з RNN

Повернемося до задачі з лекції 10: класифікація відгуків IMDB (positive/negative). Тепер замість усереднення використаємо RNN.

### Архітектура

```
Текст (токени) → Embedding → RNN → Останній h_n → Linear → Softmax → Клас
```

Ми беремо **останній прихований стан** :math-formula{tex="h_n" inline} (який містить інформацію про все речення) і подаємо його на лінійний класифікатор.

::jupyter-notebook
```python
import torch.nn as nn

class RNNClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes, pad_idx):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=pad_idx)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)
    
    def forward(self, x):
        # x: (batch, seq_len)
        embedded = self.embedding(x)  # (batch, seq_len, embed_dim)
        output, h_n = self.rnn(embedded)  # output: (batch, seq_len, hidden_dim)
        # Беремо останній стан
        last_hidden = h_n.squeeze(0)  # (batch, hidden_dim)
        logits = self.fc(last_hidden)  # (batch, num_classes)
        return logits

# Приклад
vocab_size = 10000
model = RNNClassifier(vocab_size, embed_dim=100, hidden_dim=128, num_classes=2, pad_idx=0)
print(model)
```

### Повний приклад: Навчання на IMDB

Використаємо код з лекції 11 (датасет з padding) і модифікуємо його для RNN.

::jupyter-notebook
```python
from torch.utils.data import Dataset, DataLoader
import torch

# Простий датасет (як у лекції 11)
class IMDBDataset(Dataset):
    def __init__(self, texts, labels, vocab):
        self.texts = [[vocab.get(w, vocab['<unk>']) for w in text.split()] for text in texts]
        self.labels = labels
    
    def __len__(self):
        return len(self.texts)
    
    def __getitem__(self, idx):
        return torch.tensor(self.texts[idx]), torch.tensor(self.labels[idx])

def collate_fn(batch):
    texts, labels = zip(*batch)
    # Padding (як у лекції 11)
    max_len = max(len(t) for t in texts)
    padded = torch.zeros(len(texts), max_len, dtype=torch.long)
    for i, t in enumerate(texts):
        padded[i, :len(t)] = t
    return padded, torch.stack(labels)

# Приклад даних
texts_train = [
    "this movie is great",
    "terrible film not good",
    "amazing acting and plot",
    "worst movie ever"
]
labels_train = [1, 0, 1, 0]  # 1 = positive, 0 = negative

vocab = {"<pad>": 0, "<unk>": 1, "this": 2, "movie": 3, "is": 4, "great": 5, 
         "terrible": 6, "film": 7, "not": 8, "good": 9, "amazing": 10, 
         "acting": 11, "and": 12, "plot": 13, "worst": 14, "ever": 15}

dataset = IMDBDataset(texts_train, labels_train, vocab)
loader = DataLoader(dataset, batch_size=2, collate_fn=collate_fn)

# Модель
model = RNNClassifier(len(vocab), embed_dim=16, hidden_dim=32, num_classes=2, pad_idx=0)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# Навчання (5 епох)
model.train()
for epoch in range(5):
    total_loss = 0
    for texts, labels in loader:
        optimizer.zero_grad()
        logits = model(texts)
        loss = criterion(logits, labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    print(f"Epoch {epoch+1}, Loss: {total_loss/len(loader):.4f}")

# Тестування
model.eval()
with torch.no_grad():
    test_text = ["this movie is terrible"]
    test_tokens = torch.tensor([[vocab.get(w, vocab['<unk>']) for w in test_text[0].split()]])
    logits = model(test_tokens)
    pred = torch.argmax(logits, dim=1)
    print(f"\nТекст: '{test_text[0]}'")
    print(f"Передбачення: {'positive' if pred.item() == 1 else 'negative'}")
```

      "\n",

## Backpropagation Through Time (BPTT)

### Як навчається RNN?

Пригадайте з Модуля 2 (Перцептрон): навчання нейронної мережі — це **backpropagation**:

1. Forward pass: обчислюємо вихід
2. Обчислюємо loss
3. Backward pass: обчислюємо градієнти :math-formula{tex="\frac{\partial L}{\partial W}" inline} за допомогою chain rule
4. Оновлюємо ваги: :math-formula{tex="W \leftarrow W - \eta \frac{\partial L}{\partial W}" inline}

Для RNN backward pass відбувається **у зворотному напрямку в часі** — це називається **Backpropagation Through Time (BPTT)**.

### Розгортання в часі

Нехай у нас є послідовність з 3 токенів. RNN можна записати як:

::math-formula{tex="\begin{aligned} h_1 &= \tanh(W_h h_0 + W_x x_1 + b) \\ h_2 &= \tanh(W_h h_1 + W_x x_2 + b) \\ h_3 &= \tanh(W_h h_2 + W_x x_3 + b) \end{aligned}"}
::

Для класифікації ми обчислюємо loss на основі :math-formula{tex="h_3" inline}:

::math-formula{tex="L = \text{CrossEntropy}(\text{Linear}(h_3), y_{\text{true}})"}
::

### Градієнти

Щоб оновити :math-formula{tex="W_h" inline}, нам потрібен градієнт :math-formula{tex="\frac{\partial L}{\partial W_h}" inline}. За chain rule:

::math-formula{tex="\frac{\partial L}{\partial W_h} = \frac{\partial L}{\partial h_3} \cdot \frac{\partial h_3}{\partial h_2} \cdot \frac{\partial h_2}{\partial h_1} \cdot \frac{\partial h_1}{\partial W_h} + \ldots"}
::

Градієнт "тече" назад у часі: :math-formula{tex="L \to h_3 \to h_2 \to h_1" inline}.

**Важливо**: кожен крок множить градієнт на :math-formula{tex="\frac{\partial h_t}{\partial h_{t-1}}" inline}. Якщо ця похідна мала (<1), градієнти **зникають**. Якщо велика (>1), градієнти **вибухають**.

:::callout{type="warning" title="Проблема довгих послідовностей"}
Для послідовності з 100 токенів градієнт проходить 100 кроків назад. Якщо на кожному кроці він множиться на 0.9, то:

::math-formula{tex="0.9^{100} \approx 0.0000265"}
::

Градієнт стає **майже нулем** — модель не навчається на далеких токенах!
:::

## Проблема зникнення градієнта

### Математика

Розглянемо похідну :math-formula{tex="h_t" inline} по :math-formula{tex="h_{t-1}" inline}:

::math-formula{tex="h_t = \tanh(W_h h_{t-1} + W_x x_t + b)"}
::

::math-formula{tex="\frac{\partial h_t}{\partial h_{t-1}} = W_h^T \cdot \text{diag}(1 - \tanh^2(\ldots))"}
::

Оскільки :math-formula{tex="\tanh^2(z) \leq 1" inline}, то :math-formula{tex="1 - \tanh^2(z) \leq 1" inline}. Якщо власні значення :math-formula{tex="W_h" inline} малі, то норма :math-formula{tex="\|\frac{\partial h_t}{\partial h_{t-1}}\|" inline} може бути < 1.

Для :math-formula{tex="T" inline} кроків назад:

::math-formula{tex="\left\| \frac{\partial h_T}{\partial h_0} \right\| = \left\| \prod_{t=1}^{T} \frac{\partial h_t}{\partial h_{t-1}} \right\| \leq \gamma^T"}
::

де :math-formula{tex="\gamma < 1" inline}. Це **експоненціальне затухання**!

### Візуалізація

![Зникнення градієнта](/images/16.ai-python/16.natural-language-processing/12.rnn/vanishing-gradient.png)

Графік показує норму градієнта :math-formula{tex="\|\frac{\partial L}{\partial h_t}\|" inline} залежно від кроку :math-formula{tex="t" inline} (де :math-formula{tex="t=0" inline} — початок послідовності).

Для довгих послідовностей (>20-30 токенів) градієнти стають дуже малими, і RNN не може навчитися на ранніх токенах.


### Приклад: Траєкторія прихованого стану

Подивимося, як змінюється прихований стан :math-formula{tex="h_t" inline} під час обробки речення. Візуалізуємо його в 2D (за допомогою PCA):

![Траєкторія прихованого стану](/images/16.ai-python/16.natural-language-processing/12.rnn/hidden-state-trajectory.png)

**Інтерпретація**:

- Кожна точка — це :math-formula{tex="h_t" inline} після обробки :math-formula{tex="t" inline}-го токена
- Траєкторія показує, як RNN "рухається" в просторі станів
- Для позитивного відгуку: траєкторія йде вправо-вгору
- Для негативного: вліво-вниз

RNN навчився **відокремлювати** класи в просторі прихованих станів!

## Рішення проблеми зникнення градієнта

### 1. Gradient Clipping

Обрізаємо градієнти, якщо їхня норма перевищує порог:

::jupyter-notebook
```python
import torch.nn.utils as nn_utils

# Під час навчання
for batch in loader:
    optimizer.zero_grad()
    loss = criterion(model(batch), labels)
    loss.backward()
    
    # Gradient clipping
    nn_utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    
    optimizer.step()
```

Це допомагає з **вибухом** градієнтів, але не з **зникненням**.

### 2. Ініціалізація ваг

Ініціалізуємо :math-formula{tex="W_h" inline} так, щоб власні значення були близькі до 1 (наприклад, orthogonal ініціалізація):

::jupyter-notebook
```python
import torch.nn.init as init

rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
# Orthogonal ініціалізація для W_h
for name, param in rnn.named_parameters():
    if 'weight_hh' in name:  # W_h
        init.orthogonal_(param)
```

### 3. LSTM і GRU (наступна лекція!)

Найефективніше рішення — використовувати **LSTM** (Long Short-Term Memory) або **GRU** (Gated Recurrent Unit). Ці архітектури мають спеціальні **вентилі (gates)**, які контролюють потік градієнтів.

::callout{type="info" title="Що далі?"}
У [лекції 13](/16.ai-python/16.natural-language-processing/13.lstm-gru) ми детально розглянемо LSTM і GRU — архітектури, які розв'язують проблему зникнення градієнта за допомогою **забувального вентиля**, **вхідного вентиля** та **вихідного вентиля**.
::

## Варіанти RNN

### Many-to-One (класифікація)

Це те, що ми вже бачили: обробляємо послідовність, беремо останній стан :math-formula{tex="h_n" inline} → класифікуємо.

```
Tokens: [w1, w2, w3, w4]
        ↓   ↓   ↓   ↓
RNN:   h1→ h2→ h3→ h4 → Linear → Class
```

### Many-to-Many (мовне моделювання)

Передбачаємо наступний токен на **кожному** кроці:

```
Tokens: [w1,  w2,  w3,  w4]
        ↓    ↓    ↓    ↓
RNN:   h1 → h2 → h3 → h4
        ↓    ↓    ↓    ↓
     Linear Linear Linear Linear
        ↓    ↓    ↓    ↓
Pred:  w2?  w3?  w4?  w5?
```

Це схоже на біграми з лекції 11, але тепер модель бачить **весь контекст** (не лише попереднє слово).

::jupyter-notebook
```python
class RNNLanguageModel(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)
    
    def forward(self, x):
        # x: (batch, seq_len)
        embedded = self.embedding(x)  # (batch, seq_len, embed_dim)
        output, _ = self.rnn(embedded)  # (batch, seq_len, hidden_dim)
        logits = self.fc(output)  # (batch, seq_len, vocab_size)
        return logits

# Приклад
model_lm = RNNLanguageModel(vocab_size=10000, embed_dim=100, hidden_dim=128)
x = torch.randint(0, 10000, (2, 10))  # 2 послідовності по 10 токенів
logits = model_lm(x)
print(f"Вхід: {x.shape}, Вихід: {logits.shape}")
```

:::jupyter-cell
```json
{
  "output": {
    "type": "stream",
    "text": [
      "Вхід: torch.Size([2, 10]), Вихід: torch.Size([2, 10, 10000])\n"
    ]
  }
}
```
:::
::

Для навчання використовуємо **teacher forcing**: на кроці :math-formula{tex="t" inline} подаємо справжній токен :math-formula{tex="w_t" inline}, а передбачаємо :math-formula{tex="w_{t+1}" inline}.

### Bidirectional RNN

Обробляємо послідовність у **обох напрямках**: зліва направо і справа наліво.

```
Forward:   h1→ h2→ h3→ h4→
Tokens:    w1  w2  w3  w4
Backward:  h1← h2← h3← h4←
```

Об'єднуємо стани: :math-formula{tex="h_t = [\overrightarrow{h_t}, \overleftarrow{h_t}]" inline} (конкатенація).

::jupyter-notebook
```python
# У PyTorch
rnn_bi = nn.RNN(embed_dim, hidden_dim, batch_first=True, bidirectional=True)
x = torch.randn(2, 4, 10)  # (batch, seq_len, embed_dim)
output, h_n = rnn_bi(x)
print(f"Output: {output.shape}")  # (2, 4, hidden_dim*2)
print(f"h_n: {h_n.shape}")  # (2, 2, hidden_dim) — 2 напрямки
```

:::jupyter-cell
```json
{
  "output": {
    "type": "stream",
    "text": [
      "Output: torch.Size([2, 4, 32])\n",
      "h_n: torch.Size([2, 2, 16])\n"
    ]
  }
}
```
:::
::

**Важливо**: Bidirectional RNN не можна використовувати для генерації (бо він бачить майбутні токени), але він корисний для класифікації і розуміння тексту.

## Практика

::::accordion
:::accordion-item{title="Завдання 1: Bidirectional RNN для IMDB (★★☆)"}

Модифікуйте `RNNClassifier` з прикладу вище, щоб використовувати bidirectional RNN.

**Підказки**:

1. Додайте `bidirectional=True` в `nn.RNN`
2. Розмір `h_n` буде `(2, batch, hidden_dim)` — об'єднайте обидва напрямки
3. Оновіть вхід `fc`: тепер він має бути `hidden_dim * 2`

**Розв'язок**:

```python
class BiRNNClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes, pad_idx):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=pad_idx)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(hidden_dim * 2, num_classes)  # *2 бо bidirectional
    
    def forward(self, x):
        embedded = self.embedding(x)
        output, h_n = self.rnn(embedded)
        # h_n: (2, batch, hidden_dim) — forward і backward
        # Об'єднуємо останні стани обох напрямків
        h_fwd = h_n[0]  # forward
        h_bwd = h_n[1]  # backward
        h_combined = torch.cat([h_fwd, h_bwd], dim=1)  # (batch, hidden_dim*2)
        logits = self.fc(h_combined)
        return logits

# Тестування
model_bi = BiRNNClassifier(len(vocab), embed_dim=16, hidden_dim=32, num_classes=2, pad_idx=0)
test_input = torch.randint(0, len(vocab), (2, 5))  # 2 послідовності по 5 токенів
logits = model_bi(test_input)
print(f"Вихід: {logits.shape}")  # (2, 2)
```

**Очікуваний результат**: Bidirectional RNN має дати трохи кращу accuracy (~1-2%), бо він бачить контекст з обох боків.
:::

:::accordion-item{title="Завдання 2: RNN Language Model (★★★)"}

Реалізуйте і навчіть RNN мовну модель на простому датасеті (наприклад, казка "Колобок"). Генеруйте текст за допомогою **sampling**.

**Кроки**:

1. Підготуйте текст: токенізація, словник
2. Створіть датасет: вхід = `[w1, w2, ..., w_n]`, таргет = `[w2, w3, ..., w_{n+1}]`
3. Навчіть `RNNLanguageModel` (код вище)
4. Генерація: почніть з seed токена, передбачайте наступний, додайте його до послідовності, повторюйте

**Розв'язок** (скорочена версія):

```python
import torch
import torch.nn as nn

# 1. Підготовка даних
text = "жил был колобок колобок от бабушки ушел от дедушки ушел"
tokens = text.split()
vocab = {w: i for i, w in enumerate(set(tokens))}
vocab_inv = {i: w for w, i in vocab.items()}
ids = [vocab[w] for w in tokens]

# 2. Датасет (x = [0:n-1], y = [1:n])
X = torch.tensor(ids[:-1]).unsqueeze(0)  # (1, seq_len-1)
y = torch.tensor(ids[1:]).unsqueeze(0)

# 3. Модель
model = RNNLanguageModel(len(vocab), embed_dim=16, hidden_dim=32)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# Навчання
for epoch in range(200):
    optimizer.zero_grad()
    logits = model(X)  # (1, seq_len, vocab_size)
    loss = criterion(logits.view(-1, len(vocab)), y.view(-1))
    loss.backward()
    optimizer.step()
    if (epoch + 1) % 50 == 0:
        print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")

# 4. Генерація
model.eval()
seed = vocab["колобок"]
generated = [seed]
for _ in range(10):
    x = torch.tensor([generated[-1]]).unsqueeze(0)  # (1, 1)
    with torch.no_grad():
        logits = model(x)[:, -1, :]  # (1, vocab_size)
    probs = torch.softmax(logits, dim=-1)
    next_token = torch.multinomial(probs, 1).item()
    generated.append(next_token)

print("Згенерований текст:", " ".join([vocab_inv[i] for i in generated]))
```

**Очікуваний результат**: Щось на кшталт "колобок від бабушки ушел колобок жил ушел…" (може бути нелогічно, бо корпус малий).
:::

:::accordion-item{title="Завдання 3: Візуалізація прихованого стану (★☆☆)"}

Візуалізуйте траєкторію прихованого стану :math-formula{tex="h_t" inline} для одного речення в 2D (використовуючи PCA).

**Кроки**:

1. Візьміть навчену `RNNClassifier`
2. Пропустіть речення через модель, зберігаючи всі :math-formula{tex="h_t" inline} (`output` з RNN)
3. Застосуйте PCA до :math-formula{tex="(h_1, h_2, \ldots, h_n)" inline} → 2D координати
4. Намалюйте траєкторію з matplotlib

**Розв'язок**:

```python
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# Візьмемо навчену модель з прикладу
model.eval()
text = "this movie is not good"
tokens_ids = [vocab.get(w, vocab['<unk>']) for w in text.split()]
x = torch.tensor([tokens_ids])

with torch.no_grad():
    embedded = model.embedding(x)
    output, _ = model.rnn(embedded)  # (1, seq_len, hidden_dim)

# Витягуємо hidden states
hidden_states = output.squeeze(0).cpu().numpy()  # (seq_len, hidden_dim)

# PCA → 2D
pca = PCA(n_components=2)
coords_2d = pca.fit_transform(hidden_states)

# Візуалізація
plt.figure(figsize=(8, 6))
plt.plot(coords_2d[:, 0], coords_2d[:, 1], 'o-', markersize=8)
for i, word in enumerate(text.split()):
    plt.annotate(word, (coords_2d[i, 0], coords_2d[i, 1]), fontsize=12)
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Траєкторія прихованого стану RNN")
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig("hidden_state_trajectory_example.png", dpi=150)
plt.show()
```

**Очікуваний результат**: Траєкторія, де кожна точка підписана відповідним словом. Ви побачите, як RNN "рухається" від слова до слова.

## Підсумок

::grid{cols=2}
  ::card{icon="lucide:brain"}
  **Рекурентні нейронні мережі**
  
  RNN обробляють послідовності **крок за кроком**, зберігаючи інформацію в **прихованому стані** :math-formula{tex="h_t" inline}. На відміну від усереднення, RNN враховує порядок слів і контекст.
  ::

  ::card{icon="lucide:git-branch"}
  **Розгортання в часі**
  
  RNN — це **одна мережа**, застосована до кожного токена. Розгортання в часі показує, як :math-formula{tex="h_t" inline} залежить від :math-formula{tex="h_{t-1}, h_{t-2}, \ldots" inline}
  ::

  ::card{icon="lucide:trending-down"}
  **Зникнення градієнта**
  
  Під час BPTT градієнти проходять багато кроків назад і можуть **експоненціально зменшуватися**. Це утруднює навчання на довгих послідовностях.
  ::

  ::card{icon="lucide:split"}
  **Варіанти архітектур**
  
  - **Many-to-One**: класифікація (sentiment)
  - **Many-to-Many**: мовне моделювання
  - **Bidirectional**: контекст з обох боків (не для генерації)
