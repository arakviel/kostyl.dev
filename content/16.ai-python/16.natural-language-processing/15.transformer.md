# Лекція 15: Transformer

## Революція: "Attention Is All You Need"

У 2017 році команда Google (Vaswani et al.) опублікувала статтю **"Attention Is All You Need"**, яка змінила NLP назавжди.

**Основна ідея**: замість RNN/LSTM використовувати **лише attention** для обробки послідовностей.

::callout{type="info" title="Чому Transformer такий важливий?"}
До Transformer всі state-of-the-art моделі використовували RNN/LSTM:
- **2014**: Seq2seq з LSTM (Sutskever et al.)
- **2015**: Attention mechanism (Bahdanau et al.)
- **2016**: Google Neural Machine Translation (GNMT) — LSTM + attention

**2017: Transformer** — ніяких RNN/LSTM, лише attention!

Результат:
- **+2 BLEU** проти найкращих LSTM моделей
- **Швидше** (паралельна обробка)
- **Легше тренувати** (немає проблеми зникнення градієнта)

Сьогодні **всі** сучасні моделі (BERT, GPT, T5, ChatGPT) базуються на Transformer!
::

---

## Проблеми RNN/LSTM

Чому RNN/LSTM не ідеальні для послідовностей?

| Проблема | RNN/LSTM | Transformer |
|----------|----------|-------------|
| **Послідовна обробка** | Токен $t$ залежить від $t-1$ → не паралелиться | Всі токени обробляються **одночасно** |
| **Довгі залежності** | Зникнення градієнта (навіть з LSTM) | Пряме з'єднання через attention |
| **Швидкість** | Повільно на GPU (послідовні операції) | Швидко (матричні операції) |
| **Пам'ять** | $O(n)$ для послідовності з $n$ токенів | $O(n^2)$ (але паралельно!) |

**Ключове обмеження RNN**: щоб обробити токен $t$, потрібно **спочатку** обробити всі $1, 2, \ldots, t-1$. Це не паралелиться!

## Self-Attention: Увага до себе

У лекції 14 ми бачили **cross-attention**: decoder дивиться на encoder outputs.

**Self-attention** — кожен токен дивиться на **всі токени в тій самій послідовності** (включно з собою).

### Приклад

Речення: "The animal didn't cross the street because it was too tired"

Питання: що означає "it"? (тварина чи вулиця?)

Self-attention дозволяє "it" "подивитися" на всі попередні слова і зрозуміти, що йдеться про "animal".

![Self-attention приклад](/images/16.ai-python/16.natural-language-processing/15.transformer/self-attention-example.png)

### Математика Self-Attention

Нагадаємо формулу attention з лекції 14:

::math-formula
---
formula: "\\text{Attention}(Q, K, V) = \\text{softmax}\\left(\\frac{Q K^T}{\\sqrt{d_k}}\\right) V"
mode: block
---
::

**У self-attention**: $Q$, $K$, $V$ походять з **одного джерела** (входу $X$):

::math-formula
---
formula: "\\begin{aligned} Q &= X W_Q \\\\ K &= X W_K \\\\ V &= X W_V \\end{aligned}"
mode: block
---
::

де:
- $X \in \mathbb{R}^{n \times d}$ — вхідна послідовність ($n$ токенів, $d$ розмірність embedding)
- $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$ — навчальні матриці проєкції

**Процес**:

1. Проєкція: обчислюємо $Q$, $K$, $V$ з входу
2. Scores: $\text{score}_{i,j} = \frac{q_i \cdot k_j}{\sqrt{d_k}}$ (схожість токена $i$ з токеном $j$)
3. Attention weights: $\alpha_{i,j} = \text{softmax}(\text{score}_{i,:})$
4. Вихід: $z_i = \sum_j \alpha_{i,j} v_j$

::jupyter-notebook
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def self_attention(X, W_Q, W_K, W_V):
    """
    Self-attention для послідовності X
    """
    # X: (batch, seq_len, d_model)
    Q = torch.matmul(X, W_Q)  # (batch, seq_len, d_k)
    K = torch.matmul(X, W_K)  # (batch, seq_len, d_k)
    V = torch.matmul(X, W_V)  # (batch, seq_len, d_v)
    
    d_k = Q.size(-1)
    
    # Scores: Q @ K^T
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    # scores: (batch, seq_len, seq_len)
    
    # Attention weights
    alpha = F.softmax(scores, dim=-1)
    
    # Weighted sum
    output = torch.matmul(alpha, V)  # (batch, seq_len, d_v)
    
    return output, alpha

# Приклад
batch_size = 2
seq_len = 5
d_model = 64
d_k = 64

X = torch.randn(batch_size, seq_len, d_model)
W_Q = torch.randn(d_model, d_k)
W_K = torch.randn(d_model, d_k)
W_V = torch.randn(d_model, d_k)

output, alpha = self_attention(X, W_Q, W_K, W_V)

print(f"Вхід X: {X.shape}")
print(f"Вихід: {output.shape}")
print(f"Attention weights alpha: {alpha.shape}")
print(f"\nПриклад alpha[0] (перший батч, всі токени):")
print(alpha[0])
print(f"Сума по рядках: {alpha[0].sum(dim=1)}")  # Кожен рядок має сумуватися до 1
```

**Спостереження**:

::callout{type="warning" title="Складність self-attention"}

Для $n=1000$ це $10^6$ операцій! Це чому Transformer важко масштабувати на **дуже довгі** послідовності (>512 токенів).

Рішення: Sparse attention, Linformer, Performer (це beyond scope цієї лекції).

## Multi-Head Attention

**Проблема**: один attention head може "дивитися" лише на один аспект відносин між токенами.

**Рішення**: використовуємо **кілька attention heads** паралельно!

### Архітектура

![Multi-head attention](/images/16.ai-python/16.natural-language-processing/15.transformer/multi-head-attention.png)

**Ідея**: замість одного $Q, K, V$, створюємо $h$ різних наборів:

::math-formula
---
formula: "\\text{head}_i = \\text{Attention}(X W_Q^i, X W_K^i, X W_V^i)"
mode: block
---
::

де кожна голова має **власні** ваги $W_Q^i, W_K^i, W_V^i$.

Потім **конкатенуємо** всі голови і проєкціюємо:

::math-formula
---
formula: "\\text{MultiHead}(Q, K, V) = \\text{Concat}(\\text{head}_1, \\ldots, \\text{head}_h) W_O"
mode: block
---
::

де $W_O \in \mathbb{R}^{h \cdot d_v \times d_{\text{model}}}$ — вихідна проєкція.

### Чому це працює?

Різні голови навчаються дивитися на **різні аспекти**:

- **Head 1**: синтаксис (іменник → дієслово)
- **Head 2**: семантика (суб'єкт → об'єкт)
- **Head 3**: локальний контекст (сусідні слова)
- **Head 4**: довгі залежності

::jupyter-notebook
```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # Проєкції для Q, K, V (всі голови разом)
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        
        # Вихідна проєкція
        self.W_O = nn.Linear(d_model, d_model)
    
    def forward(self, X):
        batch_size, seq_len, d_model = X.shape
        
        # Проєкції
        Q = self.W_Q(X)  # (batch, seq_len, d_model)
        K = self.W_K(X)
        V = self.W_V(X)
        
        # Розділяємо на голови
        Q = Q.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        # Після transpose: (batch, num_heads, seq_len, d_k)
        
        # Scaled dot-product attention для кожної голови
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.d_k ** 0.5)
        alpha = torch.softmax(scores, dim=-1)
        attention_output = torch.matmul(alpha, V)
        # attention_output: (batch, num_heads, seq_len, d_k)
        
        # Конкатенація голів
        attention_output = attention_output.transpose(1, 2).contiguous()
        attention_output = attention_output.view(batch_size, seq_len, d_model)
        
        # Вихідна проєкція
        output = self.W_O(attention_output)
        
        return output

# Приклад
mha = MultiHeadAttention(d_model=512, num_heads=8)
X = torch.randn(2, 10, 512)  # (batch=2, seq_len=10, d_model=512)
output = mha(X)

print(f"Вхід: {X.shape}")
print(f"Вихід: {output.shape}")
print(f"Параметри: {sum(p.numel() for p in mha.parameters()):,}")
```

## Positional Encoding

**Проблема**: Self-attention не враховує **порядок токенів**!

Attention обробляє токени як **множину** (set), а не **послідовність** (sequence). Речення "cat ate mouse" і "mouse ate cat" матимуть однакові attention weights (якщо не враховувати позиції).

**Рішення**: додати **positional encoding** — інформацію про позицію кожного токена.

### Sinusoidal Positional Encoding

Vaswani et al. використовують **синусоїдальні функції**:

::math-formula
---
formula: "\\begin{aligned} PE_{(pos, 2i)} &= \\sin\\left(\\frac{pos}{10000^{2i/d_{\\text{model}}}}\\right) \\\\ PE_{(pos, 2i+1)} &= \\cos\\left(\\frac{pos}{10000^{2i/d_{\\text{model}}}}\\right) \\end{aligned}"
mode: block
---
::

де:
- $pos$ — позиція токена в послідовності (0, 1, 2, ...)
- $i$ — індекс розмірності embedding (0, 1, ..., $d_{\text{model}}/2 - 1$)
- Парні розмірності — $\sin$, непарні — $\cos$

**Властивості**:

- **Унікальність**: кожна позиція має унікальне кодування
- **Відносні відстані**: $PE_{pos+k}$ можна виразити через $PE_{pos}$ (модель може навчитися відносним позиціям)
- **Необмежена довжина**: працює для будь-якої довжини послідовності

::jupyter-notebook
```python
import torch
import numpy as np
import matplotlib.pyplot as plt

def positional_encoding(max_len, d_model):
    """
    Створює positional encoding матрицю
    """
    pe = torch.zeros(max_len, d_model)
    position = torch.arange(0, max_len).unsqueeze(1).float()
    div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                         -(np.log(10000.0) / d_model))
    
    pe[:, 0::2] = torch.sin(position * div_term)
    pe[:, 1::2] = torch.cos(position * div_term)
    
    return pe

# Генеруємо positional encoding
pe = positional_encoding(max_len=100, d_model=128)

print(f"Positional encoding shape: {pe.shape}")
print(f"PE для позиції 0 (перші 10 dim):\n{pe[0, :10]}")
print(f"PE для позиції 50 (перші 10 dim):\n{pe[50, :10]}")

# Візуалізація
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Heatmap
ax = axes[0]
im = ax.imshow(pe[:50, :64].numpy().T, cmap='RdBu', aspect='auto', vmin=-1, vmax=1)
ax.set_xlabel('Позиція токена', fontweight='bold')
ax.set_ylabel('Розмірність embedding', fontweight='bold')
ax.set_title('Positional Encoding Heatmap', fontweight='bold')
plt.colorbar(im, ax=ax)

# Криві для кількох розмірностей
ax = axes[1]
for i in [0, 1, 10, 20, 50]:
    ax.plot(pe[:50, i].numpy(), label=f'dim {i}')
ax.set_xlabel('Позиція токена', fontweight='bold')
ax.set_ylabel('Значення PE', fontweight='bold')
```

Сучасні моделі (BERT, GPT) часто використовують **learned PE**.

## Feed-Forward Network (FFN)

Після attention кожен токен проходить через **feed-forward мережу** (однакову для всіх токенів):

::math-formula
---
formula: "\\text{FFN}(x) = \\text{ReLU}(x W_1 + b_1) W_2 + b_2"
mode: block
---
::

- Два лінійні шари з ReLU між ними
- Зазвичай $d_{\\text{ff}} = 4 \\cdot d_{\\text{model}}$ (наприклад, 512 → 2048 → 512)
- Застосовується **незалежно** до кожного токена (position-wise)

::jupyter-notebook
```python
import torch.nn as nn

class FeedForward(nn.Module):
    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.linear1 = nn.Linear(d_model, d_ff)
        self.linear2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x):
        # x: (batch, seq_len, d_model)
        x = torch.relu(self.linear1(x))  # (batch, seq_len, d_ff)
        x = self.dropout(x)
        x = self.linear2(x)  # (batch, seq_len, d_model)
        return x

# Приклад
ffn = FeedForward(d_model=512, d_ff=2048)
x = torch.randn(2, 10, 512)
output = ffn(x)
print(f"Вхід: {x.shape}")
print(f"Вихід: {output.shape}")
print(f"Параметри: {sum(p.numel() for p in ffn.parameters()):,}")
```

## Transformer Block (Encoder шар)

Повний encoder шар складається з:

1. **Multi-head self-attention**
2. **Add & Norm** (residual connection + layer normalization)
3. **Feed-forward network**
4. **Add & Norm**

![Transformer encoder block](/images/16.ai-python/16.natural-language-processing/15.transformer/transformer-block.png)

::jupyter-notebook
```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x):
        # Self-attention + residual + norm
        attn_output = self.attention(x)
        x = self.norm1(x + self.dropout(attn_output))
        
        # FFN + residual + norm
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))
        
        return x

# Приклад
block = TransformerBlock(d_model=512, num_heads=8, d_ff=2048)
x = torch.randn(2, 10, 512)
output = block(x)
print(f"Вхід: {x.shape}")
print(f"Вихід: {output.shape}")
print(f"Параметри: {sum(p.numel() for p in block.parameters()):,}")
```

::callout{type="info" title="Residual Connections & Layer Norm"}
**Residual connections** (пригадайте з лекції про CNN, модуль 5):

$$x_{\text{out}} = x_{\text{in}} + F(x_{\text{in}})$$

Допомагають:
- Тренувати глибокі мережі (градієнти течуть напряму)
- Стабілізувати навчання

**Layer Normalization** (з лекції про перцептрон, модуль 2):

$$\text{LayerNorm}(x) = \gamma \cdot \frac{x - \mu}{\sigma} + \beta$$

Нормалізує кожен токен окремо (на відміну від Batch Norm).

## Повна архітектура Transformer

Оригінальний Transformer має **encoder-decoder** структуру:

![Повна архітектура Transformer](/images/16.ai-python/16.natural-language-processing/15.transformer/transformer-architecture.png)

**Encoder** (ліворуч):
- $N=6$ шарів (TransformerBlock)
- Кожен шар: Multi-head self-attention → FFN
- Вихід: контекстні представлення входу

**Decoder** (праворуч):
- $N=6$ шарів
- Кожен шар має **три** під-шари:
  1. **Masked self-attention** (не бачить майбутніх токенів)
  2. **Cross-attention** (дивиться на encoder outputs)
  3. **FFN**

### Masked Self-Attention

У decoder self-attention **маскується**, щоб токен $t$ не бачив токени $t+1, t+2, \ldots$ (майбутнє).

::jupyter-notebook
```python
def create_causal_mask(seq_len):
    """
    Створює маску для causal (autoregressive) attention
    """
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    mask = mask.masked_fill(mask == 1, float('-inf'))
    return mask

mask = create_causal_mask(5)
print("Causal mask (5 токенів):")
print(mask)
print("\nПісля softmax (стає 0):")
print(torch.softmax(mask, dim=-1))
```

## Порівняння: RNN vs Transformer

| Параметр | RNN/LSTM | Transformer |
|----------|----------|-------------|
| **Паралелізація** | ❌ Послідовна обробка | ✅ Всі токени одночасно |
| **Довгі залежності** | ⚠️ Зникнення градієнта | ✅ Пряме з'єднання |
| **Складність (час)** | $O(n \cdot d^2)$ | $O(n^2 \cdot d)$ |
| **Складність (пам'ять)** | $O(n \cdot d)$ | $O(n^2)$ |
| **Швидкість на GPU** | Повільно | Швидко |
| **Interpretability** | ❌ Прихований стан | ✅ Attention weights |

**Висновок**: Transformer **краще** для більшості задач, якщо послідовність не надто довга ($n < 2048$).

## Варіанти Transformer

Після оригінального Transformer з'явилося безліч варіантів:

### 1. Encoder-only (BERT)

Використовує лише **encoder** (без decoder):

```
Вхід → Encoder (N шарів) → Контекстні представлення
```

**Застосування**: класифікація, NER, Q&A

**Приклад**: BERT, RoBERTa, DistilBERT

### 2. Decoder-only (GPT)

Використовує лише **decoder** (з masked self-attention):

```
Вхід → Decoder (N шарів) → Генерація наступного токена
```

**Застосування**: генерація тексту, dialogue, completion

**Приклад**: GPT-2, GPT-3, GPT-4

### 3. Encoder-Decoder (T5)

Повна архітектура (як оригінальний Transformer):

```
Вхід → Encoder → Decoder → Вихід
```

**Застосування**: переклад, summarization, seq2seq

**Приклад**: T5, BART, мт5

::callout{type="info" title="Яку архітектуру вибрати?"}
- **Encoder-only (BERT)**: коли потрібно **розуміння** тексту (класифікація, екстракція інформації)
- **Decoder-only (GPT)**: коли потрібна **генерація** тексту (chat, completion, coding)
- **Encoder-Decoder (T5)**: коли вхід і вихід мають різну структуру (переклад, summarization)

У лекції 16 ми використаємо **BERT** для класифікації sentiment.
::

:::accordion-item{title="Завдання 3: Міні Transformer для класифікації (★★★)"}

Реалізуйте простий Transformer encoder для класифікації sentiment (лише encoder, без decoder).

**Розв'язок**:

```python
class SimpleTransformerClassifier(nn.Module):
    def __init__(self, vocab_size, d_model, num_heads, num_layers, num_classes, max_len=512):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pe = positional_encoding(max_len, d_model)
        
        # N encoder блоків
        self.layers = nn.ModuleList([
            TransformerBlock(d_model, num_heads, d_ff=d_model*4)
            for _ in range(num_layers)
        ])
        
        self.classifier = nn.Linear(d_model, num_classes)
    
    def forward(self, x):
        # x: (batch, seq_len)
        batch_size, seq_len = x.shape
        
        # Embedding + PE
        x = self.embedding(x)  # (batch, seq_len, d_model)
        x = x + self.pe[:seq_len].unsqueeze(0).to(x.device)
        
        # Encoder layers
        for layer in self.layers:
            x = layer(x)
        
        # Pooling (береми перший токен, як BERT [CLS])
        x = x[:, 0, :]  # (batch, d_model)
        
        # Classification
        logits = self.classifier(x)  # (batch, num_classes)
        return logits

# Приклад
model = SimpleTransformerClassifier(
    vocab_size=10000,
    d_model=256,
    num_heads=8,
    num_layers=4,
    num_classes=2
)

# Тест
x = torch.randint(0, 10000, (2, 20))  # 2 послідовності по 20 токенів
logits = model(x)
print(f"Вхід: {x.shape}")
print(f"Логіти: {logits.shape}")
print(f"Параметри: {sum(p.numel() for p in model.parameters()):,}")
```

**Примітка**: Це спрощена версія. У реальному BERT є додаткові трюки (segment embeddings, pre-training objectives).

## Підсумок

::grid{cols=2}
  ::card{icon="lucide:zap"}
  **Революція: Attention Is All You Need**
  
  Transformer замінив RNN/LSTM на **чистий attention**. Результат: швидше, краще, легше тренувати. Всі сучасні моделі (BERT, GPT, T5) базуються на Transformer.
  ::

  ::card{icon="lucide:eye"}
  **Self-Attention**
  
  Кожен токен "дивиться" на всі токени (включно з собою). Формула: $\text{Attention}(Q,K,V) = \text{softmax}(QK^T / \sqrt{d_k})V$, де $Q=K=V$ (з одного джерела).
  ::

  ::card{icon="lucide:layers-3"}
  **Multi-Head Attention**
  
  Кілька attention heads паралельно дивляться на різні аспекти (синтаксис, семантика, контекст). Результати конкатенуються і проєкціюються.
  ::

  ::card{icon="lucide:map-pin"}
  **Positional Encoding**
  
  Додається до embeddings, щоб модель знала порядок токенів. Використовуються синусоїди або навчальні параметри.
  ::
::
