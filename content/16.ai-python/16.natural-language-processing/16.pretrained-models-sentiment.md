# Лекція 16: Pretrained Models & Hugging Face

## Від нуля до Transfer Learning

У попередніх лекціях ми навчали моделі **з нуля** (from scratch):

- Лекція 10: Embeddings + усереднення
- Лекція 12-13: RNN/LSTM
- Лекція 14-15: Attention, Transformer

**Проблема**: навчання великих моделей вимагає:
- Величезні датасети (мільйони текстів)
- Потужні GPU (дні/тижні тренування)
- Експертизу в налаштуванні гіперпараметрів

**Рішення**: **Transfer Learning** — використовуємо модель, навчену на великому корпусі, і **дотренуємо** (fine-tune) на своїй задачі.

::callout{type="success" title="Transfer Learning у NLP"}
**Етапи**:

1. **Pre-training**: модель навчається на величезному корпусі (Wikipedia, Books, Web) розв'язувати загальну задачу (наприклад, передбачати маскований токен)
2. **Fine-tuning**: модель дотренуємо на конкретній задачі (sentiment, NER, Q&A) з малим датасетом

**Приклад**:
- BERT pre-training: 3.3B слів, 16 TPU, 4 дні
- BERT fine-tuning на IMDB: 25K відгуків, 1 GPU, 1 година

Transfer learning дає **+5-10% accuracy** порівняно з навчанням з нуля!
::

## Hugging Face Transformers

**Hugging Face** — найпопулярніша бібліотека для роботи з pretrained моделями.

## Subword Tokenization (токенізація підслів)

До цього ми використовували **word-level tokenization** (кожне слово — окремий токен).

**Проблема**: 
- Рідкісні слова → `<UNK>`
- Словник стає величезним (>100K токенів)
- Морфологія ігнорується ("run", "running", "runs" — різні токени)

**Рішення**: **Subword tokenization** — розбиваємо слова на підслова (subwords).

### Приклади алгоритмів

1. **Byte Pair Encoding (BPE)** — GPT-2, RoBERTa
2. **WordPiece** — BERT
3. **SentencePiece** — T5, XLM-RoBERTa

### Як працює WordPiece (BERT)

::jupyter-notebook
```python
from transformers import BertTokenizer

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# Приклад токенізації
text = "I love running and swimming!"
tokens = tokenizer.tokenize(text)
token_ids = tokenizer.convert_tokens_to_ids(tokens)

print(f"Текст: {text}")
print(f"Токени: {tokens}")
print(f"Token IDs: {token_ids}")
print(f"\nРідкісне слово:")
rare_text = "I love antidisestablishmentarianism"
rare_tokens = tokenizer.tokenize(rare_text)
print(f"'{rare_text}' → {rare_tokens}")
```

:::jupyter-cell
```json
{
  "output": {
    "type": "stream",
    "text": [
      "Текст: I love running and swimming!\n",
      "Токени: ['i', 'love', 'running', 'and', 'swimming', '!']\n",
      "Token IDs: [1045, 2293, 2770, 1998, 5742, 999]\n",
      "\n",
      "Рідкісне слово:\n",
      "'I love antidisestablishmentarianism' → ['i', 'love', 'anti', '##dis', '##est', '##ab', '##lish', '##menta', '##rian', '##ism']\n"
```

:::
::

**Спостереження**:
- Часті слова ("love", "running") — цілі токени
- Рідкісне слово розбивається на підслова: "anti", "##dis", "##est", ...
- `##` — префікс для продовження слова

![Subword tokenization](/images/16.ai-python/16.natural-language-processing/16.pretrained-models-sentiment/subword-tokenization.png)

**Переваги**:
- Словник менший (~30K токенів замість 100K+)
- Немає `<UNK>` (будь-яке слово можна розбити)
- Морфологія частково захоплюється ("run" → "run", "running" → "run" + "##ning")

```python
def tokenize_function(examples):
    return tokenizer(examples['text'], padding='max_length', truncation=True, max_length=512)

# Токенізуємо (це може зайняти хвилину)
tokenized_datasets = dataset.map(tokenize_function, batched=True)

# Залишаємо лише потрібні колонки
tokenized_datasets = tokenized_datasets.remove_columns(['text'])
tokenized_datasets = tokenized_datasets.rename_column('label', 'labels')
tokenized_datasets.set_format('torch')

print("Токенізація завершена!")
print(f"Приклад токенізованого input_ids: {tokenized_datasets['train'][0]['input_ids'][:20]}")
```

### Навчання (Fine-tuning)

::jupyter-notebook
```python
from transformers import Trainer, TrainingArguments
import numpy as np
from datasets import load_metric

# Метрика
metric = load_metric('accuracy')

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    return metric.compute(predictions=predictions, references=labels)

# Налаштування навчання
training_args = TrainingArguments(
    output_dir='./results',
    evaluation_strategy='epoch',
    learning_rate=2e-5,
    per_device_train_batch_size=8,
    per_device_eval_batch_size=8,
    num_train_epochs=3,
    weight_decay=0.01,
    save_strategy='epoch',
    load_best_model_at_end=True,
)

# Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_datasets['train'].select(range(1000)),  # Для швидкості беремо 1000
    eval_dataset=tokenized_datasets['test'].select(range(500)),
    compute_metrics=compute_metrics,
)

# Навчання
train_result = trainer.train()
print(f"\nНавчання завершено!")
print(f"Train loss: {train_result.metrics['train_loss']:.4f}")

# Оцінка
eval_result = trainer.evaluate()
print(f"Eval accuracy: {eval_result['eval_accuracy']:.4f}")
```

## Підсумок модуля: Три підходи

Ми пройшли шлях від базових методів до state-of-the-art:

![Порівняння підходів](/images/16.ai-python/16.natural-language-processing/16.pretrained-models-sentiment/comparison-approaches.png)

### 1. Класичні методи (лекції 1-6)

**Підхід**: Bag-of-words + LogisticRegression

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression

vectorizer = CountVectorizer(max_features=5000)
X = vectorizer.fit_transform(texts)
model = LogisticRegression()
model.fit(X, labels)
```

**Переваги**: швидко, просто, interpretable  
**Недоліки**: не враховує порядок слів, семантику

**Accuracy**: ~82%

### 2. Neural networks з нуля (лекції 7-15)

**Підхід**: Embeddings + LSTM/Transformer, навчання з нуля

```python
model = nn.Sequential(
    nn.Embedding(vocab_size, 100),
    nn.LSTM(100, 128),
    nn.Linear(128, 2)
)
# Тренуємо багато епох...
```

**Переваги**: враховує порядок, семантику, контекст  
**Недоліки**: вимагає багато даних, довге навчання

**Accuracy**: ~88-90%

### 3. Transfer learning (лекція 16)

**Підхід**: Pretrained BERT + fine-tuning

```python
model = BertForSequenceClassification.from_pretrained('bert-base-uncased')
trainer = Trainer(model=model, ...)
trainer.train()  # Швидке дотренування
```

**Переваги**: найкраща accuracy, швидке навчання (pre-training вже зроблений)  
**Недоліки**: великі моделі (потрібна GPU для inference)

**Accuracy**: ~89-92%

::callout{type="success" title="Коли використовувати кожен підхід?"}
- **Bag-of-words**: baseline, швидкі експерименти, коли даних мало
- **Neural з нуля**: коли є багато даних і специфічна domain
- **Transfer learning**: **default choice** для більшості задач у 2024+

:::accordion-item{title="Завдання 2: Fine-tune на власному датасеті (★★★)"}

Зберіть власний датасет (наприклад, відгуки на продукти) і навчіть BERT.

**Підказки**:

1. Формат датасету: список словників `[{'text': '...', 'label': 0/1}, ...]`
2. Використайте `Dataset.from_dict()` з Hugging Face Datasets
3. Токенізуйте і навчіть як у прикладі вище

**Розв'язок** (скорочений):

```python
from datasets import Dataset

# Ваші дані
data = {
    'text': [
        "This product is amazing!",
        "Terrible quality, waste of money",
        "Good value for the price",
        # ... більше прикладів
    ],
    'label': [1, 0, 1, ...]  # 1 = positive, 0 = negative
}

# Створюємо Dataset
dataset = Dataset.from_dict(data)
dataset = dataset.train_test_split(test_size=0.2)

# Токенізація
tokenized = dataset.map(tokenize_function, batched=True)

# Fine-tuning (як вище)
trainer = Trainer(model=model, train_dataset=tokenized['train'], ...)
trainer.train()
```

:::accordion-item{title="Завдання 3: Attention Visualization (★★☆)"}

Візуалізуйте attention weights з BERT для речення.

**Розв'язок**:

```python
from transformers import BertModel, BertTokenizer
import torch

model = BertModel.from_pretrained('bert-base-uncased', output_attentions=True)
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

text = "The cat sat on the mat"
inputs = tokenizer(text, return_tensors='pt')

with torch.no_grad():
    outputs = model(**inputs)
    attentions = outputs.attentions  # Tuple of (num_layers, )

# Візуалізуємо останній шар, перша голова
last_layer_attn = attentions[-1][0, 0].numpy()  # (seq_len, seq_len)
tokens = tokenizer.convert_ids_to_tokens(inputs['input_ids'][0])

import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(8, 8))
im = ax.imshow(last_layer_attn, cmap='YlOrRd')
ax.set_xticks(range(len(tokens)))
ax.set_xticklabels(tokens, rotation=90)
ax.set_yticks(range(len(tokens)))
ax.set_yticklabels(tokens)
ax.set_title('BERT Attention (Layer 12, Head 1)')
plt.colorbar(im, ax=ax)
plt.tight_layout()
plt.savefig('bert_attention.png', dpi=150)
plt.show()
```
