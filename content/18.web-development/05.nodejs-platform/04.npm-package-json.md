# npm та package.json

## Короткий зміст

- Що таке npm (Node Package Manager)
- Ініціалізація проєкту: npm init
- Структура package.json: name, version, description, main, scripts
- dependencies vs devDependencies vs peerDependencies
- Встановлення пакетів: npm install, npm i -D
- Глобальне vs локальне встановлення
- package-lock.json: фіксація версій залежностей
- Семантичне версіонування (semver): MAJOR.MINOR.PATCH
- Оператори версій: ^, ~, >=, *
- npm scripts: автоматизація задач (start, test, build)
- npx: запуск виконуваних файлів без глобального встановлення
- Альтернативи npm: yarn, pnpm
- node_modules: структура та проблеми (розмір, дублікати)
