# Вбудовані модулі: os, url, crypto, util

## Короткий зміст

- **Модуль os:** системна інформація
  - os.platform(), os.arch(), os.cpus()
  - os.totalmem(), os.freemem()
  - os.homedir(), os.tmpdir()
  - os.hostname(), os.uptime()
- **Модуль url:** парсинг та маніпуляції з URL
  - new URL() — сучасний API
  - url.parse() — застарілий API
  - URLSearchParams для query-параметрів
  - url.format() — створення URL зі частин
- **Модуль crypto:** хешування та шифрування
  - crypto.createHash() — MD5, SHA256
  - crypto.randomBytes() — випадкові байти
  - crypto.pbkdf2() — хешування паролів
  - Приклад: хешування пароля з bcrypt (npm пакет)
- **Модуль util:** допоміжні функції
  - util.promisify() — перетворення callbacks у promises
  - util.inspect() — форматування об'єктів
  - util.types — перевірка типів даних
