# Змінні середовища та конфігурація

## Короткий зміст

- Що таке змінні середовища (environment variables)
- Навіщо потрібні (конфігурація без зміни коду)
- process.env — доступ до змінних
- Встановлення змінних у різних ОС (Windows vs Unix)
- Передача змінних при запуску: NODE_ENV=production node app.js
- Файл .env для зберігання секретів
- Пакет dotenv: завантаження .env у process.env
- .env.example — шаблон для команди
- .gitignore — не комітити .env!
- NODE_ENV: development, production, test
- Різна конфігурація для різних середовищ
- Best practices: не хардкодити секрети, використовувати валідацію
- Приклади: DATABASE_URL, API_KEY, PORT
