# Налагодження та інструменти розробки

## Короткий зміст

- Вбудований debugger Node.js: node inspect
- Точки зупинки (breakpoints): debugger;
- VS Code Debugger: launch.json, автозавершення
- Налагодження через Chrome DevTools: node --inspect
- console.log vs debugger (коли що використовувати)
- nodemon — автоматичний перезапуск при зміні файлів
- Встановлення: npm i -D nodemon
- Конфігурація через nodemon.json
- ts-node — запуск TypeScript без компіляції
- tsx — сучасна альтернатива ts-node (швидша)
- nvm (Node Version Manager) — управління версіями Node.js
- fnm — швидка альтернатива nvm
- Перемикання між версіями для різних проєктів
- .nvmrc файл для фіксації версії проєкту
