# Продуктивність та Best Practices

## Короткий зміст

- Профілювання коду: node --prof
- Аналіз flame graphs для пошуку вузьких місць
- Модуль perf_hooks для вимірювання продуктивності
- Кластеризація: модуль cluster
- Запуск декількох інстансів на всіх CPU-ядрах
- PM2 — менеджер процесів (кластери, автоперезапуск)
- Кешування: in-memory (Map, Redis)
- Compression — стиснення HTTP-відповідей
- Connection pooling для БД
- Уникнення синхронного коду (readFileSync у продакшені)
- Не блокувати Event Loop (важкі обчислення у Worker)
- Логування: структуроване (pino, winston)
- Моніторинг: health checks, метрики
- Поширені помилки та як їх уникати
