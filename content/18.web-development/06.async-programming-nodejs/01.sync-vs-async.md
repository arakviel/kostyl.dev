# Синхронний vs асинхронний код

## Короткий зміст

- Що таке синхронний код (послідовне виконання)
- Проблема блокування потоку (Event Loop)
- Що таке асинхронний код (неблокуючий)
- Приклади: fs.readFileSync() vs fs.readFile()
- Наслідки для продуктивності (тисячі запитів)
- Чому JavaScript ідеальний для асинхронності
- Візуалізація: як працює блокуючий vs неблокуючий код
- Коли можна використовувати синхронний код (startup scripts)
- Коли потрібен асинхронний код (сервери, API)
- Приклад: HTTP-сервер з синхронними операціями (антипаттерн)
