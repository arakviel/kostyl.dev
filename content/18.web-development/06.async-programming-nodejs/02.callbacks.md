# Callbacks — перша парадигма асинхронності

## Короткий зміст

- Що таке callback-функція
- Error-First Callback pattern: (err, data) => {}
- Чому перший параметр — помилка (конвенція Node.js)
- Приклад: fs.readFile() з callback
- Вкладені callbacks (nested callbacks)
- Callback Hell (Pyramid of Doom) — антипаттерн
- Проблеми callbacks: читабельність, обробка помилок
- Втрата контролю над потоком виконання
- Проблема "забутого return" після callback
- Чому від callbacks перейшли до Promises
- Історичний контекст: Node.js до 2015 року
