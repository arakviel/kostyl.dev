# Promises — стандарт асинхронності

## Короткий зміст

- Що таке Promise (обіцянка результату)
- Три стани: pending, fulfilled, rejected
- Створення Promise: new Promise((resolve, reject) => {})
- Ланцюжки (chaining): .then(), .catch(), .finally()
- Передача значення між .then()
- Обробка помилок: .catch() ловить усі помилки у ланцюжку
- .finally() — виконується завжди (cleanup)
- Порівняння з callbacks: плоска структура vs піраміда
- Приклад: читання файлу через fs.promises
- Перетворення callback API в Promise (util.promisify)
- Promise завжди асинхронний (навіть якщо resolve одразу)
- Помилки: забути return у .then()
