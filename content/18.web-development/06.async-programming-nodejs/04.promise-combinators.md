# Promise комбінатори

## Короткий зміст

- Навіщо потрібні комбінатори (паралельні операції)
- **Promise.all([p1, p2, p3]):**
  - Чекає завершення всіх promises
  - Повертає масив результатів
  - Відхиляється при першій помилці
  - Use case: завантаження декількох ресурсів
- **Promise.allSettled([p1, p2, p3]):**
  - Чекає завершення всіх (успіх або помилка)
  - Повертає статус кожного: {status, value/reason}
  - Ніколи не відхиляється
  - Use case: логування результатів незалежних операцій
- **Promise.race([p1, p2, p3]):**
  - Повертає результат першого завершеного
  - Use case: timeout для запиту
- **Promise.any([p1, p2, p3]):**
  - Повертає результат першого успішного
  - Відхиляється, якщо всі відхилені
  - Use case: запит до декількох серверів
- Практичні приклади для кожного
