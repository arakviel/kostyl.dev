# Async/Await — синтаксичний цукор над Promises

## Короткий зміст

- Що таке async/await (ES2017)
- async function — функція, що повертає Promise
- await — чекає завершення Promise (лише всередині async)
- Синхронний вигляд асинхронного коду
- Обробка помилок: try/catch замість .catch()
- await можна використовувати тільки в async функціях
- Top-level await (ES2022) — await поза функціями (у модулях)
- Порівняння: .then() vs async/await (читабельність)
- Помилка: забути await (Promise не виконається)
- Помилка: не обгорнути в try/catch (необроблена помилка)
- Повернення значення з async функції (автоматичний Promise)
- Async/await під капотом — це Promises
