# Паралельне vs послідовне виконання

## Короткий зміст

- Послідовне виконання (sequential):
  - await op1; await op2; await op3;
  - Кожна операція чекає попередню
  - Use case: залежні операції (result1 → result2)
- Паралельне виконання (parallel):
  - Promise.all([op1, op2, op3])
  - Всі операції стартують одночасно
  - Use case: незалежні операції (API запити)
- Порівняння продуктивності: 3 запити по 1с
  - Послідовно: 3 секунди
  - Паралельно: 1 секунда
- Помилка: await у циклі (sequential замість parallel)
- Рішення: Promise.all(array.map(async item => {}))
- Контрольована паралельність (concurrency limit)
- Приклад: завантаження користувачів та їх постів
- Коли використовувати послідовне, коли паралельне
