# EventEmitter — подієва модель Node.js

## Короткий зміст

- Патерн Observer (Спостерігач)
- Що таке EventEmitter (клас для роботи з подіями)
- Імпорт: require('events') або import { EventEmitter }
- Створення власного emitter: class MyEmitter extends EventEmitter
- Методи:
  - .on(event, listener) — підписка на подію
  - .once(event, listener) — підписка на одну подію
  - .emit(event, ...args) — виклик події
  - .off(event, listener) — відписка
  - .removeAllListeners(event) — видалити всі слухачі
- Передача даних через emit
- Обробка помилки: подія 'error' (обов'язково!)
- Приклад: власний Logger з подіями
- EventEmitter у Node.js: Stream, HTTP Server, Child Process
- Різниця EventEmitter vs Promises (багаторазові події vs одноразовий результат)
