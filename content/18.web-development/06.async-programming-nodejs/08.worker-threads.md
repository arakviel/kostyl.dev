# Worker Threads — багатопотоковість у Node.js

## Короткий зміст

- Проблема: CPU-інтенсивні задачі блокують Event Loop
- Рішення: винесення обчислень у окремі потоки
- Модуль worker_threads (з'явився у Node.js 12)
- Worker vs Child Process (відмінності)
- Створення Worker: new Worker(filename)
- Передача даних: postMessage() та on('message')
- Передача SharedArrayBuffer для спільної пам'яті
- workerData — початкові дані для worker
- parentPort — комунікація з головним потоком
- isMainThread — перевірка, чи це головний потік
- Приклад: обчислення чисел Фібоначчі у worker
- Thread Pool у libuv (для файлових операцій)
- Коли використовувати: обробка зображень, криптографія, обчислення
- Обмеження: накладні витрати на створення потоків
