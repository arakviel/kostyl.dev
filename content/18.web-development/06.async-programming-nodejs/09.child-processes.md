# Child Processes — запуск зовнішніх процесів

## Короткий зміст

- Модуль child_process для запуску інших програм
- Методи: exec(), execSync(), spawn(), fork()
- exec() — запуск shell-команд, отримання виводу
- execSync() — синхронна версія (блокує)
- spawn() — запуск процесу зі streaming виводом
- Відмінності exec vs spawn (буферизація vs потоки)
- fork() — створення дочірніх Node.js процесів
- Комунікація через process.send() та process.on('message')
- Приклад: запуск Python-скрипта з Node.js
- Приклад: паралельна обробка даних через fork()
- Обробка помилок (exit codes, stderr)
- Коли використовувати: виклик системних утиліт, мікросервіси
- Різниця Worker Threads vs Child Processes
