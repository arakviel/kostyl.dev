# Обробка помилок у асинхронному коді

## Короткий зміст

- Типи помилок: синхронні vs асинхронні
- try/catch для синхронного коду
- try/catch для async/await
- Error-First Callback pattern (err, data)
- Promise rejection: .catch() vs try/catch
- Глобальні обробники помилок:
  - process.on('uncaughtException') — необроблені синхронні помилки
  - process.on('unhandledRejection') — необроблені Promise rejection
- Чому не можна ігнорувати ці події
- Graceful Shutdown: коректне завершення процесу
- Обробка SIGTERM, SIGINT (Ctrl+C)
- Закриття з'єднань (БД, сервер) перед завершенням
- Створення власних класів помилок
- Stack trace та налагодження
- Best practices: логувати помилки, перезапускати процес
