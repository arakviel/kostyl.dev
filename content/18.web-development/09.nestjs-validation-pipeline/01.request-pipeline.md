# Request Pipeline: конвеєр обробки запитів

## Короткий зміст

- Що таке Request Pipeline у NestJS
- Етапи обробки HTTP-запиту від прийняття до відповіді
- Послідовність виконання: Middleware → Guards → Interceptors (before) → Pipes → Handler → Interceptors (after) → Exception Filters
- Діаграма повного циклу обробки запиту
- Точки втручання на кожному етапі
- Як компоненти передають управління далі по ланцюгу
- Припинення обробки: викидання виключень
- Трансформація даних на різних етапах
- ExecutionContext: контекст виконання на кожному етапі
- Розуміння pipeline для проєктування архітектури
