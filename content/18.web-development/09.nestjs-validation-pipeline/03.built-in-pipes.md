# Вбудовані pipes: ParseIntPipe, ParseBoolPipe, ParseUUIDPipe

## Короткий зміст

- ParseIntPipe: перетворення рядка у число (integer)
- ParseFloatPipe: перетворення рядка у число з плаваючою комою
- ParseBoolPipe: перетворення рядка у boolean
- ParseArrayPipe: перетворення рядка у масив
- ParseUUIDPipe: валідація UUID-формату
- ParseEnumPipe: валідація значення з enum
- DefaultValuePipe: встановлення значення за замовчуванням
- Використання pipes на рівні параметра: @Param('id', ParseIntPipe)
- Налаштування pipes: передача опцій конфігурації
- Обробка помилок: автоматичне повернення 400 Bad Request
