# Декоратори class-validator для DTO

## Короткий зміст

- Базові декоратори: @IsString(), @IsNumber(), @IsBoolean()
- Email та URL: @IsEmail(), @IsUrl()
- Діапазони: @Min(value), @Max(value), @Length(min, max)
- Масиви: @IsArray(), @ArrayMinSize(), @ArrayMaxSize()
- Вкладені об'єкти: @ValidateNested(), @Type()
- Опціональні поля: @IsOptional()
- Умовна валідація: @ValidateIf(condition)
- Enum-валідація: @IsEnum(enumType)
- Дата та час: @IsDate(), @MinDate(), @MaxDate()
- Кастомні повідомлення помилок через параметр `message`
