# Створення власних Pipes

## Короткий зміст

- Створення класу з інтерфейсом PipeTransform
- Декоратор @Injectable() для pipes
- Метод transform(value, metadata): логіка обробки
- ArgumentMetadata: інформація про параметр (type, metatype, data)
- Приклад: TrimPipe для видалення пробілів
- Приклад: ParseSlugPipe для нормалізації slug
- Приклад: SanitizePipe для очищення HTML
- Викидання BadRequestException при помилці
- Використання pipes: @UsePipes(CustomPipe)
- Передача опцій конфігурації у pipe через конструктор
