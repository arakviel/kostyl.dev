# Middleware: проміжні обробники запитів

## Короткий зміст

- Що таке Middleware у NestJS
- Виконання перед маршрутизацією до контролера
- Функціональний middleware: (req, res, next) => void
- Класовий middleware: інтерфейс NestMiddleware
- Метод use(req, res, next): логіка обробки
- Виклик next() для передачі управління наступному middleware
- Реєстрація middleware у модулі: клас реалізує NestModule
- Метод configure(consumer): налаштування маршрутів
- Застосування до конкретних маршрутів: apply(), forRoutes()
- Виключення маршрутів: exclude()
