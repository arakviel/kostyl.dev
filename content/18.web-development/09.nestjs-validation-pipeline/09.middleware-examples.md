# Практичні приклади Middleware

## Короткий зміст

- LoggerMiddleware: логування деталей запиту (метод, URL, IP)
- TimingMiddleware: вимірювання часу обробки запиту
- AuthenticationMiddleware: перевірка токена перед контролером
- CorsMiddleware: налаштування CORS headers
- CompressionMiddleware: стиснення відповідей (gzip)
- BodyParserMiddleware: парсинг JSON/URL-encoded тіла
- RateLimitMiddleware: обмеження частоти запитів
- RequestIdMiddleware: генерація унікального ID для кожного запиту
- Глобальний middleware: app.use() у main.ts
- Порівняння з Express middleware: сумісність екосистеми
