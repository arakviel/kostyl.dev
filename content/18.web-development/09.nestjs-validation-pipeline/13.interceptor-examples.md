# Практичні приклади Interceptors

## Короткий зміст

- LoggingInterceptor: логування часу виконання запиту
- TransformInterceptor: обгортання відповіді у стандартний формат
- TimeoutInterceptor: встановлення timeout для запиту
- CacheInterceptor: кешування відповідей
- ErrorsInterceptor: обробка та трансформація помилок
- FilesInterceptor: обробка завантаження файлів
- SerializeInterceptor: виключення полів з відповіді
- RxJS оператори: map, tap, catchError, timeout
- Приклад: обгортання всіх відповідей у { data, timestamp, status }
- Best practices: композиція кількох interceptors
