# Exception Filters: обробка виключень

## Короткий зміст

- Що таке Exception Filter
- Вбудовані виключення: HttpException та його підкласи
- NotFoundException, BadRequestException, UnauthorizedException
- ForbiddenException, InternalServerErrorException
- Створення кастомних виключень: extends HttpException
- Інтерфейс ExceptionFilter: метод catch()
- ArgumentsHost: доступ до контексту виконання
- Формування стандартизованого JSON-відповіді помилки
- Декоратор @Catch(ExceptionClass)
- Глобальні exception filters: app.useGlobalFilters()
