# ExecutionContext та ArgumentsHost

## Короткий зміст

- Що таке ExecutionContext
- Наслідування від ArgumentsHost
- Методи ArgumentsHost: getArgs(), getArgByIndex(), switchToHttp()
- switchToHttp(): доступ до request, response, next
- switchToRpc(): доступ до RPC контексту
- switchToWs(): доступ до WebSocket контексту
- Методи ExecutionContext: getClass(), getHandler()
- Використання у Guards, Interceptors, Exception Filters
- Витягування метаданих через getClass() та getHandler()
- Мультипротокольна підтримка: HTTP, WebSocket, Microservices
