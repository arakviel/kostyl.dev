# Глобальне застосування компонентів Pipeline

## Короткий зміст

- app.useGlobalPipes(): глобальне підключення pipes
- app.useGlobalGuards(): глобальне підключення guards
- app.useGlobalInterceptors(): глобальне підключення interceptors
- app.useGlobalFilters(): глобальне підключення exception filters
- Реєстрація у main.ts vs модулі (APP_PIPE, APP_GUARD)
- Глобальні компоненти через providers: інтеграція з DI
- Порядок виконання: глобальні → контролерні → метод-специфічні
- Переваги глобальних компонентів: централізація логіки
- Недоліки: складність виключення для окремих маршрутів
- Best practices: використання для інфраструктурних компонентів
