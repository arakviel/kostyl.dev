### Частина 2: Основні типи schedulers (~165 рядків)
1. **StepLR** — зменшення кожні N епох
   - Математика, приклад, візуалізація
   - Переваги/недоліки
   
2. **MultiStepLR** — зменшення у конкретні епохи
   - Гнучкість milestones
   
3. **ExponentialLR** — експоненціальне зменшення
   - Плавна крива, складність підбору gamma
   
4. **CosineAnnealingLR** — косинусоїдальне зменшення
   - Математика косинусного decay
   - Чому косинусоїда оптимальна
   - Популярність у сучасних архітектурах
   
5. **ReduceLROnPlateau** — адаптивне зменшення
   - Реагування на plateau у val_loss
   - Симуляція реалістичної кривої loss
   - Візуалізація моментів зміни LR

**Візуалізація:** Порівняння всіх 5 schedulers на одному графіку

### Частина 3: Advanced техніки (~150 рядків)

**Learning Rate Warm-up:**
- Проблема нестабільних градієнтів на початку
- PlantUML діаграма 3 фаз навчання (warm-up → main → decay)
- Математика лінійного warm-up
- Реалізація WarmupCosineScheduler з нуля
- Візуалізація warm-up фази
- Коли використовувати (великі batch, глибокі мережі, transfer learning)

**SGDR (Warm Restarts):**
- Ідея періодичних restart для escape з локальних мінімумів
- Метафора кулі у долині
- Математика CosineAnnealingWarmRestarts
- Візуалізація з періодами, що подвоюються
- Snapshot ensembling
- Переваги для змагань

**OneCycleLR:**
- Super-convergence (Leslie Smith, 2018)
- Один великий цикл: збільшення → зменшення
- Параметри: max_lr, pct_start, div_factor
- Візуалізація циклу
- Найшвидша конвергенція

### Частина 4: Експеримент та практика (~150 рядків)

## 💡 Практичні висновки

### Універсальний рецепт для CNN:
```python
# Optimizer
optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9, 
                     weight_decay=5e-4, nesterov=True)

# Scheduler
scheduler = WarmupCosineScheduler(optimizer, warmup_epochs=5, 
                                 total_epochs=100, eta_min=1e-6)
```

### Коли використовувати що:
- **Перший експеримент:** ReduceLROnPlateau (адаптивний)
- **Фінальне тренування:** CosineAnnealing або Warm-up + Cosine
- **Великий batch (>256):** Обов'язковий Warm-up
- **Змагання (Kaggle):** SGDR або OneCycleLR
- **Transfer Learning:** Малий фіксований LR (1e-4)
