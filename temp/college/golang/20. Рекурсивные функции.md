## Рекурсивные функции

Последнее обновление: 11.06.2025

Рекурсивная функция представляет такую функцию, которая вызывает саму себя. Рекурсивные функции представляют мощный инструмент для обработки рекурсивных структур данных, например, различных деревьев.

Здесь функция sum получает некоторое число и вычисляет сумму чисел от 0 до этого числа. Полученный результат возвращается из функции.

Вначале идет условие, что если число равно 0, то функция возвращает значение этого числа - то есть 1:

|1
|---|
2
3|`if` `n == 1{`
    `return` `n`
`}`|

Иначе функция возвращает сумму числа n и результата этой же функции для числа n-1.

|1|`return` `n + sum(n - 1)`|
|---|---|

При создании рекурсивной функции в ней обязательно должен быть некоторый базовый вариант, который использует оператор return и помещается в начале функции. В случае с функцией вычисления суммы это `if x == 1 {return n}`.

И, кроме того, все рекурсивные вызовы должны обращаться к подфункциям, которые в конце концов сходятся к базовому варианту. Так, при передаче в функцию положительного числа при дальнейших рекурсивных вызовах подфункций в них будет передаваться каждый раз число, меньшее на единицу. И в конце концов мы дойдем до ситуации, когда число будет равно 1, и будет использован базовый вариант.

Например, вызов `sum(4)` фактически можно расписать следующим образом:

-   sum(4)
    
-   4 \* sum(3)
    
-   4 \* 3 \* sum(2)
    
-   4 \* 3 \* 2 \* sum(1)
    
-   4 \* 3 \* 2 \* 1
    

Стоит отметить, что хотя мы можем написать подобное вычисление сумму чисел, но обычно более производительным решением вместо рекурсивных функций являются циклы.

17|`package` `main`
`import` `"fmt"`
`func` `factorial(n` `uint``)` `uint``{`
    `if` `n == 0{`
        `return` `1`
    `}`
    `return` `n * factorial(n - 1)`
`}`
`func` `main() {`
    `fmt.Println(factorial(4))`  
    `fmt.Println(factorial(5))`  
    `fmt.Println(factorial(6))`  
`}`|

Здесь функция factorial получает некоторое положительное число, для которого надо вычислить факториал. Полученный результат возвращается из функции. Вначале идет условие, что если число равно 0, то функция возвращает 1. Это есть базовый вариант функции:

|1|`if` `x == 0 {``return` `1}`|
|---|---|

Иначе функция возвращает произведение числа n на результат этой же функции для числа n-1.

Например, вызов `factorial(4)` фактически можно расписать следующим образом:

-   factorial(4)
    
-   4 \* factorial(3)
    
-   4 \* 3 \* factorial(2)
    
-   4 \* 3 \* 2 \* factorial(1)
    
-   4 \* 3 \* 2 \* 1 \* factorial(0)
    
-   4 \* 3 \* 2 \* 1 \* 1
