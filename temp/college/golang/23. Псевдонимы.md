## Производные типы

## Псевдонимы

Последнее обновление: 17.02.2024

Оператор type позволяет определять для некоторого типа псевдоним. Псевдоним не представляет новый тип, а лишь определяет новое название для уже существующего типа. Например:

|1|`type` `mile` `uint`|
|---|---|

В данном случае для типа uint определяется псевдоним mile, который основывается на типе uint. По сути mile представляет тип uint и работа с ним будет производиться также, как и с типом uint. Однако в то же время фактически это новый тип.

Мы можем определять переменные данного типа, работать с ними как с объектами базового типа uint:

    `fmt.Println(``"расстояние для противника:"``)`

    `distanceToEnemy(distance)`

Здесь определены два псевдонима: mile и kilometer, которые по сути представляют тип uint и которые предназначены для выражения расстояния в милях и километрах соответственно. И также определена функция `distanceToEnemy()`, которая отображает расстояние в милях до условного противника. В качестве параметра принимает значение mile - именно значение типа mile, а не типа uint. Это позволит нам уменьшить вероятность передачи некорректных данных. То есть передаваемые данные должны быть явным образом определены в программе как значение типа mile, а не типа uint или типа kilometer.

Также псевдонимы позволяют придать типу некоторый дополнительный смысл. Так, использование в коде типа "kilometer" или "mile" позволит указать на предназначение переменной или параметра и будет более описательным, чем просто тип `uint`.

Еще одна ситуация, где можно применять псевдонимы - это сокращение названия типов в том случае, если они слишком длинные или громоздкие. Например, рассмотрим следующий пример:

`func` `action(n1` `int``, n2` `int``, op` `func``(``int``,` `int``)` `int``){`
    `result := op(n1, n2)`
    `fmt.Println(result)`

Здесь определена функция action, которая принимает два числа и некоторую другую функцию с типом `func(int, int) int` - то есть функцию, которая принимает два числа и также возвращает число. В функции main определяется переменная myOperation, которая как раз представляет функцию типа `func(int, int) int`, получает ссылку на функцию add и передается в вызов `action(10, 25, myOperation)`

Теперь тип функции `func(int, int) int` проецируется на псевдоним BinaryOp, который представляет бинарную операцию над двумя операндами:

|1|`type` `BinaryOp` `func``(``int``,` `int``)` `int`|
|---|---|

Такой псевдоним короче оригинального определения типа и в то же время является более описательным (по крайней мере для меня). Соответственно далее его можно использовать для указания типа параметра:

|1|`func` `action(n1` `int``, n2` `int``, op BinaryOp){ ... }`|
|---|---|

или переменной:

|1|`var` `myOperation BinaryOp = add`|
|---|---|
