## Структуры как поля других структур

Последнее обновление: 20.06.2025

Язык Go позволяет определять поля структур как значения других структур. В этом случае мы имеем дело с вложенными и встроенными структурами:

-   Вложенные структуры (nested struct) определяются как именованные поля внутри другой структуры, и доступ к их полям осуществляется с использованием имени поля внешней структуры.
    
-   Встроенные структуры (embedded struct) определяются без имени поля, что продвигает их поля во внешнюю структуру для прямого доступа. Встроенные структуры предлагают более чистый синтаксис, но могут вызывать конфликты имен.

### Хранения ссылки на структуру того же типа

При этом надо учитывать, что структура не может иметь поле, которое представляет тип этой же структуры. Например:

|1
|---|
2
3
4|`type` `node` `struct``{`
    `value` `int`
    `next node`
`}`|

Подобное определение будет неправильным. Вместо этого поле должно представлять указатель на структуру:

31|`package` `main`
`import` `"fmt"`
`type` `node` `struct``{`
    `value` `int`
    `next *node`
`}`
`func` `printNodeValue(n *node){`
    `fmt.Println(n.value)`
    `if` `n.next != nil{`
        `printNodeValue(n.next)`
    `}`
`}`
`func` `main() {`
    `first := node{value: 4}`
    `second := node{value: 5}`
    `third := node{value: 6}`
    `first.next = &second`
    `second.next = &third`
    `var` `current *node = &first`
    `for` `current != nil{`
        `fmt.Println(current.value)`
        `current = current.next`
    `}`
`}`|

Здесь определена структура node, которая представляет типичный узел односвязного списка. Она хранит значение в поле value и ссылку на следующий узел через указатель next.

В функции main создаются три связанных структуры, и с помощью цикла for и вспомогательного указателя current выводятся их значения.
