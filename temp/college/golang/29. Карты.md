## Карты

Последнее обновление: 22.06.2025

Карта или map (также называемые хеш-таблицами и словарями) представляет ссылку на хеш-таблицу - структуру данных, где каждый элемент представляет пару "ключ-значение". При этом каждый элемент имеет уникальный ключ, по которому можно получить значение элемента. Посредством ключа мы можем управлять элементом карты - добавлять, удалять или изменять его.

### Определение карты

Карта определяется как объект типа map\[K\]V, где К представляет тип ключа, а V - тип значения. Причем тип ключа K должен поддерживать операцию сравнения ==, чтобы оображение могло сопоставить значение с одним из ключей и хеш-таблицы.

Например, определение карты, которое в качестве ключей имеет тип string, а в качестве значений - тип int:

|1|`var` `people` `map``[``string``]``int`|
|---|---|

Go также поддерживает вывод карты на консоль:

|1
|---|
2
3
4
5
6
7
8|`package` `main`
`import` `"fmt"`
`func` `main() {`
    `var` `people` `map``[``string``]``int`
    `fmt.Println(people)` 
`}`|

### Инициализация карты

После объявления карты ее значение по умолчанию равно **nil**. Чтение из такой карты возвращает пустой результат (`map[]`), поскольку она не содержит ключей, но попытка записи в такую карту вызывает ошибку времени выполнения. Подобно срезам, карты являются ссылочными типами, и их необходимо инициализировать перед использованием.

Присваиваемое карте значение представляет выражение типа `map[string]int {}`, где внутри фигурных скобок через запятую перечисляются элементы хеш-таблицы в формате:

|1
|---|
2
3
4
5
6|`map``[тип_ключей]тип_значений{`
    `ключ_элемента_1: значение_элемента_1,`
    `ключ_элемента_2: значение_элемента_2,`
    `.................................`
    `ключ_элемента_N: значение_элемента_N,`
`}`|

Например, создание пустой карты:

|1
|---|
2

`}`|

Также можно сразу передать значения карты:

|1

Как и в массиве или в срезе элементы помещаютя в фигурные скобки. Каждый элемент представляет пару ключ -значение. Вначале идет ключ и через двоеточие значение. Определение элемента завершается запятой.

Стоит отметить, что ключи чувствительны к регистру, поэтому мы можем хранить ключи с одинаковыми именами, но с разными регистрами, если это необходимо:

### Проверка наличия ключа

Для проверки наличия элемента по определенному ключу можно применять выражение **if**:

|1|`i, ok := map_name[key_name]`|
|---|---|

Это выражение проверяет наличие ключа key\_name в карте map\_name. Если ключ существует, то `ok` будет содержать `true`, а значение найденного ключа присваивается переменной `i`. Если ключ не существует, `ok` будет содержать `tfalse`, а переменной `i` присваивается значение по умолчанию. Пример применения:

|1
|---|
2
3
4
5
6
7
8
9|`var` `people =` `map``[``string``]``int``{`
    `"Tom"``: 1,`
    `"Bob"``: 2,`
    `"Sam"``: 4,`
    `"Alice"``: 8,`
`}`
`if` `val, ok := people[``"Tom"``]; ok{`
    `fmt.Println(val)`
`}`|

Если значение по заданному ключу имеется в карте, то переменная ok будет равна true, а переменная val будет хранить полученное значение. Если переменная ok равна false, то значения по ключу в карте нет.

Для перебора элементов применяется цикл for:

|1
|---|
2
3
4
5
6
7
8
9|`people :=` `map``[``string``]``int``{`
    `"Tom"``: 1,`
    `"Bob"``: 2,`
    `"Sam"``: 4,`
    `"Alice"``: 8,`
`}`
`for` `key, value :=` `range` `people{`
    `fmt.Println(key, value)`
`}`|

Консольный вывод программы:

```

Bob 2
Sam 4
Alice 8
```

### Создание карты с помощью функции make

Функция make представляет альтернативный вариант создания карты. Она создает пустую хеш-таблицу:

|1|`var` `people = make(``map``[``string``]``int``)`|
|---|---|

Или сокращенное определение без указания типа

|1|`people := make(``map``[``string``]``int``)`|
|---|---|

### Добавление и удаление элементов

Для добавления элементов достаточно просто выполнить установку значения по новому ключу и элемент с этим ключом будет добавлен в коллекцию:

|1
|---|
2
3|`people :=` `map``[``string``]``int``{` `"Tom"``: 1,` `"Bob"``: 2}`
`people[``"Kate"``] = 128`
`fmt.Println(people)`|

Для удаления применяется встроенная функция delete(map, key), первым параметром которой является карта, а вторым - ключ, по которому надо удалить элемент.

|1
|---|
2
3|`var` `people =` `map``[``string``]``int``{` `"Tom"``: 1,` `"Bob"``: 2,` `"Sam"``: 8}`
`delete(people,` `"Bob"``)`
`fmt.Println(people)`|

### Сравнение карт

Для сравнения двух карт по элементам Go предоставляет функцию **DeepEqual** в пакете `reflect`. Она возвращает `true`, если обе карты имеют одинаковые ключи и одинаковые связанные значения ключей, в противном случае возвращается `false`:

|1

14|`package` `main`
`import` `(`
    `"fmt"`
    `"reflect"`
`)`
`func` `main() {`
    `people1 :=` `map``[``string``]``int``{` `"Tom"``: 1,` `"Bob"``: 2,` `"Sam"``: 3}`
    `people2 :=` `map``[``string``]``int``{` `"Tom"``: 1,` `"Bob"``: 2,` `"Sam"``: 3}`
    `people3 :=` `map``[``string``]``int``{` `"Tom"``: 1,` `"Bob"``: 2,` `"Sam"``: 4}`
    `fmt.Println(``"people1 == people2:"``, reflect.DeepEqual(people1, people2))`    
    `fmt.Println(``"people1 == people3:"``, reflect.DeepEqual(people1, people3))`    
`}`|
