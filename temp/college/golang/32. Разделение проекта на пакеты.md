## Разделение проекта на пакеты

Последнее обновление: 15.06.2025

Для упрощения структуры и разработки проекта мы можем разделить функционал проекта на несколько файлов, которые располагаются в разных пакетах. Но стоит учитывать, что в Go в последних версиях (начиная с 1.16), если мы хотим разделить проект на несколько пакетов, то предпочтительным подходом является определение пакетов в рамках модуля. То есть нам надо сначала определить модуль, и в рамках этого модуля определяются пакеты.

Посмотрим на примере. Сначала определим папку, где будет располагаться наш модуль. Пусть, к примеру это будет папка hello. Перейдем в терминале/командной строке к этой папке. Допустим, наш модуль будет называться также, как и папка - hello. Для его создания выполним команду `go mod init hello`:

```
eugene@Eugene:/workspace/go$ cd hello
eugene@Eugene:/workspace/go/hello$ go mod init hello
go: creating new go.mod: module hello
eugene@Eugene:/workspace/go/hello$ 
```

После выполнения этой команды в папке появится файл go.mod

Теперь добавим в наш проект новый пакет. Пусть наш пакет будет называться "messages", и для него определим в папке проекта одноименный подкаталог messages. Далее в этом подкаталоге messages создадим новый файл, который назовем messages\_en.go (название файлов произвольные) и который будет иметь следующий код:

|1
|---|
2

11|`package` `messages`
`import` `"fmt"`
`func` `Hello_en() {`
    `fmt.Println(``"Hello"``)`

`func` `Bye_en() {`
    `fmt.Println(``"Good Bye"``)`

Итак, код этого файла определен в пакете "messages" (о чем свидетельствует в начале файла инструкция `package messages`). Для примера здесь определены две простейшие функции, которые выводят на консоль некоторые сообщения.

Стоит отметить, что, чтобы функции пакета можно было использовать в других пакетах, название этих функций должно начинаться с заглавной буквы. Если, к примеру, вместо функции `Hello_en` мы определим функцию `hello_en`, то другие пакеты ее не увидят.

Теперь используем функции пакета messages и для этого в корневой папке проекта определим главный файл приложения - main.go со следующим кодом:

|1
|---|
2
3
4
5
6
7
8|`package` `main`
`import` `"hello/messages"`
`func` `main() {`
    `messages.Hello_en()`
    `messages.Bye_en()`
`}`|

Прежде всего для подключения пакета messages применяется выражение импорта по шаблону

|1|`import` `"[путь_к_модулю]/[путь_к_пакету]"`|
|---|---|

В качестве путь к модулю здесь выступает его название - "hello", а название пакета - "messages":

|1|`import` `"hello/messages"`|
|---|---|

Затем, как и в случае с пакетами стандартной библиотеки, мы можем обращаться к функциям пакета, используя его название:

|1|`messages.Hello_en()`|
|---|---|

В итоге наш проект (модуль hello) будет иметь следующую структуру каталогов и файлов:

-   Файл go.mod (ранее автосгенерированный файл модуля)
    
-   Файл main.go: главный файл проекта, в котором определен пакет main
    
-   Папка messages: папка для пакета "messages"
    
    -   Файл messages\_en.go: файл с кодом пакетв messages
        

Запустим проект и увидим результат работы фукций пакета messages:

```
eugene@Eugene:/workspace/go/hello$ go run .
Hello
Good Bye
eugene@Eugene:/workspace/go/hello$
```

### Вложенные пакеты

В языке Go мы можем создать пакет внутри пакета. Например, выше мы определили пакет "messages", в котором есть два файла: messages\_en.go (для сообщений на английском языке) и messages\_ru.go (для сообщений на руском языке). Поместим каждый из этих файлов во вложенные пакеты и для этого изменим структуру проекта на следующую:

-   Файл go.mod (ранее автосгенерированный файл модуля)
    
-   Файл main.go: главный файл проекта, в котором определен пакет main
    
-   Папка messages: папка для пакета "messages"
    
    -   Папка messages\_en: папка для вложенного пакета "messages\_en"
        
        -   Файл messages\_en.go: файл с кодом вложенного пакета "messages\_en"
            
    -   Папка messages\_ru: папка для вложенного пакета "messages\_ru"
        
        -   Файл messages\_ru.go: файл с кодом вложенного пакета "messages\_ru"
