## Создание разделяемого модуля

Последнее обновление: 15.06.2025

Возможно на каком-то этапе развития проекта мы захотим выделять некоторый функционал в отдельный модуль, которые можно повторно использовать в других проектах. То есть создать разделяемый модуль. Посмотрим, как это сделать. И прежде всего определим общую папку для наших проектов, допустим, она будет называться projects (проект модуля и проект, который использует этот модуль, не обязательно должны располагаться в одной папке. В данном случае это сделано для упрощения)

### Создание библиотеки

Создадим в каталоге projects для нашего модуля новую папку, которую назовем, к примеру, **messageslib**. Затем перейдем в эту папку в консоли и инициализируем модуль:

```
go mod init metanit.com/messages
```

В данном случае модуль будет называться "metanit.com/messages".

Далее в этой папке определим файл messages.go, который будет представлять код модуля и будет иметь следующий код:

|1
|---|
2
3
4
5
6
7
8|`package` `messages`
`import` `"fmt"`
`func` `Hello() {`
    `fmt.Println(``"Hello METANIT.COM"``)`
`}`|

Здесь для примера определена функция для вывода сообщения на консоль. Причем, чтобы функция была видна всем пакетам, ее название начинается с заглавной буквы.

### Создание основной программы

Затем создадим основной проект, где будет использоваться наш выше определенный модуль. Для этого на уровнь выше создадим новую папку, которую назовем, к примеру, **helloapp**. Затем перейдем в эту папку в консоли и инициализируем модуль:

```
go mod init helloapp
```

В данном случае модуль будет называться, как и папка, "helloapp". И в этом проекте определим новый файл main.go:

|1
|---|
2
3
4
5
6
7|`package` `main`
`import` `"metanit.com/messages"`
`func` `main() {`
    `messages.Hello()`
`}`|

### Связь модулей

Итак, у нас должна получиться следующая структура проектов:

-   Папка projects (общая папка для проектов)
    
    -   Папка messageslib (папка разделяемого модуля)
        
        -   Файл messages.go (код разделяемого модуля)
            
    -   Папка projects/helloapp (папка основного проекта)
        
        -   Файл main.go (код основного проекта, где применяется разделяемый модуль)
            

Теперь нам надо связать оба модуля с помощью выражения replace. Для этого в каталоге основного проекта - helloapp выполним следующую команду:

|1|`go` `mod edit -replace=``"metanit.com/messages=../messageslib"`|
|---|---|

Эта команда сообщаетт Go, по какому локальному пути найти код для пакета `metanit.com/messages`. То есть папка "messageslib" расположена в соседней папке на уровень выше по отношению к каталогу модуля helloapp. Поэтому применяется "../", который заменяет папку "projects".

После этого файл `helloapp/go.mod` будет выглядеть так:

|1
|---|
2
3
4
5|`module helloapp`
`go` `1.24.4`
`replace metanit.com/messages => ../messageslib`|

Затем для синхронизации зависимостей в проекте helloapp выполним команду go mod tidy

```
eugene@Eugene:/projects/helloapp$ go mod tidy
go: found metanit.com/messages in metanit.com/messages v0.0.0-00010101000000-000000000000
eugene@Eugene:/projects/helloapp$
```

Теперь мы можем запустить наш файл **main.go** из каталога **helloapp**, и он будет использовать код из нашего локального модуля `metanit.com/messages` из папки **messageslib**.

```
eugene@Eugene:/projects/helloapp$ go run .
Hello METANIT.COM
eugene@Eugene:/projects/helloapp$ 
```
