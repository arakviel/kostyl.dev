# Go | Синхронизация горутин и

> ## Excerpt
> Совместное выполнение групп горутин и их синхронизация с помощью WaitGroup в языке программирования Go

---
Последнее обновление: 22.06.2025

Для упрощения синхронизации между горутинами в Go имеется пакет sync, который предоставляет ряд возможностей, в частности, структуру sync.WaitGroup. Этот тип позволяет определить группу горутин, которые должны выполняться вместе как одна группа. И можно установить блокировку, которая приостановит выполнение функции, пока не завершит выполнение вся группа горутин.

**WaitGroup** — это структура, которая содержит счетчик количества горутин, завершения которых нам нужно дождаться. Он используется для ожидания завершения всех горутин. Для отслеживания всех горутин, которые вызываются в программе, **WaitGroup** предоставляет ряд методов:

-   **Add**: сообщает, сколько горутин нужно дождаться.
    
-   **Done**: вызывается при завершении горутины, чтобы указать, что ее выполнение завершено.
    
-   **Wait**: используется основной горутиной, пока счетчик не станет равным нулю. Когда все горутины завершаются и счетчик становится равным нулю, функция `Wait()` возвращается и продолжает дальнейшее выполнение.

Вначале определяем группу в виде переменной `wg sync.WaitGroup`. С помощью метода Add определяем, что группа будет состоять из двух элементов:

|1|`wg.Add(2)`|
|---|---|

Число, которое передается в метод Add определяет значение внутреннего счетчика активных элементов.

Все элементы группы wg будут представлять анонимную функцию в виде переменной work, которая в качестве параметра принимает условный числовой идентификатор горутины. Эта функция будет вызываться в виде горутин. Чтобы сигнализировать, что элемент группы завершил свое выполнение, в горутине в конце необходимо вызвать метод `Done()`:

|1|`wg.Done()`|
|---|---|

Вызов метода wg.Done() уменьшает внутренний счетчик активных элементов на единицу.

В самой функции `work()` с помощью задержки времени на две секунды (`time.Sleep(2 * time.Second)`) имитируется работа горутины

Далее вызываем две горутины:

|1
|---|
2|`go` `work(1)`
`go` `work(2)`|

Причем количество горутин, которые вызывают метод `wg.Done()` должно соответствовать количеству элементов группы wg, то есть в данном случае 2 элемента.

Затем вызывается метод `Wait()`, который ожидает завершения всех горутин из группы wg:

|1|`wg.Wait()`|
|---|---|

Метод деблокирует функцию main, когда внутренний счетчик активных элементов в группе wg стает равен 0. Поэтому когда все горутины из группы wg завершат выполнение, функция main продолжит свою работу.

Результат работы программы:

```
Горутина 1 начала выполнение
Горутина 2 начала выполнение
Горутина 1 завершила выполнение
Горутина 2 завершила выполнение
Горутины завершили выполнение
```

Отмечу, что в примере выше горутина запускала анонимную функцию, что немного упрощает задачу. Тем не менее мы могли бы также вынести все действия горутины во внешнюю функцию, только в этом случае нам надо было бы передавать в нее указатель на `sync.WaitGroup`:

`"sync"`
`"time"`
`)`
`func` `work(id` `int``, wg *sync.WaitGroup ) {`
    `fmt.Printf(``"Горутина %d начала выполнение \n"``, id)`
    `time.Sleep(2 * time.Second)` 
    `fmt.Printf(``"Горутина %d завершила выполнение \n"``, id)`
    `wg.Done()` 
`}` 
`func` `main() {`
    `var` `wg sync.WaitGroup`
    `wg.Add(2)`      
   `go` `work(1, &wg)`
   `go` `work(2, &wg)`
   `wg.Wait()`       
   `fmt.Println(``"Горутины завершили выполнение"``)`
`}`|
