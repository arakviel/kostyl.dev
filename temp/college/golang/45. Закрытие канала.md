## Закрытие канала

Последнее обновление: 22.06.2025

Она запускается 2 раза, соответственно мы ждем, что send\_value отправит через канал 2 значения. Однако в send\_value мы отправляет только одно число и потом закрываем канал:

После закрытия канала мы не сможем послать в него новые данные. Если мы попробуем это сделать, то получим ошибку. Однако мы можем получить ранее добавленные данные. Но при попытке получить данные из канала, которых нет, мы получим значение по умолчанию. Например, в примере выше в канал добавляется одно число и потом канал щзакрывается. При попытке получить в функции get\_value второе значение, которого нет в канале, мы получим значение по умолчанию - число 0. Консольный вывод программы:

```
10
0
```

Чтобы не столкнуться с проблемой, когда канал уже закрыт, мы можем проверять состояние канала. В частности, из канала мы можем получить два значения:

|1|`val, opened:= <-intCh`|
|---|---|

Первое значение - val - это собственно данные из канала, а opened представляет логическое значение, которое равно `true`, если канал открыт и мы можем успешно считать из него данные. Если же канал закрыт, то opend будет равен `false`, а val будет содержать значение по умолчанию. Например, мы можем проверять с помощью условной конструкции состояние канала:

Теперь в функции get\_value при получении данных из канала мы используем выражение `value, ok := <- intCh`. Далее мы можем проверить значение переменной ok и узнать, закрыт канал или нет и стоит ли получать данные из канала. Консольный вывод программы:

```
Получено число: 10
Канал закрыт
```
