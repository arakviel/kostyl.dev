## Двухнаправленные и однонаправленные каналы

Последнее обновление: 23.06.2025

По умолчанию через канал в Go мы можем как отправлять, так и получать данные. Подобный канал определяется как значение `chan тип_данных`. Например, двунаправленный канал для передачи значений типа `int`, определяется как значение типа

|1|`chan` `int`|
|---|---|

а для его создания применяется функция `make`

|1|`intCh := make(``chan` `int``)`|
|---|---|

Например:

`func` `double_value(intCh` `chan` `int``){`
    `num := <-intCh`
    `intCh <- (num + num)` 
`}`
`func` `main() {`
    `intCh := make(``chan` `int``)`
    `go` `double_value(intCh)`
    `intCh <- 22` 
    `num := <-intCh`
    `fmt.Println(num)`
`}`|

Здесь горутина функции main и горутина double\_value обмениваются данными друг с другом. Функция main получаем в double\_value число, double\_value увеличивает полученное число в два раза и результат отправляет в main. Таким образом, обе стороны канала могут как отправлять, так и посылать данные.

Однако в языке Go также можно определить канал, как доступный только для отправки данных или только для чтения данных.

-   Определение канала только для отправки данных:
    
    |1|`var` `inCh` `chan` `<-` `int`|
    |---|---|
    
-   Определение канала только для чтения данных:
    
    |1|`var` `outCh <-` `chan` `int`|
    |---|---|
    

Для создания однонаправленных каналов также изменяется вызов функции make, где стрелка указывает на тип канала:

-   Создание канала только для отправки данных:
    
    |1|`make(``chan` `<-` `int``)`|
    |---|---|
    
-   Создание канала только для чтения данных:
    
    |1|`make(<-` `chan` `int``)`|
    |---|---|
    

Стоит отметить, что канал можно создать как двухнаправленный, но в рамках конкретных функций использовать его как однонаправленный - только для чтения или только для записи. Рассмотрим на примерах.

`func` `send_value(sendCh` `chan` `<-` `int``){`
    `sendCh <- 22` 
`}`
`func` `main() {`
    `send_ch := make(``chan` `int``)`
    `go` `send_value(send_ch)`
    `fmt.Println(<-send_ch)`
`}`|

Здесь параметр функции send\_value определен как канал, доступный только для отправки данных: `ch chan <- int`:

|1|`func` `send_value(sendCh` `chan` `<-` `int``){`|
|---|---|

Соответственно внутри функции send\_value мы можем только отправлять данные в канал, но не получать их.

В функции main создаем двунаправленный канал, запускаем в качестве горутины функцию `send_value` и получаем из канала отправленное число

|1
|---|
2
3|`send_ch := make(``chan` `int``)`
`go` `send_value(send_ch)`
`fmt.Println(<-send_ch)`|

Причем здесь канал создается как двухнаправленный, но внутри функции send\_value он используется исключительно как доступный только для чтения.

Теоретически мы могли бы создать канал только для записи, но это не имело бы смысла, так как если канал был бы доступен только для записи, то мы не смогли бы получить из него данные. В итоге мы попали бы в состояние блокировки.

|---|---|

Соответственно в этой функции мы можем только считывать данные из канала, но не отправлять их.

В функции main создаем двунаправленный канал, запускаем в качестве горутины функцию `get_value` и отправляем в канал число 123

`var` `wg sync.WaitGroup`
`func` `get_value(getCh <-` `chan` `int``){`
    `fmt.Println(<-getCh)`
    `wg.Done()`
`}`
`func` `main() {`
    `get_ch := make(<-``chan` `int``)`
    `wg.Add(1)`  
    `go` `get_value(get_ch)`
    `wg.Wait()`  
`}`|

Чтобы функция main не завершилась ранее горутину, здесь применяем инструмент синхронизации `sync.WaitGroup`. Однако поскольку канал доступен только для чтения, и никто в него ничего не отправляет и не может ничего отправить, то здесь сталкиваемся в блокировкой горутины. В итоге она никогда не завершится. Поэтому при запуске Go укажет нам на этот нюанс.
