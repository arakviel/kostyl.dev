## Синхронизация с помощью каналов

Последнее обновление: 23.06.2025

Использование каналов открывает нам возможности по синхронизации между различными горутинами. Например, одна горутина производит некоторое действие, результат которой используется в другой горутине. В этом плане мы можем использовать каналы для синхронизации. Например, одна горутина вычисляет квадрат числа, а результат выводится в другой горутине:

`import` `"fmt"`
`func` `main() {`
   `intCh := make(``chan` `int``)`
   `go` `square(5, intCh)`
   `fmt.Println(<-intCh)` 
`}`
`func` `square(n` `int``, ch` `chan` `int``){`
    `fmt.Println(``"Вычисляем квадрат числа"``, n)`
    `result := n * n`
    `ch <- result` 
`}`|

Канал не обязательно должен нести данные, которые представляют некоторый результат, от которого зависит дальнейшее выполнение горутины. Иногда это может быть холостой объект, например, пустая структура, которая необходима только для синхронизации горутин:

`import` `"fmt"`
`func` `main() {`
   `results := make(``map``[``int``]``int``)`
   `structCh := make(``chan` `struct``{})`
   `go` `square(5, structCh, results)`
   `<-structCh`       
   `for` `i, v :=` `range` `results{`
    `fmt.Println(i,` `" - "``, v)`
   `}`
`}`
`func` `square(n` `int``, ch` `chan` `struct``{}, results` `map``[``int``]``int``){`
    `for` `i:=1; i <= n; i++{`
        `results[i] = i * i`
    `}`
    `close(ch)`    
`}`|

В данном случае функция square по-прежнему вычисляет квадрат числа, но помещает все квадраты чисел от 1 до n в отображение results, где ключи представляют числа, а значения - квадраты чисел.

Канал, через который горутины взаимодействуют, представляет тип `chan struct{}`. Причем функция square не отправляе конкретные данные в канал, а просто закрывает его после выполнения всех своих инструкций с помощью вызова `close(ch)`. После закрытия канала в функции main получает соответствующий сигнал в строке `<-structCh`, и после этого функция main продолжает свою работу.
