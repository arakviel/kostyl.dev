# Go | Каналы и конструкция select

> ## Excerpt
> Каналы и конструкция select в языке программирования Go, получение результатов канала с помощью операторов case

---
Последнее обновление: 23.06.2025

Ключевое слово **select** в Go используется для ожидания нескольких операций канала одновременно. Оператор **select** похож на `switch`, который работает с несколькими выражениями `case`. В операторе **select** операторы `case` применяются к операциям отправки/получения данных канала. **Select** выбирает определенный оператор `case` для выполнения операции.

Синтаксис оператора `select` такой же, как у оператора `switch`, за исключением оператора `case`. Здесь оператор `case` определяет операцию канала.

Здесь у нас есть две горутины, square и cube. Мы вызываем обе, передавая в канал из основной горутины два числа. Оператор `select` имеет дваблока `case`. В первом случае мы получаем значение из канала sqr\_ch, которое отправляется горутиной square. Во втором случае мы получаем значение из канала cube\_ch, которое отправляется горутиной cube. Та горутина, которая первой отправит данные, будет обрабатываться в соответствующем блоке case. Например, если первой завершила выполнение горутина square, то выполняется блок `case sqr_val`.

Если в операторе **select** нет операторов `case`, которые могут выполнить операцию, то это приведет к взаимоблокировке. Чтобы избежать блокировки, конструкция **select** может иметь оператор `default` для обработки операций, которые не охвачены блоками case:

В данном случае добавлен запуск еще одной горутины - double, которая увеличает полученное число в два раза. Чтобы гарантировать, что эта горутина будет выполнена первой, для остальных горутин установлена задержка в 1 секунду. Однако для обработки получения данных из горутины double в конструкции select нет соответствующего блока case, поэтому этот случай будет обрабатываться блоком `default`

```

Cube: 125
Square: 9
```
