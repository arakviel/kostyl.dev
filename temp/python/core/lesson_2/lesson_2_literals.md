# Літерали в Python

**Lesson 2: Literals & Data Types**

*Дані, які говорять самі за себе*

---

## Що таке літерал?

**Літерал** — це дані, значення яких визначаються самим літералом

```python
print("2")    # "2" - рядковий літерал
print(2)      # 2 - числовий літерал
```

**Питання:** Що таке `123`?
- ✅ Це літерал — значення очевидне: сто двадцять три

**Питання:** Що таке `c`?
- ❓ Швидкість світла? Константа? Змінна? Незрозуміло!

---

## Літерал vs Змінна

```python
# Літерали - значення зрозумілі самі собою
123                 # ціле число
3.14               # число з крапкою
"Hello"            # рядок
True               # булеве значення

# Змінні - потрібен контекст
x                  # що це?
name               # що всередині?
result             # який результат?
```

**Літерал = самоочевидне значення**

## Типи літералів у Python

Python підтримує кілька типів літералів:

| Тип | Приклад | Опис |
|-----|---------|------|
| **int** | `123`, `-5`, `0` | Цілі числа |
| **float** | `3.14`, `-0.5`, `2.0` | Числа з крапкою |
| **str** | `"Hello"`, `'World'` | Рядки |
| **bool** | `True`, `False` | Логічні значення |
| **None** | `None` | Відсутність значення |

## Цілі числа (Integers)

Числа без дробової частини

```python
# Звичайні цілі числа
print(123)          # 123
print(-456)         # -456
print(0)            # 0

# З знаком плюс (необов'язково)
print(+123)         # 123
```

**Діапазон:** У Python 3 цілі числа мають **необмежений** розмір!
(обмежено лише доступною пам'яттю)

## Підкреслення в числах (Python 3.6+)

Для читабельності великих чисел можна використовувати `_`

```python
# Без підкреслень (важко читати)
population = 7900000000

# З підкресленнями (легко читати)
population = 7_900_000_000

# Python ігнорує підкреслення
million = 1_000_000
print(million)      # 1000000
```

**Правило:** `_` можна ставити між цифрами, але не на початку/кінці

---

## Підкреслення: Приклади

```python
# ✅ Правильно
x = 1_000_000
y = 100_000_000
z = 1_2_3_4_5       # технічно OK, але не рекомендовано

# ❌ Неправильно
x = _1000           # SyntaxError
y = 1000_           # SyntaxError
z = 1__000          # SyntaxError (подвійне підкреслення)
```

**Порада:** Групуйте по 3 цифри для зручності

## Системи числення

Python підтримує різні системи числення:

| Система | Основа | Префікс | Цифри | Приклад |
|---------|--------|---------|-------|---------|
| Десяткова | 10 | (немає) | 0-9 | `123` |
| Двійкова | 2 | `0b` / `0B` | 0-1 | `0b1010` |
| Вісімкова | 8 | `0o` / `0O` | 0-7 | `0o123` |
| Шістнадцяткова | 16 | `0x` / `0X` | 0-9, A-F | `0x1A3` |

---

## Вісімкові числа (Octal)

Система числення з основою 8 (цифри 0-7)

```python
# Вісімкове число
octal = 0o123
print(octal)        # 83 (в десятковій)

# Як обчислити: 1×8² + 2×8¹ + 3×8⁰ = 64 + 16 + 3 = 83

# Інші приклади
print(0o10)         # 8
print(0o77)         # 63
print(0o100)        # 64
```

**Префікс:** `0o` або `0O` (нуль-о)

---

## Шістнадцяткові числа (Hexadecimal)

Система числення з основою 16 (цифри 0-9, A-F)

```python
# Шістнадцяткове число
hex_num = 0x123
print(hex_num)      # 291 (в десятковій)

# Як обчислити: 1×16² + 2×16¹ + 3×16⁰ = 256 + 32 + 3 = 291

# Літери A-F (регістр не важливий)
print(0xFF)         # 255
print(0xff)         # 255
print(0xABCD)       # 43981
```

**Префікс:** `0x` або `0X` (нуль-ікс)

---

## Двійкові числа (Binary)

Система числення з основою 2 (цифри 0-1)

```python
# Двійкове число
binary = 0b1010
print(binary)       # 10 (в десятковій)

# Як обчислити: 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 8 + 0 + 2 + 0 = 10

# Інші приклади
print(0b1111)       # 15
print(0b10000000)   # 128
print(0b11111111)   # 255
```

**Префікс:** `0b` або `0B` (нуль-бі)

---

## Конверсія між системами

Python має вбудовані функції для конверсії:

```python
number = 42

# Конверсія з десяткової
print(bin(number))      # '0b101010' (двійкова)
print(oct(number))      # '0o52' (вісімкова)
print(hex(number))      # '0x2a' (шістнадцяткова)

# Конверсія в десяткову
print(int('0b101010', 2))    # 42
print(int('0o52', 8))        # 42
print(int('0x2a', 16))       # 42
```

## Числа з рухомою крапкою (Floats)

Числа, які мають (або можуть мати) дробову частину


**Важливо:** Крапка (`.`), а не кома (`,`)!

## Float vs Int

```python
# Різні типи
x = 4               # int
y = 4.0             # float

print(x)            # 4
print(y)            # 4.0
print(type(x))      # <class 'int'>
print(type(y))      # <class 'float'>

# Вони не рівні за типом, але рівні за значенням
print(x == y)       # True
print(type(x) == type(y))  # False
```

## Експоненційний запис

Для дуже великих або малих чисел

```python
# Швидкість світла: 300 000 000 м/с
speed_of_light = 3e8        # 3 × 10⁸
print(speed_of_light)       # 300000000.0

# Постійна Планка: 0.000000000000000000000000000000000662607
planck = 6.62607e-34        # 6.62607 × 10⁻³⁴
print(planck)               # 6.62607e-34
```

**Формат:** `аЕb` означає `а × 10^b`

## Обмеження точності Float

⚠️ **Важливо:** Float має обмежену точність!

```python
# Проблема точності
print(0.1 + 0.2)    # 0.30000000000000004 (!?)
print(0.1 + 0.2 == 0.3)  # False (!?)

# Чому? Внутрішнє представлення у двійковій системі
# 0.1 не може бути точно представлене у двійковій системі

# Рішення: округлення
result = round(0.1 + 0.2, 2)
print(result)       # 0.3
```

## Екранування символів

Зворотна коса риска `\` — спеціальний символ екранування

| Послідовність | Значення | Опис |
|---------------|----------|------|
| `\'` | `'` | Апостроф |
| `\"` | `"` | Лапки |
| `\\` | `\` | Зворотна коса риска |
| `\n` | Новий рядок | Перехід на новий рядок |
| `\t` | Табуляція | Горизонтальна табуляція |
| `\r` | Повернення каретки | Повернення на початок рядка |

## Сирі рядки (Raw Strings)

Префікс `r` відключає екранування:

```python
regex = r"\d+\.\d+"
```

## Boolean у виразах

```python

# Boolean в умовах
is_adult = True
```

## Boolean як числа

У Python `True` = `1`, `False` = `0`

```python
# Boolean в арифметиці

print(True * 5)         # 5
print(False + 10)       # 10

# Порівняння
print(True == 1)        # True
print(False == 0)       # True
print(True > False)     # True

# Чому? Історична причина: bool успадковується від int
print(isinstance(True, int))  # True
```

## None - спеціальне значення

`None` означає "відсутність значення"

```python
# None - окремий тип
x = None
print(type(x))          # <class 'NoneType'>

# Використання
def no_return():
    pass

result = no_return()
print(result)           # None

# Перевірка на None
if result is None:
    print("No value")
```

**Важливо:** Використовуйте `is None`, а не `== None`

## None vs False vs 0 vs ""

Всі "хибні", але різні:

```python
# Різні типи
print(type(None))       # <class 'NoneType'>
print(type(False))      # <class 'bool'>
print(type(0))          # <class 'int'>
print(type(""))         # <class 'str'>

# Всі хибні в логічному контексті
print(bool(None))       # False
print(bool(False))      # False
print(bool(0))          # False
print(bool(""))         # False

# Але не рівні між собою
print(None == False)    # False
print(0 == False)       # True (!)
```

## Цікаві факти

🐍 Python 3 має **необмежені** int (обмежені лише пам'яттю)

💾 Float у Python — це 64-бітні числа (double precision IEEE 754)

🔢 Hex популярна у веб (кольори: `#FF5733`) та низькорівневому програмуванні

📊 Для фінансових розрахунків використовуйте `decimal.Decimal`, а не float

🚀 Наукова нотація `e` походить від "exponent" (показник степеня)

⚠️ `0.1 + 0.2 != 0.3` — класична проблема float у всіх мовах!

## Корисні функції

```python
# Перевірка типу
print(type(42))                 # <class 'int'>
print(isinstance(42, int))      # True

# Конверсія систем числення
print(bin(42))                  # '0b101010'
print(oct(42))                  # '0o52'
print(hex(42))                  # '0x2a'

# Конверсія з систем числення
print(int('0b101010', 2))       # 42
print(int('52', 8))             # 42
print(int('2a', 16))            # 42
```

---

## Розширені можливості

```python
# f-strings з форматуванням (Python 3.6+)
x = 42
print(f"{x:b}")         # 101010 (двійкова)
print(f"{x:o}")         # 52 (вісімкова)
print(f"{x:x}")         # 2a (hex малі літери)
print(f"{x:X}")         # 2A (hex великі літери)

# Форматування float
pi = 3.14159265359
print(f"{pi:.2f}")      # 3.14 (2 знаки після коми)
print(f"{pi:.5f}")      # 3.14159 (5 знаків)
print(f"{pi:10.2f}")    # '      3.14' (ширина 10)
```
