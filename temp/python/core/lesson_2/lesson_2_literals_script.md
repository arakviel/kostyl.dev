## Слайд 2: Що таке літерал?

**Текст:**
Почнемо з визначення. **Літерал** — це дані, значення яких визначаються самим літералом. Звучить заплутано? Давайте розберемо на прикладі.

Коли ви бачите `123`, ви одразу розумієте — це число сто двадцять три. Вам не потрібна додаткова інформація. Це і є літерал — самоочевидне значення.

Але коли ви бачите `c`, що це? Це може бути змінна, яка містить будь-яке значення. Це може бути швидкість світла (константа в фізиці), або постійна інтегрування в математиці, або довжина гіпотенузи в геометрії. Без контексту ми не знаємо, що таке `c`. Тому `c` — це НЕ літерал.

**Ключова відмінність:**
- **Літерал:** `123` — ви одразу знаєте, що це число 123
- **Змінна:** `x` — ви не знаєте значення без додаткової інформації

Давайте подивимося на код:
```python
print("2")    # "2" - це рядковий літерал
print(2)      # 2 - це числовий літерал
```

Обидва виводять `2`, але перший — це рядок (текст), а другий — число. Python розрізняє їх за наявністю лапок. Внутрішньо вони зберігаються зовсім по-різному в пам'яті комп'ютера, але функція `print()` виводить їх у зрозумілій для людини формі.

## Слайд 3: Літерал vs Змінна

**Текст:**
Давайте чітко розмежуємо два поняття: літерали та змінні.

**Літерали** — це конкретні значення, записані безпосередньо в коді:
- `123` — очевидно, що це число 123
- `3.14` — очевидно, що це число "пі" (приблизно)
- `"Hello"` — очевидно, що це текст "Hello"
- `True` — очевидно, що це логічна істина

**Змінні** — це імена, які вказують на значення:
- `x` — що це? Невідомо без контексту
- `name` — що всередині? Потрібно подивитися на попередній код
- `result` — який результат? Залежить від обчислень

**Важливий момент:** Літерали — це частина синтаксису мови. Python має чіткі правила, як їх записувати. Якщо ви порушите ці правила, код не запуститься.

Наприклад:
- `123` — правильний літерал
- `1 2 3` — неправильно (пробіли заборонені)
- `"Hello` — неправильно (не закриті лапки)

**Аналогія:** Літерали — це як числа і слова у математиці або природній мові. Ви не можете змінити значення числа "5" — воно завжди означає п'ять. Але змінна `x` може мати будь-яке значення.

## Слайд 4: Типи літералів у Python

**Текст:**
Python підтримує п'ять основних типів літералів. Давайте познайомимося з ними.

**1. Integer (int) — Цілі числа:**
Приклади: `123`, `-5`, `0`, `1000000`
Використання: Лічильники, індекси, цілі кількості
Особливість: У Python 3 має **необмежений розмір**!

**2. Float — Числа з рухомою крапкою:**
Приклади: `3.14`, `-0.5`, `2.0`, `1e-3`
Використання: Вимірювання, наукові розрахунки, фінанси
Застереження: Обмежена точність (побачимо пізніше)

**3. String (str) — Рядки:**
Приклади: `"Hello"`, `'World'`, `"""Multi\nline"""`
Використання: Текст, повідомлення, імена
Особливість: Незмінні (immutable)

**4. Boolean (bool) — Логічні значення:**
Приклади: `True`, `False`
Використання: Умови, прапорці, логіка
Цікавий факт: `True == 1` і `False == 0`

**5. NoneType — Відсутність значення:**
Приклад: `None`
Використання: Ініціалізація, повернення "нічого" з функцій
Особливість: Єдине значення свого типу

**Важливо:** Тип літерала визначається його формою — як він записаний у коді. Python автоматично розпізнає тип за синтаксисом.

## Слайд 5: Цілі числа (Integers)

**Текст:**
Почнемо з найпростішого типу літералів — цілих чисел.

**Що таке цілі числа:**
Це числа без дробової частини — `..., -2, -1, 0, 1, 2, ...`

**Як записувати:**
```python
print(123)          # Додатне
print(-456)         # Від'ємне
print(0)            # Нуль
print(+123)         # Знак + необов'язковий
```

Всі ці записи валідні. Знак плюс можна опустити для додатних чисел, але іноді його додають для наголосу.

**Унікальна особливість Python 3:**
На відміну від багатьох інших мов (C, Java, JavaScript), цілі числа в Python 3 мають **необмежений розмір**! Обмеження лише у доступній пам'яті.

```python
# У Python це працює:
huge = 123456789012345678901234567890
print(huge)

# В інших мовах таке число викликало б переповнення
```

**Історична довідка:**
У Python 2 були два типи: `int` (32 або 64 біти) і `long` (необмежений). У Python 3 вони об'єднані в один тип `int`.

**Практичне застосування:**
- Лічильники циклів: `for i in range(100)`
- Індекси масивів: `array[5]`
- Кількості: `students = 30`
- Коди помилок: `error_code = 404`

**Що НЕ можна робити:**
```python
# ❌ Пробіли всередині числа
x = 1 000 000  # SyntaxError

# ❌ Кома як роздільник
x = 1,000,000  # Це не число, це кортеж!
```

## Слайд 6: Підкреслення в числах (Python 3.6+)

**Текст:**
Однією з проблем у програмуванні є читабельність великих чисел. Подивіться на це число: `7900000000`. Скільки тут нулів? Важко порахувати, правда?

Python 3.6 вирішив цю проблему, дозволивши використовувати підкреслення `_` як візуальний роздільник.

**Приклади:**
```python
# Важко читати
population = 7900000000

# Легко читати
population = 7_900_000_000

# Python ігнорує підкреслення при обчисленнях
print(population)  # 7900000000 (без підкреслень)
```

**Правила використання підкреслень:**
1. ✅ Між цифрами: `1_000_000`
2. ❌ На початку: `_1000` (це буде змінна, а не літерал)
3. ❌ В кінці: `1000_` (SyntaxError)
4. ❌ Подвійне підкреслення: `1__000` (SyntaxError)
5. ❌ Після префікса: `0x_FF` (SyntaxError)

**Рекомендації стилю:**
- Для десяткових: групуйте по 3 цифри (як у реальному світі)
  ```python
  million = 1_000_000
  billion = 1_000_000_000
  ```

- Для двійкових: групуйте по 4 або 8 біт
  ```python
  byte = 0b1111_1111      # 8 біт
  word = 0b1111_1111_1111_1111  # 16 біт
  ```

- Для hex: групуйте по 2 або 4 символи
  ```python
  color = 0xFF_5A_33      # RGB кольор
  address = 0xDEAD_BEEF   # Адреса пам'яті
  ```

**Цікавий факт:**
Ця можливість запозичена з інших мов (Java, C++, Rust), де вона вже існувала. Python завжди запозичує кращі практики!

## Слайд 7: Системи числення

**Текст:**
Python підтримує чотири системи числення. Це може здатися складним, але насправді дуже корисно в певних ситуаціях.

**Чому різні системи числення?**
- **Десяткова (10)** — природна для людей (10 пальців!)
- **Двійкова (2)** — природна для комп'ютерів (біти: 0 або 1)
- **Вісімкова (8)** — компактніша за двійкову, історично популярна
- **Шістнадцяткова (16)** — дуже компактна, популярна в програмуванні

**Таблиця еквівалентності:**
```
Десяткова | Двійкова | Вісімкова | Hex
    0     |    0     |     0     |  0
    1     |    1     |     1     |  1
    2     |   10     |     2     |  2
    3     |   11     |     3     |  3
    4     |  100     |     4     |  4
    5     |  101     |     5     |  5
    6     |  110     |     6     |  6
    7     |  111     |     7     |  7
    8     | 1000     |    10     |  8
    9     | 1001     |    11     |  9
   10     | 1010     |    12     |  A
   15     | 1111     |    17     |  F
   16     | 10000    |    20     | 10
  255     | 11111111 |   377     | FF
```

**Як Python розрізняє системи:**
За **префіксом** на початку числа:
- Немає префікса → десяткова: `42`
- `0b` або `0B` → двійкова: `0b101010`
- `0o` або `0O` → вісімкова: `0o52`
- `0x` або `0X` → шістнадцяткова: `0x2A`

**Важливо:** Префікс `0o` — це нуль і літера "о" (як "octal"), а не два нулі!

## Слайд 8: Вісімкові числа (Octal)

**Текст:**
Вісімкова система числення має основу 8, тобто використовує цифри від 0 до 7.

**Префікс:** `0o` або `0O` (нуль-о)

**Приклад:**
```python
octal = 0o123
print(octal)  # 83
```

**Як перетворити вісімкове в десяткове:**
`0o123` означає: 1×8² + 2×8¹ + 3×8⁰ = 64 + 16 + 3 = 83

**Практичні приклади:**
```python
print(0o10)   # 8 (1×8 + 0)
print(0o77)   # 63 (7×8 + 7)
print(0o100)  # 64 (1×64 + 0×8 + 0)
print(0o777)  # 511 (максимум для 3 цифр)
```

**Історія:**
Вісімкова система була популярна в ранніх комп'ютерах, особливо тих, що базувалися на 12-бітних або 36-бітних словах (які зручно діляться на групи по 3 біти).

**Де використовується сьогодні:**
1. **Unix/Linux права доступу:**
   ```python
   permissions = 0o755  # rwxr-xr-x
   # 7 (111) = rwx (власник)
   # 5 (101) = r-x (група)
   # 5 (101) = r-x (інші)
   ```

2. **Старі системи:**
   Деякі старі протоколи та формати файлів використовують вісімкові числа.

**Типова помилка:**
```python
x = 0o89  # ❌ SyntaxError: invalid digit '8' in octal literal
```
Цифри 8 і 9 не існують у вісімковій системі!

## Слайд 9: Шістнадцяткові числа (Hexadecimal)

**Текст:**
Шістнадцяткова (hex) система — найпопулярніша після десяткової в програмуванні.

**Основа:** 16  
**Цифри:** 0-9, A-F (де A=10, B=11, C=12, D=13, E=14, F=15)  
**Префікс:** `0x` або `0X`

**Приклад:**
```python
hex_num = 0x123
print(hex_num)  # 291
```

**Як перетворити hex в десяткове:**
`0x123` = 1×16² + 2×16¹ + 3×16⁰ = 256 + 32 + 3 = 291

**Літери A-F:**
```python
print(0xA)     # 10
print(0xF)     # 15
print(0xFF)    # 255 (максимум для 1 байта)
print(0xABCD)  # 43981
```

**Регістр не важливий:**
```python
print(0xFF)    # 255
print(0xff)    # 255
print(0xFf)    # 255 (але не рекомендовано мішати)
```

**Де використовується:**

1. **Кольори у веб:**
   ```python
   red = 0xFF0000      # RGB: (255, 0, 0)
   white = 0xFFFFFF    # RGB: (255, 255, 255)
   black = 0x000000    # RGB: (0, 0, 0)
   ```

2. **Адреси пам'яті:**
   ```python
   address = 0x7FFF5A3C
   ```

3. **Байтові дані:**
   ```python
   byte = 0x5A         # 01011010 у двійковій
   ```

4. **Маски та прапорці:**
   ```python
   READ = 0x04         # 100
   WRITE = 0x02        # 010
   EXECUTE = 0x01      # 001
   ```

**Чому hex популярна:**
- Компактна: `0xFF` vs `0b11111111` (двійкова)
- Легко конвертувати в двійкову: кожна hex-цифра = 4 біти
- Зручно для байтів: 1 байт = 2 hex-цифри (00-FF)

## Слайд 10: Двійкові числа (Binary)

**Текст:**
Двійкова система — це мова комп'ютерів. Все в комп'ютері зберігається як послідовність 0 і 1.

**Основа:** 2  
**Цифри:** 0, 1  
**Префікс:** `0b` або `0B`

**Приклад:**
```python
binary = 0b1010
print(binary)  # 10
```

**Як перетворити двійкове в десяткове:**
`0b1010` = 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 8 + 0 + 2 + 0 = 10

**Візуалізація:**
```
Позиція:  3  2  1  0
Степінь: 2³ 2² 2¹ 2⁰
Вага:     8  4  2  1
Біт:      1  0  1  0
         ─────────────
Сума:     8+ 0+ 2+ 0 = 10
```

**Практичні приклади:**
```python
print(0b0)         # 0
print(0b1)         # 1
print(0b1111)      # 15 (всі біти встановлені)
print(0b10000000)  # 128 (старший біт байта)
print(0b11111111)  # 255 (максимум для 1 байта)
```

**Де використовується:**

1. **Прапорці та маски:**
   ```python
   # Права доступу
   READ = 0b100       # 4
   WRITE = 0b010      # 2
   EXECUTE = 0b001    # 1
   
   # Комбінація прав
   RW = 0b110         # READ | WRITE
   RWX = 0b111        # READ | WRITE | EXECUTE
   ```

2. **Біт-маски:**
   ```python
   # Перевірка окремого біта
   value = 0b10110
   mask = 0b00100
   if value & mask:
       print("Третій біт встановлений")
   ```

3. **Налагодження низького рівня:**
   Коли потрібно побачити точне бінарне представлення

**Підкреслення для читабельності:**
```python
byte = 0b1111_1111           # 1 байт
word = 0b1111_1111_1111_1111 # 2 байти
ipv4 = 0b11000000_10101000_00000001_00000001  # IP: 192.168.1.1
```

## Слайд 11: Конверсія між системами

**Текст:**
Python надає вбудовані функції для конверсії чисел між різними системами числення.

**Функції конверсії з десяткової:**

1. **bin()** — перетворює в двійкову (binary)
2. **oct()** — перетворює в вісімкову (octal)
3. **hex()** — перетворює в шістнадцяткову (hexadecimal)

```python
number = 42

print(bin(number))  # '0b101010'
print(oct(number))  # '0o52'
print(hex(number))  # '0x2a'
```

**Важливо:** Ці функції повертають **рядки**, а не числа!

**Конверсія В десяткову:**
Використовуємо функцію `int()` з другим аргументом — основою системи:

```python
# З двійкової (основа 2)
print(int('101010', 2))      # 42
print(int('0b101010', 2))    # 42 (префікс опціональний)

# З вісімкової (основа 8)
print(int('52', 8))          # 42
print(int('0o52', 8))        # 42

# З шістнадцяткової (основа 16)
print(int('2A', 16))         # 42
print(int('0x2a', 16))       # 42
```

**Практичний приклад — конвертер:**
```python
def convert_number(num, from_base, to_base):
    """Конвертує число з однієї системи в іншу"""
    # Спочатку конвертуємо в десяткову
    decimal = int(str(num), from_base)
    
    # Потім в цільову систему
    if to_base == 2:
        return bin(decimal)
    elif to_base == 8:
        return oct(decimal)
    elif to_base == 16:
        return hex(decimal)
    else:
        return decimal

# Приклад: з двійкової в hex
result = convert_number('1010', 2, 16)
print(result)  # '0xa'
```

**Без префіксів:**
Якщо потрібні числа без префіксів (`0b`, `0o`, `0x`), використовуйте зріз:
```python
print(bin(42)[2:])   # '101010' (без '0b')
print(oct(42)[2:])   # '52' (без '0o')
print(hex(42)[2:])   # '2a' (без '0x')
```

## Слайд 12: Числа з рухомою крапкою (Floats)

**Текст:**
Тепер переходимо до чисел з дробовою частиною — floats (числа з рухомою крапкою).

**Що таке float:**
Число, яке має (або може мати) дробову частину після десяткової крапки.

**Приклади:**
```python
pi = 3.14159
temperature = -0.5
price = 19.99
zero = 0.0
```

**Важливо:** В Python використовується **крапка** (`.`), а не кома (`,`)!

**Можна опустити 0:**
```python
# Перед крапкою
x = .5              # те саме, що 0.5

# Після крапки
y = 4.              # те саме, що 4.0
```

Але для читабельності краще писати повністю: `0.5` і `4.0`.

**Float vs Int — критична різниця:**
```python
x = 4        # int
y = 4.0      # float

print(x)     # 4
print(y)     # 4.0

# Різні типи!
print(type(x))  # <class 'int'>
print(type(y))  # <class 'float'>
```

**Чому це важливо:**
```python
# Ділення int може дати float
print(5 / 2)      # 2.5 (float)
print(5 // 2)     # 2 (int, цілочисельне ділення)

# Операції з float завжди дають float
print(4.0 + 1)    # 5.0 (не 5!)
print(4.0 * 2)    # 8.0 (не 8!)
```

**Внутрішнє представлення:**
Float у Python — це 64-бітні числа з рухомою крапкою подвійної точності (IEEE 754 double).

Структура:
- 1 біт: знак (+ або -)
- 11 біт: експонента (степінь)
- 52 біти: мантиса (цифри)

**Діапазон значень:**
- Мінімальне додатне: приблизно `2.2e-308`
- Максимальне: приблизно `1.8e+308`

```python

```

Python переключається на експоненційний формат приблизно при:

   ```python
   x = 0.0001

   ```

## Слайд 15: Обмеження точності Float

**Текст:**
Це одна з найважливіших тем! Числа з рухомою крапкою мають обмежену точність, що може призвести до несподіваних результатів.

**Класична проблема:**
```python
print(0.1 + 0.2)           # 0.30000000000000004 (!?)
print(0.1 + 0.2 == 0.3)    # False (!?)
```

**Чому так відбувається?**

Комп'ютери зберігають числа у **двійковій системі**. Деякі десяткові дроби не можуть бути точно представлені у двійковій системі.

Аналогія: Спробуйте записати `1/3` в десятковій системі:
- 1/3 = 0.333333... (нескінченний періодичний дріб)

Так само, `0.1` у двійковій системі:
- 0.1₁₀ = 0.0001100110011... (нескінченний періодичний дріб у двійковій)

Комп'ютер зберігає лише перші 53 біти мантиси, тому відбувається округлення.

**Візуалізація проблеми:**
```python
# Що ми пишемо
x = 0.1

# Що насправді зберігається (приблизно)
x ≈ 0.1000000000000000055511151231257827021181583404541015625

# При виведенні Python округлює для читабельності
print(x)  # 0.1
```

**Рішення 1: Округлення**
```python
result = 0.1 + 0.2
print(round(result, 2))      # 0.3
print(round(result, 2) == 0.3)  # True
```

**Рішення 2: math.isclose() (Python 3.5+)**
```python
import math
print(math.isclose(0.1 + 0.2, 0.3))  # True
```

**Рішення 3: decimal модуль (для фінансів)**
```python
from decimal import Decimal

x = Decimal('0.1')
y = Decimal('0.2')
print(x + y)           # 0.3 (точно!)
print(x + y == Decimal('0.3'))  # True
```

**Золоті правила роботи з float:**

1. ❌ Ніколи не порівнюйте float на точну рівність:
   ```python
   # Погано
   if price == 19.99:
       ...
   ```

2. ✅ Використовуйте діапазон (epsilon):
   ```python
   # Добре
   epsilon = 0.0001
   if abs(price - 19.99) < epsilon:
       ...
   ```

3. ✅ Для грошей використовуйте Decimal:
   ```python
   from decimal import Decimal
   price = Decimal('19.99')
   ```

4. ✅ Округлюйте для виведення:
   ```python
   print(f"{price:.2f}")  # 19.99
   ```

**Цікавий факт:**
Ця проблема існує в **усіх** мовах програмування, які використовують IEEE 754 float (C, C++, Java, JavaScript, тощо). Це не баг Python!

```python
text = "I'm happy"
print(text)  # I'm happy
```

```python
text = """I said: "I'm here!" """
```

## Слайд 18: Екранування символів

**Текст:**
Зворотна коса риска `\` — це спеціальний символ у Python, який змінює значення наступного символу. Це називається **екранування** (escaping).

**Основні послідовності екранування:**

| Код | Символ | Опис | Приклад |
|-----|--------|------|---------|
| `\'` | `'` | Апостроф | `'It\'s OK'` |
| `\"` | `"` | Лапки | `"Say \"Hi\""` |
| `\\` | `\` | Зворотна коса риска | `"C:\\Users"` |
| `\n` | Новий рядок | Line feed | `"Line 1\nLine 2"` |
| `\t` | Табуляція | Tab | `"Name:\tJohn"` |
| `\r` | Повернення каретки | Carriage return | `"Text\rNew"` |

**Практичні приклади:**

1. **Новий рядок (`\n`):**
   ```python
   print("First line\nSecond line\nThird line")
   # Результат:
   # First line
   # Second line
   # Third line
   ```

2. **Табуляція (`\t`):**
   ```python
   print("Name:\tAlice")
   print("Age:\t25")
   print("City:\tKyiv")
   # Результат (вирівняно):
   # Name:   Alice
   # Age:    25
   # City:   Kyiv
   ```

3. **Шляхи до файлів (`\\`):**
   ```python
   # Windows шлях
   path = "C:\\Users\\Documents\\file.txt"
   print(path)  # C:\Users\Documents\file.txt
   ```

4. **Комбінування:**
   ```python
   text = "She said:\n\t\"Hello, World!\"\nAnd smiled."
   print(text)
   # Результат:
   # She said:
   #     "Hello, World!"
   # And smiled.
   ```

**Менш поширені послідовності:**

- `\b` — Backspace (стирає попередній символ)
- `\f` — Form feed (сторінка)
- `\v` — Вертикальна табуляція
- `\a` — Звуковий сигнал (beep)
- `\0` — Нульовий символ (null)

**Unicode символи:**
```python
# За кодом (16-біт)
print("\u0048\u0065\u006C\u006C\u006F")  # Hello

# За кодом (32-біт)
print("\U0001F600")  # 😀 (emoji)

# За ім'ям
print("\N{SMILE}")  # ☺
```

**Важливо:** Якщо після `\` іде символ, який не є спеціальною послідовністю, Python залишає `\` як є:
```python
print("\k")  # \k (не спеціальна послідовність)
```

## Слайд 20: Сирі рядки (Raw Strings)

**Текст:**
Іноді екранування стає проблемою, особливо для регулярних виразів або шляхів до файлів. Сирі рядки (raw strings) вирішують цю проблему.

**Префікс `r`:**
Додайте `r` перед рядком, щоб відключити екранування:
```python
# Звичайний рядок
path1 = "C:\\Users\\Documents\\file.txt"

# Сирий рядок (raw string)
path2 = r"C:\Users\Documents\file.txt"

print(path1)  # C:\Users\Documents\file.txt
print(path2)  # C:\Users\Documents\file.txt (той самий результат!)
```

**Переваги:**
- Менше коду
- Легше читати
- Менше помилок

**Використання 1: Шляхи до файлів (Windows)**
```python
# Без raw string (важко читати)
path = "C:\\Program Files\\Python\\python.exe"

# З raw string (зрозуміліше)
path = r"C:\Program Files\Python\python.exe"
```

**Використання 2: Регулярні вирази**
```python
import re

# Без raw string (подвійне екранування!)
pattern = "\\d+\\.\\d+"

# З raw string (набагато простіше)
pattern = r"\d+\.\d+"

# Знайти числа з крапкою (наприклад, 3.14)
text = "Pi is approximately 3.14159"
match = re.search(pattern, text)
print(match.group())  # 3.14159
```

**Важливо:** У raw string `\` ВСЕ ЩЕ має спеціальне значення для самого Python, але всередині рядка він зберігається як є.

**Обмеження:**
Raw string не може закінчуватися на непарну кількість зворотних косих рисок:
```python
# ❌ Помилка
path = r"C:\Users\Documents\"  # SyntaxError

# ✅ Рішення 1: Додати символ
path = r"C:\Users\Documents" + "\\"

# ✅ Рішення 2: Не використовувати raw string
path = "C:\\Users\\Documents\\"
```

**Коли використовувати:**
- ✅ Регулярні вирази (завжди!)
- ✅ Windows шляхи (зручно)
- ✅ LaTeX формули
- ❌ Звичайний текст (немає необхідності)

## Слайд 22-23: Булеві значення (Boolean)

**Текст:**
Булеві (логічні) значення — це тип даних для представлення істинності: правда або хибність.

**Два значення:**
- `True` — істина (правда)
- `False` — хибність (брехня)

**Важливо:** Регістр має значення! Тільки з великої літери:
```python
x = True    # ✅ Правильно
y = False   # ✅ Правильно

z = true    # ❌ NameError
w = TRUE    # ❌ NameError
```

**Походження:**
Названі на честь Джорджа Буля (George Boole, 1815-1864), математика, який створив булеву алгебру — основу цифрової логіки.

**Використання 1: Порівняння**
```python
print(5 > 3)       # True
print(10 == 5)     # False
print(7 <= 7)      # True
print("a" < "b")   # True (лексикографічне порівняння)
```

**Використання 2: Умовні оператори**
```python
is_adult = True
if is_adult:
    print("Welcome!")
else:
    print("Access denied")
```

**Використання 3: Логічні операції**
```python
print(True and True)    # True
print(True and False)   # False
print(True or False)    # True
print(not True)         # False
print(not False)        # True
```

**Таблиці істинності:**

AND (і):
```
True  and True  = True
True  and False = False
False and True  = False
False and False = False
```

OR (або):
```
True  or True  = True
True  or False = True
False or True  = True
False or False = False
```

NOT (не):
```
not True  = False
not False = True
```

## Слайд 24: Boolean як числа

**Текст:**
Це може здатися дивним, але в Python `bool` насправді є підтипом `int`!

**True = 1, False = 0:**
```python
print(True == 1)     # True
print(False == 0)    # True
print(True == 2)     # False
```

**Boolean в арифметиці:**
```python
print(True + True)       # 2
print(True * 5)          # 5
print(False + 10)        # 10
print(True - False)      # 1
```

**Порівняння:**
```python
print(True > False)      # True (бо 1 > 0)
print(False < True)      # True (бо 0 < 1)
```

**Перевірка типу:**
```python
print(type(True))            # <class 'bool'>
print(isinstance(True, bool)) # True
print(isinstance(True, int))  # True (!)
```

**Чому так?**
Історична причина. У багатьох мовах програмування (C, C++) булеві значення представлені цілими числами: 0 = false, не-0 = true. Python зберіг цю сумісність.

**Практичне застосування:**
```python
# Підрахунок кількості True значень
conditions = [True, False, True, True, False]
count = sum(conditions)  # sum() додає числа, True = 1, False = 0
print(count)  # 3 (три True)

# Відсоток успішних тестів
tests = [True, True, False, True, False, True]
success_rate = sum(tests) / len(tests) * 100
print(f"Success rate: {success_rate}%")  # 66.67%
```

**Застереження:**
Хоча `True == 1`, не використовуйте їх взаємозамінно для читабельності:
```python
# Погано (незрозуміло)
if x == 1:
    do_something()

# Добре (зрозуміло)
if is_active:
    do_something()
```

## Слайд 25-26: None - спеціальне значення

**Текст:**
`None` — це унікальне значення в Python, яке представляє "відсутність значення" або "нічого".

**Тип:**
```python
x = None
print(type(x))  # <class 'NoneType'>
```

`NoneType` — це окремий тип, у якого є тільки одне можливе значення: `None`.

**Коли використовується:**

1. **Функції без return:**
   ```python
   def say_hello():
       print("Hello!")
   
   result = say_hello()
   print(result)  # None (функція нічого не повернула)
   ```

2. **Ініціалізація змінних:**
   ```python
   user = None  # Користувач ще не завантажений
   # ... код для завантаження ...
   if user is None:
       print("User not found")
   ```

3. **Опціональні аргументи:**
   ```python
   def greet(name=None):
       if name is None:
           print("Hello, stranger!")
       else:
           print(f"Hello, {name}!")
   ```

4. **Відсутність результату:**
   ```python
   def find_user(id):
       # ... пошук у базі даних ...
       if not found:
           return None
       return user
   ```

**Перевірка на None:**
Завжди використовуйте `is`, а не `==`:
```python
# ✅ Правильно
if x is None:
    print("x is None")

# ❌ Не рекомендовано
if x == None:
    print("x is None")
```

Чому? Тому що `None` — це singleton (єдиний об'єкт у пам'яті). `is` перевіряє ідентичність об'єкта, що швидше і точніше.

**None vs інші "хибні" значення:**
```python
print(None == False)     # False
print(None == 0)         # False
print(None == "")        # False
print(None == [])        # False

# Але всі вони хибні в логічному контексті
print(bool(None))        # False
print(bool(False))       # False
print(bool(0))           # False
print(bool(""))          # False
print(bool([]))          # False
```

**Практичний приклад:**
```python
def get_config(key):
    config = {"host": "localhost", "port": 8080}
    return config.get(key)  # Повертає None, якщо ключ не знайдено

host = get_config("host")
if host is not None:
    connect(host)

database = get_config("database")
if database is None:
    print("Database not configured!")
```

## Слайд 27: None vs False vs 0 vs ""

**Текст:**
Усі ці значення "хибні" в логічному контексті, але вони **НЕ рівні** між собою!

**Порівняння типів:**
```python
print(type(None))   # <class 'NoneType'>
print(type(False))  # <class 'bool'>
print(type(0))      # <class 'int'>
print(type(0.0))    # <class 'float'>
print(type(""))     # <class 'str'>
```

**Логічний контекст (всі хибні):**
```python
print(bool(None))   # False
print(bool(False))  # False
print(bool(0))      # False
print(bool(0.0))    # False
print(bool(""))     # False
```

**Але НЕ рівні:**
```python
print(None == False)  # False
print(None == 0)      # False
print(None == "")     # False

# Єдине виключення:
print(0 == False)     # True (бо bool є підтипом int)
print(0.0 == False)   # True
```

**Практичне застосування:**

1. **None для "не ініціалізовано":**
   ```python
   user = None
   if user is None:
       user = load_user()
   ```

2. **False для логічних прапорців:**
   ```python
   is_active = False
   if not is_active:
       activate()
   ```

3. **0 для числових лічильників:**
   ```python
   count = 0
   if count == 0:
       print("No items")
   ```

4. **"" для порожніх рядків:**
   ```python
   name = ""
   if not name:
       name = "Anonymous"
   ```

**Типова помилка:**
```python
def get_value():
    return 0  # Може бути валідне значення!

result = get_value()
if not result:  # ❌ Погано! 0 теж хибне
    print("No value")

# ✅ Правильно: перевіряти на None
if result is None:
    print("No value")
```

## Слайд 28: Таблиця істинності значень

**Текст:**
У Python є концепція "truthy" (істинні) та "falsy" (хибні) значень. Давайте систематизуємо, які значення вважаються хибними.

**Хибні (Falsy) значення:**

| Значення | Тип | bool() | Опис |
|----------|-----|--------|------|
| `None` | NoneType | `False` | Відсутність значення |
| `False` | bool | `False` | Логічна хибність |
| `0` | int | `False` | Числовий нуль |
| `0.0` | float | `False` | Float нуль |
| `0j` | complex | `False` | Комплексний нуль |
| `""` | str | `False` | Порожній рядок |
| `[]` | list | `False` | Порожній список |
| `()` | tuple | `False` | Порожній кортеж |
| `{}` | dict | `False` | Порожній словник |
| `set()` | set | `False` | Порожня множина |

**Всі інші значення — істинні (Truthy)!**

Приклади істинних значень:
```python
print(bool(1))          # True
print(bool(-1))         # True
print(bool(0.1))        # True
print(bool("0"))        # True (рядок "0", не число!)
print(bool(" "))        # True (рядок з пробілом)
print(bool([0]))        # True (список з одним елементом)
print(bool([False]))    # True (список з False всередині)
```

**Використання в умовах:**
```python
# Перевірка на порожній список
items = []
if items:  # Хибне, бо список порожній
    print("Has items")
else:
    print("Empty list")

# Перевірка на непорожній рядок
name = input("Enter name: ")
if name:  # Істинне, якщо користувач ввів щось
    print(f"Hello, {name}!")
else:
    print("Name cannot be empty")
```

**Пастка для новачків:**
```python
# ❌ Погано
if x == True:
    do_something()

# ✅ Добре
if x:
    do_something()

# ❌ Погано
if x == False:
    do_something()

# ✅ Добре
if not x:
    do_something()
```

### Демонстрації для уроку

**Демо 1: Внутрішнє представлення float**
```python
import struct

def float_to_binary(num):
    """Показує, як float зберігається в пам'яті"""
    # Перетворити float в байти
    bytes_repr = struct.pack('>d', num)
    # Байти в біти
    bits = ''.join(f'{byte:08b}' for byte in bytes_repr)
    
    # Розбити на частини
    sign = bits[0]
    exponent = bits[1:12]
    mantissa = bits[12:]
    
    print(f"Number: {num}")
    print(f"Sign: {sign}")
    print(f"Exponent: {exponent}")
    print(f"Mantissa: {mantissa}")
    print(f"Full binary: {bits}")

float_to_binary(0.1)
```

**Демо 2: Проблема точності float**
```python
def show_float_precision():
    """Демонструє обмеження float"""
    x = 0.1
    y = 0.2
    z = 0.3
    
    print(f"0.1 + 0.2 = {x + y}")
    print(f"Точне представлення 0.1: {x:.60f}")
    print(f"Точне представлення 0.2: {y:.60f}")
    print(f"Результат: {(x + y):.60f}")
    print(f"Очікуємо: {z:.60f}")
    
show_float_precision()
```
