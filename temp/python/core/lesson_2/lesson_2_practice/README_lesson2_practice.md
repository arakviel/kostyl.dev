## Що тут є

Папка `lesson_2_practice/` містить повний комплект інтерактивного практикуму до Уроку 2:

| Файл | Опис |
| :--- | :--- |
| `02_python_core_practice.ipynb` | **Основний зошит для студентів.** 22 практичні завдання (ТЗ) + бліц-тест на 6 запитань + підсумкова відомість самоперевірки по 8 блоках. |

## Як перегенерувати та перевірити зошит локально

За потреби змінити тексти завдань або додати нові перевірки:

```bash
# 1. Перегенерувати .ipynb зошит
python3 lesson_2_practice/build_practice_notebook.py

# 2. Прогнати автотест валідації (має видати 8/8 ✅)
python3 lesson_2_practice/validate_practice_notebook.py
```

`validate_practice_notebook.py` автоматично:
1. Заповнює всі клітинки зошита еталонними відповідями і проганяє його через рушій `nbclient`.
2. Перевіряє, що фінальна таблиця показує `8 з 8 блоків`.
3. Запускає порожній зошит і перевіряє коректність повідомлень `❌ Спершу виконайте клітинку із завданням`.
4. Перевіряє, що в клітинках для студентів немає завчасно зашитих розв'язків.

3. Додайте в `settings.json`:
```json

    "chat.disableAIFeatures": true
}
```
*(Це налаштування вимикає чат, інлайн-підказки, next edit suggestions і Copilot).*

```json
    "chat.disableAIFeatures": true,
    "editor.inlineSuggest.enabled": false,
    "github.copilot.enable": { "*": false },
    "github.copilot.chat.enable": false,
    "github.copilot.nextEditSuggestions.enabled": false,
    "chat.commandCenter.enabled": false,
    "inlineChat.enableV2": false
}
```

### Спосіб 3 (видалення розширень)
`Ctrl + Shift + X` (на macOS: `Cmd + Shift + X`) → знайти й видалити (`Uninstall`):

## Архітектурні особливості та хелпери

* **`set_inputs(...)` та `reset_inputs()`** — перехоплюють системний виклик `input()`, автоматично подаючи тестові дані в чергу. Завдяки цьому студент пише простий чистий код із функцією `input()`, а перевірочні клітинки тестують його автоматично без зависання.
* **`_need(...)`** — перевіряє, чи створені необхідні змінні у просторі імен зошита. Якщо студент забув виконати попередню клітинку, виводиться зрозуміла підказка українською замість неінформативного `NameError`.
* **Приховані розв'язки `<details>`** — готове еталонне рішення кожного завдання заховане під спойлером 💡, що стимулює студентів спершу спробувати виконати код самостійно.
