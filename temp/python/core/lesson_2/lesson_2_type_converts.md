# Перетворення типів у Python

**Lesson 2: Type Conversion & String Operations**

---

## Що таке перетворення типів?

Python дозволяє конвертувати дані з одного типу в інший

**Основні функції:**
- `int()` — перетворення в ціле число
- `float()` — перетворення в число з рухомою крапкою
- `str()` — перетворення в рядок

---

## Функція int()

Перетворює значення в ціле число

```python
# Приклад
age = int(input("Enter your age: "))
print("Next year you will be", age + 1)
```

**Важливо:** Якщо перетворення неможливе, програма видасть помилку

---

## Функція float()

Перетворює значення в число з рухомою крапкою

```python
# Приклад
anything = float(input("Enter a number: "))
something = anything ** 2.0
print(anything, "to the power of 2 is", something)
```

**Переваги:** Працює з десятковими числами

---

## input() + Перетворення типів

Комбінування функцій для отримання числових даних

```python
# Пряме перетворення
leg_a = float(input("Input first leg length: "))
leg_b = float(input("Input second leg length: "))
hypo = (leg_a**2 + leg_b**2) ** .5
print("Hypotenuse length is", hypo)
```

Не потрібно проміжних змінних!

---

## Оптимізація коду

Можна передати вираз безпосередньо в `print()`

```python
# До:
hypo = (leg_a**2 + leg_b**2) ** .5
print("Hypotenuse length is", hypo)

# Після:
print("Hypotenuse length is", (leg_a**2 + leg_b**2) ** .5)
```

---

## Рядкові оператори

Оператори `+` та `*` працюють не лише з числами!

**Два режими:**
- `+` для чисел → додавання
- `+` для рядків → конкатенація
- `*` для чисел → множення
- `*` для рядків → повторення

---

## Конкатенація рядків (+)

Об'єднання (склеювання) рядків в один

```python
string1 + string2
```

**Приклад:**
```python
fnam = input("May I have your first name, please? ")
lnam = input("May I have your last name, please? ")
print("Thank you.")
print("\nYour name is " + fnam + " " + lnam + ".")
```

---

## Властивості конкатенації

**Важливо:**
- Оператор **НЕ є перестановним**
  - `"ab" + "ba"` ≠ `"ba" + "ab"`
- Обидва аргументи мають бути **рядками**
- Можна використовувати **декілька разів** в одному виразі
- Використовує **лівостороннє зв'язування**

---

## Повторення рядка (*)

Повторює рядок задану кількість разів

```python
рядок * число
число * рядок
```

**Приклади:**
```python
"James" * 3          # "JamesJamesJames"
3 * "an"             # "ananan"
5 * "2"              # "22222" (не 10!)
"Hi" * 0             # "" (порожній рядок)
```

---

## Практика: Малювання фігур

```python
print("+" + 10 * "-" + "+")
print(("|" + " " * 10 + "|\n") * 5, end="")
print("+" + 10 * "-" + "+")
```

**Результат:**
```
+----------+
|          |
|          |
|          |
|          |
|          |
+----------+
```

## Функція str()

Перетворює число в рядок

```python
str(число)
```

**Використання:**
```python
leg_a = float(input("Input first leg length: "))
leg_b = float(input("Input second leg length: "))
print("Hypotenuse length is " + str((leg_a**2 + leg_b**2) ** .5))
```

Простіше і безпечніше, ніж зворотнє перетворення!

---

## Порівняння підходів

```python
# З комами (автоматичне перетворення)
print("Result:", 42)

# З конкатенацією (потрібно str())
print("Result: " + str(42))
```

**Переваги конкатенації:**
- Точніший контроль над форматуванням
- Більше гнучкості в побудові виводу

---

## Ключові висновки: input()

- `input()` отримує дані з консолі **як рядок**
- Має необов'язковий параметр — **prompt** (підказка)
- Зупиняє виконання програми до введення даних
- Можна використати для паузи:

```python
print("\nPress Enter to end the program.")
input()
print("THE END.")
```

---

## Ключові висновки: Оператори

**Конкатенація (+):**
- Об'єднує два рядки
- Обидва операнди мають бути рядками

**Повторення (*):**
- Повторює рядок N разів
- Один операнд — рядок, другий — число

```python
num1 = input("Enter first: ")   # "12"
num2 = input("Enter second: ")  # "21"
print(num1 + num2)              # "1221"
```

---

## Ключові висновки: Перетворення

| Функція | Призначення | Приклад |
|---------|-------------|---------|
| `int()` | → ціле число | `int("42")` → `42` |
| `float()` | → число з крапкою | `float("3.14")` → `3.14` |
| `str()` | → рядок | `str(42)` → `"42"` |

**Пам'ятайте:** При помилці перетворення програма завершиться з помилкою!

**Слайд 1-2: Вступ**
Сьогодні ми розглянемо одну з найважливіших тем у Python — перетворення типів даних. Це критично важливо, оскільки функція input() завжди повертає рядок, але часто нам потрібні числа для обчислень.

**Слайд 3-4: int() та float()**
Python надає дві основні функції для перетворення рядків у числа. Функція int() перетворює в ціле число, що корисно для лічильників, індексів тощо. Функція float() дозволяє працювати з дробовими числами. Важливо пам'ятати, що якщо користувач введе некоректні дані, програма завершиться з помилкою — до цього ми повернемося в наступних уроках.

**Слайд 5-6: Комбінування з input()**
Найпотужніша практика — це комбінування input() з функціями перетворення. Не потрібно створювати проміжні змінні, можна викликати функцію перетворення безпосередньо. Приклад з теоремою Піфагора демонструє, як ми можемо створити корисну програму всього за кілька рядків.

## Текст до слайдів для викладача (продовження)

**Слайд 7-9: Рядкові оператори**
Цікава особливість Python — оператори + та * працюють по-різному залежно від типу даних. З рядками + виконує конкатенацію (склеювання), а не додавання. Це дуже потужний інструмент для форматування виводу. Важливо, що конкатенація НЕ є перестановною — порядок має значення!

**Слайд 10-11: Повторення рядків**
Оператор * дозволяє повторювати рядки, що зручно для створення візуальних елементів, заповнення або форматування. Приклад з малюванням прямокутника показує, як можна створювати прості ASCII-графіки.

**Слайд 12-13: Функція str()**
Для повного циклу перетворень існує функція str(), яка перетворює числа назад у рядки. Це потрібно, коли ви хочете використовувати конкатенацію замість print() з комами. Це простіше і безпечніше, ніж перетворення рядків у числа.

**Слайд 14-17: Висновки**
У цьому уроці ви отримали фундаментальні інструменти для роботи з різними типами даних. Тепер ви можете створювати інтерактивні програми, які приймають введення від користувача, обробляють його і виводять результати. Наступним кроком буде вивчення умовних операторів, які дозволять програмам приймати рішення.
