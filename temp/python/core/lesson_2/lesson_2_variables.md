# Змінні в Python

**Lesson 2: Variables & Assignment**

*Зберігаємо та керуємо даними*

---

## Навіщо потрібні змінні?

**Проблема:** Як зберігати результати обчислень для подальшого використання?

**Рішення:** Змінні — спеціальні "контейнери" для зберігання даних

```python
# Без змінної (незручно)
print(3.14 * 5 * 5)
print(3.14 * 5 * 5 * 2)

# Зі змінною (зручно)
radius = 5
pi = 3.14
print(pi * radius * radius)
```

---

## Аналогія: Змінна як коробка

```
┌─────────────────┐
│   Ім'я: age     │  ← Етикетка на коробці
├─────────────────┤
│   Значення: 25  │  ← Вміст коробки
└─────────────────┘
```

**Два компоненти змінної:**
- **Ім'я** — як ви звертаєтеся до неї
- **Значення** — що в ній зберігається

---

## Правила іменування змінних

✅ **Дозволено:**
- Літери (A-Z, a-z)
- Цифри (0-9)
- Підкреслення (_)

❌ **Заборонено:**
- Починати з цифри
- Використовувати пробіли
- Використовувати спецсимволи (@, #, $, %, тощо)
- Використовувати ключові слова Python

## Стандарти іменування (PEP 8)

**snake_case** — для змінних та функцій
```python
user_name = "Alice"
total_count = 100
calculate_sum()
```

**UPPER_CASE** — для констант
```python
MAX_SPEED = 120
PI = 3.14159
API_KEY = "secret"
```

**camelCase** — не типово для Python (але допустимо)
```python
userName = "Bob"  # краще user_name
```

## Регістрочутливість

Python розрізняє великі та малі літери!

```python
name = "Alice"
Name = "Bob"
NAME = "Charlie"

print(name)   # "Alice"
print(Name)   # "Bob"
print(NAME)   # "Charlie"
```

**Це три різні змінні!**

## Динамічна типізація

Python сам визначає тип даних!

```python

x = "Hello"         # x тепер str
print(x)            # Hello

x = 3.14            # x тепер float
print(x)            # 3.14
```

**Гнучкість:** Змінна може змінювати свій тип!

## Використання змінних

```python
# Створення
var = 1
account_balance = 1000.0
client_name = "John Doe"

# Виведення
print(var)                                    # 1
print(account_balance)                        # 1000.0
print(var, account_balance, client_name)      # 1 1000.0 John Doe

# Комбінування з текстом
version = "3.12"
print("Python version: " + version)           # Python version: 3.12
```

---

## Помилка: Неіснуюча змінна

```python
var = 1
print(Var)  # ❌ NameError: name 'Var' is not defined
```

**Пам'ятайте:**
- Змінну потрібно спочатку створити (присвоїти значення)
- `var` ≠ `Var` (регістрочутливість!)

---

## Присвоєння нового значення

Змінна може змінювати своє значення

```python
var = 1
print(var)        # 1

var = var + 1
print(var)        # 2

var = 100
print(var)        # 100
```

**Важливо:** `=` це **присвоєння**, а не "дорівнює"!

---

## Оператор присвоєння (=)

```python
# Математика vs Програмування
# x = x + 1  ← У математиці це неможливо!
# В Python: "візьми значення x, додай 1, збережи назад у x"

x = 5
x = x + 1     # x стає 6
x = x * 2     # x стає 12
print(x)      # 12
```

**Читання:** `var = var + 1` → "збільшити var на 1"

---

## Практика: Теорема Піфагора

Обчислимо гіпотенузу прямокутного трикутника

```python
# c² = a² + b²
# c = √(a² + b²)

a = 3.0
b = 4.0
c = (a ** 2 + b ** 2) ** 0.5
print("c =", c)              # c = 5.0
```

**Хитрість:** √x = x^0.5, тому `** 0.5` — це квадратний корінь

---

## Скорочені оператори

Замість `x = x + 1` можна писати `x += 1`

| Повна форма | Скорочена | Опис |
|-------------|-----------|------|
| `x = x + 5` | `x += 5` | Додати |
| `x = x - 3` | `x -= 3` | Відняти |
| `x = x * 2` | `x *= 2` | Помножити |
| `x = x / 4` | `x /= 4` | Поділити |
| `x = x % 10` | `x %= 10` | Остача |
| `x = x ** 2` | `x **= 2` | Степінь |

---

## Приклади скорочених операторів

```python
# Лічильник
count = 0
count += 1        # count = 1
count += 1        # count = 2

# Подвоєння
x = 5
x *= 2            # x = 10

# Складні вирази
score = 100
score -= 10 * 2   # score = 80
score *= 1.5      # score = 120.0
```

**Переваги:** Швидше писати, легше читати

## Множинне присвоєння

Python дозволяє присвоювати значення кільком змінним одночасно!

```python
# Однакове значення
x = y = z = 0
print(x, y, z)    # 0 0 0

# Різні значення
a, b, c = 1, 2, 3
print(a, b, c)    # 1 2 3

# Обмін значеннями
x, y = 10, 20
x, y = y, x       # Swap!
print(x, y)       # 20 10
```

## Константи в Python

Python **не має** справжніх констант, але є домовленість:

```python
# UPPER_CASE = "константа" (домовленість)
PI = 3.14159
MAX_USERS = 100
API_URL = "https://api.example.com"

# Технічно можна змінити (але НЕ ТРЕБА!)
PI = 3.14         # Працює, але порушує домовленість
```

**Правило:** Якщо ім'я ВЕЛИКИМИ_ЛІТЕРАМИ — не змінюйте!

## Сфера видимості (preview)

```python
# Глобальна змінна
global_var = "Доступна скрізь"

def my_function():
    # Локальна змінна
    local_var = "Доступна лише в функції"
    print(global_var)   # OK
    print(local_var)    # OK

my_function()
print(global_var)       # OK
print(local_var)        # ❌ NameError
```

## Перевірка типу змінної

Функція `type()` показує тип змінної:

```python
x = 10
print(type(x))          # <class 'int'>

y = 3.14
print(type(y))          # <class 'float'>

z = "Hello"
print(type(z))          # <class 'str'>

flag = True
print(type(flag))       # <class 'bool'>
```
