## Слайд 2: Навіщо потрібні змінні?

**Текст:**
Давайте почнемо з практичної проблеми. Уявіть, що вам потрібно обчислити площу та довжину кола з радіусом 5. Без змінних ваш код виглядатиме так:

```python
print(3.14 * 5 * 5)           # площа
print(3.14 * 5 * 5 * 2)       # довжина
```

Що не так з цим кодом? По-перше, якщо нам потрібно змінити радіус, доведеться міняти його у двох місцях. По-друге, якщо ми помилимося в одному місці, отримаємо неправильний результат. По-третє, незрозуміло, що таке 3.14 і 5 без коментарів.

Тепер подивіться на версію зі змінними:

```python
pi = 3.14
radius = 5
area = pi * radius * radius
circumference = 2 * pi * radius
print(area)
print(circumference)
```

Це набагато зрозуміліше! Ми бачимо, що таке `pi`, що таке `radius`, і якщо нам потрібно змінити радіус, ми робимо це в одному місці. Код стає самодокументованим — він пояснює сам себе.

Змінні дозволяють нам:
- Зберігати результати обчислень
- Робити код більш читабельним
- Уникати повторів
- Легко змінювати значення в одному місці

## Слайд 3: Аналогія: Змінна як коробка

**Текст:**
Найкраща аналогія для розуміння змінних — це коробка. Уявіть, що у вас є коробка для зберігання речей. На коробці є етикетка з назвою — це ім'я змінної. Всередині коробки лежить щось — це значення змінної.

Наприклад, у вас є коробка з етикеткою "age" (вік), і всередині лежить число 25. Коли ви хочете дізнатися свій вік, ви дивитеся на етикетку "age", відкриваєте коробку і дивитеся, що всередині — 25.

Важливі моменти цієї аналогії:
1. **Етикетка (ім'я)** — має бути унікальною. Не може бути двох коробок з однаковою етикеткою в одній кімнаті (області видимості).
2. **Вміст (значення)** — може змінюватися. Ви можете витягнути 25 і покласти 26.
3. **Коробка може зберігати різні типи речей** — сьогодні число, завтра рядок. Це називається динамічною типізацією Python.

У деяких мовах програмування (C++, Java) ви повинні наперед сказати, що буде в коробці — число, рядок чи щось інше. Python не вимагає цього — він сам визначає, що ви поклали в коробку.

## Слайд 4: Правила іменування змінних

**Текст:**
Python має чіткі правила іменування змінних. Якщо ви порушите їх, код просто не запуститься.

**Дозволені символи:**
- Латинські літери: A-Z, a-z (як великі, так і малі)
- Цифри: 0-9 (але НЕ на початку!)
- Підкреслення: _ (дуже популярний символ у Python)

**Заборонені дії:**
- Починати з цифри: `1variable` — помилка
- Використовувати пробіли: `my variable` — помилка
- Використовувати спецсимволи: `my-var`, `my@var`, `my$var` — все помилки
- Використовувати ключові слова Python: `for`, `if`, `while` — заборонено

**Важливий момент:** Python підтримує Unicode, тому технічно ви можете використовувати кирилицю: `змінна = 10`. Це працює! Але в професійному коді це не прийнято — весь код пишеться англійською для міжнародної співпраці.

**Цікавий факт:** Підкреслення `_` саме по собі — валідне ім'я змінної! Його часто використовують для "викинутих" значень, які нам не потрібні:
```python
_, result = some_function()  # нам потрібен тільки result
```

## Слайд 5: Приклади правильних імен

**Текст:**
Тепер подивімося на конкретні приклади правильних імен змінних.

**Ідеальні імена** — описові, зрозумілі, відповідають PEP 8:
```python
user_name = "Alice"        # зрозуміло, що це ім'я користувача
age = 25                   # коротко і ясно
total_price = 199.99       # описово
is_active = True           # булеве значення з префіксом is_
```

**Допустимі, але не дуже гарні імена:**
```python
MyVariable = 10            # не відповідає PEP 8 (camelCase замість snake_case)
i = 1                      # однолітерне ім'я (OK тільки для лічильників циклів)
x1y2z3 = "value"          # незрозуміло, що це
_ = 42                     # валідно, але використовується для "викинутих" значень
_secret = "hidden"         # підкреслення на початку має спеціальне значення
```

**Коли однолітерні імена OK:**
- `i`, `j`, `k` — для лічильників у циклах
- `x`, `y`, `z` — для координат
- `n` — для кількості елементів
- Але навіть тут краще використовувати `index`, `count`, `coordinate_x`

**Золоте правило:** Якщо ви не можете зрозуміти призначення змінної через місяць після написання коду, ім'я погане.

## Слайд 6: Приклади неправильних імен

**Текст:**
Розберемо типові помилки, які роблять початківці при іменуванні змінних.

**Помилка 1: Починати з цифри**
```python
10var = 5  # ❌ SyntaxError
```
Чому заборонено? Щоб Python міг відрізнити змінні від чисел. Якби це було дозволено, як інтерпретатор зрозумів би `10var` — це число `10` і змінна `var`, чи це змінна `10var`?

**Помилка 2: Дефіс замість підкреслення**
```python
user-name = "Bob"  # ❌ SyntaxError
```
Python сприймає це як віднімання: `user minus name`. Правильно: `user_name`.

**Помилка 3: Пробіли**
```python
my var = 10  # ❌ SyntaxError
```
Python бачить два окремі токени: `my` і `var`. Правильно: `my_var`.

**Помилка 4: Ключові слова**
```python
for = 25   # ❌ SyntaxError
if = True  # ❌ SyntaxError
```
Ці слова зарезервовані Python для спеціальних цілей.

**Помилка 5: Спецсимволи**
```python
@price = 100    # ❌ SyntaxError
$money = 50     # ❌ SyntaxError
price% = 0.2    # ❌ SyntaxError
```

**Практична порада:** Сучасні IDE (PyCharm, VS Code) підсвічують ці помилки ще до запуску коду!

## Слайд 7: Стандарти іменування (PEP 8)

**Текст:**
PEP 8 — це офіційний посібник зі стилю коду Python. Він не є обов'язковим, але дуже рекомендований. Якщо ви працюєте в команді або публікуєте код на GitHub, дотримання PEP 8 — знак професіоналізму.

**snake_case для змінних та функцій:**
```python
user_name = "Alice"          # дві слова, розділені підкресленням
total_count = 100
items_in_cart = 5
calculate_total_price()      # функції теж snake_case
```

Чому називається "snake_case"? Тому що підкреслення схожі на змію, що повзе між словами: user_____name.

**UPPER_CASE для констант:**
```python
MAX_SPEED = 120              # константи завжди великими літерами
PI = 3.14159
API_KEY = "secret_key_123"
DATABASE_URL = "localhost:5432"
```

Зверніть увагу: Python не має справжніх констант (значення можна змінити), але угода наказує використовувати UPPER_CASE для значень, які **не повинні** змінюватися.

**PascalCase (CapitalizedWords) для класів:**
```python
class UserProfile:           # назви класів
    pass

class ShoppingCart:
    pass
```

**camelCase — НЕ типово для Python:**
```python
userName = "Bob"             # можна, але не рекомендовано
totalPrice = 199.99          # краще total_price
```
camelCase популярний у JavaScript, Java, C#, але не в Python.

**Особливі конвенції:**
- `_single_leading_underscore` — "слабо приватна" змінна (конвенція, а не примус)
- `__double_leading_underscore` — запускає name mangling (складна тема)
- `__double_leading_and_trailing_underscore__` — "магічні" методи (`__init__`, `__str__`)

## Слайд 8: Регістрочутливість

**Текст:**
Це дуже важлива особливість Python, яка часто призводить до помилок у початківців.

Python розрізняє великі та малі літери. Це означає, що `name`, `Name` та `NAME` — це **три абсолютно різні змінні**. Вони зберігаються в різних місцях пам'яті і не мають нічого спільного.

```python
name = "Alice"    # змінна name
Name = "Bob"      # змінна Name (інша!)
NAME = "Charlie"  # змінна NAME (ще одна!)

print(name)       # Alice
print(Name)       # Bob
print(NAME)       # Charlie
```

**Типова помилка початківців:**
```python
userName = "Alice"
print(username)   # ❌ NameError: name 'username' is not defined
```

Студент створив `userName` (з великою N), але намагається використати `username` (з малою n). Python каже: "Я не знаю такої змінної `username`!"

**Практична порада:**
1. Дотримуйтеся одного стилю іменування (переважно snake_case)
2. Використовуйте автодоповнення в IDE (Tab або Ctrl+Space)
3. Будьте уважні при наборі — одна помилка в регістрі = баг

**Цікавий факт:** У деяких мовах (PHP, SQL) регістр не має значення. Програмісти, які переходять з цих мов на Python, часто стикаються з цією проблемою.

## Слайд 10: Створення змінної

**Текст:**
Створення змінної в Python — це найпростіша річ у світі. На відміну від багатьох інших мов програмування, вам не потрібно заздалегідь оголошувати змінну або вказувати її тип.

**Синтаксис:**
```python
ім'я_змінної = значення
```

Це називається **оператор присвоєння**. Знак `=` означає не "дорівнює" (як у математиці), а "присвоїти значення".

**Магія Python:** Змінна створюється автоматично при першому присвоєнні!

У мовах як C++ або Java, ви повинні спочатку оголосити змінну:
```java
// Java
int age;           // оголошення
age = 25;          // присвоєння
```

У Python все простіше:
```python
age = 25  # одночасно оголошення і присвоєння!
```

**Приклади різних типів:**
```python
var = 1                  # int (ціле число)
price = 19.99            # float (число з крапкою)
name = "John"            # str (рядок)
is_student = True        # bool (булеве значення)
nothing = None           # NoneType (відсутність значення)
```

Python сам визначає тип змінної за значенням, яке ви присвоюєте. Це називається **динамічною типізацією**.

**Важливо:** У Python немає "оголошення без ініціалізації". Наступний код не працює:
```python
var         # ❌ Це не створює змінну
var = 1     # ✅ Тепер змінна створена
```

## Слайд 11: Динамічна типізація

**Текст:**
Одна з найпотужніших (і іноді найнебезпечніших) особливостей Python — це динамічна типізація. Це означає, що змінна може змінювати свій тип під час виконання програми.

```python
x = 10              # x тепер int
print(x)            # 10
print(type(x))      # <class 'int'>

x = "Hello"         # x тепер str
print(x)            # Hello
print(type(x))      # <class 'str'>

x = 3.14            # x тепер float
print(x)            # 3.14
print(type(x))      # <class 'float'>
```

Це працює, тому що в Python змінна — це просто "етикетка", яка вказує на об'єкт у пам'яті. Коли ми пишемо `x = 10`, ми створюємо об'єкт `10` і прикріплюємо до нього етикетку `x`. Коли ми пишемо `x = "Hello"`, ми просто перенаправляємо етикетку на інший об'єкт.

**Переваги динамічної типізації:**
- Швидше писати код
- Більше гнучкості
- Менше шаблонного коду

**Недоліки:**
- Легше зробити помилку
- Складніше знайти баги
- Може бути повільніше

**Порівняння зі статичною типізацією:**

Python (динамічна):
```python
x = 10
x = "Hello"  # OK
```

Java (статична):
```java
int x = 10;
x = "Hello";  // ❌ Помилка компіляції!
```

**Сучасний Python:** Python 3.5+ підтримує type hints (підказки типів), які допомагають уникнути помилок:
```python
age: int = 25
name: str = "Alice"
price: float = 19.99
```
Але це лише підказки — Python не примусово перевіряє їх під час виконання.

## Слайд 12: Використання змінних

**Текст:**
Після створення змінної, ми можемо її використовувати в будь-якому місці коду — передавати в функції, виводити на екран, використовувати в обчисленнях.

**Виведення змінних:**
```python
var = 1
print(var)                    # виведе 1
```

Функція `print()` може приймати будь-яку кількість аргументів:
```python
account_balance = 1000.0
client_name = "John Doe"
print(var, account_balance, client_name)  # 1 1000.0 John Doe
```

Python автоматично додає пробіли між аргументами.

**Комбінування з текстом:**
```python
version = "3.12"
print("Python version: " + version)  # Python version: 3.12
```

Зверніть увагу: ми використовуємо конкатенацію (`+`) для об'єднання рядків. Але це працює тільки з рядками! Якщо `version` було числом, ми б отримали помилку.

**Альтернативні способи форматування:**
```python
age = 25
# Спосіб 1: Коми в print()
print("Age:", age)                      # Age: 25

# Спосіб 2: Конкатенація
print("Age: " + str(age))               # Age: 25

# Спосіб 3: f-strings (рекомендовано!)
print(f"Age: {age}")                    # Age: 25

# Спосіб 4: format()
print("Age: {}".format(age))            # Age: 25
```

f-strings (Python 3.6+) — найсучасніший і найзручніший спосіб!

**Використання у виразах:**
```python
price = 100
quantity = 3
total = price * quantity
print(f"Total: {total}")                # Total: 300
```

## Слайд 13: Помилка: Неіснуюча змінна

**Текст:**
Одна з найчастіших помилок початківців — спроба використати змінну, яка не була створена.

```python
var = 1
print(Var)  # ❌ NameError: name 'Var' is not defined
```

Що тут не так? Ми створили змінну `var` (з малої літери), але намагаємося використати `Var` (з великої літери). Через регістрочутливість Python, це дві різні змінні!

**Типи помилок з іменами:**

**1. Друкарська помилка:**
```python
count = 10
print(cont)  # ❌ NameError (написали 'cont' замість 'count')
```

**2. Використання перед створенням:**
```python
print(x)     # ❌ NameError
x = 10       # створення після використання
```

**3. Помилка в регістрі:**
```python
userName = "Alice"
print(username)  # ❌ NameError
```

**4. Помилка в області видимості:**
```python
def my_function():
    local_var = 10

print(local_var)  # ❌ NameError (локальна змінна недоступна ззовні)
```

**Як уникнути цих помилок:**
1. Використовуйте автодоповнення в IDE
2. Перевіряйте регістр літер
3. Переконайтеся, що змінна створена перед використанням
4. Використовуйте лінтери (pylint, flake8), які знаходять такі помилки

**Цікавий факт:** NameError — це RuntimeError, тобто помилка, яка виявляється лише під час виконання програми. У статично типізованих мовах такі помилки виявляються на етапі компіляції.

## Слайд 14: Присвоєння нового значення

**Текст:**
Змінна називається "змінною" саме тому, що її значення може змінюватися. Ми можемо присвоїти нове значення тій самій змінній у будь-який момент.

```python
var = 1
print(var)        # 1

var = var + 1
print(var)        # 2

var = 100
print(var)        # 100
```

**Що відбувається покроково:**

1. `var = 1` — створюється змінна `var`, їй присвоюється значення `1`
2. `print(var)` — виводиться поточне значення: `1`
3. `var = var + 1` — береться поточне значення `var` (1), додається 1, результат (2) присвоюється назад у `var`
4. `print(var)` — виводиться нове значення: `2`
5. `var = 100` — змінній присвоюється зовсім нове значення `100`, старе значення (2) втрачається
6. `print(var)` — виводиться `100`

**Важливий концепт:** Коли ми пишемо `var = var + 1`, правий бік виразу обчислюється першим, а потім результат присвоюється лівому боку.

**Візуалізація процесу:**
```
Крок 1: var = 1
[var] -> 1

Крок 2: var = var + 1
Обчислити: var + 1 = 1 + 1 = 2
Присвоїти: [var] -> 2

Крок 3: var = 100
[var] -> 100
```

**Типова помилка:**
```python
result = result * 2  # ❌ NameError, якщо result ще не створена
```

Треба спочатку ініціалізувати:
```python
result = 1
result = result * 2  # ✅ Тепер працює
```

## Слайд 15: Оператор присвоєння (=)

**Текст:**
Дуже важливо розуміти, що знак `=` у програмуванні означає **НЕ "дорівнює"**, а **"присвоїти значення"**.

У математиці рівняння `x = x + 1` — це абсурд. Жодне число не може дорівнювати самому собі плюс один. Це суперечність.

Але в програмуванні `x = x + 1` — абсолютно нормальний вираз. Ми читаємо його так:
"Візьми поточне значення x, додай до нього 1, і збережи результат назад у x"

**Напрямок операції:**
```python
x = 5
```
Стрілка йде справа наліво: значення `5` присвоюється змінній `x`.

```
5 -----> [x]
```

**Складніші приклади:**
```python
x = 5
x = x + 1     # x стає 6
x = x * 2     # x стає 12
x = x - 3     # x стає 9
print(x)      # 9
```

**Математика vs Програмування:**

Математика:
```
x = 5         (x дорівнює 5)
x = x + 1     (НЕМОЖЛИВО!)
```

Програмування:
```python
x = 5         # присвоїти 5 до x
x = x + 1     # присвоїти (x + 1) до x
```

**Оператор порівняння:**
Якщо ми хочемо **перевірити рівність** (як у математиці), використовуємо `==`:
```python
x = 5         # присвоєння
x == 5        # перевірка (чи дорівнює x п'яти?)
```

**Цікавий факт:** У деяких мовах (Pascal, R) для присвоєння використовують інші символи: `:=` або `<-`, щоб уникнути плутанини з рівністю.

## Слайд 16: Практика: Теорема Піфагора

**Текст:**
Давайте застосуємо наші знання про змінні для вирішення реальної математичної задачі — обчислення гіпотенузи прямокутного трикутника за теоремою Піфагора.

**Теорема Піфагора:**
У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів:
```
c² = a² + b²
c = √(a² + b²)
```

**Реалізація в Python:**
```python
a = 3.0
b = 4.0
c = (a ** 2 + b ** 2) ** 0.5
print("c =", c)              # c = 5.0
```

**Розбір коду:**

1. `a = 3.0` — перший катет (використовуємо float для точності)
2. `b = 4.0` — другий катет
3. `a ** 2` — квадрат першого катета (3² = 9)
4. `b ** 2` — квадрат другого катета (4² = 16)
5. `a ** 2 + b ** 2` — сума квадратів (9 + 16 = 25)
6. `(a ** 2 + b ** 2) ** 0.5` — квадратний корінь з суми (√25 = 5)
7. Результат присвоюється змінній `c`

**Хитрість з коренем:**
Чому `** 0.5` дає квадратний корінь? Тому що математично:
```
√x = x^(1/2) = x^0.5
```

**Альтернативні способи обчислити корінь:**
```python
# Спосіб 1: використати ** 0.5
c = (a ** 2 + b ** 2) ** 0.5

# Спосіб 2: використати модуль math
import math
c = math.sqrt(a ** 2 + b ** 2)

# Спосіб 3: використати гіпотенузу з math
import math
c = math.hypot(a, b)
```

**Переваги використання змінних:**
1. Код зрозумілий — видно, що таке `a`, `b`, `c`
2. Легко змінити значення
3. Можна перевикористати змінні
4. Уникаємо повторів у обчисленнях

**Вправа для студентів:** Спробуйте обчислити гіпотенузу для катетів 5 і 12. Відповідь має бути 13.

## Слайд 17: Скорочені оператори

**Текст:**
Python пропонує зручні скорочені форми запису для операцій, де ми змінюємо значення змінної на основі її поточного значення.

**Проблема:** Ми часто пишемо код на зразок:
```python
x = x + 5
count = count + 1
total = total * 2
```

Це багатослівно — ми двічі пишемо ім'я змінної. Python дозволяє скоротити це:

```python
x += 5            # еквівалентно x = x + 5
count += 1        # еквівалентно count = count + 1
total *= 2        # еквівалентно total = total * 2
```

**Всі скорочені оператори:**

| Повна форма | Скорочена | Опис |
|-------------|-----------|------|
| `x = x + 5` | `x += 5` | Додати до x |
| `x = x - 3` | `x -= 3` | Відняти від x |
| `x = x * 2` | `x *= 2` | Помножити x на |
| `x = x / 4` | `x /= 4` | Поділити x на |
| `x = x // 4` | `x //= 4` | Цілочисельне ділення |
| `x = x % 10` | `x %= 10` | Остача від ділення |
| `x = x ** 2` | `x **= 2` | Піднести x до степеня |

**Переваги:**
1. Менше коду — швидше писати
2. Легше читати — очевидно, що ми модифікуємо змінну
3. Менше ймовірність помилитися (не потрібно двічі писати ім'я)

**Важливо:** Скорочені оператори працюють тільки з існуючими змінними:
```python
x += 5    # ❌ NameError, якщо x не існує
```

Треба спочатку ініціалізувати:
```python
x = 0
x += 5    # ✅ Тепер x дорівнює 5
```

**Складні вирази:**
Праві частини можуть бути складними виразами:
```python
score = 100
score += 10 * 2        # score = score + (10 * 2) = 120
score *= 1.5           # score = score * 1.5 = 180.0
```

## Слайд 19: Множинне присвоєння

**Текст:**
Python має кілька унікальних можливостей для присвоєння значень змінним, які роблять код більш компактним та елегантним.

**1. Однакове значення кільком змінним:**
```python
x = y = z = 0
```

Це еквівалентно:
```python
x = 0
y = 0
z = 0
```

Усі три змінні отримують однакове значення. Корисно для ініціалізації групи змінних.

**Важливо:** Якщо значення — це змінний об'єкт (список, словник), всі змінні вказуватимуть на один і той же об'єкт!
```python
x = y = []        # обидві вказують на ОДИН список
x.append(1)
print(y)          # [1] — змінився і y!
```

**2. Розпакування (unpacking):**
```python
a, b, c = 1, 2, 3
print(a, b, c)    # 1 2 3
```

Python "розпаковує" праву частину і присвоює значення по порядку.

**3. Обмін значень (swap):**
```python
x, y = 10, 20
x, y = y, x       # Обмін!
print(x, y)       # 20 10
```

Це унікальна особливість Python! В інших мовах потрібна тимчасова змінна:
```python
# Java/C++:
temp = x
x = y
y = temp
```

**Як це працює:**
Python спочатку обчислює праву частину `(y, x)`, створюючи кортеж `(20, 10)`, а потім розпаковує його в `x` і `y`.

**Більше прикладів:**
```python
# Розпакування з функцій
def get_coordinates():
    return 10, 20

x, y = get_coordinates()

# Ігнорування значень
a, _, c = 1, 2, 3    # нас не цікавить друге значення

# Розширене розпакування (Python 3+)
first, *middle, last = [1, 2, 3, 4, 5]
print(first)         # 1
print(middle)        # [2, 3, 4]
print(last)          # 5
```

## Слайд 20: Константи в Python

**Текст:**
У багатьох мовах програмування є поняття "константи" — значення, яке не можна змінити після ініціалізації. Python не має справжніх констант, але є **домовленість** про іменування.

**Домовленість:** Якщо ім'я змінної написане ВЕЛИКИМИ_ЛІТЕРАМИ, це сигнал іншим програмістам: "Це константа, не змінюйте її!"

```python
PI = 3.14159
MAX_USERS = 100
API_URL = "https://api.example.com"
DATABASE_NAME = "mydb"
```

**Важливо:** Це лише домовленість, а не примус. Python не заборонить вам змінити значення:
```python
PI = 3.14159
PI = 3.14         # ✅ Технічно працює
PI = "hello"      # ✅ Технічно працює, але це ДУЖЕ ПОГАНА ідея!
```

Але професійні програмісти не роблять так, бо це порушує домовленість.

**Де використовувати константи:**

1. **Математичні константи:**
```python
PI = 3.14159265359
E = 2.71828182846
GOLDEN_RATIO = 1.61803398875
```

2. **Налаштування програми:**
```python
MAX_RETRIES = 3
TIMEOUT_SECONDS = 30
DEFAULT_LANGUAGE = "uk"
```

3. **URL та шляхи:**
```python
API_BASE_URL = "https://api.example.com"
DATABASE_PATH = "/var/data/mydb"
LOG_FILE = "/var/log/app.log"
```

4. **Бізнес-правила:**
```python
TAX_RATE = 0.20
MIN_PASSWORD_LENGTH = 8
MAX_LOGIN_ATTEMPTS = 3
```

**Справжні константи:**
Якщо вам дуже потрібні незмінні константи, можна використати:
```python
from enum import Enum

class Status(Enum):
    PENDING = 1
    APPROVED = 2
    REJECTED = 3

# Status.PENDING = 5  # ❌ AttributeError: не можна змінити!
```

Або модуль `typing.Final` (Python 3.8+):
```python
from typing import Final

MAX_SIZE: Final = 100
# MAX_SIZE = 200  # Статичний аналізатор (mypy) покаже помилку
```

**Переваги використання констант:**
1. Код стає більш читабельним
2. Легше змінити значення в одному місці
3. Запобігає "магічним числам" у коді
4. Документує призначення значення

## Слайд 23: Сфера видимості (preview)

**Текст:**

```python
print(global_var)       # ✅ OK
```

**Локальні змінні:**
Створені всередині функції, доступні лише в ній.

```python
def my_function():
    local_var = "Я локальна"
    print(local_var)    # ✅ OK всередині функції

my_function()
print(local_var)        # ❌ NameError: не існує ззовні
```

**Чому це важливо:**
Локальні змінні дозволяють ізолювати код функції від решти програми. Ви можете використовувати однакові імена змінних у різних функціях без конфліктів.

**Правило LEGB:**
Python шукає змінні в такому порядку:
1. **L**ocal — локальна (в поточній функції)
2. **E**nclosing — вкладена (у зовнішній функції)
3. **G**lobal — глобальна (на рівні модуля)
4. **B**uilt-in — вбудована (print, len, тощо)

**Приклад:**
```python
x = "global"

def outer():
    x = "enclosing"
    
    def inner():
        x = "local"
        print(x)    # Що виведе?
    
    inner()
    print(x)        # Що виведе?

outer()
print(x)            # Що виведе?
```

Відповідь: "local", "enclosing", "global" — кожна функція бачить свою версію `x`.

**На цьому етапі запам'ятайте:** Змінні, створені в функції, недоступні ззовні. Детальніше — у наступних уроках!

## Слайд 24: Перевірка типу змінної

**Текст:**
Python динамічно типізований, тому іноді корисно перевірити, якого типу змінна в даний момент. Для цього є вбудована функція `type()`.

**Синтаксис:**
```python
type(змінна)
```

**Приклади:**
```python
x = 10
print(type(x))          # <class 'int'>

y = 3.14
print(type(y))          # <class 'float'>

z = "Hello"
print(type(z))          # <class 'str'>

flag = True
print(type(flag))       # <class 'bool'>

nothing = None
print(type(nothing))    # <class 'NoneType'>
```

**Використання в умовах:**
```python
x = 10

if type(x) == int:
    print("x — це ціле число")
elif type(x) == float:
    print("x — це число з крапкою")
elif type(x) == str:
    print("x — це рядок")
```

**Краще використовувати isinstance():**
```python
x = 10

if isinstance(x, int):
    print("x — це ціле число")
```

`isinstance()` краще, бо працює з успадкуванням класів (складна тема для пізніше).

**Практичне використання:**
```python
def add_ten(value):
    if isinstance(value, (int, float)):
        return value + 10
    elif isinstance(value, str):
        return value + "10"
    else:
        return None

print(add_ten(5))       # 15
print(add_ten("5"))     # "510"
print(add_ten([]))      # None
```

**Дебагінг:**
`type()` дуже корисна для дебагінгу, коли ви не впевнені, який тип має змінна:
```python
def mysterious_function():
    # ... багато коду ...
    return some_value

result = mysterious_function()
print(f"Result type: {type(result)}")  # Дізнаємося тип
```

## Слайд 30-31: Цікаві факти

**Текст:**
Давайте розглянемо кілька цікавих фактів про Python та змінні, які допоможуть вам краще зрозуміти мову.

**Факт 1: Python — одна з найгнучкіших мов завдяки динамічній типізації**

У багатьох мовах (C++, Java) ви повинні оголосити тип змінної:
```java
// Java
int age = 25;
age = "twenty-five";  // ❌ Помилка компіляції!
```

Python дозволяє змінювати типи:
```python
age = 25

```

Це гнучко, але потребує дисципліни.

**Факт 2: PEP 8 рекомендує максимум 79 символів на рядок**

Це стандарт з 1970-х років, коли термінали були 80 символів завширшки. Сьогодні це допомагає читабельності коду — рядки не розтягуються за межі екрану.

**Факт 3: Python підтримує Unicode**

Ви можете використовувати будь-які символи Unicode в іменах змінних:
```python
привіт = "світ"       # валідно!
año = 2024            # валідно!
变量 = "Chinese"      # валідно!
```

Але в професійному коді використовується лише англійська для міжнародної сумісності.

**Факт 4: Множинне присвоєння працює атомарно**

```python
x, y = 10, 20
x, y = y, x
```

Python обчислює праву частину повністю перед присвоєнням, тому обмін працює без тимчасової змінної.

**Факт 5: Підкреслення `_` має спеціальне значення**

1. **Викинуті значення:**
```python
_, result = some_function()  # нам потрібен тільки result
```

2. **Останній результат в інтерактивному режимі:**
```python
>>> 2 + 2
4
>>> _ * 3
12
```

3. **Розділювач для великих чисел (Python 3.6+):**
```python
million = 1_000_000  # легше читати, ніж 1000000
```

**Факт 6: Python має оператор "морж" (walrus) `:=` (Python 3.8+)**

Дозволяє присвоєння всередині виразів:
```python
# До Python 3.8:
n = len(my_list)
if n > 10:
    print(n)

# З walrus operator:
if (n := len(my_list)) > 10:
    print(n)
```

**Факт 7: Змінні — це посилання, а не коробки**

```python
x = [1, 2, 3]
y = x
y.append(4)
print(x)  # [1, 2, 3, 4] — змінився і x!
```

`y` не копіює список, а посилається на той самий об'єкт!

```python
x = 100
y = 0.2
z = x + (x * y)
print(z)
```

Після:
```python
price = 100
tax_rate = 0.2
total_price = price + (price * tax_rate)
print(f"Total: ${total_price}")
```

1. **Чому важливо використовувати описові імена змінних?**

2. **Чим відрізняється `=` від `==` в Python?**
   - Відповідь: `=` — присвоєння, `==` — порівняння

3. **Чому Python дозволяє змінювати тип змінної?**
   - Відповідь: Динамічна типізація — гнучкість vs безпека

4. **Коли варто використовувати однолітерні імена (`i`, `x`)?**
   - Відповідь: Для локальних лічильників, координат, математичних формул

5. **Що станеться, якщо використати ключове слово як ім'я змінної?**
   - Відповідь: SyntaxError
