## Вступ до дебагінгу

### Що таке дебагінг?

**Дебагінг (Debugging)** — це процес **пошуку та виправлення помилок** (багів) у програмі.

**Простими словами:** Ваша програма працює не так, як очікувалося. Дебагінг — це детективна робота з пошуку причини проблеми.

### Походження терміну "баг"

**Історія:** У 1947 році інженери знайшли справжнього метелика (bug) у комп'ютері Mark II, який спричинив несправність. З тих пір програмні помилки називають "багами".

```
🦋 bug (англ.) = метелик
🐛 bug у програмуванні = помилка
```

### Чому дебагінг важливий?

1. **Ніхто не пише ідеальний код** — помилки неминучі
2. **Економія часу** — швидке виявлення помилок економить години роботи
3. **Розуміння коду** — дебагінг допомагає краще розуміти, як працює програма
4. **Навчання** — на помилках вчаться!

### Менталітет дебагера:

```
❌ "Код не працює! Я не розумію!"
✅ "Код працює не так. Розберемося чому!"

❌ "Це Python винен!"
✅ "Я припустився помилки. Де саме?"

❌ "Занадто складно!"
✅ "Розіб'ю проблему на частини і перевірю кожну"
```

## Що таке баг (помилка)?

### Визначення

**Баг** — це **відхилення** фактичного результату програми від очікуваного.

### Типи ситуацій:

#### 1. Програма не запускається

```python
print("Привіт"
```

**Результат:** `SyntaxError: unexpected EOF while parsing`

#### 2. Програма падає під час роботи

```python
number = int(input("Введіть число: "))
result = 100 / number
print(result)
```

**Вхід:** `0`  
**Результат:** `ZeroDivisionError: division by zero`

#### 3. Програма працює, але видає неправильний результат

```python
# Хочемо суму від 1 до 10
total = 0
for i in range(10):  # Помилка: range(10) → 0..9, а не 1..10
    total = total + i
print(total)  # Виведе 45 замість 55
```

**Очікували:** 55  
**Отримали:** 45  
**Проблема:** Логічна помилка

## Типи помилок у Python

Python має **три основні типи помилок**:

### 1. Синтаксичні помилки (Syntax Errors)

**Що це:** Порушення правил синтаксису Python.

**Коли виникають:** **ДО** запуску програми (Python не може "прочитати" код).

**Приклад:**

```python
if x > 5
    print("Більше 5")
```

**Помилка:** Відсутня двокрапка після `if`

### 2. Помилки виконання (Runtime Errors / Exceptions)

**Що це:** Помилки, які виникають **під час виконання** програми.

**Коли виникають:** Програма запустилася, але щось пішло не так.

**Приклад:**

```python
x = 10
y = 0
result = x / y  # Ділення на нуль!
```

**Помилка:** `ZeroDivisionError`

### 3. Логічні помилки (Logic Errors)

**Що це:** Програма працює, але **логіка неправильна**.

**Коли виникають:** Програма запускається і завершується без помилок, але результат неправильний.

**Приклад:**

```python
# Хочемо знайти середнє арифметичне
a = 10
b = 20
average = a + b / 2  # Помилка: пріоритет операцій!
print(average)  # Виведе 20.0 замість 15.0
```

**Правильно:**

```python
average = (a + b) / 2
```

### Порівняння типів помилок:

| Тип помилки       | Коли виявляється | Python зупиняється? | Легко знайти? |
| ----------------- | ---------------- | ------------------- | ------------- |
| Синтаксична       | До запуску       | Так, одразу         | ✅ Легко      |
| Виконання         | Під час роботи   | Так, у момент помилки | ✅ Легко    |
| Логічна           | Ніколи (автоматично) | Ні              | ❌ Складно    |

## Синтаксичні помилки (Syntax Errors)

### Що таке синтаксична помилка?

**Синтаксична помилка** — це порушення граматики мови Python.

**Аналогія з мовою:**

```
Українська: "Я йду до школи" ✅
            "Я школи до йду" ❌ (неправильний синтаксис)

Python: "if x > 5:" ✅
        "if x > 5" ❌ (відсутня :)
```

### Поширені синтаксичні помилки:

#### 1. Відсутня двокрапка

```python
# ❌ Неправильно
if x > 5
    print("Більше 5")

# ✅ Правильно
if x > 5:
    print("Більше 5")
```

**Помилка:**

```
SyntaxError: invalid syntax
```

#### 2. Незакрита дужка/лапка

```python
# ❌ Неправильно
print("Привіт
print(5 + (3 * 2)

# ✅ Правильно
print("Привіт")
print(5 + (3 * 2))
```

**Помилка:**

```
SyntaxError: EOL while scanning string literal
або
SyntaxError: unexpected EOF while parsing
```

#### 3. Неправильний відступ

```python
# ❌ Неправильно
if x > 5:
print("Більше 5")

# ✅ Правильно
if x > 5:
    print("Більше 5")
```

**Помилка:**

```
IndentationError: expected an indented block
```

#### 4. Неправильне використання ключових слів

```python
# ❌ Неправильно
for i in range(5)
    print(i)

# ✅ Правильно
for i in range(5):
    print(i)
```

#### 5. Неправильне присвоєння

```python
# ❌ Неправильно
5 = x

# ✅ Правильно
x = 5
```

**Помилка:**

```
SyntaxError: cannot assign to literal
```

### Як виправляти синтаксичні помилки:

1. **Читайте повідомлення про помилку** — Python вказує рядок і тип проблеми
2. **Перевірте рядок, на який вказує помилка** — іноді помилка на попередньому рядку!
3. **Шукайте типові проблеми:**
   - Відсутні двокрапки (`:`)
   - Незакриті дужки/лапки
   - Неправильні відступи
4. **Використовуйте IDE** — багато IDE підсвічують синтаксичні помилки

## Помилки виконання (Runtime Errors)

### Що таке помилка виконання?

**Runtime Error (Exception)** — помилка, яка виникає **під час роботи** програми.

**Характеристики:**

-   Синтаксис правильний
-   Програма запустилася
-   Помилка виникла в конкретному місці

### Найпоширеніші помилки виконання:

#### 1. ZeroDivisionError

**Коли:** Ділення на нуль.

```python
x = 10
y = 0
result = x / y
```

**Помилка:**

```
ZeroDivisionError: division by zero
```

**Виправлення:**

```python
x = 10
y = 0

if y != 0:
    result = x / y
    print(result)
else:
    print("Не можна ділити на нуль!")
```

#### 2. ValueError

**Коли:** Неправильне значення для операції.

```python
age = int(input("Вік: "))
```

**Вхід:** `abc`

**Помилка:**

```
ValueError: invalid literal for int() with base 10: 'abc'
```

**Виправлення:**

```python
age_str = input("Вік: ")

if age_str.isdigit():
    age = int(age_str)
    print("Ваш вік:", age)
else:
    print("Будь ласка, введіть число!")
```

#### 3. NameError

**Коли:** Використання неіснуючої змінної.

```python
print(x)  # x не визначена!
```

**Помилка:**

```
NameError: name 'x' is not defined
```

**Виправлення:**

```python
x = 10  # Спочатку визначаємо
print(x)
```

#### 4. TypeError

**Коли:** Неправильний тип даних для операції.

```python
result = "5" + 10
```

**Помилка:**

```
TypeError: can only concatenate str (not "int") to str
```

**Виправлення:**

```python
# Спосіб 1: Конкатенація рядків
result = "5" + str(10)

# Спосіб 2: Арифметика
result = int("5") + 10
```

#### 5. IndentationError

**Коли:** Неправильні відступи.

```python
if x > 5:
print("Більше 5")
  print("Ще рядок")
```

**Помилка:**

```
IndentationError: unexpected indent
```

**Виправлення:**

```python
if x > 5:
    print("Більше 5")
    print("Ще рядок")
```

### Як виправляти runtime помилки:

1. **Читайте тип помилки** — назва говорить про проблему
2. **Дивіться на рядок помилки** — Python точно вказує місце
3. **Аналізуйте причину:**
   - `ZeroDivisionError` → перевірте дільник
   - `ValueError` → перевірте ввід
   - `NameError` → визначте змінну
   - `TypeError` → перевірте типи даних
4. **Додайте перевірки** — передбачайте можливі проблеми

## Логічні помилки (Logic Errors)

### Що таке логічна помилка?

**Логічна помилка** — це коли програма працює, але робить **не те, що ви хочете**.

**Характеристики:**

-   ❌ Python не видає помилку
-   ❌ Програма не падає
-   ❌ Результат неправильний
-   ✅ Проблема в логіці програміста

### Приклади логічних помилок:

#### Приклад 1: Пріоритет операцій

```python
# Хочемо середнє арифметичне
a = 10
b = 20
average = a + b / 2
print(average)  # Виведе 20.0, а не 15.0
```

**Проблема:** `/` має вищий пріоритет, ніж `+`

**Що відбувається:**

```python
average = a + (b / 2)  # 10 + 10 = 20
```

**Виправлення:**

```python
average = (a + b) / 2  # (10 + 20) / 2 = 15
```

#### Приклад 2: Неправильний діапазон

```python
# Хочемо суму від 1 до 10
total = 0
for i in range(10):
    total = total + i
print(total)  # Виведе 45, а не 55
```

**Проблема:** `range(10)` → 0, 1, 2, ..., 9 (без 10)

**Виправлення:**

```python
total = 0
for i in range(1, 11):  # 1, 2, 3, ..., 10
    total = total + i
print(total)  # Виведе 55
```

#### Приклад 3: Неправильна умова

```python
# Хочемо перевірити, чи x в діапазоні 10-20
x = 15

if x > 10 and x < 20:
    print("В діапазоні")
else:
    print("Поза діапазоном")
```

**Проблема:** Що якщо `x = 10` або `x = 20`?

**Вхід:** `x = 10` → виведе "Поза діапазоном" (але ми хотіли включно?)

**Виправлення (якщо включно):**

```python
if x >= 10 and x <= 20:
    print("В діапазоні")
```

#### Приклад 4: Неправильна зміна змінної

```python
# Хочемо подвоїти число 5 разів
x = 1
for i in range(5):
    x = x + x  # Це помножити на 2, правильно?
print(x)
```

**Результат:** 32  
**Очікували:** 2, 4, 8, 16, 32 → так, це правильно!

**Але якщо хотіли зробити інакше:**

```python
# Якщо хотіли x = x + 1 п'ять разів
x = 1
for i in range(5):
    x = x + 1
print(x)  # 6
```

#### Приклад 5: Помилка off-by-one

```python
# Хочемо вивести "Привіт" 10 разів
for i in range(1, 10):  # ПОМИЛКА!
    print("Привіт")
```

**Проблема:** `range(1, 10)` → 1, 2, ..., 9 (9 разів, а не 10)

**Виправлення:**

```python
for i in range(1, 11):  # 1, 2, ..., 10 (10 разів)
    print("Привіт")
```

або

```python
for i in range(10):  # 0..9 (10 разів)
    print("Привіт")
```

### Як знаходити логічні помилки:

1. **Перевірте очікуваний результат** — що має бути?
2. **Перевірте фактичний результат** — що є?
3. **Використовуйте print()** — виводьте проміжні значення
4. **Виконайте код ментально** — пройдіться по кроках вручну
5. **Перевірте граничні випадки** — 0, 1, максимум, мінімум
6. **Спростіть код** — зменште до мінімуму і знайдіть проблему

## Читання Traceback

### Що таке Traceback?

**Traceback** — це **звіт про помилку** від Python. Він показує:

-   Тип помилки
-   Повідомлення
-   Де саме виникла помилка

### Структура Traceback:

```
Traceback (most recent call last):
  File "script.py", line 3, in <module>
    result = 10 / x
ZeroDivisionError: division by zero
```

**Розбір:**

```
Traceback (most recent call last):  ← "Ось що сталося:"
  File "script.py", line 3, in <module>  ← Файл і рядок
    result = 10 / x  ← Проблемний код
ZeroDivisionError: division by zero  ← Тип помилки і опис
```

### Як читати Traceback:

#### 1. Почніть знизу

**Найважливіша інформація — ВНИЗУ!**

```
Traceback (most recent call last):
  File "script.py", line 3, in <module>
    result = 10 / x
ZeroDivisionError: division by zero  ← ПОЧНІТЬ ЗВІДСИ!
```

**Питання:**

-   Який тип помилки? → `ZeroDivisionError`
-   Що означає? → Ділення на нуль

#### 2. Дивіться на рядок коду

```
  File "script.py", line 3, in <module>
    result = 10 / x  ← ОСЬ ДЕ ПОМИЛКА
```

**Питання:**

-   У якому рядку? → рядок 3
-   Який код? → `result = 10 / x`

#### 3. Аналізуйте причину

```
result = 10 / x
ZeroDivisionError: division by zero
```

**Висновок:** `x` дорівнює 0!

### Приклад детального розбору:

**Код:**

```python
x = int(input("Введіть число: "))
y = 100 / x
print("Результат:", y)
```

**Вхід:** `0`

**Traceback:**

```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    y = 100 / x
ZeroDivisionError: division by zero
```

**Читання:**

1. **Тип помилки:** `ZeroDivisionError` — ділення на нуль
2. **Де:** файл `test.py`, рядок 2
3. **Що:** `y = 100 / x`
4. **Чому:** `x` дорівнює 0

**Виправлення:**

```python
x = int(input("Введіть число: "))

if x != 0:
    y = 100 / x
    print("Результат:", y)
else:
    print("Помилка: не можна ділити на нуль!")
```

### Складніший Traceback (кілька рядків):

**Код:**

```python
def divide(a, b):
    return a / b

x = 10
y = 0
result = divide(x, y)
```

**Traceback:**

```
Traceback (most recent call last):
  File "test.py", line 6, in <module>
    result = divide(x, y)
  File "test.py", line 2, in divide
    return a / b
ZeroDivisionError: division by zero
```

**Читання:**

```
Рядок 6: result = divide(x, y)  ← Тут викликали функцію
    ↓
Рядок 2: return a / b  ← Тут виникла помилка
    ↓
ZeroDivisionError  ← Помилка ділення на нуль
```

### Поради для читання Traceback:

1. **Не панікуйте!** — Traceback — ваш друг
2. **Читайте знизу вгору** — тип помилки внизу
3. **Знайдіть свій код** — іноді traceback містить рядки з бібліотек
4. **Дивіться на номер рядка** — це точне місце
5. **Аналізуйте код у цьому рядку** — що могло піти не так?

## Print-debugging: основний метод

### Що таке print-debugging?

**Print-debugging** — це техніка дебагінгу за допомогою **`print()`** для виведення проміжних значень.

**Ідея:** Якщо не знаємо, що відбувається в програмі — виведемо все на екран!

### Базовий приклад:

**Код з помилкою:**

```python
x = 5
y = 10
result = x + y * 2
print("Результат:", result)
```

**Очікували:** (5 + 10) * 2 = 30  
**Отримали:** 25

**Додаємо print для дебагінгу:**

```python
x = 5
y = 10

print("DEBUG: x =", x)
print("DEBUG: y =", y)

result = x + y * 2

print("DEBUG: result =", result)
print("Результат:", result)
```

**Виведення:**

```
DEBUG: x = 5
DEBUG: y = 10
DEBUG: result = 25
Результат: 25
```

**Знайшли проблему:** Пріоритет операцій! `y * 2` обчислюється першим.

**Виправлення:**

```python
result = (x + y) * 2
```

### Техніки print-debugging:

#### 1. Виведення значень змінних

```python
x = 10
print("DEBUG: x =", x)

y = x * 2
print("DEBUG: y =", y)
```

#### 2. Маркери виконання

```python
print("DEBUG: Початок програми")

x = int(input("Число: "))

print("DEBUG: Після вводу, x =", x)

if x > 0:
    print("DEBUG: x додатнє")
    result = x * 2
else:
    print("DEBUG: x не додатнє")
    result = 0

print("DEBUG: Кінець програми")
```

**Користь:** Бачимо, яка гілка if виконується.

### Приклад реального дебагінгу:

**Проблема:** Програма рахує факторіал, але видає неправильний результат.

```python
    factorial = factorial * i

```

**Вихід:** `Факторіал 5 = 0` ❌ (має бути 120)

**Додаємо print-debugging:**

```python
n = 5
factorial = 1

print("DEBUG: Початок, factorial =", factorial)

for i in range(n):
    print("DEBUG: i =", i, ", factorial до множення =", factorial)
    factorial = factorial * i
    print("DEBUG: factorial після множення =", factorial)

print("Факторіал", n, "=", factorial)
```

**Виведення:**

```

DEBUG: i = 0 , factorial до множення = 1
DEBUG: factorial після множення = 0  ← ОТ ВОНа проблема!
DEBUG: i = 1 , factorial до множення = 0
DEBUG: factorial після множення = 0
DEBUG: i = 2 , factorial до множення = 0
DEBUG: factorial після множення = 0
...
Факторіал 5 = 0
```

**Знайшли проблему:** `i = 0` на першій ітерації! `1 * 0 = 0`

**Виправлення:**

```python
for i in range(1, n + 1):  # Починаємо з 1, а не 0
    factorial = factorial * i
```

## Техніка "Розділяй і володарюй"

### Принцип

**Розділяй і володарюй (Divide and Conquer)** — розбийте проблему на менші частини і перевіряйте кожну окремо.

### Процес:

```
Велика проблема
    ↓
Розділити навпіл
    ↓
Перевірити першу половину → OK або ПОМИЛКА
Перевірити другу половину → OK або ПОМИЛКА
    ↓
Якщо помилка знайдена → Розділити ЦЮ частину навпіл
    ↓
Повторювати до знаходження точного місця
```

### Приклад:

**Код (100 рядків):**

```python
# Рядки 1-25: Ввід даних
# Рядки 26-50: Обчислення 1
# Рядки 51-75: Обчислення 2
# Рядки 76-100: Виведення
```

**Крок 1:** Додайте print після рядка 50:

```python
# Рядок 50
print("DEBUG: Checkpoint 1")
```

-   Якщо виводиться → проблема в рядках 51-100
-   Якщо не виводиться → проблема в рядках 1-50

**Крок 2:** Розділіть проблемну частину навпіл:

```python
# Якщо проблема в 1-50, додайте print після рядка 25
print("DEBUG: Checkpoint 2")
```

**Крок 3:** Повторюйте до знаходження точного рядка.

### Практичний приклад:

**Код:**

```python
a = 10
b = 20
c = 30

result1 = a + b
result2 = result1 * c
result3 = result2 / a
result4 = result3 - b

print("Фінальний результат:", result4)
```

**Проблема:** Результат неправильний.

**Дебагінг:**

```python
a = 10
b = 20
c = 30

result1 = a + b
print("DEBUG 1: result1 =", result1)  # Перевірка

result2 = result1 * c
print("DEBUG 2: result2 =", result2)  # Перевірка

result3 = result2 / a
print("DEBUG 3: result3 =", result3)  # Перевірка

result4 = result3 - b
print("DEBUG 4: result4 =", result4)  # Перевірка

print("Фінальний результат:", result4)
```

**Виведення:**

```

DEBUG 2: result2 = 900
DEBUG 3: result3 = 90.0
DEBUG 4: result4 = 70.0
Фінальний результат: 70.0
```

Тепер можемо перевірити кожен крок і знайти, де результат стає неправильним!

## Перевірка припущень

### Що таке припущення?

**Припущення** — це те, що ви **думаєте**, що відбувається в коді, але не **перевірили**.

### Поширені помилкові припущення:

#### Припущення 1: "input() повертає число"

```python
x = input("Число: ")
y = x + 10  # TypeError!
```

**Проблема:** `input()` **завжди** повертає рядок!

**Перевірка:**

```python
x = input("Число: ")
print("DEBUG: type(x) =", type(x))
```

#### Припущення 2: "range(10) включає 10"

```python
for i in range(10):
    print(i)  # 0..9, БЕЗ 10!
```

**Перевірка:**

```python
print("DEBUG: range(10) створює:", list(range(10)))
```

*(Примітка: Використання `list()` тут лише для демонстрації)*

#### Припущення 3: "Ділення повертає ціле"

```python
result = 10 / 4
print(result)  # 2.5, а не 2
```

**Перевірка:**

```python
result = 10 / 4
print("DEBUG: result =", result, ", type =", type(result))
```

#### Припущення 4: "Оператори виконуються зліва направо"

```python
result = 10 + 5 * 2
print(result)  # 20, а не 30
```

**Проблема:** Пріоритет операцій!

**Перевірка:**

```python
print("DEBUG: 10 + 5 * 2 =", 10 + 5 * 2)
print("DEBUG: (10 + 5) * 2 =", (10 + 5) * 2)
```

### Правило: "Не довіряй, перевіряй!"

```python
# ❌ Припущення
x = input("Число: ")
y = x * 2  # Думаємо, що це множення

# ✅ Перевірка
x = input("Число: ")
print("DEBUG: x =", x, ", type =", type(x))
y = x * 2
print("DEBUG: y =", y)
```

## Покрокове ментальне виконання

### Що це?

**Ментальне виконання** — це коли ви **вручну** проходите по кожному рядку коду і **стежите за значеннями** змінних.

### Як це робити:

1. Візьміть папір і ручку
2. Створіть таблицю для змінних
3. Виконуйте код рядок за рядком
4. Записуйте зміни змінних

### Приклад:

**Код:**

```python
x = 5
y = 10
x = x + y
y = x - y
x = x - y
print("x =", x, ", y =", y)
```

**Покрокове виконання:**

| Крок | Код            | x   | y   | Пояснення        |
| ---- | -------------- | --- | --- | ---------------- |
| 1    | `x = 5`        | 5   | ?   | x тепер 5        |
| 2    | `y = 10`       | 5   | 10  | y тепер 10       |
| 3    | `x = x + y`    | 15  | 10  | x = 5 + 10 = 15  |
| 4    | `y = x - y`    | 15  | 5   | y = 15 - 10 = 5  |
| 5    | `x = x - y`    | 10  | 5   | x = 15 - 5 = 10  |
| 6    | `print(...)`   | 10  | 5   | Виводимо x=10, y=5 |

**Результат:** `x = 10 , y = 5` (обмін значень!)

### Приклад з циклом:

**Код:**

```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)
```

**Покрокове виконання:**

| Крок | Код                 | total | i   | Пояснення            |
| ---- | ------------------- | ----- | --- | -------------------- |
| 1    | `total = 0`         | 0     | ?   | Ініціалізація        |
| 2    | `for i in range...` | 0     | 1   | Початок циклу, i=1   |
| 3    | `total = total + i` | 1     | 1   | 0 + 1 = 1            |
| 4    | (цикл)              | 1     | 2   | Наступна ітерація    |
| 5    | `total = total + i` | 3     | 2   | 1 + 2 = 3            |
| 6    | (цикл)              | 3     | 3   | Наступна ітерація    |
| 7    | `total = total + i` | 6     | 3   | 3 + 3 = 6            |
| 8    | (цикл закінчився)   | 6     | -   | i більше не існує    |
| 9    | `print(total)`      | 6     | -   | Виводимо 6           |

### Приклад з умовами:

**Код:**

```python
x = 15

if x > 10:
    result = "Велике"
else:
    result = "Мале"

print(result)
```

**Покрокове виконання:**

| Крок | Код                 | x   | result  | Пояснення         |
| ---- | ------------------- | --- | ------- | ----------------- |
| 1    | `x = 15`            | 15  | ?       | x тепер 15        |
| 2    | `if x > 10:`        | 15  | ?       | 15 > 10? Так!     |
| 3    | `result = "Велике"` | 15  | "Велике"| Виконуємо if      |
| 4    | (else пропускаємо)  | 15  | "Велике"| else не виконується |
| 5    | `print(result)`     | 15  | "Велике"| Виводимо "Велике" |

### Коли використовувати:

-   ✅ Для короткого коду (10-20 рядків)
-   ✅ Для складної логіки
-   ✅ Для циклів з малою кількістю ітерацій
-   ✅ Коли print-debugging не допомагає
-   ❌ Для великого коду (занадто довго)
-   ❌ Для циклів з багатьма ітераціями

## Помилки з відступами

### Чому відступи важливі?

У Python **відступи — це частина синтаксису**! Вони визначають блоки коду.

### Правила відступів:

1. **Стандарт: 4 пробіли**
2. **Консистентність:** Весь код — однакові відступи
3. **НІКОЛИ не змішуйте** табуляції та пробіли

### Помилка 1: Відсутній відступ

```python
# ❌
if x > 5:
print("Більше 5")
```

**Помилка:**

```
IndentationError: expected an indented block
```

**Виправлення:**

```python
# ✅
if x > 5:
    print("Більше 5")
```

### Помилка 2: Зайвий відступ

```python
# ❌
x = 10
    print(x)  # Чому відступ?
```

**Помилка:**

```
IndentationError: unexpected indent
```

**Виправлення:**

```python
# ✅
x = 10
print(x)
```

### Помилка 3: Непослідовні відступи

```python
# ❌
if x > 5:
    print("Рядок 1")  # 4 пробіли
      print("Рядок 2")  # 6 пробілів - помилка!
```

**Виправлення:**

```python
# ✅
if x > 5:
    print("Рядок 1")  # 4 пробіли
    print("Рядок 2")  # 4 пробіли
```

### Помилка 4: Плутанина в блоках

```python
# ❌
if x > 5:
    print("Більше 5")
      if x > 10:  # Занадто великий відступ!
        print("Більше 10")

# ✅
if x > 5:
    print("Більше 5")
    if x > 10:  # Правильний відступ для вкладеного if
        print("Більше 10")
```

### Поради:

1. **Використовуйте IDE** — автоматичні відступи
2. **Налаштуйте редактор** — таб = 4 пробіли
3. **Будьте консистентні** — весь код однаково
4. **Перевіряйте візуально** — чи всі рядки вирівняні?

## Практичні приклади дебагінгу

### Приклад 1: Знаходження помилки в обчисленні

**Код:**

```python
# Програма для обчислення середнього
a = int(input("Перше число: "))
b = int(input("Друге число: "))
c = int(input("Третє число: "))

average = a + b + c / 3
print("Середнє:", average)
```

**Проблема:**  
Вхід: `10, 20, 30`  
Очікували: `20`  
Отримали: `40.0`

**Дебагінг:**

```python
a = int(input("Перше число: "))
b = int(input("Друге число: "))
c = int(input("Третє число: "))

print("DEBUG: a =", a)
print("DEBUG: b =", b)
print("DEBUG: c =", c)

average = a + b + c / 3
print("DEBUG: average =", average)
print("DEBUG: a + b + c =", a + b + c)
print("DEBUG: c / 3 =", c / 3)

print("Середнє:", average)
```

**Виведення:**

```
DEBUG: a = 10
DEBUG: b = 20
DEBUG: c = 30
DEBUG: average = 40.0
DEBUG: a + b + c = 60
DEBUG: c / 3 = 10.0
```

**Знайшли проблему:** Пріоритет операцій! `c / 3` обчислюється першим.

**Виправлення:**

```python
average = (a + b + c) / 3
```

### Приклад 2: Помилка в циклі

**Код:**

```python
# Підрахунок парних чисел
count = 0

    if i % 2 == 0:
        count = 0
```

**Проблема:**

```python
count = 0
for i in range(1, 11):

    if i % 2 == 0:
```

```
DEBUG: i парне!
DEBUG: count після = 1
DEBUG: i = 3 , count до перевірки = 1
DEBUG: i = 4 , count до перевірки = 1
DEBUG: i парне!
DEBUG: count після = 1  ← Скидається до 0!
...
```

**Знайшли проблему:** `count = 0` всередині if скидає лічильник!

### Приклад 3: Логічна помилка в умові

**Код:**

```python
# Перевірка паролю
password = input("Введіть пароль: ")

if password == "secret" or "password":
    print("Доступ дозволено")
else:
```

**Проблема:** Будь-який пароль підходить!

```python
if password == "secret" or "password":
```

```python
if (password == "secret") or ("password"):
```

**Дебагінг:**

```python
password = input("Введіть пароль: ")

print("DEBUG: password =", password)

print("DEBUG: 'password' =", "password")
print("DEBUG: bool('password') =", bool("password"))

if password == "secret" or "password":
    print("Доступ дозволено")
else:
    print("Доступ заборонено")
```

**Виправлення:**

```python
if password == "secret" or password == "password":
    print("Доступ дозволено")
else:
    print("Доступ заборонено")
```

### Приклад 4: Помилка в факторіалі

**Код:**

```python
n = 5
factorial = 1

for i in range(n):
    factorial = factorial * i

print("Факторіал", n, "=", factorial)
```

**Проблема:**  
Очікували: `120`  
Отримали: `0`

**Дебагінг:**

```python
n = 5
factorial = 1

print("DEBUG: Початок, factorial =", factorial)

for i in range(n):
    print("DEBUG: i =", i, ", factorial до =", factorial)
    factorial = factorial * i
    print("DEBUG: factorial після =", factorial)

print("Факторіал", n, "=", factorial)
```

**Виведення:**

```
DEBUG: Початок, factorial = 1
DEBUG: i = 0 , factorial до = 1
DEBUG: factorial після = 0  ← ОСЬ ПРОБЛЕМА!
DEBUG: i = 1 , factorial до = 0
DEBUG: factorial після = 0
...
```

**Знайшли проблему:** `range(n)` починається з 0! `1 * 0 = 0`

**Виправлення:**

```python
for i in range(1, n + 1):  # Від 1 до n включно
    factorial = factorial * i
```

### Приклад 5: Нескінченний цикл

**Код:**

```python
x = 0

while x != 10:
    print(x)
    x = x + 2
```

**Проблема:** Програма зависає!

**Чому:** `x` стає `0, 2, 4, 6, 8, 10, 12, 14...` — пропускає 10!

**Дебагінг (додаємо аварійний вихід):**

```python
x = 0
iterations = 0

while x != 10:
    print("DEBUG: x =", x)
    x = x + 2
    
    iterations = iterations + 1
    if iterations > 20:
        print("ПОПЕРЕДЖЕННЯ: Занадто багато ітерацій!")
        break
```

**Виведення:**

```
DEBUG: x = 0
DEBUG: x = 2
DEBUG: x = 4
DEBUG: x = 6
DEBUG: x = 8
DEBUG: x = 10  ← x тепер 10, але цикл продовжується!
DEBUG: x = 12
...
```

**Знайшли проблему:** Умова `x != 10` спрацьовує після 10!

**Виправлення:**

```python
while x < 10:  # Замість != використовуємо <
    print(x)
    x = x + 2
```

## Підсумок

### Основні концепції:

1. **Дебагінг** — це нормальна частина програмування
2. **Три типи помилок:**
   - Синтаксичні (до запуску)
   - Виконання (під час роботи)
   - Логічні (неправильний результат)
3. **Traceback** — ваш друг, читайте його!
4. **Print-debugging** — найпростіший і ефективний метод
5. **Стратегії:**
   - Читайте помилку
   - Спрощуйте код
   - Перевіряйте припущення
   - Розділяй і володарюй

### Золоті правила дебагінгу:

1. **Не панікуйте** — помилки — це нормально
2. **Читайте уважно** — Python говорить, що не так
3. **Виводьте все** — print() — ваш кращий друг
4. **Спрощуйте** — зменшіть код до мінімуму
5. **Перевіряйте** — не вірте припущенням
6. **Тестуйте часто** — після кожних 5-10 рядків
7. **Вчіться на помилках** — кожна помилка — урок

### Типові помилки початківців:

-   Забута двокрапка
-   Неправильний відступ
-   Забута конвертація input()
-   Off-by-one в range()
-   Нескінченний цикл
-   = замість ==
-   Ділення на нуль

### Інструменти дебагінгу:

1. **print()** — основний інструмент
2. **type()** — перевірка типу
3. **Коментарі** — відключення коду
4. **Ментальне виконання** — вручну
5. **IDE debugger** — для складних випадків
