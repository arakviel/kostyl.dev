# Вправи до уроку 5: Колекції в Python

## Рівень 1: Початковий

### Завдання 1.1: Створення та базові операції зі списками

Створіть список з 5-ти різних фруктів. Виконайте такі операції:

1. Додайте ще один фрукт у кінець списку
2. Вставте новий фрукт на другу позицію (індекс 1)
3. Виведіть довжину списку
4. Виведіть третій елемент списку
5. Виведіть останні 3 фрукти

### Завдання 1.2: Робота з кортежами

Створіть кортеж, що містить координати точки (x, y). Виконайте:

1. Створіть кортеж з координатами (10, 20)
2. Розпакуйте кортеж у дві змінні x та y
3. Виведіть значення x та y
4. Створіть новий кортеж, що містить суму та різницю x та y

### Завдання 1.3: Основи роботи з множинами

Створіть дві множини з різних кольорів:

1. Створіть множину з кольорами: "червоний", "синій", "зелений"
2. Створіть другу множину з кольорами: "жовтий", "синій", "пурпурний"
3. Знайдіть об'єднання двох множин
4. Знайдіть перетин множин
5. Перевірте, чи міститься колір "зелений" у першій множині

## Рівень 2: Середній

### Завдання 2.1: Словник користувача

Створіть словник, що представляє інформацію про користувача:

1. Створіть словник з ключами: "ім'я", "вік", "місто", "професія"
2. Заповніть його власними даними
3. Додайте новий ключ "хобі" зі списком улюблених справ
4. Виведіть всі ключі словника
5. Виведіть всі значення словника
6. Перевірте, чи існує ключ "вік" у словнику

### Завдання 2.2: Фільтрація списку

Створіть список чисел від 1 до 20 і виконайте наступне:

1. Створіть новий список з парних чисел
2. Створіть список з чисел, які діляться на 3
3. Створіть список з квадратів усіх чисел
4. Використовуйте list comprehension для виконання цих завдань

### Завдання 2.3: Аналіз тексту

Створіть програму для аналізу тексту:

1. Створіть рядок з кількома словами, де деякі повторюються
2. Розділіть текст на слова
3. Порахуйте кількість унікальних слів
4. Створіть словник, де ключі - це слова, а значення - кількість їх входжень
5. Виведіть слова, які зустрічаються більше одного разу

## Рівень 3: Просунутий

### Завдання 3.1: Матричні операції

Створіть програму для роботи з матрицями:

1. Створіть дві матриці 3x3 як вкладені списки
2. Реалізуйте додавання матриць
3. Реалізуйте транспонування матриці
4. Знайдіть суму всіх елементів матриці
5. Виведіть результати у вигляді таблиці

### Завдання 3.2: Система обліку книг

Створіть програму для обліку книг у бібліотеці:

1. Створіть словник, де ключі - це ISBN книг, а значення - словники з інформацією про книгу (назва, автор, рік видання, кількість сторінок, наявність)
2. Додайте 5-6 книг до системи
3. Реалізуйте функцію для пошуку книги за назвою
4. Реалізуйте функцію для фільтрації книг за роком видання
5. Реалізуйте функцію для підрахунку загальної кількості сторінок усіх книг

### Завдання 3.3: Аналіз даних про студентів

Створіть систему для аналізу даних про студентів:

1. Створіть список словників, де кожен словник представляє студента з такими даними: ім'я, вік, курс, список оцінок з різних предметів
2. Додайте 5-7 студентів до системи
3. Реалізуйте функцію для обчислення середнього балу кожного студента
4. Знайдіть студента з найвищим середнім балом
5. Розрахуйте середній бал для кожного курсу
6. Створіть словник, де ключі - це предмети, а значення - списки оцінок усіх студентів з цього предмету

## Додаткові завдання

### Завдання: Гра "Морський бій"

Реалізуйте спрощену версію гри "Морський бій":

1. Створіть ігрове поле 10x10 як вкладений список
2. Розмістіть 5 кораблів (однопалубних) на полі
3. Організуйте ігровий цикл, де гравець вводить координати пострілу
4. Перевіряйте, чи влучив гравець у корабель
5. Ведіть облік влучень і промахів
6. Гра триває, доки гравець не потопить усі кораблі
7. Виводьте ігрове поле після кожного пострілу

### Завдання: Телефонна книга

Створіть програму "Телефонна книга":

1. Реалізуйте зберігання контактів у словнику, де ключі - імена, а значення - словники з інформацією (телефон, email, адреса)
2. Додайте можливість додавання, видалення та редагування контактів
3. Реалізуйте пошук контакту за ім'ям
4. Реалізуйте пошук за телефоном
5. Виведіть список усіх контактів у відсортованому вигляді
6. Зберігайте дані у файлі для можливості завантаження при наступному запуску

## Підказки та рекомендації

1. Для кожного завдання створюйте окремий Python-файл
2. Використовуйте функції для структурування коду
3. Додавайте коментарі до складних ділянок коду
4. Перевіряйте роботу програми на різних вхідних даних
5. Використовуйте list/dict/set comprehension там, де це доречно
6. Для складних структур даних використовуйте вкладені колекції
