# Створюємо файл з кодом, де є порожні рядки

### Рівень 1: "Прибиральник" (Форматування та читання частинами)

**Мета:** Навчитися чистити дані та читати не весь файл одразу.

1. **Видалення порожніх рядків (Cleaner).**

-   **Дано:** Файл `script_dirty.txt` (створений вище).
-   **Завдання:** Прочитати файл. Створити новий файл `script_clean.txt`, у який записати лише ті рядки, що містять текст (не порожні).
-   **Підказка:** Метод `line.strip()` допоможе перевірити, чи рядок порожній.
-   **Що тренуємо:** `readlines()`, перевірка вмісту рядка.

2. **Нумерація рядків (Editor).**

-   **Дано:** Будь-який текстовий файл (можна той же `script_clean.txt`).
-   **Завдання:** Прочитати файл і перезаписати його так, щоб перед кожним рядком стояв його номер.
-   _Приклад:_ `1. def hello():`
-   **Що тренуємо:** `enumerate`, f-рядки, запис у файл.

3. **Команда Head (Partial Read).**

-   **Дано:** Великий текстовий файл (або уявимо, що він великий).
-   **Завдання:** Написати функцію, яка приймає ім'я файлу та число `N`. Вона має вивести на екран **тільки перші N рядків** файлу.
-   **Важливо:** Не використовувати `read()` (читати все), бо файл може бути на 10 ГБ. Використовувати цикл або `readline()`.
-   **Що тренуємо:** Оптимізація пам'яті, переривання циклу `break`.

### Рівень 2: "Менеджер даних" (CSV модуль та конфіги)

**Мета:** Використання вбудованого модуля `csv` (це стандарт індустрії) та парсинг форматів "ключ=значення".

1. **Аналіз продажів (CSV Reader).**

-   **Дано:** Файл `inventory.csv`.
-   **Завдання:** Використати `import csv`. Відкрити файл, порахувати загальну вартість товарів на складі (Price \* Quantity) для кожного рядка і вивести загальну суму.
-   **Що тренуємо:** `csv.DictReader` (дуже зручно, бо звертаєшся по назвах колонок: `row['Price']`), приведення типів.

2. **Парсер налаштувань (.env).**

-   **Дано:** Створи файл `.env` з текстом:

```text
DB_HOST=localhost
DB_PORT=5432
DEBUG=True

```

-   **Завдання:** Прочитати файл і перетворити його у словник Python:
    `{'DB_HOST': 'localhost', 'DB_PORT': '5432', ...}`.
-   **Логіка:** Розділяти рядок по знаку `=` (split).
-   **Що тренуємо:** Робота з рядками, наповнення словника.

3. **Генератор CSV (CSV Writer).**

-   **Дано:** Список користувачів (список кортежів або словників):
    `users = [("Alex", "admin"), ("Bob", "guest"), ("Charlie", "user")]`
-   **Завдання:** Зберегти ці дані у файл `users.csv`.
-   **Важливо:** Використати `csv.writer`. Першим рядком записати заголовки: `Name, Role`.
-   **Що тренуємо:** `csv.writer`, метод `writerows`.

### Рівень 3: "Системний адміністратор" (Бінарні файли та HTML)

**Мета:** Робота з картинками (як з байтами), генерація веб-сторінок та ротація логів.

1. **Крадій картинок (Binary Mode).**

-   **Дано:** Будь-яка картинка `image.jpg` (або `png`) на комп'ютері. (Якщо немає, спробуй скопіювати будь-який `.exe` або `.pdf`).
-   **Завдання:** Відкрити картинку для читання в **бінарному режимі** (`rb`). Відкрити новий файл `image_copy.jpg` для запису в бінарному режимі (`wb`). Прочитати байти з першого і записати в другий.
-   **Чому це важливо:** Якщо відкрити картинку як текст (`r`), Python видасть помилку кодування.
-   **Що тренуємо:** Режими `rb`, `wb`.

2. **HTML-генератор (Report).**

-   **Дано:** Словник з даними про погоду: `{'Kyiv': 20, 'Lviv': 18, 'Odesa': 25}`.
-   **Завдання:** Згенерувати файл `weather.html`.
-   **Вимоги:** Файл має містити HTML-код таблиці (`<table>`), де будуть виведені міста і температури. Після запуску скрипта, відкрити цей файл у браузері і побачити табличку.
-   **Що тренуємо:** Генерація складних рядків, запис у файл з розширенням, відмінним від .txt.

3. **Ротація логів (Log Rotation).**

-   **Сценарій:** У нас є файл `app.log`.
-   **Завдання:** Написати скрипт, який імітує запис логу.

1. Перевірити розмір файлу `app.log` (модуль `os.path.getsize` або просто прочитати `len()` вмісту, якщо файл невеликий).
2. Якщо файл більший за 100 символів — перейменувати його в `app_old.log` (або видалити вміст) і почати писати в новий чистий `app.log`.

-   **Що тренуємо:** Логіка обслуговування файлів, модуль `os` (для перейменування/видалення).
