### Рівень 1: "Секретар" (Читання та Запис)

**Мета:** Освоїти режими `w` (write), `r` (read), `a` (append) та менеджер контексту.

1. **Особистий щоденник (Write/Append).**

- **Завдання:** Написати скрипт, який запитує у користувача: "Що нового?".
- Отриманий текст треба **дописати** в кінець файлу `diary.txt`.
- Важливо: Кожен новий запис має бути з нового рядка.
- **Що тренуємо:** Режим `open(..., "a")` (append), символ переносу `\n`.

2. **Лічильник слів (Read).**

- **Дано:** Будь-який текстовий файл (можна використати той самий `diary.txt`).
- **Завдання:** Відкрити файл, прочитати весь текст і вивести в консоль:
- Загальну кількість символів.
- Кількість слів (підказка: метод `.split()`).

- **Що тренуємо:** `file.read()`, методи рядків.

3. **Копіювальний апарат (Read + Write).**

- **Дано:** Файл `source.txt` з будь-яким текстом.
- **Завдання:** Створити скрипт, який читає `source.txt` і створює новий файл `backup.txt`, копіюючи туди вміст.
- _Ускладнення:_ При копіюванні перетворити весь текст у ВЕРХНІЙ РЕГІСТР.
- **Що тренуємо:** Одночасна робота з двома файлами (читання з одного, запис в інший).

### Рівень 2: "Аналітик" (Порядкова обробка та CSV)

**Мета:** Навчитися читати файл рядок за рядком (щоб не забити пам'ять, якщо файл великий) і парсити прості структури.

1. **Калькулятор оцінок (Processing).**

- **Дано:** Файл `students.txt` (формат: `Ім'я,Бали`), який ми створили на початку.
- **Завдання:**

1. Прочитати файл рядок за рядком (`for line in file:`).
2. Розділити кожен рядок по комі (`split(',')`).
3. Перетворити бали в число (`int`).
4. Порахувати і вивести середній бал по групі.

- **Що тренуємо:** Парсинг рядків, конвертація типів, ітерація по файлу.

2. **Фільтр логів (Search).**

- **Дано:** Створи файл `server.log` з таким змістом:

```text
[INFO] Server started
[ERROR] Database connection failed
[INFO] User logged in
[ERROR] Timeout exception
[WARNING] High memory usage

```

- **Завдання:** Прочитати цей файл. Знайти всі рядки, що містять слово `[ERROR]`, і записати їх в окремий файл `errors_only.txt`.
- **Що тренуємо:** Умови `if "text" in line`, фільтрація даних.

3. **Заміна слів (Modify).**

- **Дано:** Текстовий файл з "поганими" словами (наприклад "java").
- **Завдання:** Прочитати файл. Замінити всі входження слова "java" на "python". Перезаписати файл оновленим текстом (або зберегти в новий).
- **Що тренуємо:** `replace()`, читання всього вмісту в змінну.

### Рівень 3: "Backend Developer" (JSON та Структури)

**Мета:** Робота з модулем `json`, збереження складних даних (списків, словників) та обробка винятків.

1. **Конвертер (TXT -> JSON).**

- **Дано:** Файл `students.txt` (Ім'я,Бали).
- **Завдання:**

1. Прочитати файл і створити список словників у Python:
   `[{"name": "Andrii", "score": 85}, {"name": "Olena", "score": 92}, ...]`
2. Зберегти цю структуру у новий файл `students.json` за допомогою модуля `json`.

- **Що тренуємо:** `import json`, `json.dump()`, структури даних.

2. **Менеджер налаштувань (Load Config).**

- **Дано:** Файл `config.json`: `{"theme": "dark", "volume": 80, "autosave": true}`.
- **Завдання:**

1. Спробувати відкрити файл налаштувань.
2. Якщо файлу немає (`FileNotFoundError`) — створити його з налаштуваннями за замовчуванням.
3. Якщо файл є — завантажити налаштування, змінити `"volume"` на 100 і зберегти назад.

- **Що тренуємо:** `try-except`, `json.load()`, оновлення даних.

3. **Об'єднувач звітів (Merger).**

- **Дано:** У папці є три файли: `part1.txt`, `part2.txt`, `part3.txt` (створи їх з будь-яким текстом).
- **Завдання:** Скрипт має знайти всі `.txt` файли в папці (модуль `os` або `glob`), прочитати їх вміст і злити в один великий файл `full_report.txt`, додаючи розділювач між частинами (наприклад `--- FILE END ---`).
- **Що тренуємо:** Робота зі списком файлів, масова обробка.
