### Рівень 1: "Лаборант файлової системи" (FS Explorer)

_Ціль: Навчитися отримувати інформацію про файли, будувати шляхи та робити "точкові" маніпуляції всередині файлу._

**Завдання 1.1: Конструктор шляхів**

- **Дано:** Змінна з назвою папки `reports` та змінна з назвою файлу `october.txt`.
- **Завдання:**

1. Використовуючи `pathlib`, створити об'єкт шляху, який вказує на цей файл (враховуючи поточну робочу директорію).
2. Вивести: абсолютний шлях, назву батьківської директорії, та розширення файлу (suffix).
3. Перевірити, чи існує цей файл. Якщо ні — вивести попередження.

- **Що тренуємо:** `Path()`, `.resolve()`, `.parent`, `.suffix`, `.exists()`.

**Завдання 1.2: Файловий шпигун**

- **Дано:** Будь-який текстовий файл `data.txt` (створи його вручну з текстом "Hello World" всередині).
- **Завдання:**

1. Отримати розмір цього файлу в байтах.
2. Отримати час останньої модифікації та вивести його у читабельному форматі (наприклад, через `datetime.fromtimestamp`).

- **Що тренуємо:** `Path.stat().st_size`, `os.path.getmtime()` або `Path.stat().st_mtime`, перетворення timestamp.

**Завдання 1.3: Навігатор (Seek & Tell)**

- **Дано:** Текстовий файл `alphabet.txt`, в якому записано рядок: `ABCDEFGHIJKLMNOPQRSTUVWXYZ`.
- **Завдання:**

1. Відкрити файл.
2. Прочитати перші 5 букв.
3. Використати `tell()`, щоб вивести поточну позицію курсору.
4. Використати `seek()`, щоб перемістити курсор на 10-ту позицію від початку.
5. Прочитати одну літеру (це має бути 'K') і вивести її.

- **Що тренуємо:** Методи файлового об'єкта `.seek()`, `.tell()`, режими відкриття файлу.

### Рівень 2: "Системний адміністратор" (SysAdmin)

_Ціль: Масова обробка файлів, логіка сортування, переміщення та копіювання._

**Завдання 2.1: Прибиральник (Garbage Collector)**

- **Дано:** Папка `Downloads`, в якій лежать файли `.txt`, `.jpg`, `.tmp`.
- **Завдання:**

1. Пройтися циклом по всіх файлах у папці.
2. Якщо файл має розширення `.tmp` — видалити його.
3. Якщо файл має розширення `.txt` — створити підпапку `Documents` (якщо її немає) і перемістити файл туди.

- **Що тренуємо:** `Path.iterdir()` або `os.listdir()`, `Path.unlink()` (видалення), `Path.mkdir()`, `shutil.move()` або `Path.rename()`.

**Завдання 2.2: Рекурсивний пошук**

- **Дано:** Структура папок з великою вкладеністю (наприклад, `Project/src/components/header/...`).
- **Завдання:** Знайти всі файли з розширенням `.py` у папці `Project` та **всіх** її підпапках. Вивести список знайдених файлів (їхні абсолютні шляхи).
- **Що тренуємо:** `Path.rglob()` або `os.walk()` (рекурсивний обхід).

**Завдання 2.3: Бінарний редактор заголовків**

- **Дано:** Файл `config.bin` (можна створити простий файл, записавши туди байти). У першому байті файлу зберігається "версія конфігу" (число).
- **Завдання:**

1. Відкрити файл у режимі читання та запису бінарних даних (`rb+`).
2. Перевірити, чи файл не порожній.
3. Переміститися на початок (0 байт).
4. Перезаписати перший байт на значення `0x02` (версія 2).
5. Перевірити зміну, прочитавши байт знову.

- **Що тренуємо:** Режим `rb+`, робота з байтами, `seek(0)`, запис даних у середину файлу.

### Рівень 3: "Розробник утиліт" (Tool Developer)

_Ціль: Створення складних сценаріїв, синхронізація та аналіз структури._

**Завдання 3.1: Розумний бекап (Smart Backup)**

- **Дано:** Дві папки: `Source` (джерело) і `Backup` (резервна копія).
- **Завдання:** Написати скрипт, який копіює файли з `Source` в `Backup`, АЛЕ:

1. Якщо файлу в `Backup` немає — копіюємо.
2. Якщо файл є, перевіряємо час модифікації (`st_mtime`). Якщо файл у `Source` новіший — замінюємо файл у `Backup`.
3. Якщо файл у `Source` старіший або такий самий — нічого не робимо.
4. Виводити лог дій: "Copied: file.txt", "Updated: image.png", "Skipped: data.csv".

- **Що тренуємо:** Порівняння атрибутів файлів, `shutil.copy2()` (копіює дані + метадані), умовна логіка.

**Завдання 3.2: Дедуплікатор за розміром**

- **Дано:** Папка з купою файлів, деякі з яких мають однаковий вміст (або принаймні однаковий розмір).
- **Завдання:**

1. Просканувати папку.
2. Знайти файли, які мають ідентичний розмір (в байтах).
3. Вивести групи "підозрілих" файлів-дублікатів:

```
Група 1 (1024 bytes):
- file1.txt
- copy_of_file1.txt

```

- **Що тренуємо:** Словники (Dict) для групування, `os.path.getsize` або `Path.stat().st_size`, алгоритми обробки колекцій.

**Завдання 3.3: Клонування структури проекту**

- **Дано:** Папка `TemplateProject` з готовою структурою (папки `src`, `tests`, `docs` та порожні файли `__init__.py`, `README.md`).
- **Завдання:**

1. Запитати у користувача назву нового проекту (наприклад, `MyNewApp`).
2. Створити нову папку з цією назвою.
3. **Повністю відтворити** структуру папок з `TemplateProject` у `MyNewApp` (ті самі імена папок).
4. Скопіювати всі файли, але до назви кожного файлу додати префікс `new_` (наприклад, `new_README.md`).

- **Що тренуємо:** `os.walk()` для аналізу дерева, `os.path.join` / `pathlib` для склеювання нових шляхів, створення директорій, масове копіювання з перейменуванням.

**Порада для студента:**
Спробуй вирішувати завдання, використовуючи переважно модуль `pathlib`. Це сучасний стиль ("Pythonic way"). Замість `os.path.join(a, b)` пиши `a / b`. Це значно покращує читабельність коду, особливо при роботі зі шляхами Windows/Linux. Успіхів!
