### Рівень 1: "Ізолятор" (The Isolator)

_Ціль: Створити віртуальне середовище, активувати його та встановити першу сторонню бібліотеку._

**Бібліотека:** `art` (Генерує красиві ASCII-написи).

**Завдання 1.1: Чистий старт**

1. Створи нову папку для проєкту, наприклад `ascii_project`.
2. Відкрий цю папку в терміналі (або VS Code).
3. **Головна місія:** Створи віртуальне середовище.

- Команда: `python -m venv .venv`

4. Активуй його:

- Windows: `.venv\Scripts\activate`
- MacOS/Linux: `source .venv/bin/activate`

5. Переконайся, що в терміналі з'явився напис `(.venv)`.

**Завдання 1.2: Перша інсталяція**

1. Встанови бібліотеку `art`:

- Команда: `pip install art`

2. Створи файл `main.py`.
3. Напиши код, який використовує цю бібліотеку (ось готовий приклад, бо ми вчимо саме venv):

```python
from art import tprint

# tprint друкує текст великими літерами з символів
tprint("PYTHON", font="block")
tprint("IS COOL")

```

4. Запусти код. Якщо побачив красивий великий напис — ти впорався.

**Завдання 1.3: Перевірка ізоляції**

1. Деактивуй середовище командою `deactivate`.
2. Спробуй запустити `main.py` знову.
3. **Очікуваний результат:** Помилка `ModuleNotFoundError: No module named 'art'`.
4. **Пояснення:** Це доказ того, що бібліотека встановлена ТІЛЬКИ у віртуальне середовище, а не в глобальний Python. Активуй venv назад, щоб все знову запрацювало.

### Рівень 2: "Архітектор Пакетів" (Package Architect)

_Ціль: Створити власний локальний пакет (структуру папок) і зв'язати його з головним файлом._

**Завдання 2.1: Структура**
У тій же папці створи таку структуру файлів:

```text
my_project/
├── main.py           (твій файл запуску)
└── my_math/          (папка для твого пакету)
    ├── __init__.py   (порожній файл, маркер пакету)
    └── operations.py (файл з функціями)

```

**Завдання 2.2: Наповнення пакету**

1. У файл `my_math/operations.py` додай прості функції:

```python
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

```

2. Файл `my_math/__init__.py` залиш порожнім (або додай коментар `# Це пакет`). Головне, щоб він існував.

**Завдання 2.3: Імпорт і використання**

1. У файлі `main.py` імпортуй функції зі свого пакету двома способами:

```python
# Спосіб 1: Імпорт модуля
from my_math import operations

print(operations.add(10, 5))

# Спосіб 2: Імпорт конкретної функції
from my_math.operations import multiply

print(multiply(10, 5))

```

2. Запусти `main.py`. Це навчить тебе, як розбивати великі програми на маленькі модулі-пакети.

### Рівень 3: "Професійний Сетап" (Deployment Master)

_Ціль: Робота з `requirements.txt` та перенесення проєкту._

**Бібліотека:** `colorama` (Дозволяє робити кольоровий текст у консолі).

**Завдання 3.1: "Кольорова" залежність**

1. Переконайся, що venv активний.
2. Встанови нову бібліотеку: `pip install colorama`.
3. Створи файл `warning_system.py` і встав код:

```python
from colorama import init, Fore, Style

# Ініціалізація (обов'язково для Windows)
init()

print(Fore.RED + "УВАГА: Це критична помилка!" + Style.RESET_ALL)
print(Fore.GREEN + "УСПІХ: Все працює чудово!" + Style.RESET_ALL)

```

4. Запусти і перевір, чи текст кольоровий.

**Завдання 3.2: Заморозка залежностей (Freeze)**
Уяви, що тобі треба передати цей код другу. Йому треба знати, які бібліотеки ставити.

1. Виконай команду: `pip freeze > requirements.txt`.
2. Відкрий створений файл `requirements.txt`. Ти побачиш там і `art`, і `colorama` з версіями.

**Завдання 3.3: Симуляція "Нового Комп'ютера"**
Це найважливіший тест.

1. Видали папку `.venv` повністю (Shift+Delete).
2. Спробуй запустити код — він впаде (це добре).
3. **Завдання:** Відновити робоче середовище однією командою.

- Створи нове venv.
- Активуй його.
- Встанови все зі списку: `pip install -r requirements.txt`.

4. Запусти `warning_system.py`. Якщо текст знову червоний/зелений — ти вмієш деплоїти Python-проєкти!

---

На Windows, якщо ти намагаєшся запустити активацію venv і бачиш помилку про "виконання сценаріїв заборонено" (execution policies), введи в терміналі PowerShell команду:
`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process`
І спробуй активувати знову.
