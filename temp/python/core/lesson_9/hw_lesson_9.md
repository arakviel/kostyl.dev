### Рівень 1: "Імпортер-початківець"

_Ціль: Навчитися створювати свої модулі, імпортувати з них функції та змінні різними способами._

**Завдання 1.1: Сховище констант**

- **Дано:** Два файли: `config.py` та `main.py`.
- **Завдання:**

1. У файл `config.py` запиши змінні: `SITE_NAME = "Super Shop"`, `VERSION = 1.0`, `ADMIN_EMAIL = "admin@test.com"`.
2. У `main.py` імпортуй **весь модуль** (`import config`).
3. Виведи на екран рядок: "Welcome to [SITE_NAME], version [VERSION]".

- **Що тренуємо:** Створення модуля, доступ до змінних через крапку (`module.variable`).

**Завдання 1.2: Точковий імпорт (From ... Import)**

- **Дано:** Файл `geometry.py` з функціями `calculate_area(r)` та `calculate_perimeter(r)` для кола.
- **Завдання:**

1. У `main.py` нам потрібна **лише** площа.
2. Імпортуй конкретну функцію: `from geometry import calculate_area`.
3. Спробуй викликати `calculate_area(5)`.
4. Спробуй викликати `calculate_perimeter(5)` і поясни, чому виникла помилка.

- **Що тренуємо:** Імпорт конкретних об'єктів, економія пам'яті, простір імен.

**Завдання 1.3: Майстер псевдонімів (Aliasing)**

- **Дано:** Файл з дуже довгою назвою `very_complex_mathematical_operations.py`, в якому є функція `add(a, b)`.
- **Завдання:**

1. У `main.py` імпортуй цей модуль, але дай йому коротке ім'я `math_ops` (використовуючи `as`).
2. Виклич функцію додавання через скорочене ім'я.

- **Що тренуємо:** Конструкція `import ... as ...`, покращення читабельності коду.

### Рівень 2: "Інженер Логіки"

_Ціль: Розділення логіки, стандартні бібліотеки та запобігання побічним ефектам._

**Завдання 2.1: Стандартний арсенал (`math`, `random`)**

- **Дано:** Файл `casino.py`.
- **Завдання:**

1. Імпортувати вбудований модуль `random`.
2. Написати функцію `roll_dice()`, яка повертає випадкове число від 1 до 6.
3. Імпортувати модуль `math`.
4. Написати функцію `get_circle_area(radius)`, яка використовує точне значення `math.pi`.

- **Що тренуємо:** Робота з модулями стандартної бібліотеки Python (built-in modules).

**Завдання 2.2: Проблема "балакучого" модуля (`if __name__ == "__main__`)**

- **Дано:** Файл `greeter.py`. В ньому є функція `hello()` і одразу під нею (без відступів) виклик `print("Я завантажився!")`.
- **Завдання:**

1. Створи `main.py` і зроби `import greeter`. Запусти `main.py`. Ти побачиш напис "Я завантажився!", хоча ти цього не просив.
2. Виправи `greeter.py`: сховай `print` у блок `if __name__ == "__main__":`.
3. Тепер при запуску `greeter.py` напряму напис має бути, а при імпорті в `main.py` — ні.

- **Що тренуємо:** Головна конструкція модульного Python, різниця між скриптом і модулем.

**Завдання 2.3: Конфлікт імен**

- **Дано:**
- Файл `my_math.py` з функцією `sqrt()`, яка просто пише "Це моя функція!".
- Стандартний модуль `math` (у ньому теж є `sqrt`).

- **Завдання:**

1. У `main.py` спробуй імпортувати `sqrt` з обох модулів одночасно конструкцією `from ... import sqrt`.
2. Виклич `sqrt()`. Яка версія спрацює? (Та, що імпортована останньою).
3. Виправи код так, щоб можна було використовувати обидві функції в одному файлі (використовуй `import module` або `as`).

- **Що тренуємо:** Розуміння Namespace (простору імен), вирішення конфліктів.

### Рівень 3: "Архітектор"

_Ціль: Глибше розуміння роботи імпортів, `dir()` та `sys.path`._

**Завдання 3.1: Інспектор модулів (`dir()`)**

- **Дано:** Імпортувати модуль `string` (стандартний).
- **Завдання:**

1. Написати скрипт, який виводить список **всіх** імен (функцій, змінних), доступних у модулі `string`. Використовуй вбудовану функцію `dir(string)`.
2. Знайди у виводі список усіх великих літер ASCII (це константа `ascii_uppercase`) і виведи її значення.

- **Що тренуємо:** Дослідження чужих модулів без документації, функція `dir()`.

**Завдання 3.2: Небезпечна зірочка (`import *`)**

- **Дано:** Модуль `bad_style.py` зі змінними `x = 10`, `y = 20` та функцією `test()`.
- **Завдання:**

1. У `main.py` створити свою змінну `x = 100`.
2. Написати `from bad_style import *`.
3. Вивести `x`. Що сталося? (Змінна модуля переписала твою).
4. Переписати код на безпечний імпорт.

- **Що тренуємо:** Чому `from module import *` (Wildcard import) — це зло і порушення PEP8.

**Завдання 3.3: Пошук шляхів (`sys.path`)**

- **Дано:** Python шукає модулі в певних місцях.
- **Завдання:**

1. Імпортувати модуль `sys`.
2. Вивести на екран список `sys.path`.
3. Проаналізувати вивід: першим елементом буде шлях до твоєї поточної папки. Саме тому Python бачить твої файли поруч.

- **Що тренуємо:** Розуміння того, як Python знаходить файли на диску.
