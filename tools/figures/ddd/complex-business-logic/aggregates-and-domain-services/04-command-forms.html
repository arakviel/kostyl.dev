Два способи виразити команду
public void AddMessage( UserId from, string body) { var message = new Message(from, body); _messages.Append(message); }
public void Execute(AddMessage cmd) { var message = new Message( cmd.from, cmd.body); _messages.Append(message); }

Метод агрегата або команда як об'єкт-параметр. Автор віддає перевагу явним структурам команд.
