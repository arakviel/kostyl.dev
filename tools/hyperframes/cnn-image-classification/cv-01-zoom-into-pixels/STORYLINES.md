# STORYLINES — cv-01-zoom-into-pixels

**A (обрано) — «Нескінченний зум».** Один безперервний кадр: цифра «7» → піксельні квадрати → числа 0…255 → рядок 254…255 → відліт і розгортання 784 чисел у смугу.
**B — «Результат спочатку».** Стіна чисел, камера відлітає, і з потоку складається «7». Світла «паперова» частина в кінці.
**C — «Погляд програми».** Split screen: зліва людина бачить «7», справа програма читає числа рядок за рядком; права панель займає весь екран.
