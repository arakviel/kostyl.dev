# STORYLINES — cv-02-rgb-channels

**A (обрано) — «Стопка прозорок».** Занурення в справжні пікселі жоржини → ділянка 4×4 → розшарування на три листи R, G, B → піксель (0,0) = [229, 188, 132] → листи складаються адитивно й повертають колір.
**B — «Змішувач».** Починається з одного квадрата кольору, що розпадається на три стовпчики 229/188/132; 1 піксель → 16 → три матриці.
**C — «Три чорно-білі».** Ділянка розпадається на три чорно-білі картинки (R світла, G середня, B темна), кожна з таблицею чисел; сходяться в колір.
