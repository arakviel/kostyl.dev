# STORYLINES — cv-04-shift-changes-vector

**A (обрано) — «Два штрихкоди».** Цифра «3» зсувається вправо на 0…5 пікселів (np.roll по осі 1); 784 числа вектора як штрихкод. Amber — яскравий піксель на тому самому місці, cyan — на новому, сірий — місце звільнилось. Лічильник 144 → 121 → 100 → 79 → 60 → 47 (33%), змінено 300 із 784.
**B — «Нитки».** Два вектори один під одним і 144 нитки між тими самими позиціями; нитки рвуться при зсуві.
**C — «Трафарет».** Оригінальна «3» як трафарет з 144 отворів; світло проходить крізь отвори лише там, де потрапив зсунутий піксель.
