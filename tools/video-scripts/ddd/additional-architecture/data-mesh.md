# Відео: Data mesh та DDD

## Вступ для режисера

- **Головна думка.** Data mesh застосовує ідеї DDD до аналітичних даних: кожен контекст володіє своєю аналітичною моделлю й обслуговує її як продукт.
- **Центральна діаграма.** Центральна діаграма — карта обмежених контекстів, кожен із двома шарами OLTP й OLAP та вихідними портами до спільної екосистеми.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** Факти й виміри, схеми зірка й сніжинка, сховище, озеро, чотири принципи data mesh і зв'язок із DDD зі статті за розділом 16 книги Khononov.
- **Ілюстративне.** Анімація потоків даних умовна.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
