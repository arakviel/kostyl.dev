# Відео: Архітектурні патерни: шари, порти й адаптери, CQRS

## Вступ для режисера

- **Головна думка.** Архітектурний патерн має відповідати патерну бізнес-логіки: шари для простої, порти й адаптери для доменної моделі, CQRS для кількох моделей даних.
- **Центральна діаграма.** Центральна діаграма — бізнес-логіка та її оточення: шари зверху вниз перетворюються на логіку в центрі з адаптерами навколо.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** Шари PL/BLL/DAL, сервісний рівень, порт IMessaging і адаптер SQSBus, синхронні та асинхронні проєкції, межі застосування зі статті за розділом 8 книги Khononov.
- **Ілюстративне.** Анімація потоку команд і запитів умовна.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
