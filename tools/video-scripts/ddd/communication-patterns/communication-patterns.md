# Відео: Комунікаційні патерни: переклад, Outbox, Saga, Process Manager

## Вступ для режисера

- **Головна думка.** Надійна комунікація будується на перекладі моделей, outbox для публікації подій, сагах для простих і менеджерах процесу для складних бізнес-процесів.
- **Центральна діаграма.** Центральна діаграма — потік події від агрегата через outbox і ретранслятор до сагових і процесних компонентів.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** Приклади Campaign, CampaignPublishingSaga, BookingProcessManager, таблиця outbox і правила вибору патерна зі статті за розділом 9 книги Khononov.
- **Ілюстративне.** Анімація пересування подій і збоїв умовна.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
