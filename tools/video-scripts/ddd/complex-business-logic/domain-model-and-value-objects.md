# Відео: Доменна модель, об'єкти-значення та сутності

## Вступ для режисера

- **Головна думка.** Для складної бізнес-логіки код має повторювати мову домену: об'єкти-значення описують поняття без ідентичності, сутності мають ідентичність і життєвий цикл.
- **Центральна діаграма.** Центральна діаграма — заявка служби підтримки (help desk), яку крок за кроком розбирають на об'єкти-значення й сутності.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** Вимоги help desk, приклади Ticket, Email, Color, Money, Person, правила рівності та ідентичності взято зі статті за розділом 6 книги Khononov.
- **Ілюстративне.** Анімації переходів станів заявки й порівняння типів умовні.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
