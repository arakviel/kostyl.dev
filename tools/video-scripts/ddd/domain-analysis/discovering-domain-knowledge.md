# Відео: Знання предметної області та єдина мова

## Вступ для режисера

- **Головна думка.** Щоб побудувати правильну систему, інженери й експерти мають говорити однією мовою бізнесу; ця мова точна, без синонімів, і розвивається разом із проєктом.
- **Центральна діаграма.** Крок 2 будує ланцюжок «знання → переклади → код». Крок 3 замінює його кільцем єдиної мови навколо всіх ролей. Кроки 4–5 показують терміни й карти-моделі. Крок 6 завершується кільцем розвитку мови.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** FedEx, WolfDesk, приклади з рекламною кампанією (policy, visitor, account), цитати Брандоліні, Вірфс-Брок, Бокса, Дейкстри та Gherkin-сценарій взяті зі статті, що адаптує розділ 2 книги Khononov.
- **Ілюстративне.** Приклад «зіпсованого телефону» зі знижкою, форми глосарію та вміст карт умовні; решта в статті.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
