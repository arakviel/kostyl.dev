# Відео: EventStorming: воркшоп для моделювання бізнес-процесів

## Вступ для режисера

- **Головна думка.** EventStorming за кілька годин перетворює розрізнені знання учасників на єдину модель процесу, а головний результат — спільна мова.
- **Центральна діаграма.** Центральна діаграма — стіна зі стікерами: оранжеві події, що поступово обростають командами, політиками, агрегатами й межами контекстів.
- **Нові компоненти.** Немає: всі сцени збираються з компонентів скіла.
- **Реальне / зі статті.** Десять кроків, кольори стікерів, приклад із замовленням, поради ведучому й віддалений формат зі статті за розділом 12 книги Khononov.
- **Ілюстративне.** Анімація наклеювання стікерів умовна.
- **Стиль.** Темний фон `#090909`, рукописний `Caveat` 700 для заголовків, бірюзові технічні піктограми, рожеві люди, золоті виділення. Логотип kostyl.dev у правому верхньому куті.
